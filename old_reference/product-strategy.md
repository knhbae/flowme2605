# Product Strategy Reference

## 한 줄 정의

Flow는 컨텐츠 플랫폼과 사용자 툴 사이에서, 실제 경험자의 체크리스트를 사용자가 바로 실행 가능한 형태로 복사/내보내는 플랫폼이다.

원문 핵심 카피:

- 내부 비전: "인간의 모든 경험을 실행 가능한 형태로 기록한다"
- 제작자 카피: "당신의 경험, 누구나 실행할 수 있게"
- 사용자 카피: "해본 사람 경험, 복붙해서 바로 시작"

## 해결하려는 문제

유튜브, 블로그, 커뮤니티에는 경험 컨텐츠가 많지만 사용자는 결국 직접 체크리스트, 캘린더, 엑셀을 다시 만들어야 한다. Flow는 그 중간 과정을 줄이고, 경험 컨텐츠를 실행 가능한 체크리스트/일정으로 바꾼다.

대표 사례:

- 여행 영상 → 직접 일정표 작성
- 결혼 준비 후기 → 직접 체크리스트 작성
- 이유식/육아 글 → 직접 엑셀 정리
- 이사 가이드 → 직접 할 일 목록 작성

## 핵심 플레이어

- 제작자: 자기 경험/노하우를 체크리스트로 구조화한다.
- AI: 글, 영상, URL을 구조화된 플랜 초안으로 바꾼다.
- 사용자: 플랜을 가져와 일정 기준을 입력하고 실행한다.
- 비즈니스: 실행 타이밍에 맞춰 광고/쿠폰/매칭으로 연결된다.

## 최신 MVP 방향

최신 `claude_ver` 기준 현재 MVP는 큰 플랫폼 비전보다 검증 가능한 "복붙 실행"에 집중한다.

- 첫 카테고리: 육아, 우선 후보는 백신 접종 체크리스트.
- 검증 가설: 육아 경험자의 체크리스트를 받았을 때 부모들이 실제로 사용하는가.
- Phase 0: 개발 없이 구글 시트/수동 제작으로 검증.
- Phase 1: 제작자용 체크리스트 에디터, 공개 플랜 페이지, 사용자 날짜 입력, 클립보드/CSV 내보내기.

## Phase별 범위

### Phase 0: Concierge MVP

- 기간: 1~2주.
- 코드 없이 육아 블로거/유튜버 1~2명의 글을 체크리스트화한다.
- 지인 부모 10명에게 시트 링크를 보낸다.
- Gate: 10명 중 5명이 실제로 사용하면 개발 진행.

### Phase 1: Web MVP

- 기간: 4주.
- 제작자 툴: 체크리스트 에디터, 월령/단계 태그, 공개 플랜 페이지와 공유 링크.
- 사용자 툴: 아기 생일/시작일 입력, 자동 일정 계산, 클립보드 복사, CSV 다운로드, 가능하면 텍스트 기반 `.ics`.
- Gate: 링크 클릭 대비 내보내기 전환율 30% 이상.

### Phase 2: 외부 연동

- Google OAuth, Calendar/Sheets API.
- AI 초안 생성: Jina Reader로 본문 추출 후 Claude API로 구조화.
- Supabase Auth 로그인.
- 사용자 진행률 트래커와 제작자 통계.
- Gate: 100명 사용자, 캘린더 연동 10% 이상, 평균 완료율 40% 이상.

### Phase 3: 수익화/생태계

- 실행 타이밍 기반 광고 세그먼트.
- 쿠폰/이벤트 노출.
- 제작자 포인트/정산.
- 브랜드 파트너십 대시보드.

## Phase 1에서 만들지 말 것

- 모바일 앱.
- AI 자동 구조화.
- 회원가입 필수화.
- 커뮤니티.
- Notion 연동.
- Google Calendar API 직접 연동.
- 토큰/코인.

## 레거시 기획에서 보존할 개념

`old/FlowMe260316`은 더 앱다운 실행 관리 플랫폼을 상정했다. 이 안의 일부 개념은 Phase 1을 넘어갈 때 가치가 있다.

- 공개 상세 페이지가 사실상 랜딩 페이지다.
- 로그인 후 홈은 "오늘 할 수 있는 것" 중심이어야 한다.
- Flow 실행 중 하나를 미루면 의존 항목이 자동 조정되는 UX는 장기 차별점이다.
- EventLog는 나중에 행동 그래프와 제작자 인사이트의 원천이 된다.
- 통계/리뷰가 없을 때는 허위 숫자를 표시하지 않고 섹션을 숨기거나 정성 표현만 쓴다.
