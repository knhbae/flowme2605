# 최신 10개 사용자 피드백 원문 — sealed informed input

> 원문 보존 규칙: 아래 fenced block은 맞춤법, 띄어쓰기, 대소문자, 번호 및 표현을 수정하지 않는다. 해석과 구조화는 [04-feedback-root-question-map-ko.md](./04-feedback-root-question-map-ko.md)에서 별도로 수행한다.

```text
[**사용자 피드백**]
1. F-05: 내 flow 어디선가 에서 가져가야지. (내보내기를 말이지)
2. 전체: 도움말같은 성격은 모두 물음표를 누르면 팝업 뜨게하자. 너무 지저분함. 주의사항도 느낌표를 누르면 팝업이 뜨게하자.
3. 내 flow 탭 자체가 어떻게 구성되어야하는 전체적인 재 고민이 필요한 것 같음. 다른 앱 study 필요. 정보의 흐름 같은 것도 고민해서 뭐가 앞에 나오고 뭐가 뒤로 가고 그런거 고민 필요.
4. Item 상세,메모, 완료
   - 실행할 일 바탕 색상의 통일감 필요(다른 영역과.. 말이지). 얘만 파란색 바탕임. 이상함
   - "실행할 일" 이것도 삭제해도 되지 않겠니?
   - "할일 수정"은 "수정"으로
5. Flow Map 잔여 구조 --> 3칸 요약하는 거 삭제해도 되지 않아? 꼭 필요해? 그럼 물음표를 누르면 뜨게 하면되지 않아?
6. flow 찾기 -> "시작일" 설정하는 부분에서 시작일 설정했는데 왜 또 바로 아래 시작일 선택한게 표시될까? 필요 없지 않음?
7. flow 찾기 탭에서 플로우 상세보기 하면 매번 "... 시작" 버튼이 다르니까 이상
   - 왜 flow 미리보기가 한 종류씩만 나옴? 여러 종류가 나올 수 있도록 수정 부탁, 여기에서 캘린더/메모/체크리스트/투두/시트 가능하면 다 나와야지.
   - 하단엔 "편집"/"완료" 버튼만 있음되지 않겠음?
   - 완료 후에는 내 flow 탭으로 이동하고 원하면 캘린더/메모 ... / 보내기를 할 수 있는 버튼이 크게 하단에 있고(그 옆에 수정 버튼 있음 되겠음), 그거 누루면 팝업 떠서 내 플로우 찾기에서와 같은 UI로 여러 포멧 미리보기 가능하고..
8. 내 flow 탭 -> flow 관리 -> 편집 -> 하단에 편집 가능한 페이지가 나옴
   - 이 UI와 flow 찾기의 편집 UI가 동일해야함.
   - 그리고 하단으로 나오니까 헷갈림 팝업이든 다른 화면이든 해야함.
   - 근데 아까 단에 편집/완료 버튼 있으면 중복인가? 만들면서 판단해보셈
9. 그냥 flow 찾기 -> 더보기 에선 수정 UI 없고 5개 format 미리보기만 있으면 되지 않나. 하단에 편집 / 완료 버튼 있는 거에서 편집 누르면 수정할 수 있는 UI뜨면 되는거 아님?
10. flow라는 단어가 이해가 가겠나? 싶은 의구심이 들긴함.. ㅎㅎ;;
```

이 원문은 내부 owner 진술이다. 실제 관찰 사용자 세션을 뜻하지 않으며 관찰 사용자 수는 `0명`이다.
