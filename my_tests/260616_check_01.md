1. 이사 D-30 준비 Flow
- flow 컨텐츠/ux, ui 기본적으로 깔끔하고 좋음
- "이사 방식"을 ui따로 빼서 선택할 필요가 있을까?

2. 중고차 방문 당일 체크 Flow
- 원 컨텐츠는 좋은 것 같음. flow 컨텐츠도 하나하나는 좋은 것 같긴함.
- "매물 URL 또는 이름"을 ui따로 빼서 선택할 필요가 있을까?
- "볼 순서" 쪽 ui가 좀 꼬인듯?
- 체크리스트가 "볼 순서"마다 3개씩 억지로 붙여서 ux가 이상해짐. 이 부분 좀 고민해보면 좋겠음.
- 이런 건 방문일 등록해놓으면, 그 안에 item 하나에 체크리스트가 쭉 있으면 될 것 같음.
- 할튼 좀 ux가 이상함.

3. 초등 입학 준비 D-30 Flow
- "학교 안내문 URL 또는 파일명" ui따로 빼서 선택할 필요가 있을까?
- flow 컨텐츠/ux, ui 기본적으로 깔끔하고 좋음
- 근데, 이것도 체크리스트를 3개씩 만드는 로직때문에 좀 꼬인 것 같긴함.

4. 영유아 검진

- 여길 보면, 진짜 지금 만든 flow 컨텐츠가 어울리지 않는다는 것을 알 수 있음.
