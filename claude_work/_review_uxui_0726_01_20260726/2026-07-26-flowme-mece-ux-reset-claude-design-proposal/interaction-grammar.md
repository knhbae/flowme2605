# Interaction grammar — 공통 명령 문법

한 동작은 어디에서 보이든 **같은 말 · 같은 자리 · 같은 피드백 · 같은 되돌리기**를 갖는다.
완료 / 제외 / 삭제 / 보관은 서로 다른 뜻이며, 같은 색·같은 아이콘·같은 위치를 쓰지 않는다.

## 0. 소유 규칙 두 줄

1. **편집은 소유 surface가 하나다.** 제목·날짜·메모·순서·포함 여부·series 정의는 개인 Flow(또는 그 Item detail)만 바꾼다.
2. **완료는 소유 기능이 아니라 row primitive다.** 실행 row가 렌더되는 곳(개인 Flow, Item detail, Calendar agenda)이면 어디서든 같은 컨트롤로 토글할 수 있고, 라벨·아이콘·피드백·되돌리기가 완전히 동일해야 한다. 이 조항을 지키지 못하면 Calendar의 완료 토글을 제거하고 순수 lens로 되돌린다.

## 2. 파괴성 계층

| 계층 | 동작 | 시각 처리 | 확인 |
| --- | --- | --- | --- |
| 0 상태 | 완료 · 다시 열기 | 초록 채움 / 중립 | 없음 (토스트 되돌리기) |
| 1 범위 | 제외 · 다시 포함 · 날짜 제거 | 중립 outline, 취소선 | 없음 (토스트 되돌리기) |
| 2 보관 | 보관 · 복구 | 중립 outline | 없음 (토스트 + 필터 복구) |
| 3 개인 데이터 삭제 | 개인 Item 삭제 | 텍스트 danger | 없음 (복구 목록 유지) |
| 4 되돌릴 수 없음 | 이 기기에서 영구 삭제 | filled danger, 보관 상태에서만 | dialog + 백업 안내 |

같은 화면에 계층 3·4를 계층 0·1과 나란히 놓지 않는다.

## 3. 금지

- 완료 체크박스와 제외 토글을 같은 모양으로 만들지 않는다(완료=채워지는 사각 토글, 제외=텍스트 버튼).
- `삭제`라는 말을 보관에 쓰지 않는다.
- 같은 동작에 화면마다 다른 라벨(`시작` / `저장` / `내 Flow에 담기`)을 쓰지 않는다. 저장 동사는 `N개 …으로 시작` 하나다.
- 되돌릴 수 있는 동작에 확인 dialog를 쓰지 않는다(토스트 되돌리기로 충분).
- internal taxonomy(projection, overlay, run identity, RRULE, readiness, source-backed)를 라벨에 쓰지 않는다.
