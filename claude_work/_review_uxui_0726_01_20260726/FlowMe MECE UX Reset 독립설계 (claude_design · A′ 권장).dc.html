Codex의 소유권 방향(찾기 → 공개 Flow → 저장 결과 → 개인 Flow, My Flow는 목록, Calendar는 날짜 렌즈)은 유지한다. production을 직접 확인한 결과 실제 결함은 “탭이 4개”가 아니라 한 화면이 여러 질문에 동시에 답하는 composition이었고, 그 문제는 Codex 안으로 대부분 닫힌다. 다만 두 곳에서 Codex 안은 덜어내는 방향을 사용자 비용으로 지불한다 — 재방문 첫 화면(결정 1)과 가장 잦은 단일 동작인 완료(결정 3). 그래서 최종 권장은 A′ = A(subtractive) 기반 + 두 surface에만 C 수정이다.

아래 wireflow는 실제 콘텐츠 5종(이사 24개 · 자동차검사 10개 · 아침 5분 홈트 반복 · 중1 수학 8단원 · 개인 메모 5개)으로 동작한다. 회색 배경은 review chrome이고, 흰 화면 안쪽만 제품 surface다. current/proposed 설명은 제품 화면 안에 넣지 않았다.
