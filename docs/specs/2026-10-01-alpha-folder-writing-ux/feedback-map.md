# 피드백1~21 처리 범위

2026-10-01 조사 시점의 대조다. 원문 정본의 위치·읽기 SHA·세션은 [spec](spec.md#현재-기준과-출처)에 있다. 이 파일은 원장을 복제하지 않고 실행 범위만 연결한다. ‘기존 보완’은 아래 과거 근거가 있다는 뜻이며 이번 재검사나 원래 사용 환경의 문제 종료가 아니다.

근거: [9/30 요구 U01~U14](../2026-09-30-alpha-core-workspace-ux/requirements.md), [현재 후보 J01~J14](../2026-10-01-alpha-ux-journey/requirements.md), [현재 후보 QA](../2026-10-01-alpha-ux-journey/qa.md), [같은 요청 ACK 후속](../2026-09-30-alpha-private-save-ack/spec.md), [개발계 반영 기록](../2026-10-01-alpha-cloudflare-core-ux/qa.md).

| 피드백 | 현재 상태와 근거 | 이번 목표의 처리 |
| --- | --- | --- |
| 1 서버 업데이트 빈도 | 요청 빈도/전송량 미측정. U14·ACK는 저장 복구 근거이며 비용/빈도 최적화 증거가 아님 | 조회/제안/취소의0쓰기와 시험 동작별 요청 수 확인. 성능·debounce 전면 개선은 별도 |
| 2 할 일 누락 | 사용자가 폴더 필터로 설명하고 오류 종료. U08 | 결함으로 재등록하지 않음. 현재 범위/전체 복귀의 회귀 사례 |
| 3 문서 작업 공간 완성도 | 광범위한 사용자 인상. A안 세로 본문 약81px 증가, 낮은 가로는0 | 낮은 화면 본문·정보 계층 개선. 이것만으로 전체 완성도 피드백 종료 금지 |
| 4 폴더 표현 | U04 보관 위치·Item 소속 구분 보완 | 폴더 경로/선택 범위의 구별과 탐색 표현을 이번 UX 비교에 포함 |
| 5 문서·폴더 관계 | U04에 독립 관계 근거 | 보관 위치/문서 내 연결 영역/전체 폴더 할 일의 구분을 핵심 비교 |
| 6 Shift+Tab | U03 구조 재분류·반대 키 기대 미결 | 기존 편집 보호 회귀만. 들여쓰기 정책 해결은 별도 목표 |
| 7 둘러보기 기존 Flow 없음 | 기대 콘텐츠·실제 URL·필터/공개 상태 미확인, J12 기존 경로 있음 | 현재 합성 진입/조회 범위와 후보 기능 보존 확인. 실자료 반입/공개 탐색 전체 개선 별도 |
| 8 drag 이동 | 입력 장치·대상/목적지 미확인, U11 부분 근거 | 새 범위에서 메뉴/키보드 대안·경계 보호 검사. 전체 drag 보완으로 확대하지 않음 |
| 9 +/추가/더보기 예측 | U06 대상/변환 설명과 A안 보조 도구 정리 근거 | 연결 제안의 대상/결과와 새 범위 행동 확인. 불필요한 상시 설명은 감산 |
| 10 폴더 변환 중복 | U05 같은 줄/lineId 변환 보완 | 기존 helper 재사용·회귀. 구형 v11 중복을 현재 미수정 결함으로 쓰지 않음 |
| 11 시간 입력 발견 | U07 기존 HH:MM 연결/삭제·Undo 보완 | 폴더 영역/기간/원문 왕복에서 시간 접근·보존 회귀 |
| 12 캘린더 UI | 원래 사용 URL/진입점 미확인. 문서 시안과 제품의 별도 route 구분 필요 | 현재 기간 보기와 별도 캘린더를 혼동하지 않음. 새 달력 UI는 제외 |
| 13 전체 줄 형식 반복 | U02 합성 조합 이벤트 주변 줄 유지 보완 | 신규 제안/범위 전환이 같은 보호를 깨지 않는지 합성 회귀. 실제 IME 성공 주장 금지 |
| 14 날짜 변경 | U07/U10 부분 근거 | 같은 Item의 날짜/시간·원문·기간·reload 보존 회귀. 전 조합 완료로 확대하지 않음 |
| 15 Enter 다음 할 일 | U03 기존 연속 작성/빈 줄 탈출, 기본 정책 질문 | 기존 입력 유지. 매 Enter 선택창/새 영구 정책은 별도 비교 |
| 16 메모 줄바꿈 | 문법/종료/호환 정책 미결 | 기존 메모 숨김·부분 편집 손실 방지 회귀. 새 메모 문법은 제외 |
| 17 폴더 직접 입력 문법 | U05 일반 이름 줄 명시 변환 있음. 새 @·이름 정책 미확정 | #20과 함께 기존 이름 검색/명시 연결 비교. @/#·중복/정규화 정책 확정 금지 |
| 18 Flow 제작 발견 | J13 기존 제작/인계 경로 있음. 원래 환경 동작 미확인 | 후보의 기존 진입/인계 기능 보존 확인. 제작/공개 전체 UX 개편 별도 |
| 19 기간의 폴더 맥락 | U04/U08/U09 실제 경로·원문/범위 표시 보완 | 동명 중첩·여러 문서·새 문서 영역 왕복 회귀. 통째 신규 구현 아님 |
| 20 이름 입력 뒤 기존 폴더 제안 | 신규. v11 확인만 있으며 Alpha 자동 제안 미확인 | 이번 핵심: 실제 코드 기준선→명시/비강제 제안 비교→안전 계약→최소 구현 |
| 21 폴더 선택의 문서 영역 보기 | 신규. Alpha 현재는 보관 위치로 문서 목록 필터, 열린 본문은 전체 | 이번 핵심:6가지 보기 사례·부분 편집/원문 보호 계약→최소 구현 |

전체21개는 범위 분류한 수이며 ‘21개 전부 해결’ 또는 v4.1·개발1·개발2 전체 요구 커버리지로 사용하지 않는다. 실제 사용 환경이 특정되지 않은 항목은 미확인으로 유지하며 사용자에게 전수 검사를 요구하지 않는다. 추가 원장 변경은 다음 단계에서 delta로 대조한다.
