# Note A cumulative writing/today integration

Status: local candidate; publication and Alpha status are recorded separately in the private release ledger.

## Accepted scope

Integrate the frozen writing/execution hierarchy and Note A interface into a separate clean candidate based on d89a1428. Preserve the donor worktree and the currently served baseline. The cumulative product delta is seven runtime files and eight direct tests, not only the final four-runtime visual adjustment.

Writing retains one input owner, original text and Item identities, explicit raw mode, native Undo, selection and composition protection. Reading uses a consistent check gutter and hierarchy. The current title, warning, add action, storage status and tools share the Note layout. Today retains date controls and makes the existing list appear earlier. A partial progress click opens the existing detail rather than silently completing the item.

The selected-item return uses the same source offset with a top inset; ordinary return and ProgramApp checkpoint ownership remain unchanged. View-change notices may clear only when the same input owner is actually clean and no pending composition or save remains. A refused navigation does not automatically resume.

Normal scoped publication, new exact-HEAD CI and necessary Alpha application follow the existing approval and unchanged recovery guards. No merge, force push, skipped checks, increased permit TTL or reused old permits. The prior r2/r8 release is a baseline, not a new test result.
