## Component inventory

- fixed compact header
- route switcher: four plain buttons, one selection
- case list: eight examples with one-line outcome
- source input composer with detected input kind
- source scope confirmation row
- creator/user stage switch
- progressive details disclosure
- five artifact tabs
- Calendar list, Checklist/Todo rows, Sheet table, Memo decision card
- boundary card for safety hold or source import
- input/source count footer

## Hierarchy

1. One primary input/action.
2. Source-confirmed scope and missing rows.
3. Actual artifact preview.
4. User-only values after the structure is visible.
5. Evidence/QA below the product surface.

The UI intentionally avoids a marketing hero, decorative charts, excessive pills, gradients, glass effects, and raw taxonomy/schema labels.
