# Plan

1. 기준 자료, worktree, corpus 수치와 canonical/runtime drift를 동결한다.
2. 세 아키텍처, 네 Map type, attribution, loss와 점수 계약을 작성한다.
3. 9개 representative bundle과 expansion/boundary/regression corpus를 분리한다.
4. 동일 gold semantic contract에서 세 구조를 생성한다.
5. Calendar compact/granular, Checklist, Todo, Sheet, Memo와 ICS fixture를 생성한다.
6. semantic/ICS round-trip, provenance, reference integrity와 forbidden behavior를 검증한다.
7. 카테고리·Map별 fit, 사용자 입력, migration 영향을 점수화한다.
8. hard gate와 adoption rule로 최종 구조를 판정한다.
9. HTML 기준 보고서와 PPT 요약을 만들고 데스크톱/모바일/slide overflow를 검사한다.
10. 요구사항별 완료 증거를 감사하고 사용자 검토 대기로 인계한다.

## Independence

- corpus/gold 작성자는 architecture 점수를 보고 source rows를 바꾸지 않는다.
- architecture 변환은 같은 gold contract를 사용한다.
- 최종 score는 사전에 동결한 기준을 사용한다.
- 기존 creator verdict와 value-qualified 결과를 재계산하지 않는다.

## Iteration Limit

Validator나 투영의 공통 오류는 최대 2회 수정한다. 특정 사례만 통과시키는 예외는 추가하지 않는다.
