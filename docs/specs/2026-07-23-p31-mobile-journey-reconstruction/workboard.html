판정

Architecture: bounded revision

4탭, public shell, source/personal/run/occurrence/export identity는 유지합니다.

Interaction: coordinated simplification required

Home/Find, save-before, My Flow, Calendar를 각각 따로 다듬지 않고 공통 질문·동사·detail layer로 정리합니다.

권장 모바일 여정

HOME

카탈로그가 아니라 이어서 하기와 실제 사용 예시

처음에는 source에서 결과로 이어지는 예시, 재방문에는 오늘·최근 Flow·날짜 없는 일을 보여 줍니다.

FIND

검색과 발견 전담

source 링크, 한 줄 결과, 실제 범위, 대표 Item 1~2개, 더보기만 남깁니다.

SAVE-BEFORE

결과 → 필요한 값 → 미리보기 → 저장

결혼과 운동도 같은 뼈대를 쓰되 primary artifact와 필요한 입력은 콘텐츠에 맞춰 바뀝니다.

MY FLOW

목록과 실행 workspace 분리

Flow를 목록 안에서 길게 펼치지 않고 dedicated workspace로 열어 한 Flow에 집중합니다.

CALENDAR

Item detail은 sheet

month/agenda 맥락을 유지한 채 bottom sheet로 실행·일정·메모를 다룹니다.

LIFECYCLE

보관·복구·영구 삭제 분리

모바일/와이드 같은 경로, 보관 row 직접 복구, 보관된 Flow danger zone에서만 영구 삭제를 제공합니다.
