# FLOW 사용자용 콘텐츠 검토본 v2 · 품질 기록

## 결과

네 콘텐츠 모두 원문 링크가 제목 가까이에 보이고, 원문에서 확인하지 못한 수치·시간·자격은 생성하지 않았습니다. 사용자 콘텐츠와 검토 의견 데이터는 `contentBundles`와 `reviewRecords`로 분리했습니다.

| 콘텐츠 | 자연스러운 결과 | 자체 품질 평균 | 핵심 경계 |
| --- | --- | ---: | --- |
| 평일 저녁 5일 식단 | 시작일 기반 5개 캘린더 일정 + 재료·조리 메모 | 4.2/5 | 현재 가격·건강 효과·빠진 재료 수량을 보장하지 않음 |
| 국가근로장학금 2차 신청 | 공식 기한 ICS + 조건부 할 일 TXT | 4.8/5 | 대학별 운영·선발·개인 자격을 대신 판정하지 않음 |
| 부산 2박 3일 코스 | 시작일 기반 3개 종일 일정 | 4.4/5 | 원문에 없는 시간·교통·운영정보를 넣지 않음 |
| KOCW 데이터 분석 | FLOW가 고른 시작용 10행 CSV | 4.2/5 | 공식 핵심 10강이나 전체 87행으로 오인하지 않게 표시 |

평가 차원은 사용자 필요 적합성, 실행 명료성, 원문 충실도, 도구 이동성, 출처 안전성입니다. 숫자는 내부 검토용이며 관찰 사용자 검증을 의미하지 않습니다.

## 감산한 UI

- 원문 링크를 숨기던 접힌 영역을 없애고 제목 바로 위에 노출했습니다.
- 탭, 내부 QA 지표, 자리표시 문구, 같은 원문 링크의 반복을 제거했습니다.
- 장학금 체크리스트 상세는 왼쪽 본문에 한 번만 두고 도구 미리보기에는 제목만 남겼습니다.
- KOCW 10개 행의 이중 반복을 없애고 도구 미리보기는 3개 행과 전체 행 수만 보여줍니다.
- 모바일에서는 다운로드 가능한 도구 결과를 상세 목록보다 먼저 두고, 식단 미리보기는 첫 3개와 남은 개수만 보여줍니다.
- 검토자 메모는 점선 영역과 별도 데이터 구조로 분리해 실제 서비스 콘텐츠로 오인하지 않게 했습니다.

## 검증 범위

- 브라우저 콘솔 오류 0건
- 1440×900, 390×844에서 가로 넘침 0px
- ICS 3종의 이벤트 수 5/2/3, UTF-8 물리 행 최대 74바이트, CRLF 확인
- 장학금 ICS의 신청 시작·마감 시각과 대학별 운영·선발 비보장·공식 절차 링크 확인
- 식단 시작일은 월요일만 저장되고, ICS에 완료 기준과 출처 주의가 함께 들어가는지 확인
- 국가근로 TXT 체크 항목 4개와 공식 링크 확인
- KOCW CSV 데이터 행 10개와 상태·목표일·메모·원문 열 확인
- 작성 중 메모가 판정 버튼과 즉시 내보내기에서 소실되지 않는지 확인 후 QA용 로컬 저장 상태 초기화

실제 사용자에게 배포하거나 관찰 사용자 세션을 진행한 것은 아닙니다.
