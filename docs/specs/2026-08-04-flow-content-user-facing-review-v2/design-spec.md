# FLOW 사용자용 콘텐츠 검토본 v2 디자인 명세

## 기준 화면

- 기준: `docs/content-audit/2026-07-31-flow-content-other-content-review-v1-ko/review.html`
- 유지: 흰 배경, 검정 중심 타이포그래피, 파란색 강조, 1040px 안쪽 폭, 넉넉한 여백, 얇은 회색 경계
- 변경: 카드에서 바로 구조 평가를 요구하던 흐름을 `원문 → 실제 내용 → 도구 결과 → 분리된 검토자 메모` 순서로 바꾼다.
- 이번 작업은 기존 단일 파일 디자인 시스템 안에서 진행하는 콘텐츠 중심 개정이므로 별도 이미지 자산이나 ImageGen 콘셉트를 만들지 않는다.

## 첫 화면 허용 문구

- 브랜드: `FLOWMe`
- 제목: `원문에서 바로 쓰는 FLOW 4개`
- 설명: `원문 링크, 실제 실행 내용, 도구에 저장될 결과를 한 흐름에서 확인하세요.`
- 날짜: `원문 확인 · 2026. 08. 04.`
- 보조 행동: `검토 메모 받기`
- 목록 제목: `이번 검토 4개`

이 목록 밖의 배지, 지표, 기능 설명, 마케팅 문구는 첫 화면에 추가하지 않는다.

## 사용자 화면 정보 순서

1. 제공자, 작성자, 확인일, 항상 보이는 `원문 열기`
2. 콘텐츠 제목과 구체 사용자 결과
3. 시작일처럼 결과 생성에 필요한 입력만 표시
4. 원문에서 가져온 실행 내용
5. 캘린더·체크리스트·CSV에서 실제로 보일 결과
6. 목적지가 드러나는 다운로드 행동
7. 출처 한계와 주의사항
8. 점선 경계 아래 별도 `검토자 메모`

## 디자인 토큰

- 배경: `#ffffff`
- 본문: `#111318`
- 보조 본문: `#596173`
- 경계: `#dfe3ea`
- 옅은 면: `#f7f8fb`
- 강조: `#3157f5`
- 강조 면: `#eef2ff`
- 주의: `#805b10`, 면 `#fff8e8`
- 최대 폭: `1040px`
- 본문 폭: `720px`
- 모서리: `12px`와 `16px`
- 그림자: 사용하지 않으며 얇은 경계와 여백으로 계층을 만든다.

## 구성요소

- `source-line`: 출처를 행동 가까이에 고정
- `flow-card`: 제목, 목적, 목적지, 원문 제공자만 표시
- `input-row`: 날짜 입력 한 개와 즉시 갱신되는 미리보기
- `content-row`: 실제 메뉴·경로·차시와 메모
- `artifact-preview`: 캘린더 행, 체크리스트, 또는 진도표
- `primary-action`: 결과가 분명한 `캘린더 파일 받기` 또는 `CSV 받기`
- `source-note`: 원문 한계, 최신성, 안전·권리 경계
- `review-zone`: 사용자 화면과 시각적으로 분리된 검토자 전용 영역

## 반응형 규칙

- 900px 이상: 실행 내용과 도구 결과를 58:42 두 열로 배치
- 899px 이하: 한 열로 쌓고 도구 결과를 실행 내용 다음에 배치
- 390px: 바깥 여백 18px, 표는 필요한 열만 보이고 가로 스크롤을 허용하지 않는다.
- 날짜 입력과 다운로드 버튼은 모바일에서 너비 100%로 둔다.

## 상호작용

- 목록 카드에서 사용자 화면 열기
- 날짜 입력 변경 시 캘린더 미리보기 즉시 갱신
- 식단·여행·장학금은 실제 `.ics` 다운로드
- KOCW 진도표는 실제 UTF-8 `.csv` 다운로드
- 출처 링크는 새 탭에서 열기
- 검토 의견은 브라우저 로컬 저장 후 JSON으로 별도 다운로드

## 의도적 차이

- 기존 v1의 `내용 / 도구 결과 / 내 판단` 탭을 없앤다. 출처와 실행 상세가 숨겨지지 않도록 한 화면에 둔다.
- 기존 카드형 반복보다 열린 목록·표를 우선한다.
- 검토 질문과 품질 점수는 사용자 콘텐츠 안에 넣지 않는다. 품질 점수는 데이터와 manifest에만 남긴다.
