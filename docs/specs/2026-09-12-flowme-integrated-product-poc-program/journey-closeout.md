각 상황은 시작→선택/입력→실제 변경→결과 확인→취소/실패/Undo→다른 화면/재진입으로 확인한다. 목적 달성, 다음 행동, 맥락 유지, 입력 부담, 복구, 공개 경계, 모바일/키보드 접근의 일곱 관점에서 미확인 사항이 있으면 남긴다. 한 번의 정상 경로와 모델 음성 검사를 합쳐 전체 실제 브라우저 통과로 표시하지 않는다.

## 현재 확정할 수 없는 것

- 위 상황들의 진척은 확인되지만 모든 핵심 경로를 같은 최종판에서 종결하거나 두 차례 전체 개선 루프를 완료한 것은 아니다.
- 현재 상태 문서보다 오래된 초기 요구 표의 ‘미구현’을 그대로 합산하지 않는다. 반대로 새 요약 화면이 있다는 이유로 원래 제작·실행 요구를 완료로 바꾸지 않는다.
- 기존 Map 공통/하위 기준일과 구조 재검토의 확인된 결과는 유지한다. 공통 기준일의 여러 상대 반복과 후속 복귀 수정은 새 빌드의 owner/화면/동작/증거가 필요하다.
- Android/iOS, 실제 소프트키보드·한글 IME·보조기술, 실제 외부 도구 계정, 관찰 사용자 검증은 미실행이다. 관찰 사용자0명.
- 보고서 HTML은 URL 보안 정책으로 렌더가 차단됐다. 다른 주소/브라우저/미러로 우회하지 않으며 정적 링크·PNG 검사는 보고서의 반응형 검증을 대신하지 않는다.
