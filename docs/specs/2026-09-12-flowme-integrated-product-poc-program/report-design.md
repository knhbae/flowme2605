# 캡처 중심 검증 보고서 구성

2026-09-12 · 최종 결과를 담을 HTML의 배치 계약이다. 이 문서와 생성 시안은 기능 통과 증거가 아니다.

## 읽는 순서

사용자는 앱을 열거나 목적별 실제 캡처를 고른 뒤, 원래 요구와 현재 동작의 차이를 확인한다. 자동 검사·브라우저·실기기·관찰 사용자·배포는 접힌 상세에서 각각 읽는다. 성공률을 꾸며내거나 검사 개수를 요구 충족률로 바꾸지 않는다.

1. `FlowMe 통합 PoC 검증` / `구현·브라우저 확인·남은 작업을 구분합니다.` / `앱 열기`
2. 전체 판정과 검사한 실제 빌드·시점
3. `개인 문서 / 발견과 재사용 / 경험과 공개 / 원본과 업데이트` 목적 선택 → 실제 캡처·짧은 행동 설명·해당 증거
4. `요구사항과 현재 적용`: 원래 요구 / 지금 가능한 행동 / 남은 확인
5. 접힌 상세: `통합 시나리오`, `자동 검사와 저장소 보호`, `실제 기기·관찰 사용자·배포`, `실행 방법과 원본 근거`

실제 캡처는 원본 비율을 유지하고 전체 크기 열기를 제공한다. 시안에 들어간 앱 화면은 배치 참고일 뿐이다. 최종 HTML에는 실행 증거와 빌드가 일치하는 원본 캡처를 넣는다. 캡처 안의 버튼을 보고서 기능인 것처럼 사용하지 않는다.

## 배치와 스타일

생성 시안 (로컬 전용 근거: `../../content-audit/2026-09-12-flowme-integrated-product-poc-review-assets/report-concept-v1.png`)은 built-in Image Gen으로 생성했다. 입력은 실제 빈 문서 예시 캡처와 위 전체 보고서 요구다. 생성물의 앱 내부 글자·수치를 실제 결과로 전사하지 않는다.

- 흰 배경 `#ffffff`, 본문 `#123539`, 강조 `#087f79`, 구분선 `#dbe5e4`.
- 한국어 sans-serif, 본문16px/1.6, 제목36px, 모바일 제목28px. 컨트롤도 글꼴을 명시한다.
- 데스크톱 최대1240px, 목적 목록240px와 유연한 캡처 영역. 모바일은 목적 선택과 캡처를 위아래로 배치한다.
- 얇은 구분선과8px 모서리. 큰 장식·KPI 카드·장식용 배지·그라데이션을 추가하지 않는다.
- 표와 접힘은 semantic HTML이다. 방향키/Tab/Enter, 보이는 초점, reduced-motion을 고려한다. 스크립트가 없어도 근거·실행 방법은 읽힌다.

허용된 시안 차이: 최신 사실에 따른 판정·날짜·검사 결과, 요구별 추가 행, 실제 캡처 비율, 실행상 필요한 로컬 서버 안내는 갱신한다. 이는 시안의 예시 상태를 완료 주장으로 고정하지 않기 위한 차이다. 정보 구조·색·타이포그래피·여백·컨트롤 계열은 유지한다.

## 검사와 개선 기록

최종 소스 기준선을 고정한 뒤 동일 빌드에서 S01~S10을 확인한다. 이어 다른 내용 구조와 사용 목적을 적용해 추가 평가·수정을 수행한다. 과거 부분 성공이나 스크립트 준비를 전체 루프로 계산하지 않는다.

| 담당 범위 | 이번 최신판에서 종결할 핵심 |
| --- | --- |
| 개인 문서·공통 통합 | S01 이동 뒤 작성 위치·빈 예시·참조·휴지통·복구, S06 질문/긴 경험/이미지/답글/삭제 근거, S08 실제 옛 판본 제안·새 판본·부분 적용 |
| 제작·개인 실행 | S02 이틀 진행, S03 이동 동등성, S07 선택 공개, 상속 날짜의 원래 실패 입력·native Undo/재인계·선택 수용 뒤 추가 실행 |
| 발견·출력·진입 | S04 실제 파일/무저장, S05 선택·사본·다중 문서·정확 재진입, S09 손상·query·origin 차단 |
| 기존 원본 | S10 네 origin, 부분 연결과 TXT 없는 Map, 보류 재진입과 개인 기록 보존·원본 Undo |

보고서 자체는 Browser/IAB 우선으로 390px·태블릿 가로·데스크톱에서 열어 링크·이미지·접힘·가로 넘침·콘솔을 검사한다. 마지막에 생성 시안과 실제 보고서 캡처를 직접 비교하고 배치·문구·글꼴·색·사진 비율의 차이를 기록한다. 두 평가 루프의 미완료나 남은 결함을 보고서 작성으로 대신하지 않는다.

### 현재 검사 제한

14:16경 이 HTML의 최초 IAB 열기가 URL 보안 정책으로 차단됐다. 다른 주소·서버·브라우저·미러·headless 렌더로 우회하지 않는다. `program-report-static-audit.mjs`의 소스 문법·중복 ID·로컬 근거/PNG 파일·저장/네트워크 API 없음 검사는 렌더 검사를 대신하지 않는다. 생성 시안은 직접 열어 확인했으나 실제 보고서 렌더 캡처가 없으므로 시안과의 시각적 일치·반응형 동작은 미검증이다. 허용된 별도의 기능형 앱 시나리오와 그 캡처는 계속 검증한다.
