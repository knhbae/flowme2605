# 일반 항목의 원문 내용 선택 — 구현·검증 계획

2026-09-14 · P06/P07/P08의 내용 보존 연결. 전체 목표는 진행 중이다.

## 확인한 차이

여섯 실제 작성물은 개인 인계와 일부 항목의 선택 공개까지 이어졌다. 일반 항목의 공개 초안은 제목 외 설명·완료 조건·출처가 비어 있다. 이사 설명과 결혼 설명/자료는 실제 제작 원본에 있으나 선택 공개 결과에 포함되지 않았다. 반복의 불변 원문 reader와 달리 일반 항목에 이 내용을 확인하고 가져오는 경로가 없다. 개인 문서를 통째로 복제해서 해결하지 않는다.

## 작은 설계

- 기존 공개 항목 편집 안에서 `원문 내용 가져오기`를 연다. 연결된 실제 raw/native 제작 원본의 현재 수용 판본과 정확한 행 ID만 읽는다. 이름·줄번호 추정으로 다른 자료를 연결하지 않는다.
- 제목, 설명·자료, 완료 조건, 항목 출처를 현재 초안과 비교한다. 기본 선택은 없음이며, 선택한 필드만 공개 초안에 저장한다. 안내·주의·자료·출처 링크는 원래 값과 의미를 설명 안에 보존한다.
- 개인 메모·누적 진행·실행 날짜·하위 체크 완료·개인 경로는 후보에 포함하지 않는다. 기존 공개 일정과 하위 체크 선택은 그대로 둔다. 이 동작은 공개가 아니며 기존 공개 미리보기와 명시 공개를 거친다.
- 새 저장 schema나 자동 이전은 없다. 현재 공개 초안의 기존 문자열 필드만 사용한다. 이미 저장/공개한 내용은 자동 갱신하지 않는다.
- 비교/선택/취소/Escape는 저장하지 않는다. 적용 때 원본·대상 행·저장 초안을 다시 확인하고 한 Program 거래로 저장한다. 같은 값은 성공 쓰기0, 실패는 비교와 선택을 유지한다. 다른 탭 변경은 덮지 않는다.

## 순서와 판정

1. 실제 원본 reader와 선택 모델, 손상/보류/개인정보/identity 검사를 만든다.
2. 기존 공개 편집에 접힌 비교를 연결하고 키보드·취소·실패 복구를 검사한다.
3. 보존된 이사·결혼 작성물에서 이전 공개 판본·개인 50% 기록·메모를 유지한 채 새 판본을 만든다. 자료와 설명의 실제 미리보기/결과, 같은 값·실패·재시도·reload를 검증한다.
4. 최종 소스의 자동 검사/build와 5크기 브라우저 검사를 수행하고 기존 보고서에 근거와 잔여를 반영한다.

일반 공개 일정의 시간대 확장, 다른 origin의 새로운 source 연결, 실제 외부 게시·운영 migration은 이번 필드 연결로 완료 처리하지 않는다. 전체 Map 삭제·개인 충돌·긴 화면/누적 응답·S01~S10 및 두 전체 개선 루프도 계속 남긴다.
