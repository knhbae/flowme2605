# UX Cleanup Backlog Spec

Date: 2026-05-25

## Goal

Organize the parts of FLOW content and UX that are still not clean enough for broad review or route-by-route rewriting.

## Scope

- Add a code-backed cleanup backlog for unresolved content/UX areas.
- Surface group count, route count, priority count, validation count, and first batch groups in Flow Lab.
- Document the cleanup categories and next rewrite order.

## Non-Goals

- No route rewrite in this batch.
- No route promotion.
- No validation claim.
- No new native record, direct integration, login, payment, community, or AI auto publishing.

## Decisions

The first rewrite queue is:

1. Exact workout video execution detail.
2. Health/diet observation guardrails.
3. Vehicle purchase evidence-first UX.

The backlog is intentionally separate from source review. A route can have a source reviewed and still need content/UX cleanup before public or representative framing.
