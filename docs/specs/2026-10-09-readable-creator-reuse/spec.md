# 긴 글·제작 사본·개인 계획 이어쓰기

2026-10-09. 개발3 단일 구현 owner. 기준은 `c3624eb57a8ab669f0c7642aa12fc4cd5ad37dd1`이다. 이전 작성→정리→실행→재사용 결과를 다시 구현하지 않는다.

## 이번 변경

- 읽기·접힘 상태의 체크박스와 폴더 아이콘을 본문 첫 줄에 맞춘다. 44px 터치 영역, native textarea와 mirror 좌표, 원문과 Item은 바꾸지 않는다.
- 제작 초안의 저장은 상시 노출한다. 구간·할 일 추가와 작성 틀은 하나의 접힌 작성 도구에 모은다. 작성 틀은 계속 마운트하며 입력·취소·모달 복귀·native Undo를 보존한다.
- 편집 대상과 저장 실패 안내는 실제 재현 결과에 따라 판단한다. 없는 결함을 가정해 정책·안내를 추가하지 않는다.

## 확인할 과업

가상의 긴 설명·링크·하위 할 일을 작성하고 직접 작성한 할 일을 분류한다. 제작 초안을 명시 복제해 사본만 편집한다. 저장 실패에서는 입력을 유지하고 이동을 거절하며 정상 재시도로 저장한다. 개인 계획을 명시적으로 시작해 날짜·진행·결과 메모를 남기고 재열기에서 같은 계획을 확인한다.

## 경계

기존 실제 자료와 계정을 이 재현에 사용하지 않는다. 합성 localStorage 결과를 서버 저장이나 사용자 이해도 검증으로 표시하지 않는다. 제작 출처가 있는 개인 항목의 기존 분류 제한은 유지한다. 새 분류 정책·자동 자료 전환·운영 체계·TTL·권한·DB·Auth·DNS·Tunnel 변경은 없다. 필요한 정상 게시·CI·Alpha 적용은 실제 단계 근거로 별도 기록하며 main 병합은 하지 않는다.
