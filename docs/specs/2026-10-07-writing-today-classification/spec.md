# 쓰기·오늘·분류 기본 화면

승인된 로컬 UX 구현. 기준은 별도 후보 Q2iZMruizVmfUY5JpU76O의 정확 소유 source23이며, Git 기준은76e833이다. 이전 후보·미리보기3132·원본 릴리스는 보존한다.

쓰기는 현재 글을 이어 열며 생성하지 않는다. 새 글은 별도 명시 동작이다. 오늘은 모든 글의 같은 Item을 날짜로 조회하고, 분류는 기존 all 조회와 Item 분류 selector를 이용해 날짜 전체에서 찾는다. 한 번의 기존 입력 flush/lock 성공 뒤 전환하고 실패하면 보기/필터를 부분 변경하지 않는다.

문서 목록·찾기·선택 문서 작업은 보조 진입점 한곳으로 모은다. 이름/보관위치와 할 일 분류는 서로 다른 데이터 의미를 유지한다. 예정일과 진행 기록일을 실제 metadata에 맞춰 표시하고 명시적인 원문 모드의 TXT를 보존한다. native 편집/IME/Undo 보호가 필요한 활성 줄의 정확한 표시 한계는 기록한다.

가상 업무·생활 혼합 작성→항목별 분류·날짜→오늘 미루기/완료→분류 재찾기→같은 글 이어쓰기→필요 항목의 연결 메모 열기를 데스크톱과390px에서 확인한다. 기존 보존 검사와 이번 변경 영향 검사를 구분한다. 글/Item/사본 생성·입력/날짜/메모/기록 손실을 이동·reload 전후 비교한다.

서버 분류 저장, 기존 자료 전환, 삭제 정책, 공개 게시·CI·Alpha 배포·운영 변경은 제외한다. 가상 탭 저장 검사는 실제 서버/휴대폰/OS IME/처음 쓰는 사용자 이해도 검증이 아니다.
