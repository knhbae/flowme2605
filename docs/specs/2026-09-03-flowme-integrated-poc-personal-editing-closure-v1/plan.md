# P2-C 실행 계획

1. 세션 시작·최신 main·격리 worktree·세 원본 정본과 현재 추적표를 확인한다.
2. section owner, authoring source, saved personal shadow의 소유권과 D2-021 충돌 판정을 계약으로 고정한다.
3. stable section catalog와 section-title overlay를 read model, Plan transition, composition, Undo/reload에 연결한다.
4. Authoring catalog v2, singleton/append/child-action/pair transaction, exact re-entry 순수 모델을 구현한다.
5. React chooser를 네 그룹으로 정리하고 단순 inline/복합 dependent surface 및 소유권 copy를 연결한다.
6. 독립 HTML model/app/style을 같은 계약으로 맞추고 두 single-file 산출물을 재생성한다.
7. 좁은 테스트부터 전체 회귀·production build·브라우저 시나리오·운영 데이터 불변 검사를 실행한다.
8. effective requirements override, manifest, 검증 리포트, handoff를 실제 결과로 갱신한다.

각 단계는 앞 단계의 불변식이 깨지면 다음 단계로 승격하지 않는다. 실패·미실행은 통과로 표현하지 않는다.
