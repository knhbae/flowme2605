## 이번 범위

1. 기존/없는 이름의 목록 메모를 타이핑·붙여넣은 뒤 폴더 연결 제안·생성 진입이 어떻게 동작하는지 재현한다. 기존 제안이 없다고 소급 단정하지 않는다.
2. 일반 텍스트를 자동 변경하지 않고, 명시 선택으로 같은 줄/ID를 기존 폴더에 연결하거나 새 폴더 생성 패널로 이동하게 한다. 부분/IME/잠금/외부판본의 보호는 유지한다.
3. 기존 `둘러보기 → Flow 찾기 → 읽기 → 개인 사용/출력`, `내 활동 → Flow 만들기 → 비공개 초안/편집`을 현재 화면에서 대조한다. 확인한 발견성·표시·복귀 갭만 좁게 개선한다.
4. v4.1·개발1·개발2의 J12~J14와 기존 UX1·UX2 자료를 연결하고, 필요한 최소 선택은 UX2 세션에 검토 요청한다. 별도 제품 코드나 미소유 문서 수정은 요청하지 않는다.
5. 직접 조작 가능한 로컬 HTML과 요구별 결과/검증 보고서를 제공한다. HTML 시뮬레이션을 앱 parser/writer·계정 검증으로 표현하지 않는다.

- Flow/Map 전수 편집, 복합 일정·Creator 단계 연쇄 변경, 소유자 제안 부분채택, 공개 정책/커뮤니티 전면 개편.
- 신규 백업 활성화·대용량5D·실계정/DB/Auth·Tunnel/DNS/호스트 설정·유료 서비스.
- 별도 범위 확인 전 commit/push/PR/merge/개발계 교체/Preview/Production. 이번 로컬 개발 목표는 자동 게시/배포 승인이 아니다.
- 관찰 사용자 시험은 계속 보류한다. 실제 Android/iOS·OS IME·AT 미실행은 별도로 표시한다.

## 완료 조건

- 기존/없는 이름 × 타이핑/붙여넣기 × 전체/부분과 동명 경로에서 지원/전환이 분명하다.
- 제안 표시/무시/닫기/Escape/취소는0추가변경이다. 명시 연결은 기존 transition/writer로 같은 줄·원문 문맥·Item·소속·기록을 보존한다.
- 저장 실패·외부 판본·IME 입력은 남고, Undo/reload가 마지막 성공 상태와 맞는다. 단순 입력 저장과 폴더 연결 명령은 따로 센다.
- 콘텐츠의 기본 기능 존재와 현재 UX 확인을 구분하고 개인 원문/실행 기록을 공개 자료로 자동 이동하지 않는다. 안전한 기존 navigate/dirty guard를 재사용한다.
- 표적 순수/컴포넌트·관련 기존 회귀·npm test·격리 production build·다섯 화면 합성 브라우저를 실행하고 정확한 실행 수·실패·재시도를 기록한다.
- 실제 운영 계정 자료의 byte 대조를 하지 않은 경우 합성 운영 sentinel 불변을 실제 DB 전체 불변으로 확대하지 않는다.
