# URL-to-FLOW Prompt Lab v1 Plan

## Phase 0 — Freeze The Contract

1. Derive 12 source-only cases from canonical golden fixtures.
2. Keep reviewer expectations in a separate file hidden from generators.
3. Fix the prompt, proposal schema, run envelope, and review rubric.

## Phase 1 — Build Deterministic Tools

1. Generate cases and copy-paste run packets.
2. Validate one proposal or a batch without external packages.
3. Produce objective source-accounting and status evidence.

## Phase 2 — Round 1

1. Run all 12 cases in isolated in-session executions.
2. Store raw model output before any correction.
3. Validate, blind-review, and create corrected FLOW previews.

## Phase 3 — Round 2/3

1. Rank defect classes by safety and frequency.
2. Change one prompt rule at a time.
3. Rerun failed/revise cases plus pass controls.
4. Run a final stability set only after the quality gates pass.

## Phase 4 — Evidence And Handoff

1. Create comparison Markdown and Korean HTML.
2. Render desktop/mobile and check overflow/links.
3. Run builders, validators, `docs:check`, and scoped diff checks.
4. Record local/commit/push status without claiming real-provider comparison.
