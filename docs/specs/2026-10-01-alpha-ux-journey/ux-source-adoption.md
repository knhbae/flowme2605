## 제안별 처리

| 출처 / 제안 | 이번 처리 | 이유와 남은 경계 |
| --- | --- | --- |
| UX1 M18/B03~04: 작은 높이에서 본문 확보 | **부분 채택**: Alpha 관리행·편집 상시 도구 감산, 짧은 화면의 editor 최소높이 조정 | 같은 native textarea와 기존 48px target을 유지한다. 첫 화면 본문이 0인 가로 화면은 후속이며 UX1 전체 완료가 아니다. |
| UX1 M04/M11/B01/B05: 행 도구 감산·선택한 곳에서 추가 | **보류**: 이번에는 날짜순 정렬·Redo만 보조 도구로 이동 | 행 +/메뉴 제거, 54px gutter와 이동 geometry 변경은 native engine 원본/생성 경로와 별도 구조·선택 계약이 필요하다. 기존 +와 문맥 옵션을 삭제하지 않는다. |
| UX1 M06/M08/B05: 같은 Item의 정확한 원문 복귀 | **Alpha 결함 수정**: 재사용 중인 편집기에서도 해당 docId/lineId로 복귀 | baseline에서 커서가 첫 줄에 남는 결함을 실제 재현했다. Alpha에서 접힌 scope까지 native focus로 펼친 뒤 이동한다. ProgramApp의 기존 checkpoint 복원 권한에는 개입하지 않으며 이 경로의 접힘 UX까지 해결한 것은 아니다. 메모·폴더·기록과 writer는 유지한다. |
| UX1 M01/M05/B06~08: 입력·Undo·오류/IME 보호 | **유지 + 회귀** | native 입력 Undo와 서버 변경 Undo를 합치지 않는다. 오류·잠금·입력 보존을 감산 대상에서 제외한다. 실제 IME·키보드/주소창·스크린리더는 미실행이다. |
| UX2 P0: 폴더/검색 범위와 문서 보관 위치 분리 | **기존 구현 유지**: J06/J07 | 현재 U04/U08/U09 코드·기존 근거를 대조한다. 새 기본 범위·‘이 문서’ 필터 정책을 이번에 확정하지 않는다. |
| UX2 P1: 추가·항목 작업 구분, 같은 Item 날짜/시간 | **기존 유지 + 표시 개선**: J03/J04 | 날짜 폼에 해당 제목을 더한다. 기간 조회 날짜와 실행 날짜는 구분한다. 월간 목록을 새 달력으로 바꾸지 않는다. |
| UX2 R04/R05·장기 백업 재진입 | **기존 저장 복구 회귀만**: J11 | 같은 요청 ACK의 현재 해결과 복구된 첫 저장 Undo·장시간 탭 등 남은 경계를 구분한다. 신규5D/운영 자동화는 이번 밖이다. |
| UX2 A01~04/A08: 자유 작성·같은 Item·미정·비드래그/Undo·이어가기 | **이번 첫 여정의 비교 기준** | A는 현재 토큰/조작을 보존하는 좁은 구현이다. B 집중은 별도 HTML에서만 비교하며 새 제품 모드로 확정하지 않는다. |
| UX2 A05~07: Flow 준비·출력·선택적 기여 | **전체 맵에 유지**, 신규 구현 보류: J12~14 | 개인 작성이 필수 Flow/공개/참여 단계로 이어지는 funnel이 아니다. 뒤의 두 축을 이번 개인 문서 검사로 통과 처리하지 않는다. |
| UX2 B01~06/C01~04: 기준일 재계산·공동 편집·성찰·선택 업데이트·그래프 등 | **보류** | 데이터 소유·권한·기록/판본 계약 또는 실사용 근거가 필요한 별도 탐색이다. UI 감산만으로 구현됐다고 소급하지 않는다. |
