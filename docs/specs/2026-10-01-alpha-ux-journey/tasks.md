완료 범위는 이 spec의 1차 UX 탐색·비교·좁은 구현·내부 검증이다. 전체 통합 최종 재실행·짧은 가로 화면·실기기/관찰 사용자·공개 반영은 [남은 경계](qa.md#미실행후속)와 마감 기록대로 보류한다.

commit/push/PR/merge/배포·개발계 교체·관찰 사용자 시험은 작업 대상이 아니다.
