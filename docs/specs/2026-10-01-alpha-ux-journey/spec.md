## 목표

v4.1·개발1·개발2 및 UX1·UX2 결과를 현재 앱과 연결한다. 개인 자유 텍스트 작성, 공개 경험·지식 탐색과 재사용, 선택적인 커뮤니티 기여를 전체 방향에 유지한다. 이번 집중 여정은 메모·할 일 작성→날짜 배정→기간 보기→같은 원문 행으로 복귀다. 현행과 좁은 대안 A/B를 조작 비교하고 선택한 개선을 최소 구현·검증·보고한다.

## 경계

- 현재 공개 앱·Tunnel·설정·실제 계정·운영 저장소는 변경하지 않는다. 합성 Auth/API 시뮬레이션만 사용한다.
- `/my` exact gate·저장 writer·identity·schema·CAS·같은 요청 ACK·날짜/폴더/순서 transition을 바꾸지 않는다.
- prototype은 단일 HTML의 독립 시뮬레이션이다. 앱 구현이나 실제 동기화 근거가 아니다. 저장은 정확한 `flow:poc:personal-workspace:v1:ux-journey` key 하나만 사용한다. `clear()`를 호출하지 않는다.
- 일반 메모의 자동 task화, 필수 Flow 사용/공개, 새 집중 모드의 제품 정책 확정은 하지 않는다.
- 운영 자동화·장시간 인증 전체·신규5D·콘텐츠 전수 편집·공동 편집 권한은 이번 구현에 포함하지 않는다.
- 관찰 사용자 시험, 실제 기기/IME/보조기술, commit/push/PR/merge/배포·개발계 교체는 제외한다.
