# Adaptive Lean Agent Harness Plan

## Files

| File | Responsibility |
| --- | --- |
| `AGENTS.md` | Minimal automatic entry and task routing |
| `agent.md` | Concise FlowMe product and operating guardrails |
| `docs/harness/README.md` | Adaptive harness policy and compatibility |
| `docs/harness/ROLES.md` | Four core passes and optional specialists |
| `docs/harness/SDLC.md` | Minimal, standard, and full task lanes |
| `docs/workflows/*.md` | Conditional workflow triggers |
| `.agents/skills/*/SKILL.md` | Narrow discovery descriptions and procedures |
| `docs/TOOLING.md` | Complete skill classification and routing |
| `docs/DECISIONS.md` | Durable lean-harness policy |

## Sequence

1. Record the evidence baseline and durable decision.
2. Shorten the automatic entry path and expanded guide.
3. Reduce default roles and route SDLC/workflows by task risk.
4. Tighten relevant skill triggers and synchronize generated copies.
5. Run documentation and skill checks, then inspect only the scoped diff.

## Risk Controls

- Preserve hooks, CI, safety boundaries, and domain-specific skills.
- Do not touch existing content-research or source-expansion changes.
- Treat reduced context as a hypothesis until repeated real-task evidence exists.
- Keep detailed product truth in existing canonical docs instead of deleting it.
