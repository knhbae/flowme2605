## 피드백 반영

원본 피드백 21개를 전부 읽었다. 이전 기준과 hash가 달라졌으므로 현재 본문을 새 기준으로 기록했다. 이전 byte 사본이 없어 정확한 diff를 추정하지 않는다. 원문을 복사·수정하지 않았다.

| 피드백 | 이번 처리 |
| --- | --- |
| #2 필터로 보이지 않았던 작업 | 사용자가 원인을 필터로 정정했다. 누락 버그로 다시 분류하지 않는다. |
| #7 공개 Flow가 안 보임 / #18 제작 동선이 어려움 | 선택 판본→개인 사본과 제작→실행 재진입을 현재 빌드에서 검증한다. 실제 공개 콘텐츠 전수 확인으로 확대하지 않는다. |
| #14 날짜 변경이 명확하지 않음 | 같은 Item의 개인 날짜/시간·기간·Undo·원본 불변을 묶어 검사한다. |
| #15 10/1 Enter 후 체크 문법 추가 | 채워진 할 일의 다음 빈 체크와 빈 체크에서 일반 문장으로 나가는 기존 계약·회귀를 유지한다. 영구 문법을 새로 확정하지 않는다. |
| #16 메모 문법 / #17 @·#·이름 정책 | 결정되지 않은 제안이다. 이번 구현에서 제외한다. |
| #20 입력/붙여넣기 폴더 연결 / #21 문서 내부 영역 | 직전 목표의 명시 제안·연결·범위 UI를 재사용하고 관련 browser 회귀를 실행한다. 실제 사용 당시 원인이 확정됐다고 쓰지 않는다. |

## 별도 후속

제작 틀·ghost·모든 source 업데이트/반복/Map 조합, 전체 콘텐츠 전수, 공동 편집 권한, 실제 Auth/RLS·장시간 탭, OS IME·보조기술, 실기기와 관찰 사용자는 이 표의 PASS로 대신하지 않는다. 기존 원장에 남은 요구를 삭제하거나 완료 처리하지 않는다.
