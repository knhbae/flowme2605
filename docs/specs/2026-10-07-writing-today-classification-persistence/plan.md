# 실행 계획

1. 기존 소유 변경·source/build·결과를 고정하고 기존 분류/메모 저장 경로를 읽는다. 기획·콘텐츠·테스트의 작은 결과를 실제 수신해 인수하되 답변 대기만으로 독립 작업을 멈추지 않는다.
2. 일반 개인 Item 분류를 기존 Alpha M3 저장에 연결한다. 연결 메모 접근만 국소 수정한다. 날짜 중복 시안은 가시성 반례 때문에 미채택하며 기존 표시를 유지한다.
3. 기존 HTTP repository/controller/server handler를 거치는 합성 CAS 검사와 desktop/390px 표적 UI를 실행한다. 실패 입력·재시도·동일 Item/문서·해제 의미·새 빈 접속 복원을 확인한다. 필요한 타입·빌드를 새 source에 연결한다.
4. 승인된 소유 runtime/tests/docs만 선별 게시하고 기존 Draft PR 213·새 정확 CI를 확인한다. 개인 가상 원문/ID/raw/캡처/credentials는 공개하지 않는다.
5. 현재 Alpha/rollback/Task·manager 소유·새 exact binding을 확인한다. 중단/복구를 설명하고 정상 지원 경로로만 전환한다. 거부하면 그 작업은 중단하고 가능한 독립 결과를 마감한다.
6. 정상 시험계정 별도 가상 문서에서 실제 저장/reload/새 접속을 확인하고 구현/게시/배포/실제 사용/미실행을 분리한다.
