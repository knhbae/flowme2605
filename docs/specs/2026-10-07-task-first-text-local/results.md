## 바뀐 동작

1. **이름·위치 선택 없이 시작**: ‘새 글 바로 쓰기’로 일반 글과 할 일을 같은 편집기에 적는다. 빈 글에서 다시 눌러도 같은 글을 열고, 저장·보기 전환은 문서를 생성하지 않는다. 내부 저장 단위는 기존 문서 그대로다.
2. **편집 중 표시 유지**: 문서 모드에서 커서가 있는 할 일·폴더 줄에도 체크박스·폴더 표시를 남겼다. 원래 textarea, 문자 위치와 입력 Undo를 유지한다. 원문은 ‘편집 도구’에서 명시적으로 선택한다.
3. **주요 동작만 앞에**: 현재 보기·바로쓰기·추가·입력 Undo를 앞에 두고, 문서·폴더 목록과 문서 작업·원문·보조 도구는 접었다. UX 검토의 감산 원칙을 적용했다.

## 실제로 이어 확인한 흐름

가상 글에 회의 준비와 장보기를 적고 각 항목을 업무·생활로 분류했다. 오늘 날짜를 지정한 뒤 회의 준비는 다음 날로 미루고 장보기는 완료했다. 원래 글로 돌아와 설명을 이어 쓰고, 별도로 만든 비교 메모는 회의 준비에만 연결했다.

새로고침·다른 보기·원문 재진입 뒤에도 같은 글과 Item, 분류·날짜·완료 기록·메모 연결이 유지됐다. 최종 문서 2개는 원래 글 1개와 사용자가 명시적으로 만든 메모 1개이며, 할 일은 같은 2개·사본은 0개다. 새로고침 뒤 첫 원문 복귀에서 발견한 초점 문제도 수정했다.

실제 브라우저 키보드로 입력·선택·Ctrl+Z·원문 전환/복귀를 확인했다. 데스크톱과 390px에서 가로 넘침 없이 같은 흐름을 확인했다. 설명을 읽고 수행한 자동화 검사이며 처음 쓰는 사용자의 이해를 검증한 것은 아니다.
