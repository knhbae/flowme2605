# v11 자유 이동 계약

상태: 사용자 승인 범위의 독립 v11 구현·자동 검증 완료(2026-09-08). 이 명세가 v11 시안의 이동 계약이다. 제품 통합·실기기 검증 완료는 아니다. 기존 v10 명세·실행 파일은 과거 근거로 보존한다.

## 목적과 범위

사용자: 개인 텍스트 공간에서 할 일·하위 체크·폴더·개인 Flow 연결을 직접 정리하는 사람. 첫 동작은 체크칸/왼쪽 아이콘 길게 누르기, 결과는 원문의 구조 변경과 같은 항목의 기록 유지다. 자연스러운 산출물은 문서 TXT와 기간별 할 일 목록이다.

본문 내 같은 부모·같은 레벨 제한을 없앤다. 본문 드래그에 깊이를 추가하고 Tab/Shift+Tab도 같은 모델 계약을 따른다. 실제 폴더 카탈로그를 재편하거나 다른 문서로 옮기는 UI, 공유 원본·계정·외부 동기화·제품 통합·배포는 추가하지 않는다. Stage 0 전체 제품 우선순위 변경이 아닌 이미 승인된 개인 공간 독립 UX 검증이다.

## 사용자 규칙

- 원문 항목·묶음을 다른 부모·높이에 옮길 수 있다. 선택한 부모는 딸린 원문 줄을 함께 옮긴다. 하위만 잡으면 그 하위 묶음만 이동한다.
- 이동으로 제목·완료·진행 기록·날짜·시간·메모·ID·기존 참조를 잃지 않는다. 부모 상태를 자식에 자동 적용하거나 합산하지 않는다.
- 자기 자신/선택된 후손 안으로 이동, 동일 폴더·Flow를 자신의 하위에 연결하는 순환, 없는 대상·깨진 참조는 차단한다. 저장 충돌·입력 조합·원문 오류는 일시 보호 상태이며 데이터를 보존한다.
- 일반 이동은 확인창 없이 실행한다. 삽입선·깊이·새 부모를 미리 보여주며 기존 상단 Undo 한 번으로 복원한다. 실패 시 부분 이동하지 않는다.
- 본문 연결의 배치는 실제 폴더 트리·공개 Flow 원본을 변경하지 않는다. 원래 소속과 일정은 유지한다. 날짜 칸에 재일정하는 행동과 과거 진행 기록 수정은 이번 본문 이동에 섞지 않는다.

## 항목 정체성과 저장

- 독립 키 `flowme:ux-review:text-workspace-v11:20260908`, schema 11. 이전 키 자동 읽기/이전 없음.
- taskScopes는 기간 목록에 나오는 canonical 항목 ID/소속 registry다. 기존 할 일을 하위로 내려도 같은 ID로 registry와 기간 노출을 유지한다.
- 처음 쓴 일반 하위 체크는 기간 목록에 자동으로 늘리지 않는다. 최상위 또는 할 일 부모가 없는 폴더/Flow 묶음 아래로 꺼내면 같은 ID를 canonical registry에 한 번 등록한다. 이후 다시 하위로 내려도 등록은 유지한다.
- itemScopes는 모든 원본 체크 항목의 실제 소속을 유지한다. 드래그나 들여쓰기 변경만으로 소속을 바꾸지 않는다.
- 날짜·메모·시간 속성은 각 체크 항목의 직속 속성으로 해석한다. 구조 이동으로 상속 날짜가 달라질 때 이전 유효 날짜를 원문 속성으로 고정한다. 미정도 명시적으로 보존한다.
- progressRecords는 같은 항목 ID+날짜에 연결한다. 구조 이동은 과거 기록을 수정하거나 진행 기록을 추가하지 않는다. 참조 줄은 깊이와 무관하게 원래 canonical ID를 가리킨다.
- 참조 아래 일반 하위 체크는 허용한다. 참조 직속 날짜·메모·시간 속성을 원문에 붙이는 것은 기존대로 거부한다. 원본 속성 수정과 로컬 메모의 구분을 새로 정하는 작업은 이번 범위에 넣지 않는다.
- 들여쓰기만 바꿨을 때 기존 날짜·메모·시간 속성이 소유 항목을 잃는 이동은 반영하지 않는다. 원문과 기존 해석을 함께 보존한다.
- 문서 자원 제한은 기존 1,200행/100,000자와 깊이 0..32(속성은 한 단계 추가)를 사용한다. 깊이 4는 더 이상 사용자 이동 경계가 아니다.

## 모델/UI 연결

- `moveTargets`는 `{beforeLineId,index,depth,parentLineId,label,targetKey}`를 반환한다. 한 경계에서 여러 깊이가 가능하다.
- `moveSubtree(state,docId,lineId,beforeLineId,depth?)`는 원문 전체 상태 전이로 적용한다. 깊이를 생략하는 구 호출은 기존 깊이를 우선한다.
- rowMeta의 kind는 시각 구조(task/subcheck)를, isCanonical/taskId는 동일 항목 정체성을 나타낸다. parentLineId/parentTaskId와 progressTargetId는 별도다.
- 직접 드래그는 가로 위치로 깊이를 고른다. 탭 대안은 경계당 ‘여기’ 버튼과 깊이 순환 버튼이며 두 44px 슬롯을 재사용한다. 키보드 위/아래는 경계, 좌/우는 깊이, Enter는 적용이다.
- 손을 뗐다 다시 잡으면 추가 hold 없이 이동한다. 네이티브 텍스트 선택·IME·스크롤·안전한 취소를 유지한다.
