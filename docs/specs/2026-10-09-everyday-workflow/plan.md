# 계획

1. 현재 제공판/소유5경로/기존 결과를 확인하고 기존 담당의 상태를 확인한다.
2. A를 실제 제품컴포넌트 + 가상 격리 브라우저로 재현한다. 재현한 문제만 수정·표적검사하고 결과를 남긴다.
3. B를 동일 원본/Item 위에서 구현·검사한다. 기존 필터와 새 편집대상을 구분한다.
4. 콘텐츠 담당의 실제 산출물을 인수하여 C의 정상 시험계정 경로를 확인한다. 현재 입력·원본·개인 자료를 보존한다.
5. 정확 후보 source/type/build/관련 회귀와 독립 검토 후 정상 게시·CI·Alpha 절차로 제공한다. 중단 영향/복구 대상을 먼저 보고한다.
6. 최종 제공판·실제 저장/재접속과 남은 불편 최대3개, 다음 목표1개를 인계한다.

각 단계의 전달 대기는 독립 작업의 중단 사유가 아니다. 실제 권한/정책/접근 제한은 해당 행동만 미완료로 남긴다.
