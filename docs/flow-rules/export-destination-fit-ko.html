FlowMe Product Rule / 한국어 HTML
원문 기준일 2026-06-09 · Stage 0 export rule · 통합 승인 아님

내보내기 목적지는 사용자가 말한 플랫폼명이 아니라 산출물의 주된 일로 고른다

이 규칙은 Flow가 FlowMe 밖으로 나갈 때 calendar event, sheet row, memo, workspace note, task-manager project 중 무엇으로 내보낼지 정한다. Stage 0 제품 규칙이며 OAuth, sync, automation, platform clone을 승인하지 않는다.

기본값: portable export 판단 순서: date · row · memo · checklist · task project 금지: account integration · sync · clone
Core

Artifact job first

사용자가 처음 말한 플랫폼보다 산출물의 주된 일을 먼저 본다.

Stage 0

최소 외부 형태

.ics, CSV/XLSX rows, Markdown/plain text, Todoist CSV, Notion Markdown/CSV 중 고른다.

Boundary

Source context travels

source URL, caution, completion criteria, stop/hold condition이 export와 함께 이동해야 한다.

3

4

local check state, preview, source review, feedback 중 무엇이 남는가?

5

account connection, sync, automation, workspace, formula layer, generic task engine을 막는다.

3. 목적지별 규칙

Calendar

date/time이 핵심이면 사용한다. D-day와 repeated events는 .ics가 기본이다. event title, date/time, source, completion criterion, caution이 필요하다.

Sheet

rows/columns가 핵심이면 사용한다. inventory, comparison, progress, menu, document status, filter cycle, study tracker가 좋은 후보다.

Memo/Notion

context가 이동해야 할 때 사용한다. Notion은 기본 surface가 아니라 명시적 workspace handoff일 때만 Markdown/CSV로 넘긴다.

Internal Checklist

execution state가 외부 파일보다 중요할 때 사용한다. first action, completion criteria, source boundary, stop/hold condition을 포함한다.

Todoist/Task CSV

Flow가 task-first이고 사용자가 task manager 목적지를 이미 원할 때만 사용한다. 모든 Flow를 task project로 바꾸지 않는다.

Integration Gate

export fit은 integration readiness가 아니다. repeated use, import friction, stable schema, permission clarity, reversibility, source/safety transfer가 모두 필요하다.

4. 회귀 질문

  • 첫 export option이 artifact의 main job과 맞는가?
  • copy/import 뒤에도 artifact가 쓸 수 있는가?
  • source URL이나 caution이 export와 함께 이동하는가?
  • calendar label과 export wording이 서로 다른 readability needs에 맞게 분리되는가?
  • 반복 export friction이 증명되기 전에 account sync나 OAuth를 제안하고 있지 않은가?
  • FlowMe가 calendar, spreadsheet, Notion workspace, Todoist inbox, automation builder가 되고 있지 않은가?

5. 현재 소스 기준

원문은 2026-06-09 확인 기준이다. Google Calendar, Apple Calendar, Google Sheets, Notion, Todoist 공식 문서는 Stage 0 export/handoff는 지지하지만 account integration을 정당화하지 않는다.
