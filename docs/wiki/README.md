# FlowMe 진행상황 위키

FlowMe가 지금 어디까지 왔는지를 한곳에 모은다. 폰에서는 [지금 FlowMe](now.md)부터 읽는다.

## 페이지

| 페이지 | 내용 | 쓰는 방식 |
| --- | --- | --- |
| [now.md](now.md) | 현재 1장: 결론, 결정 필요, 운영 중, 미검증, 알려진 실패, 다음 | 덮어씀 |
| [backlog.md](backlog.md) | 진행판: 순서, 갈래별 현재, 사용자 몫, 선반, 시스템 상태 | 덮어씀 |
| [owners.md](owners.md) | 담당과 쓰는 경로 | 상태만 바꿈 |

## 갱신 규약

- **위키는 총괄(Claude 메인 세션) 하나만 고치고 커밋한다.** 코덱스와 다른 세션은 `D:/flowme-claude-scratch/inbox/<주제>-YYYYMMDD-HHmm.md`로 회신하고 위키는 읽기만 한다.
- 총괄은 회신이 가리키는 원장 파일을 직접 열어 대조한 뒤 반영한다. 과제 로그 한 줄에 시각, 결론, 근거 경로, "원장 대조함" 또는 "보고만 봄"을 적는다.
- 고치면 바로 커밋하고 그 턴 안에 푸시한다. 커밋 메시지는 `wiki: <과제> — <한 줄>`.
- 아무것도 안 바뀐 턴에는 고치지 않는다. 틀린 내용은 지우지 않고 "정정:" 줄을 추가한다.
- 이 브랜치(`progress-wiki`)에서는 `docs/wiki/` 밖의 파일을 커밋하지 않는다.

## 공개 저장소 규칙

이 저장소는 공개다. 위키에는 계정 이메일, 문서·할 일·소유자 ID, 사용자가 쓴 글 내용, 키·토큰을 적지 않는다. 빌드 ID, 커밋 해시, 원장 경로, 코덱스 스레드 ID는 적는다.

원장(`D:/flowme-…`)과 아직 커밋되지 않은 repo 경로는 링크가 아니라 코드 표기로 적는다. CI 링크 검사가 깨지지 않게 하기 위해서다.

## 증거의 구분

결과표는 AGENTS.md의 구분을 따른다: 구현·검사, 합성 화면(내부 QA), 운영 반영, 실계정, 실폰·관측 사용자. 한 후보의 통과를 다른 후보 칸에 옮겨 적지 않는다.

## 앞으로 할 일 (2단계)

`main`의 상태 문서 4개(STATUS, PROJECT_CONTROL, ROADMAP, specs/README) 맨 위에 "지금 진행상황은 위키 now.md" 한 줄을 넣고, 나머지는 보관으로 둔다. 시점은 사용자가 정한다. 메인 체크아웃의 미커밋 판본은 `D:/flowme-control-docs-snapshot-20261029/`에 바이트 그대로 보존돼 있다.
