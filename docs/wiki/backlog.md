## 지킬 것 (Alpha 제약)

- 핵심 여정(쓰기·한글 입력·체크·저장·재열기)과 자료 보존이 먼저다. 요청하지 않은 리팩터링·추상화는 하지 않는다.
- 운영 배포는 정해진 검사와 통합 QA를 통과하면 총괄이 판단해 하고, 후보·근거·미검증을 기록한다(10/30 결정). DB 변경·새 권한·실데이터 접근은 따로 사용자 승인을 받는다. 안전장치에 막힌 명령은 우회하지 않는다.
- 실계정이나 Alpha 탭으로 확인한 뒤에는 탭을 닫는다. 자동 읽기·응답 크기를 바꾸는 변경은 전송량 영향을 같이 적는다.
- 검증은 코덱스나 쉬는 세션에 맡기고, 두 세션이 같은 파일에 쓰지 않는다([담당표](owners.md)).
- 공개 repo다. 계정 주소·ID·사용자 글은 적지 않는다.
