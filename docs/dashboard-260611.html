FLOW Project Dashboard · 2026-06-11
좋은 콘텐츠를 즉시 실행 가능한
루트로 변환한다
FLOW는 "action compiler"다. 공식 정보·크리에이터 콘텐츠를 사용자가 이미 쓰는 캘린더·체크리스트·스프레드시트·메모로 변환해 바로 실행하게 한다. Notion, 구글 캘린더 등과 경쟁하지 않는다 — 그 도구들을 더 실용적으로 만든다.
콘텐츠→ 날짜 입력→ 아티팩트 생성→ 내 도구로 복사→ 체크 실행→ 피드백
