2026-06-29 · 원컨텐츠 기반 Flow 변환 기획

엄선 원컨텐츠 9개를 Flow Map / Flow / Step / Item으로 자르는 초안

이 문서는 실제 URL과 첨부 파일을 먼저 확인한 뒤, 현재 FlowMe의 Source-to-Flow Conversion Gate와 Flow Map > Flow > Step > Item 기준으로 변환 방향만 정리한 기획 리포트입니다. 앱 구현, seed 추가, 라우트 수정, 공개 노출 판단은 포함하지 않습니다.

실제 URL 열람 첨부 파일 일부 확인 기획안만 작성 사용자 검증 아님

판정 기준

Gate

원문 모양이 먼저

사이트, 글, 표, 영상, 재생목록, 파일 중 무엇이 원본 spine인지 먼저 정하고, UI 컴포넌트나 항목 수를 나중에 정합니다.

사용자 입력

캘린더/투두 수준

생년월일, 시작일, 시험 준비 시작일, 이사일, 결혼식 날짜처럼 산출물 생성에 필요한 값만 상단 입력으로 둡니다.

계층

Step은 최소 실행 단위

Step은 캘린더 일정, 할 일, 시트 row, 진도 row가 될 수 있어야 합니다. Item은 Step 안의 메모, URL, 기준, 체크 행입니다.

모바일 빠른 결론

바로 Flow 후보

이사, 오픽, 이유식

원문 row와 사용자 입력값이 분명합니다. 이사는 D-day, 오픽은 2주/1달 시트, 이유식은 시작일별 식단표가 spine입니다.

버전형 후보

결혼, 신차 구매

결혼은 원문별 타임라인/체크리스트 버전을 분리하고, 신차 구매는 구매 방식별 버전으로 나누는 편이 안전합니다.

공식/민감 주의

영유아 예방접종

공식 일정표 row만 사용하고, 접종 판단이나 지연접종 해석은 병원/공식 확인으로 내려야 합니다.

전체 단위는 보류

펀맘 전체, 올블랑 채널

사이트/채널 전체는 너무 넓습니다. 카테고리 하나 또는 재생목록 하나를 골라야 FlowMe gate를 통과합니다.
