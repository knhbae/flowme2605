저장한 Flow 관리 화면 P0 반영

목표는 기능을 더 붙이는 것이 아니라, 저장한 Flow가 많아졌을 때도 사용자가 오늘 처리할 일부터 바로 볼 수 있게 만드는 것이다. 이번 검증은 실제 /my 화면을 기준으로 Today, 밀린 항목, 완료 항목, 캘린더 기준월, 모바일 상세 시트를 확인했다.

사용자용 v3 화면 · 적용 범위 문서 · 상태별 v2 PoC

이번 판단

빈 카드보다 실행 가능한 항목을 먼저

Today 탭 상단 압축모바일에서 헤더 간격과 보조 설명을 줄여 실제 실행 영역을 더 빨리 노출했다.
빈 오늘 카드 제거오늘 남은 일이 0개이고 밀린 항목이 있으면 빈 Today 카드를 숨기고 밀린 항목을 바로 보여준다.
데모 기준월 고정데모 Today가 2026-05-28이면 캘린더도 2026-05로 열리게 맞췄다.

아직 완료로 보지 않는 이유

이번 P0는 Today 화면의 우선순위를 정리한 것이다. 전체 목표는 저장한 Flow가 1개, 4개, 8개 이상일 때 관리/실행이 모두 직관적인지 확인하는 것이므로 아직 완료가 아니다. 다음으로는 Flow 탭의 전체 목록 찾기, 상태판 버튼 이름, 완료 버튼의 노출 범위를 더 줄일 수 있는지 봐야 한다.
