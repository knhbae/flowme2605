실제 온라인 콘텐츠 16개로 Flow of Flows 가능성을 판정했다

이 문서는 실제 온라인 콘텐츠가 상위 실행 흐름, 중간 묶음, 하위 실행 콘텐츠, 실제 일정/표/체크 항목으로 자연스럽게 내려가는지 확인하기 위한 1차 조사다. 검색 결과 제목만 보지 않고, 공개 페이지에서 확인되는 재생목록, 강좌 목차, 일정표, 월령표, 식단표, D-day 표 같은 구조를 기준으로 판정했다.

판정 기준

Strong Parent

원문에 주차, 단원, 월령, 표, D-day 같은 상위 구조가 있고, 하위 실행 콘텐츠가 3개 이상 자연스럽다.

Child Only

단일 영상이나 단일 글로는 실행 가치가 있지만, 그 자체가 큰 흐름은 아니다.

Reference

공식 일정, 자격 조건, 주의사항처럼 하위 실행 콘텐츠의 출처/메모로 붙이는 것이 적합하다.

Park

구조가 약하거나, 실행보다 읽기/홍보에 가깝거나, 원문 기반으로 하위 콘텐츠를 만들기 어렵다.

주의: 이 조사는 구조 적합성 검토다. 실제 사용자가 저장/체크/재방문했다는 검증은 아니다.

가장 강한 원문 형태

  • 주차형 운동 프로그램
  • 학년/단원/강의 목차
  • 월령/회차 공식 일정표

  • D-day 체크리스트

상위 실행 흐름으로 약한 형태

  • 단일 팁 영상
  • 후기 중심 글
  • 홍보 랜딩 페이지
  • 원문 구조 없는 조언 모음
  • 링크 모음만 있는 글

선정 이유: 세 후보 모두 실제 원문에 하위 구조가 있고, 사용자가 전체 저장/부분 저장을 할 이유가 있으며, 공통 입력값이 1~3개로 제한된다.
