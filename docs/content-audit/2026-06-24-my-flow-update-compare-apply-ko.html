2026-06-24 P1 구현 기록

My Flow 업데이트 비교/적용 구현 리포트

저장한 Flow Map의 원문/발행본이 바뀌었을 때, 사용자가 무엇이 달라졌는지 확인하고 새 기준으로 표시할 수 있는 localStorage 기반 update bridge를 구현했습니다. 체크와 메모는 조용히 덮지 않습니다.

비교 보기 새 기준으로 표시 숨기기 유지 child Flow merge 아님 계정 저장 아님

사용자 흐름

1. 저장된 지도사용자는 이전 버전의 Flow Map을 내 Flow에 저장해 둔 상태입니다.
2. 새 발행본 감지저장 snapshot과 현재 발행 snapshot의 버전, Step 수, 출처 확인일을 비교합니다.
3. 변경 보기사용자는 영향을 받는 Flow와 Step 수 변화를 카드 안에서 확인합니다.
4. 새 기준으로 표시저장한 지도 snapshot만 갱신합니다. 체크/메모/child Flow 저장 기록은 유지됩니다.

이번 구현 범위

비교 패널

저장 버전, 현재 버전, affected Flow, Step 수 변화, 출처 확인일 변화를 보여줍니다.

안전한 적용

flow:map:saved:{mapId}와 persistence record만 새 기준으로 갱신합니다.

숨기기 유지

당장 검토하지 않을 사용자는 기존처럼 현재 saved/current 버전 notice를 숨길 수 있습니다.

명시적 경계

새 child Flow 추가, 제거, row-level conflict merge는 아직 구현하지 않았습니다.

남은 리스크

  • 실제 발행 version 생성과 연결되지는 않았습니다.
  • 계정 기반 저장/권한/히스토리는 아직 없습니다.
  • 새 child Flow가 생기는 복잡한 merge는 다음 정책 결정이 필요합니다.
