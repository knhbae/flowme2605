## 이번 slice에서 닫은 것

- 공개 Flow의 큰 외곽 카드와 중첩 카드 위계를 제거했다.
- 사용자 실행 순서를 `결과 이해 → 필요한 날짜 입력 → 주요 항목 확인 → 내 Flow 저장`으로 정리했다.
- Flow 단위 내보내기를 하단의 접힌 2차 행동 한 곳으로 통합했다.
- 타임라인은 모바일에서 할 일 8개를 먼저, wide에서 작은 일정 개요와 넓은 실행 목록을 보여준다.
- 긴 체크리스트는 핵심 8개를 먼저 보여주고 나머지는 펼친다.
- 점검형 보류 기준은 먼저 보이되 기록 폼은 필요할 때 연다.
- 루틴형은 모바일에서 현재 회차와 이번 주를 먼저 보여주고 미래 주차와 지난 기록을 펼친다.
- 제작자 귀속과 `원문 기준 실행본` 신호를 첫 화면에 올렸다.

## 의도적으로 남긴 것

- 기준 Flow의 출처, 상세, 주의, 제작자 귀속은 삭제하지 않았다.
- 사용자 개인본, 캘린더·시트·메모 export, My Flow 저장 경로를 유지했다.
- 리뷰, 수정 요청, 제작자 업데이트 수락, 제작자 성과 환류는 이 slice에서 구현하지 않았다.
- My Flow와 Calendar 전체 시각 재설계는 다음 slice다.
