제작자 Source Row Editor 구현 리포트

목적은 FlowMe가 단순 실행 화면뿐 아니라, 제작자가 원문 구조를 Step과 Item으로 바꾼 결과를 검토하고 초안으로 저장할 수 있는 플랫폼 축을 갖추는지 확인하는 것입니다. 이번 구현은 실제 발행 시스템이 아니라 localStorage 기반 P0 baseline입니다.

빌드 통과 unit/e2e 통과 모바일 overflow 없음 계정 저장 아님 발행 적용은 다음 slice

이번에 만든 것

제작자 화면 분리

/flow-maps/[map]/creator가 사용자 실행 화면이 아니라 제작자 편집 화면으로 동작합니다. 공개 화면과 저장 후 사용자 화면은 링크로만 연결됩니다.

원문 행과 생성 결과 비교

원문에서 가져온 행, 생성된 Step 제목, 저장 위치, 원문 링크, Item fallback을 한 화면에서 비교하고 수정합니다.

초안 저장

수정 내용은 flow:map:creator-draft:{mapId}에 저장됩니다. 공개 버전은 변경하지 않습니다.

모바일 보완

모바일에서 원문 행을 누르면 편집 패널로 이동합니다. 이전 PoC에서 반복 지적된 “눌렀는데 아래에서 열리는” 문제를 줄였습니다.
