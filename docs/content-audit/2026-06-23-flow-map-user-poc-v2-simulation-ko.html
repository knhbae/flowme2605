이 문서는 사용자 화면에 넣지 않는 평가/피드백만 담습니다. 실제 사용자가 확인할 화면은 아래 링크의 별도 HTML입니다.

사용자용 Flow Map v2 열기

콘텐츠 생성 원칙

중1 수학

통과 모델

  • Flow Map: 중1 수학 전체 진도
  • Flow: 원문 큰 단원 8개
  • Step: 각 큰 단원 안의 하위 개념 링크
  • Item: 원문 링크, 완료 표시, 막힌 부분 메모
  • 입력: 없음

이전 버전처럼 큰 단원을 Step으로만 두면 Flow of Flow가 약해진다. 원문은 큰 단원 아래 하위 링크가 있으므로 큰 단원을 Flow로 두는 편이 맞다.

영유아 검진·접종

통과 모델

  • Flow Map: 아이 건강 일정
  • Flow: 건강검진, 구강검진, 예방접종 확인
  • Step: 공식 기간 또는 조회 시점
  • Item: 공식 기간 확인, 예약/문진표/결과 위치 메모
  • 입력: 아이 생년월일 1개

공식 검진 기간은 여러 날의 할 일이 아니라 한 Step의 기간 정보다. 예방접종은 FlowMe가 판단하지 않고 공식 일정표/조회로 보내야 한다.

페르소나 리허설

A. 중1 수학 진도 사용자

  1. 수학방 중1 목차를 읽고 하위 개념 링크가 많아 저장 필요를 느낀다.
  2. FlowMe 공개 Flow에서 저장 후 바로 내 진도표로 이동한다.
  3. 이어보기에서 1단원 소인수분해의 하위 개념을 본다.
  4. 거듭제곱을 완료로 체크하고, 막힌 개념만 메모한다.
  5. 다음 방문 때 진도표에서 1단원의 완료율과 다음 항목을 확인한다.

결과 원문 구조와 사용 행동이 일치한다. 날짜 입력을 요구하지 않아 복잡도가 낮다.

B. 영유아 일정 사용자

  1. 공식 검진 시기와 예방접종 일정표를 보고 놓칠까 봐 저장한다.
  2. 생년월일 하나를 입력하고 내 캘린더로 저장한다.
  3. 다음 일정에서 1차 건강검진 기간과 해야 할 메모를 본다.
  4. 캘린더 탭에서 1월, 3월, 5월의 확인 일정을 훑는다.
  5. 방문 후 결과지 위치만 메모하고 공식 안내 링크를 필요할 때 연다.

결과 공식 정보와 사용자 메모가 분리된다. 의료 판단을 하지 않고 예약/문진표/결과 위치만 남긴다.

발견된 문제와 반영

Blocking: 사용자 화면과 검토 화면 혼재

이전 사용자 PoC에는 콘텐츠 선택, 저장 전, 내 Flow, 제작자/검토 뉘앙스가 한 화면에 섞였다. v2에서는 사용자 화면과 리포트를 파일 단위로 분리했다.

High: 중1 수학 계층 오류

이전 모델은 큰 단원을 Step처럼 보여 Flow of Flow가 약했다. v2에서는 원문 큰 단원을 Flow, 하위 개념 링크를 Step으로 바꿨다.

High: 영유아 공식 기간 과분해 위험

검진 가능 기간을 여러 날짜 항목으로 만들면 진행률과 캘린더가 부풀어진다. v2에서는 기간을 한 Step의 정보로 유지했다.

Medium: 탭과 카드 밀도

공통 탭을 강제하지 않고 콘텐츠에 맞게 탭을 바꿨다. 수학은 이어보기/진도표/전체 지도, 영유아는 다음 일정/캘린더/전체 일정으로 분리했다.
