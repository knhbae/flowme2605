## 001. 삼성전자서비스 시스템 1WAY 필터 청소

- 상태: 원문 확인됨
- 카테고리: 집/가전 관리
- 출처: https://www.samsungsvc.co.kr/video/1393266/
- 원문 제목: [삼성 에어컨] 시스템, 1WAY 필터 청소 및 관리 방법 안내

원문 요약:
시스템 에어컨 1WAY 필터 청소를 제품 이해, 전원 차단, 필터 분리, 세척/건조, 장착, 필터 리셋 단계로 안내한다. 사용 환경에 따라 다르지만 2주 1회 또는 청소 알림 시점이 반복 주기로 제시된다.

Flow 콘텐츠화:
- 구조/목적지: timeline_or_calendar / 캘린더 + 체크
- 캘린더 예시: 관리 기준일 입력 / 청소/점검 반복일 생성 / 이상 증상 시 서비스 문의 일정 생성
- 체크리스트 예시: 전원 차단 / 필터/외관 상태 확인 / 세척 또는 먼지 제거 / 완전 건조/장착 / 알림 리셋 또는 다음 점검일 기록
- 루틴 예시: 2주~1개월 주기 필터 확인 / 3~5월 여름 전 사전점검
- 완료 기준: 청소/점검을 완료하고 다음 점검일 또는 문의 상태를 기록함
- 출처/위험 분리: 분해, PCB, 내부 세척은 일반 사용자 실행이 아니라 전문가 문의/보류로 분리
