## 판정 기호

| 기호 | 의미 |
|---|---|
| `O` | 실제 화면·코드·연속 상태에서 요구를 충족함을 확인 |
| `△` | 일부 충족하지만 중복·예외·미확인 상태가 남음 |
| `X` | 문제를 재현했거나 구조적으로 충족하지 않음 |
| `TBD` | 자료 또는 검증이 부족해 판정할 수 없음 |
| `N/A` | 의도적으로 적용하지 않으며 이유가 문서화됨 |

자동 테스트 통과, 정적 캡처, 디자인 제안만으로 사용자 이해도를 `O`로 판정하지 않습니다.
