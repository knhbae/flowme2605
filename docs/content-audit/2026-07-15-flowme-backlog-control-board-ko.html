사용자

실제 환경과 가치 판단의 소유자

  1. P35 후보를 keep, bounded fix, block 중 하나로 판단필요하면 route, viewport, 기대/실제 차이로 코멘트
  2. P35 뒤 승격할 작업을 하나만 선택텍스트 저작, 근거 기반 수정, 또는 보류
  3. 실사용·Calendar 왕복·기기 간 복원이 필요할 때 직접 확인자동화 근거와 섞지 않음

AI

준비, 정리, 검증, 다음 작업안의 소유자

  1. 분산 작업을 원격 브랜치에 보존하고 안전하게 통합사용자 변경과 원시 리뷰 자료를 임의 삭제하지 않음
  2. docs, unit, build, E2E와 연구 validator를 실행실패·미실행·관찰 0을 그대로 표시
  3. STATUS, ROADMAP, spec index와 이 HTML을 동기화연구를 제품 구현으로 부풀리지 않음
같은 완료가 아님

P35의 `405 / 405` E2E는 구현 회귀 근거입니다. 텍스트 저작 프로토타입은 설계 근거이고, corpus lab은 연구 근거입니다. 어느 것도 관찰 사용자, 실제 Calendar/VTODO 왕복, production 배포를 대신하지 않습니다.
