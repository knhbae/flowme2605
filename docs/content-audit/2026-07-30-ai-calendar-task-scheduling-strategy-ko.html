03 / 실제 제품 화면

같은 AI라도
사용자가 확인하는 지점은 다르다.

중요한 것은 “AI 기능이 있다”는 문구가 아니다. 언제 제안만 하고, 언제 실제 일정을 바꾸며, 사용자가 어느 단계에서 멈출 수 있는지를 봐야 한다.

08 / 지금 만들 범위

지금 만들 것과
의도적으로 미룰 것을 나눈다.

FlowMe의 차별화는 “더 많이 자동화”가 아니다. 무엇을 원문에서 가져왔고, 무엇을 사용자가 정했으며, 어떤 내용이 바뀌었는지 분명히 하는 데 있다.

지금 만들기

  • 원문과 원문 항목을 그대로 보존
  • 예상 시간·마감일·날짜 이동 가능 여부 표시
  • 정해진 규칙으로 일정 후보 계산
  • 바뀐 할 일만 전후 비교
  • 적용 내역·변경 이력·되돌리기

나중에 검토

  • 외부 캘린더 일정을 읽고 충돌 피하기
  • 양방향 동기화와 계정 저장
  • 앱을 열지 않아도 자동으로 일정 바꾸기
  • 여러 기기에서 조건에 맞춰 자동 실행
  • 제작자 원문 변경과 개인 일정을 자동으로 합치기

만들지 않기

  • 기존 캘린더를 대체하는 범용 AI 캘린더
  • 원문에 없는 날짜·예상 시간·준비물 추가
  • 날짜 없는 할 일을 캘린더에 강제로 배치
  • 사용자 승인 없는 외부 일정 변경
  • 전체 Flow를 숨긴 채 오늘 할 일 3개만 강제 추천

6주 안에 확대·수정·중단을 결정한다.

구현 범위를 넓히기 전에 FlowMe가 맡을 일과 사용자가 확인할 단계를 먼저 정한다. 그다음 한 가지 사용자 여정의 가치와 외부 캘린더 저장 안정성을 따로 검증한다.

시작 전

12명 관찰

5~6주

판정

통과하면 확장하고, 이해하기 어려우면 수정하며, 가치가 없으면 중단한다.

외부 캘린더 연결 전 확인

시간대·종일 일정·반복·수정·삭제·출처 기록이 Google·Outlook·Apple에서 제대로 저장되고 돌아오는지 확인한 뒤에만 직접 연결한다.
