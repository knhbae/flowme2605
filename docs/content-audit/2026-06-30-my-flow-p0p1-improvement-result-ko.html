My Flow 저장 후 실행 UX

P0/P1 개선 결과

저장한 Flow를 실제 사용자처럼 3개 추가한 뒤, 오늘 실행, Step 상세, Flow별 보기, 캘린더를 모바일 기준으로 다시 시뮬레이션했다. 이번 단계의 목표는 상품화 완성이 아니라 “내 Flow에서 다음 행동을 바로 알 수 있는 기준선”을 만드는 것이다.

빌드 통과 단위 테스트 통과 대상 E2E 8개 통과 모바일 시뮬레이션 PASS

무엇을 고쳤나

Today 구조

오늘 할 일이 없으면 빈 상태를 먼저 보여주고, 지난 일정은 “정리” 카드로 접었다. 사용자는 밀린 과거 목록보다 지금 이어할 항목과 다음 할 일을 먼저 본다.

Step 상세

Step을 누르면 해당 카드 바로 아래에 상세가 열린다. 모바일에서는 원문과 내보내기 기능을 접어서, 체크와 메모가 먼저 보이도록 했다.

Flow 탭

Today에서 열어둔 상세가 Flow 탭으로 따라오지 않게 분리했다. Flow 탭은 저장한 묶음과 각 Flow의 다음 항목을 보는 화면으로 정리했다.

캘린더 역할

내 Flow 내부의 로컬 캘린더 탭은 제거하고, 글로벌 캘린더 탭에서 날짜별 실행 항목을 본다. 저장 후 미래 실행월로 자연스럽게 잡히도록 조정했다.

문구 정리

사용자 화면에서 내부 구조를 덜 드러내도록 “Flow” 대신 “묶음”, “목록”, “원문 보기” 중심으로 일부 카피를 정리했다.

상품화 전 추가 설계

카드 밀도, 리뷰/사용수/신뢰 신호, 홈과 Flow 찾기의 성격 차이는 아직 제품 방향과 콘텐츠 수가 늘어난 뒤 다시 봐야 한다.

컨텐츠 확장 검증

대표 컨텐츠 2~3개 외에 사용자가 엄선한 실제 원문 후보들을 같은 기준으로 Flow Map/Flow화해야 한다.

Step 데이터 모델

Step은 나중에 캘린더 일정 수준의 ICS 필드, 반복, 알림, 장소, URL을 더 자연스럽게 품을 수 있어야 한다.

관찰 사용자 검증

이번 결과는 자동 시뮬레이션과 내부 UX 리뷰다. 실제 사용자 행동 데이터가 아니므로 “사용자 검증 완료”로 표현하지 않는다.
