FlowMe 첫 전략 목표: URL-first P0 루프는 확정 가능하다

CEO 보고 결론은 명확하다. FlowMe는 지금 Home을 다시 꾸미거나 AI 생성기를 전면화할 단계가 아니다. 사용자가 외부 URL을 붙이면 기존 Flow를 먼저 찾아주고, 검증된 결과만 저장/export/My Flow로 이어주는 실행 변환 레이어를 먼저 확정해야 한다.

URL-first P0 루프는 첫 전략 목표로 확정한다. 단, 다음 단계는 기능 확장이 아니라 export pack v1, source/version/trust ledger, canary 8~12개 검증으로 좁힌다.

주의: 현재 검증은 구현/QA 검증이다. 실제 사용자 행동 검증 또는 live web extraction 검증으로 표현하면 안 된다.

1. 지금 무엇을 확정하는가

확정

URL-first / lookup-before-AI

사용자가 URL을 넣으면 같은 canonical URL의 기존 Flow를 먼저 찾는다. AI는 기본 경로가 아니다.

위치

/flows 상단

Home hero 전면 개편보다 Flow 찾기 화면의 URL lookup entry가 현재 IA에 맞다.

다음 투자

Export + Trust

새 기능을 늘리기보다 export pack v1과 source/version/trust ledger를 먼저 굳힌다.

2. URL-first P0 루프

1. URL 입력사용자가 `/flows`에서 원문 URL을 붙인다.
2. Canonical lookuptracking query를 제거하고 기존 Flow 변환본을 찾는다.
3. 상태 분기hit / needs_review / miss로 source gate를 적용한다.
4. Preview & Exporthit만 저장 전 보기, `.ics`, Markdown, checklist 기대값을 보여준다.
5. My Flow 계속저장 후 Today, Calendar, Step detail, memo, 재-export로 이어진다.
상태사용자 문구 방향허용 행동막아야 할 것
hit이미 만들어진 Flow가 있어요저장 전 보기, export 기대값, My Flow 저장fake 사용량, raw slug, 내부 `source-backed` 노출
needs_review원문 확인이 필요해요preview-only, 원문 확인 안내저장/export 허용, 확정 표현
miss아직 변환된 Flow가 없어요수집/요청/검토 대기AI 즉시 생성 기대, 기존 Flow가 있는 것처럼 표현

3. 구현/QA 상태

현재 구현은 P0 판단에 충분한가?

충분하다. 단, live extraction이나 사용자 검증은 아니다.

현재 slice는 `/flows` URL lookup entry, hit/needs_review/miss result sheet, 기존 source-backed Flow hit, AI disabled, mobile overflow guard까지 검증했다.

6. Export Pack v1 판단

Calendar .ics

날짜, 기간, 마감, 반복, 원문 링크를 가진 Step을 사용자의 기존 캘린더로 옮긴다. Google/Outlook OAuth보다 먼저다.

Markdown

원문 링크, Flow title, Step heading, checklist, caution을 Obsidian/Notion/메모로 가져갈 수 있게 한다.

Checklist

가장 낮은 마찰의 복사/붙여넣기 artifact다. 여행, 이사, 구매, 행정 후보에서 즉시 가치가 있다.

판단: P0 export v1은 `.ics + Markdown + checklist`로 충분하다. CSV/sheet는 식단/진도표 canary에서 필요하지만 P0 전체를 늦출 정도로 먼저 만들 필요는 없다.

8. 임원 의사결정 항목

이번에 결정

1. `/flows` URL-first를 첫 public acquisition loop로 둔다.

2. Export v1은 `.ics + Markdown + checklist`로 시작한다.

3. Canaries는 8~12개 유형 mix로 검증한다.

4. AI는 miss/fallback queue로 둔다.

아직 결정하지 않음

1. Home hero 전면 재설계

2. Direct Google/Todoist/Notion OAuth

3. Creator marketplace

4. Full editor/diff/version graph
