신규 외부 콘텐츠 검색 확장 큐

기존 가전/결혼/중고차 중심 후보가 반복되는 문제를 줄이기 위한 새 후보 목록입니다. 아직 대표 후보 확정이 아니라, 원문을 다시 열어 실제 Flow 변환이 가능한지 확인해야 하는 대기열입니다.

기존 상위 후보 카테고리는 최대 2개까지만 새 큐에 유지한다.
육아 놀이, 앱 설정, 요리, 텃밭, 반려동물 입양, 생활 행정처럼 다른 실행 맥락을 우선 추가한다.
각 후보는 원문 재확인 후 Flow 변환 예시와 가중 점수를 다시 매긴다.
#1 육아/놀이

공룡 발자국 엄마표 미술놀이

원문 후보

네이버 블로그

도안 다운로드, 공감 요청, 인스타그램 태그 유도처럼 제작자-사용자 상호작용 단서가 있다.

왜 새 후보인가

기존 후보에 부족했던 “아이와 오늘 할 놀이” 카테고리다.

예상 Flow 형태

주말 놀이 캘린더 + 준비물 체크 + 활동 메모

놀이 날짜 / 아이 연령 / 준비물 보유 여부

샘플 실행 항목

  • 공룡 발자국 도안 인쇄
  • 물감/매직페이퍼 준비
  • 놀이 후 작품 사진은 선택 메모
첨부 도안 접근 가능 여부와 댓글/공감 수 확인.
#2 생활 이벤트

결혼식 하루 전/당일 준비물 PDF

원문 후보

네이버 블로그

PDF 템플릿 공유와 준비물 항목이 있어 사용자가 저장/수정하려는 의도가 강하다.

왜 새 후보인가

기존 결혼 12개월 타임라인보다 훨씬 짧고 구체적인 D-1/D-day 체크 Flow다.

예상 Flow 형태

D-1 체크리스트 + 당일 준비물 메모

예식일 / 신랑/신부 역할 선택

샘플 실행 항목

  • 웨딩밴드/예복/구두 확인
  • 헬퍼비/사회자 사례금 봉투 준비
  • 가족 연락처 PDF 링크 메모
PDF 파일 항목을 직접 확인해 체크리스트로 옮길 수 있는지 검토.
#3 여행/통신

일본 여행 eSIM 등록 방법

원문 후보

네이버 블로그

구매, 발권, QR 등록, 활성화, 레이블 지정까지 순서가 분명하다.

왜 새 후보인가

여행 준비물보다 더 구체적인 “출국 전 설정 Flow”다.

예상 Flow 형태

출국 D-3 체크리스트 + 설정 메모

출국일 / 사용 기기

샘플 실행 항목

  • eSIM 구매 후 발권
  • 한국에서 QR 미리 등록
  • 도착 후 회선 전환
광고/협찬 여부와 실제 등록 단계의 일반화 가능성 확인.
#4 텃밭/가드닝

6월 주말농장 작물 10가지

원문 후보

네이버 블로그

작물별 심는 시기와 관리 포인트가 있어 계절 캘린더 후보가 된다.

왜 새 후보인가

실내 식물 물주기와 다른 “계절/작물별 농사 일정” 카테고리다.

예상 Flow 형태

월별 작물 캘린더 + 작물별 체크 메모

시작 월 / 작물 선택

샘플 실행 항목

  • 6월 심을 작물 선택
  • 본잎 5~7장 순지르기 알림
  • 수확 예상 시점 메모
각 작물별 날짜/관리 단계가 원문에 충분한지 확인.
#5 반려동물/입양

강아지 입양 전 체크리스트

원문 후보

PDF/콘텐츠

입양 전 체크리스트와 교육 필요성이 언급된 자료형 콘텐츠다.

왜 새 후보인가

기존 반려동물은 건강/청소 쪽이었고, 입양 준비 여정은 별도 대표성이 있다.

예상 Flow 형태

입양 전 체크리스트 + 첫 주 적응 캘린더

입양 예정일 / 강아지 나이

샘플 실행 항목

  • 가족 동의 확인
  • 공간/용품 준비
  • 입양 후 첫 병원 예약 메모
원문이 체크리스트로 충분히 구조화되어 있는지 직접 확인.
#6 육아/장비

신생아 카시트 설치/선택 체크

원문 후보

네이버 블로그

설치 방법, 사용 시기, 성장에 따른 조정 포인트가 있다.

왜 새 후보인가

육아 식단/놀이가 아니라 “육아 장비 설치”라는 실사용 Flow다.

예상 Flow 형태

출산 전 체크리스트 + 설치 메모

출산 예정일 / 차량/카시트 모델

샘플 실행 항목

  • 카시트 방향 확인
  • 이너시트/벨트 높이 확인
  • 퇴원 전 설치 완료
브랜드 홍보/후기와 일반 설치 체크를 분리.
#7 금융/앱 설정

토스뱅크 체크카드/OTP 등록

원문 후보

네이버 블로그

카드 발급 후 OTP 등록이라는 순서형 앱 설정 흐름이 있다.

왜 새 후보인가

돈 관리 조언이 아니라 구체적인 앱 설정 체크 Flow다.

예상 Flow 형태

설정 체크리스트 + 완료 메모

카드 수령일

샘플 실행 항목

  • 카드 수령 확인
  • 앱에서 OTP 등록
  • 고액 이체 인증 방식 확인
현재 앱 UI와 절차가 최신인지 공식 도움말로 재확인.
#8 요리/레시피

노밀가루 바나나 땅콩버터 빵

원문 후보

레시피/유튜브 기반

유튜브 출처 기반 레시피이며 재료, 도구, 조리 시간이 명확하다.

왜 새 후보인가

레시피는 FlowMe가 “한 번 실행 체크리스트”로 담을 수 있는지 보는 새 카테고리다.

예상 Flow 형태

요리 체크리스트 + 장보기 메모

요리 날짜 / 분량

샘플 실행 항목

  • 바나나/계란/땅콩버터 준비
  • 에어프라이어 예열
  • 20분 조리 완료
원본 유튜브 영상 링크와 조리 단계의 저작권/요약 범위 확인.
#9 생활 행정

사전투표소 찾기/준비물

원문 후보

네이버 블로그

장소, 준비물, 휴대폰 보관 등 방문 전 체크가 있다.

왜 새 후보인가

기존 여권/차량 행정 외에 선거/공공 이벤트형 Flow 가능성을 본다.

예상 Flow 형태

투표일 캘린더 + 준비물 체크

투표 예정일 / 지역

샘플 실행 항목

  • 사전투표소 위치 확인
  • 신분증 챙기기
  • 휴대폰 보관 안내 메모
지역/날짜 정보는 공식 선관위 링크와 함께 처리해야 함.
#10 차량/행정

자동차 검사소 예약/방문 준비

원문 후보

네이버 블로그

예약, 접수, 검사비/과태료 정보 등 방문 단계가 있다.

왜 새 후보인가

차량 구매가 아니라 보유 차량 정기 행정 Flow다.

예상 Flow 형태

검사 만료일 캘린더 + 방문 체크리스트

검사 만료일 / 검사소

공식 자동차검사 예약 링크와 지역 업체 홍보를 분리.

해외구매대행 절차 체크리스트

네이버 블로그

특정 업체 홍보성 여부와 일반화 가능한 체크만 분리.
#12 텃밭/가드닝

베란다 채소 키우기 시작

원문 후보

도서/기사/PDF

베란다 채소밭 경험과 초보자가 한 작물부터 시작하는 맥락이 있다.

왜 새 후보인가

예상 Flow 형태

작물 / 파종일

샘플 실행 항목

  • 물주기 확인
  • 수확 예상일 메모
실제 실행 단계가 충분히 추출되는 원문인지 확인.
