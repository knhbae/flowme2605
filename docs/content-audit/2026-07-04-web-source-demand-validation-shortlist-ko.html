Demand 기준 canary

  1. 아정당 이사 준비 체크리스트보이는 수요 강함 + canary 후보: 수요 신호, 최신성, copy intent, source row가 모두 강함
  2. 삼성 에어컨 필터 청소 방법보이는 수요 강함 + canary 후보: 가전 관리 루틴의 대표 후보
  3. 질병관리청 표준 예방접종 일정표높은 의도 추론 + canary 후보: 보이는 조회수는 없지만 공식성, PDF row, 부모의 날짜 민감도가 강함
  4. 오픽만수르 모의고사 공부 방법높은 의도 추론 + canary 후보: 파일 다운로드와 시험 계획표 copy intent가 강함
  5. 국세청 연말정산 체크리스트높은 의도 추론 + canary 후보: 공식성과 시즌 반복성이 강하지만 세무 판단은 원문 링크 중심
  6. 국립재활원 영유아 건강검진높은 의도 추론 + canary 후보: 공식 일정성과 부모 반복 일정 수요가 강함
  7. 안전운전 통합민원 면허 갱신/적성검사높은 의도 추론 + canary 후보: 공식 페이지이고 사용자가 그대로 준비물을 옮겨 적을 이유가 명확함
