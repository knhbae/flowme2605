완료 control 1곳

가시성 기반 Undo

완료 행이 실제로 사라질 때만 되돌리기를 보이며, 보이는 행은 checkbox로 다시 엽니다.

Shape honesty

Memo 기록, Routine series, Sheet 순서를 일반 Todo 진행률로 왜곡하지 않습니다.

Wide workspace

library, execution canvas, inspector가 각각 선택, 실행, 맥락 명령을 맡습니다.
