진행자용 · 사용자 화면 아님

My Flow v5 정리 시뮬레이션

v4의 저장 개수별 실험과 유형 혼합 화면을 하나로 합치되, 사용자 화면에서 테스트용 탭과 내부 설명을 제거했다. 사용자는 같은 내 Flow 화면을 보고, 진행자는 URL 모드로 1개/4개/8개/20개 이상 저장 상태를 확인한다.

기본: 8개 혼합 1개 저장 4개 저장 20개 이상 저장 관찰 키트 서비스 UX 백로그

판정

v5는 현재까지 가장 제품 화면에 가깝다

사용자 화면에서 저장 개수 테스트 탭을 제거했고, 유형 필터도 제거했다. 남은 구조는 오늘 항목, 필요할 때 여는 Flow 찾기, Step 상세, 체크, 메모, 외부 앱 텍스트뿐이다. 캘린더/투두 앱보다 크게 무겁지 않은 수준으로 내려왔다.

줄인 것

기능보다 실행 순서를 우선했다

이전 상태v5 처리이유
저장 개수별 상태 탭 사용자 화면에서 제거. URL 모드로만 테스트. 실제 사용자는 저장 개수를 선택하지 않는다. 테스트 장치가 제품처럼 보이면 혼란을 만든다.
유형 필터 검색과 짧은 목록으로 대체. 일정/루틴/학습/체크/보관 필터는 제작자/내부 분류에 가깝고, 사용자는 제목으로 찾을 가능성이 높다.
1개 저장에서도 날짜 rail/Flow 찾기 1개 모드에서는 바로 Step 상세만 노출. 한 개만 저장했을 때는 관리 화면이 아니라 실행 화면이면 충분하다.
20개 이상 전체 노출 Flow 찾기는 처음 8개만 보이고, 오늘 목록도 4개까지만 먼저 보인다. 첫 화면은 찾기 시작점이어야지 전체 보관함이 아니어야 한다.

드라이런

상태별 예상 저니

1개 저장사용자는 상세를 바로 보고 체크 1개와 메모만 남긴다. Finder, rail, 전체 목록이 없어서 과한 관리 느낌이 줄었다.
4개 저장오늘 목록에서 시작하고, 필요할 때 Flow 찾기를 연다. 검색 없이도 4개 전체가 한 번에 보인다.
8개 혼합날짜형, 루틴형, 학습형이 같은 Step row로 보인다. 사용자는 유형을 배우지 않고 제목으로 열 수 있다.
20개 이상검색이 우선이고 전체 펼침은 보조다. 오늘 항목도 처음 4개까지만 보여 긴 목록이 상세 실행을 밀지 않는다.
재방문오늘/이번 주/보관 rail로 현재 실행 시점만 바꾸고, 선택한 Step 상세는 같은 구조를 유지한다.
외부 앱Item은 체크리스트로 보이지만, 다른 앱에서는 접힌 텍스트로 붙일 수 있다.

User Need Fit4저장한 Flow를 다시 열어 오늘 실행하는 상황이 분명하다.사용자가 첫 화면에서 오늘 항목을 먼저 누르는지 확인.
Execution Clarity4Step 상세에 체크, 메모, fallback이 바로 있다.1개 저장에서 상세만 보여도 충분한지 확인.
Content Fidelity3예시 항목은 기존 통과 Flow 기준을 따르지만, 원문 재검토 범위는 아니다.실제 public 후보에서는 source gate가 필요.
Portability4Step과 Item이 외부 앱 텍스트로 접힌다.실제 캘린더/투두 export 문구는 별도 확인.
Cognitive Load4테스트 탭과 유형 필터를 제거했다.20개 이상에서 전체 보기 버튼이 너무 약하지 않은지 확인.
Copy Specificity4버튼은 Flow 찾기, 전체 Flow 보기, 메모 저장됨처럼 결과가 보인다.Flow 찾기라는 이름이 충분히 자연스러운지 확인.
Source/Safety3민감 항목은 판단하지 않는 구조지만 source 분리 화면은 축약되어 있다.건강/법률성 Flow는 공개 전 source panel 필요.
Accessibility/Operability4주요 row, check, search가 실제 button/input이다.모바일 touch와 keyboard 순서를 확인.

수정 조건

관찰에서 이렇게 나오면 다시 줄인다

신호등급수정
사용자가 Flow 찾기를 먼저 눌러 오늘 항목을 보지 않는다. High Flow 찾기를 오늘 목록 아래로 내리거나 아이콘형 보조 버튼으로 더 낮춘다.
20개 이상에서 전체 Flow 보기를 누른 뒤 길어진 목록에서 길을 잃는다. High 전체 펼침 대신 검색 입력에 더 집중하고, 최근 8개만 계속 유지한다.
20개 이상에서 오늘 항목 4개만 보여 나머지를 놓친다. Medium 오늘 목록 하단의 더 보기 버튼 문구를 오늘 항목 더 보기처럼 더 구체화한다.
학습 지도형 사용자가 전체 단원 위치를 계속 찾는다. Medium 상세 하단에 접힌 전체 단원 보기만 추가한다. 첫 화면에는 넣지 않는다.
메모 자동 저장 상태를 보지 못한다. Medium 저장 상태를 입력창 하단 오른쪽에서 라벨 가까이로 옮긴다.
