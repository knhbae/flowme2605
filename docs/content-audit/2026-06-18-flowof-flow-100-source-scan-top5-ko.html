Flow of Flow source scan · 2026-06-18

수학 외 Flow of Flow 후보를 100개 검색하고, 다음 PoC에 적당한 5개를 골랐다

목적은 "그럴듯한 묶음"을 늘리는 것이 아니라, 상위 구조가 반복 가능한 하위 Flow들을 실제로 생성하고 관리할 수 있는 원컨텐츠를 찾는 것이다. 이번 문서는 사용자용 화면이 아니라 원컨텐츠 심사 리포트다.

검색 결과 100개 스캔 상위 후보 18개 원문/스니펫 확인 수학 제외 선정 5개 + 예비 5개

이번 선별 기준

반복 하위 구조

상위 콘텐츠 아래에 최소 3개 이상의 하위 단위가 있고, 각 하위 단위가 같은 실행 패턴을 반복해야 한다.

저장 후 실행물

사용자가 저장하면 캘린더, 루틴, 진행표, 체크리스트, 메모 중 무엇이 생기는지 바로 설명 가능해야 한다.

제작자 확장성

제작자가 나중에 주차, 모듈, 작물, 월령, 프로젝트 같은 하위 Flow를 계속 추가할 수 있어야 한다.

단순 재생목록, 팁 모음, 일회성 체크리스트, 넓은 로드맵은 제외했다. 좋은 단일 Flow일 수는 있지만 Flow of Flow 대표로는 약하다.

상위 5개를 FlowMe에서 어떻게 다뤄야 하나

저장 전 사용자 화면

  • 상위 구조 전체를 설명하기보다 저장하면 생기는 실행물을 먼저 보여준다.
  • 전체 저장과 일부 저장의 차이를 명확히 둔다.
  • 입력은 시작일, 요일, 대상 선택 정도로 제한한다.
  • 원문 링크와 세부 설명은 하위 Flow detail에 남긴다.

내 앱 실행 화면

  • 오늘 실행할 하위 Flow 또는 세션을 먼저 보여준다.
  • 큰 지도는 접어두고, 현재 위치와 다음 항목만 가볍게 노출한다.
  • 체크, 짧은 메모, 원문 링크 접근이 핵심이다.
  • 하위 Flow 추가/건너뛰기/반복 변경은 2차 액션으로 둔다.

제작자 화면

  • 원문 목차/표/주차/모듈을 하위 Flow 후보로 가져온다.
  • 하위 Flow 공통 패턴을 한 번 정의하고 여러 단위에 반복 적용한다.
  • 각 하위 Flow에는 원문 근거 URL 또는 원문 행을 붙인다.
  • 전체 공개 전, 사용자에게 생기는 실행물 미리보기를 확인한다.

금지선

  • 외부 앱이나 코스를 FlowMe 안에 복제하지 않는다.
  • 원문에 없는 세부 체크리스트를 AI가 채우지 않는다.
  • 건강/육아/반려동물은 공식/전문가 판단 경계를 분리한다.
  • Flow of Flow라는 내부 용어를 사용자 화면에 노출하지 않는다.

다음 PoC 추천 순서

  1. NHS Couch to 5K: 수학과 완전히 다른 운동/루틴형 Flow of Flow라 첫 확산 샘플로 적합하다.
  2. RHS Crop Planner: 표 기반 source가 어떻게 다중 하위 Flow로 바뀌는지 보여준다.
  3. JustinGuitar: 제작자 교육 콘텐츠가 FlowMe에서 어떻게 운영 자산이 되는지 보여준다.
  4. freeCodeCamp: 커리큘럼/프로젝트/퀴즈가 있는 대형 학습 구조의 비교군으로 둔다.
  5. Solid Starts: 육아/식단은 민감 경계를 먼저 설계한 뒤 제한적으로 PoC를 만든다.

결론: 수학 말고도 Flow of Flow는 된다. 다만 강한 후보는 대부분 "프로그램/커리큘럼/표/모듈/월령"처럼 원문에 반복 단위가 이미 있는 콘텐츠다. 단순 카테고리 모음이나 좋은 팁 모음은 FlowMe 서비스처럼 보이게 만드는 데 오히려 방해된다.
