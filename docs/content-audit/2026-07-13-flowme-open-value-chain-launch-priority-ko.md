# FlowMe 전체 가치 사슬과 초기 제품 우선순위

기준일: 2026-07-13

참고: `2026-07-12-flowme-user-creator-value-chain-ceo-ko.html`

## 결정

개발 구조는 아래 가치 사슬을 처음부터 닫지 않는다.

`원문·제작자 → 검토된 기준 Flow → 사용자 개인본 → My Flow 실행 → Calendar·외부 도구 → 완료·수정 → 리뷰·업데이트 요청 → 제작자 학습·외부 전환`

다만 초기 제품 화면에서 이 모든 단계를 같은 무게로 노출하지 않는다. 첫 사용자가 먼저 이해해야 하는 가치는 **보던 콘텐츠를 신뢰 가능한 할 일과 일정으로 바꾸고, 자기 상황에 맞게 수정해 실제로 끝내는 것**이다.

## 초기 제품의 1차 약속

1. URL이나 메모를 넣으면 이미 준비된 Flow를 찾거나 직접 손볼 초안으로 이어진다.
2. 원문 기준본은 보존되고, 사용자의 날짜·제목·메모 수정은 비공개 개인본에 남는다.
3. My Flow에서는 오늘 끝낼 일을 바로 체크한다.
4. Calendar에서는 날짜를 기준으로 여러 Flow의 할 일을 구분한다.
5. 필요하면 캘린더·시트·메모 파일로 가져가 기존 도구에서도 계속 쓴다.

## 화면별 책임

| 화면 | 사용자가 지금 해결할 질문 | 초기 화면에 먼저 보일 것 | 뒤로 둘 것 |
| --- | --- | --- | --- |
| 홈 | 어디서 시작하는가 | URL·메모 진입, 대표 Flow | 마켓·제작자 운영 기능 |
| Flow 찾기 | 준비된 것이 있는가 | lookup 결과, 초안 경로 | 전체 카탈로그 |
| Flow Map | 무엇이 저장되는가 | 기준일, 첫 행동, 전체 실행 순서, 원문 | 세부 운영 메타 |
| public `/f` | 이 공유본을 쓸 것인가 | Flow 단위 저장, 실제 실행 미리보기 | export 형식 세부 |
| My Flow | 지금 무엇을 끝낼까 | 오늘·지난·다음 할 일과 완료 체크 | 전체 구조·설정·재사용 |
| Calendar | 이 날짜에 무엇을 할까 | 월간 개요와 선택일 실행 목록 | 장기 통계 |
| Studio | 내가 만든 초안을 어디서 관리할까 | 초안 선반과 보조 편집 진입 | 5번째 주 탭·마켓플레이스 |
| creator profile | 누가 만든 기준본인가 | 제작자 귀속, 공개 Flow, 원문 | 결제·정산 대시보드 |

## 전체 가치 사슬을 열어두는 구현 원칙

- 기준 Flow와 비공개 개인 수정본을 분리한다.
- 원문 URL, 출처 맥락, 버전, 상세·메모 데이터는 삭제하지 않는다.
- Calendar, My Flow, export는 같은 개인 수정본을 읽는다.
- 리뷰·수정 요청·성과 피드백이 들어갈 식별자와 연결 경로는 보존한다.
- 제작자 수익은 초기부터 자체 결제로 과장하지 않고 기존 상품·예약·제휴 링크의 전환 기여부터 검증한다.
- 외부 캘린더로 내보낸 뒤의 완료를 FlowMe 내부 성과처럼 추정하지 않는다.

## 지금 먼저 다듬는 이유

가치 사슬 후반의 리뷰·업데이트·수익은 사용자가 실제로 저장하고 수정하고 실행한 뒤에만 의미가 있다. 따라서 현재 시각·UX 개선은 다음 순서로 진행한다.

1. canonical Flow와 public Flow가 무엇을 저장하는지 명확하게 보이게 한다.
2. My Flow를 할 일 우선 실행 허브로 만든다.
3. Calendar를 날짜 우선 실행 화면으로 만든다.
4. URL-first hit·miss·초안 경로를 위 두 실행 화면에 자연스럽게 연결한다.
5. 그 뒤 리뷰·수정 요청·업데이트 수락·제작자 성과 회수를 실제 사용자 여정으로 검증한다.

## 이번 시각 개선의 판정 기준

- 화면마다 카드가 중첩되지 않는다.
- 사용자는 현재 필요한 행동 한두 개를 먼저 본다.
- 서로 다른 카테고리라도 `Flow 식별 → 할 일 → 날짜/필요 메타 → 완료 또는 열기` 순서가 일관된다.
- 카테고리별 특성은 구조형 metadata와 상세 화면에서 보존한다.
- 모바일 390px과 wide 1024px에서 같은 역할이 유지된다.
- 전체 가치 사슬을 위한 source, personal overlay, export, review/update 연결 가능성은 훼손하지 않는다.
