# Claude Design 1차 작업 시작

이 링크는 P35 모바일 Production을 독립적으로 검토하고 UX 구조 대안을 만드는 1차 작업용입니다. 제품 소유자의 피드백은 1차 결과가 나온 뒤 별도로 제공합니다.

아래 순서대로 자료를 읽어 주세요.

1. [작업 목표와 범위](./01-planning-session-brief-ko.md)
2. [Production 모바일 화면 증거](./02-production-evidence-index-ko.md)
3. [원격 검토용 코드 구조 사실](./03-architecture-facts-ko.md)
4. [화면 상태·차이 비교표](./04-screen-state-and-variant-matrix-ko.md)
5. [1차 독립 작업 프롬프트](./05-claude-design-round1-prompt-ko.md)

## 이 단계에서 하지 않을 일

- 제품 소유자 피드백을 먼저 읽고 동의 여부만 판단하지 않기
- 화면 차이만으로 콘텐츠별 하드코딩이라고 단정하지 않기
- 하나의 해결 방식으로 곧바로 수렴하지 않기
- 제품 코드 작성이나 배포 시작하지 않기

## 제출할 결과

- 증거가 연결된 독립 진단
- 구조 판정과 확신 수준
- 공통으로 유지할 UI와 콘텐츠별로 달라질 UI
- 삭제·통합·조건부 노출 제안
- 실제 이동과 상태 모델이 다른 모바일 구조 대안 2~3개
- MVP 권고안, P0·P1, 수용 기준
- 추가로 필요한 증거

상세 출력 형식은 [1차 독립 작업 프롬프트](./05-claude-design-round1-prompt-ko.md)를 따릅니다.
