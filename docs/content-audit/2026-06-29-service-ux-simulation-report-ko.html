FlowMe 서비스 대표 UX 시뮬레이션 리포트

목표는 홈, Flow 찾기, 공개 Flow Map, 저장 후 내 Flow 실행 화면이 실제 사용자 검토 기준에서 P0/P1 문제 없이 이어지는지 확인하는 것입니다.

이 문서는 검토용 리포트이며 사용자용 PoC 화면과 분리합니다. 실제 사용자 행동 데이터는 아직 없으므로 검증 완료가 아니라 브라우저 기반 리허설 결과로만 봅니다.

요약

영역판정핵심 결과
홈 High 수정 검토용 문구와 저장 오해 문구를 제거했습니다. 홈은 서비스 약속과 대표 시작점만 남기는 방향으로 유지합니다.
Flow 찾기 High 수정 `후보만 둡니다`, `대표 노출` 같은 내부 표현을 사용자용 설명으로 바꿨습니다.
공개 Flow Map High 수정 `Step에 들어갈 Item`을 `세부 메모 항목`으로 바꿔 공개 화면의 내부 모델 노출을 줄였습니다.
저장 후 내 Flow 통과 이사 Flow Map 저장 후 첫 Step, 캘린더 보기, inline detail 토글이 동작했습니다.
콘텐츠 품질 Medium 남김 대표 후보는 이사, 중1 수학, 전세로 유지합니다. 영유아 검진/접종은 공식 표 기반 Step 품질 보강 전까지 대표로 올리지 않습니다.

수정한 P1 문제

문제분류수정
홈 보조 카드에 `내 Flow로 저장`이 보였지만 실제 클릭은 상세 열기였습니다. High `미리 보고 저장`으로 바꿔 상세 확인 후 저장하는 흐름을 예측하게 했습니다.
홈과 Flow 찾기에 `검토할 만한`, `후보`, `대표 노출` 같은 내부 검토 문구가 남아 있었습니다. High `시작하기 좋은 Flow`, `저장하면 일정, 체크리스트, 진도표로 이어지는 Flow`, `1개 바로 실행`으로 바꿨습니다.
공개 Flow Map에 `Step에 들어갈 Item`이 노출되어 사용자 화면과 개발자 모델이 섞였습니다. High `세부 메모 항목`으로 바꿨습니다.
전세가 대표 후보로 홈/탐색에 나오지만 My Flow에서는 `검토 필요`로 분리되었습니다. High 대표 카탈로그에 허용한 단일 Flow는 My Flow에서도 `실행 가능`으로 취급하도록 정리했습니다.

시뮬레이션 결과

1개 저장: 이사 Flow Map

  • 공개 Flow Map에서 이사일 `2026-07-22`를 입력하고 전체 지도를 저장했습니다.
  • `/my?savedMap=moving-d30`로 이동했고, 저장 완료 패널이 첫 Step과 `캘린더 보기`를 보여줬습니다.
  • 첫 Step detail은 클릭한 자리에서 열렸고, 같은 Step을 다시 누르면 닫혔습니다.

3개 저장: 이사 + 중1 수학 + 전세

  • `오늘 / 캘린더 / Flow` 탭은 유지됐고, 캘린더에는 날짜가 있는 Step만 표시됐습니다.
  • 전세가 `정리 필요`로 떨어지는 문제를 수정한 뒤, 세 대표 후보가 모두 실행 가능으로 보였습니다.
  • 중1 수학은 기준일 없이도 진도형 Flow로 남아 있고, 필요 시 `진도 보기`로 열 수 있습니다.

8개 이상 저장: UX20 대량 상태

  • Today 탭은 오늘 할 일과 밀린 항목을 먼저 보여줘 대량 상태에서도 첫 행동은 유지됐습니다.
  • Flow 탭은 모바일에서 전체 목록을 즉시 펼치지 않고 `저장한 Flow 보기` 시트로 엽니다.
  • 시트에는 필터와 각 Flow의 다음 실행 항목이 보였습니다. 다만 이 데모 목록에는 레거시/실험 컨텐츠가 많아 대표 서비스 품질 판단용으로 쓰지 않습니다.

남은 백로그

우선순위항목이유
Medium 대표 카드 신뢰 신호 실제 사용수/리뷰가 없으므로 아직 가짜 신호를 넣지 않습니다. 대신 원문, 입력, 저장 항목, 업데이트일 같은 source-backed 신호를 계속 정리합니다.
Medium 영유아 검진/접종 대표 후보 보류 공식 표 기반 Step 정보가 충분히 보강되기 전까지 홈/Flow 찾기 대표 후보에 올리지 않습니다.
Medium 전세 source-backed 승격 현 UX는 기준선으로 통과했지만 seed 상태는 아직 `needs_review`입니다. 다음에는 실제 source-backed 패키지로 승격하거나 상태 필드를 정리해야 합니다.
Low 대량 Flow 목록 polish 현재는 모바일 시트로 부담을 줄였지만, 실서비스에서는 카테고리/최근 실행/보관 처리까지 더 다듬을 수 있습니다.
