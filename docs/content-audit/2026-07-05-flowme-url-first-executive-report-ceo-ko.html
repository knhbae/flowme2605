FlowMe Executive Report 2026-07-05 5분 요약

FlowMe는 URL을 실행 가능한 Flow로 바꾸는 연결 레이어다

지금 결정해야 할 방향은 명확하다. FlowMe는 AI가 계획을 새로 만들어주는 앱으로 시작하지 않는다. 사용자가 이미 보고 있는 URL을 출발점으로 기존 Flow를 찾아주고, 출처 신뢰 정보를 붙여, 캘린더·문서·체크리스트로 바로 옮기게 하는 제품으로 먼저 검증한다.

한 문장 결론

URL-first → 신뢰 가능한 Flow 찾기 → portable export → My Flow 저장이 P0다. Home 개편, direct OAuth/API, AI-first 생성, full editor는 지금 하지 않는다.

이번 보고서의 역할

기존 상세 보고서를 새로 쓰는 것이 아니라, CEO가 판단할 핵심만 하나로 압축한 최종 요약본이다.

1 우선 진입점: 사용자가 본 URL을 `/flows`에 넣는 것.
3 P0 export: `.ics`, Markdown, checklist.
12 검증 canary: P0-now 4, P1-review 6, P2-hold 2.
3 CEO가 지금 결정할 항목 수.

1. FlowMe는 무엇인가

복잡한 설명을 줄이면 FlowMe의 현재 포지션은 아래 한 줄이다.

position

사용자 입장

“좋은 글이나 안내를 봤는데, 내가 바로 실행할 수 있는 일정과 체크리스트로 바꾸고 싶다.”

FlowMe의 역할

URL을 받아 기존 Flow를 찾아주고, 출처와 주의사항을 붙인 뒤 내 도구로 옮기게 한다.

초기 승부처

새로운 앱 습관을 강요하지 않고, 사용자가 이미 쓰는 캘린더·문서·체크리스트에 붙는다.

2. 전략 지도

CEO가 봐야 할 전체 흐름은 이 다섯 단계다.

strategy map
URL을 넣는다 Home이나 AI prompt가 아니라 `/flows`의 URL lookup이 첫 검증 루프다.
기존 Flow를 찾는다 새로 생성하기 전에 이미 검토된 source-backed Flow를 재사용한다.
출처 신뢰를 붙인다 source, 확인일, 위험도, 주의 문구를 숨기지 않는다.
내 도구로 옮긴다 캘린더 파일, Markdown, 체크리스트로 바로 가져간다.
Canary로 검증한다 12개 후보로 hit, review, hold 상태를 검증한다.

3. 해야 할 것과 하지 말 것

전략이 어려워진 이유는 할 일과 하지 않을 일이 섞였기 때문이다. P0는 아래처럼 좁힌다.

focus
해야 할 것 지금 하지 말 것
URL을 넣으면 기존 Flow를 먼저 찾아준다. AI가 새 계획을 먼저 생성하게 하지 않는다.
출처, 확인일, 위험도, 주의 문구를 함께 보여준다. 검증되지 않은 정보를 확정 조언처럼 보이게 하지 않는다.
`.ics`, Markdown, checklist로 기존 도구에 붙는다. 초기부터 Google/Notion/Todoist OAuth를 붙이지 않는다.
P0-now 4개 canary로 실제 실행 루프를 검증한다. 12개 전체를 한 번에 제품화하려 하지 않는다.
My Flow 저장은 사용자의 실행 기록으로 남긴다. Home redesign, full editor, fake usage를 섞지 않는다.

4. 외부 연결 우선순위

FlowMe는 모든 생산성 앱과 경쟁하지 않는다. 먼저 export로 붙고, API는 나중에 판단한다.

connect, not compete
우선순위 연결 방식 대상 이유
P0 portable export Calendar `.ics`, Markdown, checklist 계정 연동 없이 바로 검증 가능하다.
P1 가벼운 확장 CSV/sheet, calendar feed, Todoist/Notion 후보 P0 사용 증거가 생긴 뒤 붙인다.
P2 platform / agent Zapier, MCP/agent, direct automation 데이터와 반복 사용이 확인된 뒤 검토한다.

5. Canary 12 요약

Canary 12는 콘텐츠 목록이 아니라 전략 검증 장치다. CEO 보고에서는 전체 상세보다 운영 분류가 중요하다.

12 candidates

P0-now 4개

바로 실행 루프를 검증한다. 이사, 차량구매/점검, 예방접종, 에어컨필터처럼 일정·체크리스트·주의 문구가 분명한 후보를 우선한다.

P1-review 6개

좋은 후보지만 source/import 권리, 민감 문구, creator/community 운영 기준을 더 확인해야 한다.

P2-hold 2개

비교와 백업 목적이다. P0 성공 기준에 넣지 않고 export/save도 열지 않는다.

6. 지금 필요한 결정 3개

이 세 가지가 승인되면 다음 개발 세션으로 넘길 수 있다.

CEO decision

URL-first를 P0 진입점으로 승인

FlowMe의 첫 검증 루프는 Home 개편이나 AI 생성이 아니라 `/flows` URL lookup이다.

Export Pack v1을 P0 연결 방식으로 승인

초기에는 direct API보다 `.ics`, Markdown, checklist로 기존 도구에 붙는다.

Trust와 잠금 원칙 승인

민감 영역은 출처·확인일·주의 문구를 붙이고, 검토 전 후보는 저장/export를 잠근다.

7. 다음 단계

이 보고서 이후 새 전략을 더 쓰기보다, 개발 세션 handoff를 좁게 시작해야 한다.

handoff
