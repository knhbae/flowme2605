Evidence board에는 완성된 rollup의 비식별 요약만 옮깁니다

지금은 실제 세션과 rollup이 없으므로 보드는 계속 no signal입니다. 이 runbook은 3 completed usable sessions에서 작성된 rollup이 있을 때만 사용합니다.

board decisionno signal
rollupnone
sessions0 / 3
update nowno
allowed labels3

빈 rollup, incomplete rollup, 또는 scheduling 상태(invited, agreed, scheduled)만으로는 board를 업데이트하지 않습니다.

1. 업데이트 진입 조건

하나라도 빠지면 evidence board는 그대로 no signal입니다.

세션 조건

3개 completed usable sessions, 같은 packet version, role label만 기록.

판정 조건

response coding guide 적용, rollup template에 decision 하나 선택.

행동 조건

post-rollup guide에서 rerun, revise, candidate prep 중 하나만 선택.

2. Board에 옮길 수 있는 필드

Board fieldAllowed value
Current decisionno signal, friction, candidate signal
Evidence sourcefilled rollup 링크. raw private notes는 링크하지 않습니다.
Sessions summaryusable session 수와 역할 라벨만.
Main evidence비식별 패턴 한 줄.
Main confusion있다면 비식별 혼동 패턴 한 줄.
Next actionrerun sessions, revise packet, prepare review candidate 중 하나.
Blocked movespublic route, integration, automation, contact storage, channel analytics.

3. Board에 쓰지 않을 것

민감값

이름, 연락처, 메신저 ID, 방/비밀번호/키, 결제, 건강, 신원, 초대 링크, form edit, webhook, 채팅 로그.

원문 메모

raw worksheet notes, 민감값이 포함된 정확한 채팅 인용, 개인 답장 전문.

금지 결론

validated, launched, ready, integration ready, channel ready.
