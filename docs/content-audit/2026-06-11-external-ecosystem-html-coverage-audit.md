## Readable Path

Recommended reading path for this analysis room:

1. Start with the [analysis room operating index](./2026-06-09-external-ecosystem-analysis-room-index-ko.html).
2. Read the [roadmap source HTML](./2026-06-08-external-ecosystem-analysis-roadmap-ko.html), then use the [roadmap visual](./2026-06-09-external-ecosystem-roadmap-visual-ko.html) for scanning.
3. Open the [connected docs hub](./2026-06-09-external-ecosystem-connected-docs-visual-ko.html) for document-by-document navigation.
4. For the active distribution-channel axis, open the [current-state handoff](./2026-06-11-distribution-channel-handoff-current-state-handoff-ko.html) and the [handoff hub run sequence](./2026-06-11-distribution-channel-handoff-html-hub-ko.html#run-sequence) before adding new route or integration work.
5. Confirm the [Stage 0 phase checkpoint](./2026-06-11-distribution-channel-stage0-phase-checkpoint-ko.html) so the work stays in Phase 5 / Stage 0.
6. Confirm the [documentation stop gate](./2026-06-11-distribution-channel-documentation-stop-gate-ko.html) so the same axis does not grow more planning docs before real sessions.
7. Before scheduling sessions, use the [recruiting copy](./2026-06-11-school-dorm-share-packet-recruiting-copy-ko.html) so the ask stays a 15-minute comprehension check with no private-value collection.
8. After sending the invite, update only the matching role-labeled row in the [scheduling tracker](./2026-06-11-school-dorm-share-packet-scheduling-tracker-ko.html#snippets) to `invited`.
9. Move a slot to `agreed` only after a reply confirms participation; `invited`, `agreed`, `scheduled`, and `not run` are not observation evidence.
10. Before final invitations or sessions, use the [version lock](./2026-06-11-school-dorm-share-packet-version-lock-ko.html) so all sessions use the same packet.
11. Use the [response coding guide](./2026-06-11-school-dorm-share-packet-response-coding-guide-ko.html) to keep `pass`, `fail`, and `unclear` consistent.
12. Before the first session, confirm the [preflight checklist](./2026-06-11-school-dorm-share-packet-preflight-checklist-ko.html) so all go/no-go gates pass.
13. On observation day, use the [observation-day quick start](./2026-06-11-school-dorm-share-packet-observation-day-quick-start-ko.html) before filling longer templates.
14. After 3 completed usable sessions and a filled rollup exist, use the [evidence board update runbook](./2026-06-11-school-dorm-share-packet-evidence-board-update-runbook-ko.html) before changing the board.
15. Use the [Phase 5 compression table](./2026-06-08-external-ecosystem-phase5-compression-table-ko.html) as the current decision gate.
16. Use [Export Destination Fit](../flow-rules/export-destination-fit-ko.html) before any destination or integration discussion.
17. Use [Integration Readiness Gate](../flow-rules/integration-readiness-gate-ko.html) only after export behavior produces evidence.
