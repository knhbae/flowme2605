## 이번 조사에서 확인한 결론

- 좋은 Vertical 서비스는 콘텐츠 양보다 `최소 입력 → 전체 결과 미리보기 → 오늘/다음 행동 → 완료·수정 → 다음 행동` 연결이 강하다.
- FlowMe는 자동 추천·진단·전문 계산·마켓플레이스를 복제하지 않는다.
- FlowMe의 기회는 공개 원문을 날짜 없는 저장, 기준일 일정, 반복 루틴, 상태형 체크, 캘린더·시트·메모 내보내기로 바꾸는 실행 레이어다.
- 서비스 전체가 좋은 것과 공개 콘텐츠 공급처로 좋은 것은 다르다. Benchmark와 Partner를 분리한다.
- 자동 캡처는 공개 화면 근거이지 in-app 검증이나 실제 사용자 검증이 아니다.

## 우선 발굴할 8개 기회

### 1. 공간·기간별 집 관리 루틴

- 판정: Go
- 생활 영역: 집·살림
- 찾을 source shape: 제작자 블로그·브랜드의 공간별 체크리스트, 주기표, 계절 관리표
- 제작자 유형: 살림 제작자, 청소 서비스 브랜드, 정리 전문가
- 실제 검색어: 주방 2주 청소 루틴 체크리스트 / 욕실 주간 청소표 / 계절별 집 관리 체크리스트
- 반드시 확보할 source row: 공간, 작업 제목, 권장 주기 또는 원문 순서, 원문 링크
- 예상 최초 입력: 시작일 또는 반복 요일 0~1개
- 자연스러운 결과물: 반복 체크리스트 + 캘린더
- 공개·권리 경계: 작업 제목·최소 주기·출처 링크만 사용하며 유료 표 전문과 자동 최적화 규칙은 복제하지 않는다.

### 2. 월령·목표별 2주 놀이 루틴

- 판정: Partner
- 생활 영역: 가족·육아
- 찾을 source shape: 공개 육아 활동 글·영상 시리즈와 월령·준비물·활동 목표
- 제작자 유형: 육아 활동 제작자, 놀이 전문가, 교구 브랜드
- 실제 검색어: 12개월 아기 놀이 2주 / 유아 소근육 놀이 영상 시리즈 / 집콕 놀이 월령별
- 반드시 확보할 source row: 활동 제목, 대상 월령, 원문 URL, 원문에 적힌 준비물/주의
- 예상 최초 입력: 아이 월령 또는 시작일 1개
- 자연스러운 결과물: 하루 한 활동 루틴 + 원문 링크
- 공개·권리 경계: 발달 진단을 하지 않고 공개 활동 메타데이터와 링크만 사용한다. 유료 영상은 제휴가 필요하다.

### 3. 제작자 강의·연습 시리즈 진도 Flow

- 판정: Go
- 생활 영역: 공부·독서·학습
- 찾을 source shape: 공개 강의 재생목록, 회차형 튜토리얼, 악기·언어 연습 시리즈
- 제작자 유형: 교육 유튜버, 강사, 악기·언어 교육 브랜드
- 실제 검색어: 14일 영어 말하기 재생목록 / 기타 초보 10강 커리큘럼 / 무료 강의 주차별 계획
- 반드시 확보할 source row: 회차 제목, 순서, 영상/글 URL, 원문 학습 목표
- 예상 최초 입력: 완료 목표일 또는 반복 요일 0~1개
- 자연스러운 결과물: 회차 큐 + 오늘의 다음 학습
- 공개·권리 경계: 문항·자막·유료 강의 내용을 복제하지 않고 회차 제목·링크·진도만 제공한다.

### 4. 기간형 운동 프로그램 실행표

- 판정: Go
- 생활 영역: 건강·운동
- 찾을 source shape: 공개 코치 프로그램, 영상 재생목록, 주차·회차별 운동표
- 제작자 유형: 트레이너, 러닝 코치, 운동 채널·브랜드
- 실제 검색어: 5K 8주 훈련표 공식 / 홈트 4주 재생목록 / 초보 근력 2주 프로그램
- 반드시 확보할 source row: 주차/회차, 운동 제목, 원문 URL, 원문에 명시된 휴식·범위
- 예상 최초 입력: 시작일 또는 목표일 1개
- 자연스러운 결과물: 주차별 일정 + 오늘 세션
- 공개·권리 경계: 강도·부상 위험을 새로 계산하지 않고 원문 계획과 안전 안내를 그대로 추적한다.

### 5. 제작자·브랜드 D-day 준비 타임라인

- 판정: Partner
- 생활 영역: 여행·외출·행사
- 찾을 source shape: 결혼·돌잔치·집들이·여행 준비 체크리스트와 원문 D-day 구간
- 제작자 유형: 행사 제작자, 웨딩·여행 브랜드, 지역 전문가
- 실제 검색어: 결혼 준비 체크리스트 D-180 / 돌잔치 준비 일정표 / 집들이 한달 전 체크리스트
- 반드시 확보할 source row: D-day 구간, 체크 행동, 업체/자료 링크, 원문 조건
- 예상 최초 입력: 행사일 1개
- 자연스러운 결과물: 역산 캘린더 + 체크리스트
- 공개·권리 경계: 업체 마켓플레이스를 만들지 않고 제작자·업체 원문 유입을 보존한다.

### 6. 레시피 묶음에서 식단·장보기·오늘 조리로

- 판정: Partner
- 생활 영역: 식사·장보기
- 찾을 source shape: 제작자의 공개 레시피 시리즈, 식단표, 장보기표
- 제작자 유형: 요리 제작자, 식품 브랜드, 영양 전문가
- 실제 검색어: 일주일 식단표 장보기 리스트 / 이유식 2주 식단 재료표 / 한끼 레시피 재생목록
- 반드시 확보할 source row: 식사/날짜, 레시피 제목, 원문 URL, 원문 재료 묶음
- 예상 최초 입력: 시작일 또는 식사 수 0~1개
- 자연스러운 결과물: 식단 캘린더 + 통합 장보기 + 조리 링크
- 공개·권리 경계: 레시피 전문을 복제하지 않고 제목·링크·최소 재료 메타만 사용한다.

### 7. 직무별 지원 준비·후속 Flow

- 판정: Go
- 생활 영역: 일·커리어
- 찾을 source shape: 커리어 코치의 지원 체크리스트, 면접 준비표, 직무별 포트폴리오 가이드
- 제작자 유형: 커리어 코치, 채용 전문가, 교육 브랜드
- 실제 검색어: 개발자 지원 체크리스트 / 면접 준비 7일 계획 / 신입 포트폴리오 제출 체크리스트
- 반드시 확보할 source row: 지원 단계, 체크 행동, 후속 시점 또는 순서, 원문 링크
- 예상 최초 입력: 공고 URL 또는 면접일 0~1개
- 자연스러운 결과물: 상태형 체크리스트 + 후속 캘린더
- 공개·권리 경계: 공고 데이터베이스·이력서 점수 엔진을 만들지 않고 실행 항목과 출처를 제공한다.

### 8. 대상별 반복 관리 루틴

- 판정: Go
- 생활 영역: 취미·반려
- 찾을 source shape: 전문가·판매자의 식물 관리표 또는 반려 훈련 시리즈
- 제작자 유형: 식물 판매자·전문가, 반려 훈련사, 취미 브랜드
- 실제 검색어: 몬스테라 월별 관리표 / 강아지 14일 기본 훈련 / 식물 구매 후 관리 체크리스트
- 반드시 확보할 source row: 대상, 관리/훈련 행동, 원문 주기·순서, 원문 링크
- 예상 최초 입력: 대상 이름과 시작일 1~2개
- 자연스러운 결과물: 반복 관리 캘린더 또는 일일 훈련 루틴
- 공개·권리 경계: 진단·교정 판단을 하지 않고 공개 관리 주기·훈련 순서와 전문가 링크를 보존한다.


## 발굴 통과 조건

후보는 아래를 모두 충족해야 한다.

1. 실제 공개 URL을 열고 제목·제작자·최신성을 확인한다.
2. 실행 가능한 표 row, 회차, D-day 구간, 반복 주기, 영상 목록 중 하나가 실제 원문에 있다.
3. 저장 후 생기는 결과물을 한 문장으로 설명할 수 있다.
4. 첫 사용자 입력은 기본 0~1개, 예외적으로 2개를 넘지 않는다.
5. 원문에 없는 행동·날짜·반복·완료 기준을 만들지 않는다.
6. Item은 독립적으로 체크할 가치가 있는 최소 행동만 둔다.
7. 링크·수량·조건·팁·상태는 detail/memo/sourceTrace에 둔다.
8. creator 콘텐츠, 공식 근거, 위험·주의 정보를 분리한다.
9. 공개 전환 권리가 불명확하면 link_metadata_only 또는 permission_required로 둔다.
10. 서비스 고유 추천 엔진이나 유료 콘텐츠를 source row로 간주하지 않는다.

## 다음 조사 산출물 권장 구조

- 후보 URL 원장: 40~60개
- 실제 원문 재열람: 24~36개
- source row 확보: 12개 이상
- 최종 콘텐츠 후보: 6~8개
- 각 기회별 최소 1개 후보를 목표로 하되 약한 카테고리를 억지로 채우지 않는다.
- 사용자 검토 HTML에는 주요 결과, 원문 캡처, 생성될 Flow 전체를 먼저 배치한다.

## 절대 하지 말 것

- 앱 서비스의 비공개 계획·유료 영상·도안·문항·자막을 복제하지 않는다.
- 마케팅 화면만 보고 in_app_verified로 기록하지 않는다.
- 발달·의료·세금·운동 강도·식물 질병 진단을 FlowMe가 새로 계산하지 않는다.
- 지도 최적화, 결제, 예약, 은행 연동, GPS, 웨어러블 코칭을 콘텐츠 기능으로 확장하지 않는다.
- 카테고리 수를 맞추기 위해 source row가 없는 후보를 승격하지 않는다.

## 다음 세션 완료 보고

- 실제로 연 URL 수
- source row 확보 수
- Go / Partner / Benchmark / Hold 수
- 권리 확인이 필요한 후보
- 선택한 6~8개와 선택 이유
- 원문에 없는 항목을 추가하지 않았다는 검증
- 앱 코드·seed·canonical 변경 없음
