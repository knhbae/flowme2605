운영 규칙

넓게 보되 무겁게 만들지 않는 기준

  1. 이 문서는 전체 지도입니다. 상세 UX는 서비스 UX 백로그나 별도 PoC에서 다룹니다.
  2. Stage 0 검증을 통과하기 전에는 장기 플랫폼 아이디어를 실행 작업으로 올리지 않습니다.
  3. 새 작업은 항상 어느 축인지 표시합니다: Stage 0, Source-to-Flow, My Flow, Creator Map, 장기 플랫폼.
  4. 큰 작업은 product, source, UX, content, validation, memory 렌즈 중 무엇으로 보는지 남깁니다.
  5. 완성도는 내부 진행 상태이며, 실제 사용자 검증과 혼동하지 않습니다.
  6. 모든 작은 수정마다 갱신하지 않습니다. 새 PoC, UX 리포트, spec, 관찰 결과, 중요한 판단 변경처럼 주요 Task나 milestone이 끝났을 때 산출물 링크와 다음 판단을 이 문서와 서비스 UX 백로그 중 알맞은 곳에 갱신합니다.
