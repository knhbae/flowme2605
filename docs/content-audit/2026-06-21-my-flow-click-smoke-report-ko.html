My Flow 관찰 전 클릭 Smoke Check

실제 /my 모바일 화면이 저장 개수별 UX 판정과 어긋나는지 확인했다. 이 점검은 Playwright 자동 클릭으로 UI 상태와 가로 overflow, 주요 버튼 수를 확인한 것이며, 사용자 행동 검증은 아니다.

저장 개수별 UX 판정 관찰 키트 관찰 기록지 관찰 롤업 관찰 전 드라이런 실제 /my 정렬

결론

관찰 전에 바로 고칠 Blocking은 보이지 않음

  • 단일 저장 모바일은 전역 탭이 0개로 줄어 있다.
  • 여러 개 저장 모바일 Flow 허브는 Flow 찾기만 노출하고, 밀린 Flow/다음 실행 상태 버튼은 없다.
  • 20개 이상 저장 시 Flow 목록은 처음 8개만 보이고, 명시적 전체 Flow 보기 30개가 있다.
  • 남은 관찰 리스크는 상세 안의 작은 완료 토글이다. 실제 사용자가 이 토글을 이해하면 유지하고, “뭘 완료하는지” 묻는다면 Step 내부 체크와 메모만 남기는 쪽으로 줄인다.
