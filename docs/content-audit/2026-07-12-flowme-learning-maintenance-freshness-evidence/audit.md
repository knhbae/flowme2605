# 학습자료·가전관리 원문 최신성 감사

## 판정 원칙

- 페이지가 열리는지만 보지 않고 게시 시점, 원문 단위, 현재 조건을 다시 확인한다.
- 자료 모음이나 카테고리 페이지는 실행 일정의 근거가 아니다.
- 원문이 반복 주기와 절차를 직접 제시하면 그 범위만 실행 Flow로 남긴다.
- 오래된 저장 기록은 삭제하거나 자동 교체하지 않고, 새 실행만 막거나 현재 기준을 명확히 안내한다.

## 1. 펀맘 학습자료

### 현재 원문

- 홈페이지는 2026-07-12에 접근 가능했다.
- 색칠공부, 미로찾기, 한글공부, 수학공부, 영어공부 등 1,124개 글의 카테고리를 제공한다.
- 홈페이지에서 확인되는 최신 글은 2021-09-06 게시물이다.
- 원문은 월~토 배치, 매일 한 장, 10분 기준, 다음 주 난이도 조정 같은 실행 일정을 정의하지 않는다.

### 기존 문제

- broad homepage를 source로 두고 월~토 6개 실행 row가 URL hit·저장·내보내기까지 가능했다.
- 내부 품질 상태는 `park`였지만 실제 사용자 경로는 실행 가능해 정책과 동작이 어긋났다.
- creator 자료인데 URL-first 공용 UI가 `공식 원문`, `최신 내용 확인`으로 표시했다.

### 수정

- `publicExecutionEnabled: false`, `executionHoldReason: source_rows` 적용.
- 직접 route는 200/noindex로 유지하되 저장·내보내기·주간 row를 노출하지 않는다.
- URL-first는 `needs_review`와 `원문 자료 보기`만 제공하며 draft/save/export 우회가 없다.
- 기존 저장본은 유지하고, 다시 쓰기 전 개별 자료와 난이도를 확인하라는 비삭제 경고를 제공한다.
- sourceTrace는 `source row` 주장을 제거하고 `FlowMe draft row`, `exact printable article not imported`로 사실관계를 기록한다.

### 다시 열기 위한 조건

1. 실제 활동지 article URL을 row마다 수집한다.
2. 원문에 있는 대상 연령·난이도·자료 유형을 보존한다.
3. 이미지/출력물 재사용 및 링크 제공 경계를 확인한다.
4. source row에서 도출된 2주 또는 1개월 루틴을 새 버전으로 검토한다.

## 2. 삼성 천장형 에어컨 1way 필터

### 현재 원문

- 삼성전자서비스 원문은 2025-01-06 등록 페이지이며 2026-07-12 현재 접근 가능하다.
- 원문은 사용 환경에 따라 달라질 수 있으나 약 2주에 한 번 또는 필터 청소 알림 시 청소하라고 안내한다.
- 모델에 따라 방법이 다르므로 사용설명서를 우선하고, 운전 정지와 보조전원스위치 차단, 필터 분리·청소·건조·장착·리셋을 안내한다.

### 수정

- 2주 반복 규칙은 유지했다.
- title, summary, hint, first check에 `천장형 1way` 적용 범위를 고정했다.
- 첫 체크를 `제품이 천장형 1way인지 모델명과 사용설명서 확인`으로 변경했다.
- 전원·그릴·사다리 위험을 고려해 risk를 `medium`으로 올렸다.
- source checked date와 map version을 2026-07-12 기준으로 갱신했다.
- direct-only/noindex 정책과 URL-first hit/save/export 기능은 유지했다.

## 시각 확인

- 펀맘 review hold: 390px, 1024px
- 펀맘 URL-first 차단: 390px
- 펀맘 기존 저장 경고: 390px
- 에어컨 direct route: 390px, 1024px
- 에어컨 7개 상세 체크: 390px
- 모든 캡처에서 horizontal overflow 0

## 남은 위험

- 펀맘 개별 활동지 import와 권리 검토는 아직 수행하지 않았다. 현재는 실행을 막아 위험을 격리했다.
- 에어컨 안내는 삼성 천장형 1way에만 해당한다. 다른 제조사·형태·필터에는 별도 source-backed Flow가 필요하다.
- 공식·creator 원문은 이후에도 변경될 수 있으므로 source checked date 이후 재검토가 필요하다.
