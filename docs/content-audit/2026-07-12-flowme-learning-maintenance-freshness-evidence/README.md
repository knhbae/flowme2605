# FlowMe 학습자료·가전관리 최신성 evidence

- 기준일: 2026-07-12
- 범위: `curated-funmom-learning-park`, `aircon-filter-cleaning`
- 목적: 오래되거나 넓은 원문을 현재 실행 Flow처럼 제공하지 않고, 현재 원문이 실제로 지지하는 범위만 남긴다.

## 결론

1. 펀맘 홈페이지는 현재 접근 가능하고 학습자료 카테고리를 제공하지만, 확인된 최신 게시물은 2021년이며 월~토 주간 일정과 아이별 난이도를 정의하지 않는다.
2. 따라서 직접 URL과 기존 저장 기록은 유지하되, 새 저장·내보내기·URL-first hit은 중지했다. 개별 활동지 URL, 대상 연령·난이도, 재사용 범위를 수집한 뒤 다시 연다.
3. 삼성전자서비스의 천장형 에어컨 1way 안내는 현재 접근 가능하고 약 2주 또는 필터 알림 시 청소를 명시한다.
4. 에어컨 Flow는 direct-only 실행을 유지하되 `천장형 1way` 모델 및 사용설명서 확인을 첫 체크로 올리고, 위험 수준과 출처 확인일을 갱신했다.
5. 내부 `sourceTrace`는 저장·감사 데이터에 유지하지만 공개 Flow Map DOM에서는 표시하지 않는다.
