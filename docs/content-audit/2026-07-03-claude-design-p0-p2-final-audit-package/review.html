FlowMe UX/UI final audit

Claude Design P0~P3 개선 루프 재검토 패키지

새 기능 추가 없이 홈, Flow 찾기, 공개 Flow 상세, Flow Map 상세, My Flow, 캘린더, export UX의 기준선 유지 여부를 점검했다. Claude Design에게는 이 문서와 소스 링크를 기준으로 남은 이슈와 다음 루프 우선순위를 다시 판단해 달라고 요청한다.

감사 결론

유지된 기준선

4탭 IA, seed/source-backed 구조, 저장-실행-export 흐름은 바꾸지 않았다.

개선된 표면

첫 화면은 행동/결과 중심으로 압축했고, source/detail/memo는 보조 확인 구조로 낮췄다.

검증 상태

모바일 390px route evidence, P3-01~P3-04 targeted subset, P0/P2 회귀 subset, full test/docs/build 검증 통과를 확보했다.

P3-01 재검증 결론

원인

저장 후 My Flow와 캘린더가 비어 보였던 기존 증거는 앱 버그가 아니라 저장된 브라우저 상태를 유지하지 못한 evidence 생성 오류였다.

현재 증거

`/my?savedMap=moving-d30`는 첫 실행 항목을 보여주고, `/calendar`는 저장된 일정 agenda를 보여준다.

고정 장치

저장 후 true empty state 회귀를 막는 Playwright assertion과 전용 evidence 재생성 스크립트를 추가했다.

P3-02 화면 밀도 정리

My Flow

저장 후 배너에서 반복 설명, 저장 카운트, 지난 일정 요약을 제거하고 첫 실행 항목과 `먼저 열기` 행동만 남겼다.

Calendar

모바일 선택일 카드에서 `선택한 날짜`, `0개 루틴`, 단일 일정 카운트 pill을 숨기고 agenda 제목과 체크 행동을 먼저 보이게 했다.

Evidence

`route-evidence.json`의 compact checks와 07/08 screenshot을 다시 생성했다.

P3-03 공개 Flow 상세 shell 정리

정책 결론

`/f/[slug]`는 공유 진입을 허용하지만, 일반 서비스 구조에서는 `Flow 찾기` 아래의 공개 상세 화면으로 본다.

UI 적용

전용 public shell을 제거하고 공통 `PlatformNav`를 붙였다. 모바일에서는 하단 4탭과 `Flow 찾기` active 상태가 보인다.

Fixed layer

public detail의 mobile export bar를 하단 4탭 위로 올려 저장/export 행동과 전역 탭이 겹치지 않게 했다.

P3-04 특수 workbench visual polish

적용 범위

`/f/moving-d30-basic`, `/f/computer-skills-d30-study`, `/f/new-car-delivery-check`, `/f/used-car-buying-check`의 특수 실행 화면을 점검했다.

Visual token

`#FAFAF8`, `#E7E4DD`, `#3654FF`, 16px card radius, 12px action radius 기준으로 카드/버튼/chip 톤을 맞췄다.

사용자 문구

`audit`, `대표 노출`, `묶음`처럼 내부 운영처럼 보이는 문구는 일반 사용자 화면에서 보이지 않도록 낮췄다.
