1. 현재 사실

지금 있는 것은 실행 전 준비물입니다. 이 묶음은 수신자가 패킷을 이해했다거나, 최신 공지 우선 원칙을 받아들였다거나, FlowMe가 공개 라우트로 승격해도 된다는 증거가 아닙니다.

준비된 문서

  • 플랫폼/API 경계 게이트
  • 학교/기숙사 공유 패킷 프리뷰
  • 관찰 스크립트, 관찰 로그, evidence board
  • documentation stop gate, pilot run pack, preflight checklist, worksheet, session log, rollup, post-rollup guide
  • candidate signal 이후에만 쓰는 content-flows 후보 준비 양식

아직 없는 증거

  • 실제 수신자 3명 이상의 사용 기록
  • 응답 라벨을 설명 없이 이해했다는 근거
  • 최신 공지 우선, 민감값 제외, 수동 복사 경계를 이해했다는 근거
  • public route, integration, channel automation 승격 근거

초대와 스케줄링

리크루팅 문구로 3개 role label 슬롯을 초대하고, 스케줄링 트래커에는 비식별 상태만 남깁니다. 초대 발송과 invited/agreed 상태는 관찰 증거가 아닙니다.

recruiting copy scheduling tracker version lock preflight
3

관찰하고 기록

동의된 세션에서만 15분 진행 흐름을 사용합니다. 3개 usable session이 생긴 뒤에만 session log와 rollup으로 이동합니다.

quick start pilot run pack worksheet session log rollup post-rollup
핵심: 3 completed usable sessions와 filled rollup이 생기기 전까지 evidence board의 상태는 계속 no signal입니다.

3. rollup 이후 분기

3개 이상의 usable session이 생긴 뒤에도 선택지는 세 개뿐입니다.

rollup 라벨 뜻 다음 행동
