조작 순서와 시안의 한계

폴더: 줄 선택 → 미리보기 → 취소/Escape → 기존 폴더 또는 새 폴더 연결 → 되돌리기. 미리보기 중 ‘문맥 변경 모의’를 누르면 연결이 거절됩니다. 실제 동시 편집을 재현하는 기능은 아닙니다.

날짜: 구획 날짜 변경 → 개별 날짜/미정 지정 → 오늘·전체·미정 보기 → 완료/다시 열기. 동일 제목이라도 다른 ID·메모를 유지합니다. 구획 이동·마감일·복제·반복은 독립 제안입니다. 반복 비교는 두 회차 미리보기만 지원하고 반복 writer·장기 일정은 없습니다.

저장 오류 모의에서는 성공 저장이 늘지 않으며 다시 저장 또는 대기 취소를 선택합니다. 새로 열기는 마지막 성공 상태와 Undo를 복원합니다. 일반 버튼·Tab·Enter로 조작하며 드래그는 필요하지 않습니다.
