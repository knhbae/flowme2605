# P22-00 실제 반복 사용자 관찰 Gate 준비 Evidence

실제 사용자 검증을 대신하는 자료가 아니라, 5명·3회차 관찰을 같은 조건으로 실행하기 위한 준비 evidence입니다.

## 준비된 것

- 5개 기존 도구 사용 유형별 실제 과제
- 첫 저장, 실행·수정, 완료·재사용의 3회차 관찰 순서
- factual note 중심 세션 기록 양식
- 실제 Calendar import와 중복 import gate
- 기기 변경 시 저장 기대 확인
- 완료 Flow와 새 원문 비교를 만드는 내부 setup
- 정상 사용자 route에서 `/flow-lab` 링크 0

## 판정 경계

현재 상태는 `prepared_not_observed`입니다. 자동 E2E는 setup과 사용자 route 분리를 증명하지만, 참가자가 실제로 이해하고 반복 사용하는지는 증명하지 않습니다. 15개 세션 기록과 Calendar 실 import가 채워지기 전에는 P22-00을 완료로 바꾸지 않습니다.
