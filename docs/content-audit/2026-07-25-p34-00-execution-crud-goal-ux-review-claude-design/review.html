Surface decision

Keep / Change / Remove / Defer

새 카드를 더 쌓지 않고 기존 frame의 역할을 선명하게 한다.

Keep

  • artifact preview와 count
  • 별도 saved receipt
  • My Flow 집중 workspace
  • Calendar selected-day sheet
  • undated queue + undo
  • archive/restore 안전 계약

Change

  • artifact-first 저장 전 조정
  • Flow 관리 single entry
  • Item sheet anatomy
  • Calendar roving focus
  • routine summary-first
  • scope-first export

Remove

  • 같은 사실을 반복하는 설명
  • equal-weight artifact/date controls
  • draft row의 상시 split/merge
  • 모든 날짜의 Tab stop
  • scope 없는 `가져가기`
  • 중첩 카드형 section

Defer

  • Home/Find IA reopen
  • bounded Goal overlay
  • cloud/account persistence
  • OAuth direct sync
  • creator marketplace
  • AI/crawler와 full planner

Goal boundary

목표 대시보드는 지금 답이 아니다

장기 학습과 반복 루틴의 불편을 새 Goal 객체로 덮지 않는다. 우선 현재 Flow 진행률과 run hierarchy를 읽기 쉽게 만든다.

A. Flow progress 권장

별도 Goal 객체 없이 전체/완료 수, section, next action, run history를 제공한다. 현재 계약으로 가능하며 portable execution layer 경계를 지킨다.

B. Bounded overlay 보류

goal title, milestone, review date만 personal overlay로 추가한다. 실제 반복 사용에서 Flow progress가 부족하다는 근거가 생길 때만 검토한다.

C. Full planner 적용 금지

목표 dashboard, streak, habit, 성과 추적은 FlowMe를 Notion/Todo/Calendar 대체 제품으로 확장한다. 현재 가치 사슬과 맞지 않는다.

반복 summary와 `이번 회차만` 조정이 series/occurrence 차이를 충분히 설명하는가?
export에서 format보다 whole/selected/current scope를 먼저 고르는 순서가 자연스러운가?
장기 학습에서 Flow 진행률만으로 충분한가, milestone/review date overlay가 실제로 필요한가?
