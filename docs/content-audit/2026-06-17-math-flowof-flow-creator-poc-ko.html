콘텐츠를 실행형 진도표로 만들기

목차형 원문을 단원별 공부 Flow로 바꾸기

원문 URL에서 단원과 개념 목록을 확인하고, 같은 패턴을 각 단원에 적용합니다. 사용자는 전체 진도표를 저장하거나 필요한 단원만 가져갈 수 있습니다.

반복 단위: 단원 생성 화면: 진도표 + 오답표 사용자 입력: 시작일, 요일, 시험범위

원문 구조

수학방 목차에서 확인되는 8개 단원을 반복 단위로 둡니다.

보조 목차는 학기와 시험범위 감각을 확인하는 용도입니다. 하위 Flow 구조는 원문 목차를 기준으로 둡니다.

반복 패턴

모든 단원에 같은 실행 구조를 적용하되, 행 제목은 원문 개념 목록에서 가져옵니다.
