포함과 연결은
다릅니다

들여쓰기는 실제 포함 관계입니다. 점선 관계는 UID를 이용한 참조일 뿐, component가 다른 component 안에 들어간 것이 아닙니다.

실제 문법 모양
.ics / text/calendar └─ VCALENDAR ├─ VERSION · PRODID ├─ VTIMEZONE │ ├─ STANDARD │ └─ DAYLIGHT ├─ VEVENT │ └─ VALARM ← 실제 중첩 ├─ VEVENT ← 위 VEVENT의 형제 └─ VTODO └─ VALARM ← 실제 중첩
최상위

VCALENDAR가 전체 component를 묶습니다. 필수 전체 속성은 VERSION과 PRODID입니다.

형제

VEVENT·VTODO·VJOURNAL·VFREEBUSY·VTIMEZONE은 VCALENDAR 바로 아래에 나란히 놓입니다.

실제 자식

VALARM은 VEVENT 또는 VTODO 내부에 들어갑니다. VTIMEZONE은 STANDARD와 DAYLIGHT를 품습니다.

참조 관계

RELATED-TO가 다른 component의 UID를 가리킵니다. 관계를 알려줄 뿐, 대상 앱이 자동으로 날짜·완료·삭제를 전파한다는 보장은 없습니다.

VEVENT 안에 VEVENT 또는 VTODO를 넣는 구조는 표준 문법이 아닙니다.

component 어디에 쓰나 대표 속성 구조상 위치 FlowMe 관점
VEVENT 회의, 방문, 수업, 날짜가 정해진 실행 UID, DTSTAMP, DTSTART, DTEND, SUMMARY, LOCATION, RRULE VCALENDAR의 자식·다른 일정과 형제 시간을 차지하는 Item의 calendar projection
VTODO 마감이 있거나 완료 상태가 필요한 할 일 UID, DTSTAMP, DUE, STATUS, PERCENT-COMPLETE, COMPLETED VCALENDAR의 자식·VEVENT와 형제 task client가 지원할 때 Item의 todo projection
VJOURNAL 날짜와 연결된 일지·회의록·기록 UID, DTSTAMP, DTSTART, SUMMARY, DESCRIPTION VCALENDAR의 자식 메모 projection 후보지만 client 지원 확인 필요
VFREEBUSY 사람·자원의 빈 시간/바쁜 시간 교환 UID, DTSTAMP, DTSTART, DTEND, FREEBUSY VCALENDAR의 자식 일반 Flow 콘텐츠보다는 일정 조율용
VTIMEZONE 표준시·일광절약시 규칙 정의 TZID, STANDARD, DAYLIGHT, TZOFFSETFROM, TZOFFSETTO VCALENDAR의 자식 지역 시간의 정확한 calendar export에 필요
VALARM 시작 전·마감 전 알림 ACTION, TRIGGER, DESCRIPTION VEVENT 또는 VTODO 내부의 자식 Item reminder의 calendar/todo projection
표준에 존재한다 ≠ 모든 앱이 완전히 지원한다. 특히 VTODO, VJOURNAL, RELATED-TO, VALARM의 import·표시·재export 보존은 목표 앱별 round-trip 실험이 필요합니다.

03

표준 구조

  • VCALENDAR에 VERSION·PRODID와 최소 1개 component를 둡니다.
  • VEVENT·VTODO를 서로 중첩하지 않습니다.
  • UID는 지속적이고 충돌하지 않는 opaque 값으로 만듭니다.
  • DTEND와 DURATION, DUE와 DURATION의 동시 사용 금지 규칙을 지킵니다.
  • UTF-8, CRLF 줄바꿈, escaping과 line folding을 validator로 확인합니다.

제품 호환성

  • 같은 Item ID가 재export 후에도 같은 UID로 이어지는지 확인합니다.
  • VTODO·RELATED-TO·VALARM이 import와 재export 후 보존되는지 앱별 테스트합니다.
  • 날짜 없는 Item에 임의 날짜나 VEVENT를 발명하지 않습니다.
  • 개별 완료를 묶음 VEVENT로 잃으면 projection loss를 명시합니다.
  • 출처·권리·안전·개인 overlay는 canonical 데이터에 유지합니다.
