핵심 판단

v1에서 v2로 줄인 이유

1개 저장완료/보류 버튼은 너무 이른 관리 신호다. 저장 확인, 다음 항목, 원문 링크만 남긴다.
4개 저장오늘 할 항목과 저장한 Flow 목록을 같은 층위로 두면 헷갈린다. 오늘 항목을 먼저 둔다.
8개 저장검색과 전체 목록은 필요하지만 첫 화면을 차지하면 안 된다. 기본은 접고 필요할 때 연다.
Flow Map중1 수학은 지도 구조를 유지하되, 내 Flow에서는 현재 항목과 체크/메모만 노출한다.
상태 관리큰 완료/보류 버튼보다 체크박스와 메모가 캘린더/투두 앱 복잡도에 가깝다.
외부 도구항목 아래 세부 Item은 체크리스트로 보이고, 외부 앱에서는 텍스트로 접힌다.

관점 v1 테스트 결과 v2 수정 판단
High 첫 행동 1개 저장 상태에서 나중에 보기/이 항목 완료가 먼저 보여 사용자가 상태 관리부터 떠올릴 수 있음. 1개 상태에서는 저장 확인과 다음 항목만 보여주고, 완료/보류 버튼을 제거. 저장 직후 화면으로 더 자연스러움.
Medium 정보 구조 오늘 할 일과 전체 Flow 목록이 같은 영역에 있어 4개 이상부터 복잡하게 느껴짐. 오늘 항목, 다음 항목, 저장한 Flow를 분리. 8개 상태에서는 저장한 Flow를 기본 접힘. 목록 앱보다 리마인더/오늘 화면에 가까워짐.
Medium 용어 Flow Map/Step/Item 구조를 정확히 잡았지만 사용자 화면에 모델명이 보이면 무겁다. 사용자 화면에서는 항목, 오늘, 다음, 저장한 Flow로 표현. 내부 모델은 유지하고 화면 복잡도는 낮춤.
Low 조작 체크, 메모, 검색, 선택은 동작하지만 버튼 결과가 많은 편. 주요 조작을 체크/메모/목록 열기/검색으로 축소. Stage 0 PoC 수준에서는 충분히 가벼움.

상태 사용자 행동 기대 결과 v2 결과
0개 처음 내 Flow를 연다. 관리 UI보다 저장하면 무엇이 생기는지 알 수 있어야 함. 저장 전 안내와 1개/4개 예시 진입만 보임.
1개 전세계약 Flow를 저장한 뒤 내 Flow를 본다. 완료/보류 관리보다 저장 확인과 다음 항목이 보여야 함. 저장 확인, 다음 항목, 원문 링크, 체크/메모 detail만 보임.
4개 오늘 할 항목 중 중1 수학을 연다. 지도 전체보다 오늘 강의 항목과 체크만 보여야 함. 중1 수학 지도에서 이어보기, 정수와 유리수, 10강 항목으로 열림.
8개 저장한 Flow가 많아져 정수를 검색한다. 첫 화면은 오늘 항목이고, 검색은 목록을 열었을 때 보조로 나와야 함. 기본은 저장한 Flow 접힘. 열면 검색으로 중1 수학만 좁혀짐.

루브릭

v2 자체 평가

User Need Fit: 4저장 후 재방문 상황은 명확함. 실제 사용자 관찰은 아직 없음.
Execution Clarity: 4오늘 항목, 체크, 메모가 명확함. 장기 반복/알림 편집은 아직 없음.
Portability: 4외부 앱 텍스트 fallback이 항목 단위로 보존됨.
Cognitive Load: 4상태 버튼을 제거하고 목록을 접어 첫 화면 부담을 줄임.
Copy Specificity: 3.5대부분 행동 중심이지만, 실제 앱 구현 시 더 짧게 다듬을 여지가 있음.
Accessibility/Operability: 4버튼/체크/검색 동작과 모바일 가로 overflow를 확인함.

검증 기록

확인한 것과 남은 것

  • Playwright 모바일 390px에서 1개/8개 전환, 라이브러리 접힘, 중1 수학 선택, 체크, 메모 입력 확인.
  • Playwright 데스크톱 1365px에서 중1 수학 선택, 체크, 메모 입력, 가로 overflow 없음 확인.
  • 모바일 390px에서 상태 전환 컨트롤을 4칸 세그먼트로 줄여 확인용 UI가 본 화면을 과하게 밀어내지 않도록 조정.
  • v3 사용자형 화면에서는 상태 전환 컨트롤을 제거하고, 기본 진입을 `오늘 할 항목`과 접힌 `저장한 Flow 찾기`로 단순화.
  • v3에서 체크 후 토스트를 제거해 항목 상세와 외부 앱 텍스트 영역을 가리지 않도록 조정.
  • 사용자 화면의 보이는 텍스트 기준으로 `Flow Map`, `Step`, `Item`, `PoC`, `리뷰`, `개발자`, `source fit`, `평가 점수` 노출 없음 확인.
  • `이 항목 완료`, `나중에 보기` 버튼은 v2 사용자 화면에서 제거됨.
  • 남은 리스크: 실제 `/my` 구현 반영, 20개 이상 저장 상태, 알림/반복 편집, 실제 사용자 관찰.
