중복·실패 정책

다시 내보낼 때

  • Calendar: 같은 항목 UID는 유지하지만 provider dedupe는 보장하지 않음
  • Sheet: 기존 파일에 append하지 않고 새 파일로 교체
  • Memo: 같은 문서에 반복 paste하지 않고 기존 block 교체

가져오기가 실패할 때

  • Calendar 앱의 가져오기 메뉴에서 `.ics` 직접 선택
  • 중복 방지를 위해 이전 Flow 전용 캘린더 삭제 또는 새 캘린더 사용
  • 문서가 깨지면 UTF-8로 다시 열기

남은 확인 1건

설정된 Google Calendar, Apple Calendar 또는 Outlook profile에서 artifacts/moving-d30/calendar.ics를 새 전용 캘린더로 가져오고, 같은 파일을 한 번 더 가져와 중복 동작을 기록해야 합니다. 이 확인 전에는 “실제 Calendar 앱 import 성공”을 주장하지 않습니다.
