검증 리포트

모바일 Flow 탭을 “찾아서 열기”로 축소

이 검증은 저장한 Flow가 4~8개 이상으로 늘어났을 때, Flow 탭이 실행 화면처럼 보이는지 아니면 저장 목록을 찾는 화면처럼 보이는지를 확인한 결과다. Today 탭이 오늘/밀림 실행을 맡으므로, 모바일 Flow 탭은 전체 목록 검색과 상태별 접근만 남겼다.

이전 Today P0 검증 리포트

문제

Flow 탭이 실행 탭처럼 보였음

큰 상태판모바일 첫 화면에서 진행 중, 평균 진행, 다음 실행, 밀림이 큰 카드로 노출됐다.
우선순위 카드 반복Today와 비슷한 실행 카드가 다시 나와서 Flow 탭의 목적이 흐려졌다.
직접 완료 버튼목록과 우선순위 카드에서 항목을 열지 않고 바로 완료 처리할 수 있어 오조작 가능성이 있었다.

변경

모바일 Flow 탭의 역할 재정의

영역 변경 전 변경 후
모바일 첫 카드 Flow 상태판 + 실행 우선순위 저장한 Flow / 찾아서 열기 카드 1개
전체 목록 접근 y=1389, 우선순위 카드 아래 y=496, 첫 화면 안
직접 완료 우선순위 카드와 목록 row에 완료 체크 노출 목록에서는 제거. 항목을 열어 상세에서 체크
Flow 보기 관리라는 모호한 링크 Flow 보기로 변경

남은 판단

아직 목표 완료는 아님

Today와 Flow 탭의 역할은 더 분리됐다. 다음에는 체크 탭과 루틴 탭이 같은 단순성 원칙을 따르는지 봐야 한다. 특히 체크 탭이 모든 Flow를 한꺼번에 보여주면 다시 복잡해질 수 있으므로, “최근/진행 중 Flow 선택 후 상세 체크” 흐름으로 충분한지 확인해야 한다.
