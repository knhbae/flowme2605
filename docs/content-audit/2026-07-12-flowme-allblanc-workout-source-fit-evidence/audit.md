# Allblanc 운동 영상 source-fit 감사

## 왜 다시 봤나

기존 freshness gate는 `source_checked_at`만 봅니다. 링크를 오늘 다시 열었다는 사실은 원문이 최근에 작성됐거나 현재 의미상 적합하다는 뜻이 아닙니다. 세 영상은 모두 재생 가능했지만 2020년, 2021년, 2023년 게시물이었고 앱은 원문에 없는 요일을 행 제목에 고정하고 있었습니다.

### 의미상 적용 범위

- 아침 영상은 설명에 매일 아침 따라 하는 루틴이라고 적혀 있지만 FlowMe는 이를 개인 운동 처방으로 사용하지 않습니다.
- 점프 없는 영상 제목의 빠른 감량·지방 연소 문구는 실행 효과로 가져오지 않습니다. `No Jumping`을 모든 사람에게 저강도·저소음·관절 안전으로 확대하지 않습니다.
- 하체 영상은 원문 제목부터 고강도입니다. 강도 적합성 선택 없이 일반 공개 실행으로 두지 않습니다.
- 세 영상 모두 동작 순서나 건강 효과를 FlowMe가 새로 만들지 않습니다.

## 구현 판단

1. `Flow.source_published_at`을 추가해 원문 게시일과 원문 확인 기록을 분리했습니다.
2. 부모 Map의 `publicSaveMode`를 `choose_child`로 두어 여러 영상을 기본 요일로 한꺼번에 저장하지 않게 했습니다.
3. 개별 영상 화면에서 시작일과 운동 요일을 실제로 선택할 수 있게 했습니다.
4. `SavedFlowRecord.weekdays`를 추가해 선택한 요일이 My Flow로 이어지게 했습니다.
5. 영상 행 제목에서 `월/수/금`, `화/목`, `토요일` 고정 표현을 제거했습니다.
6. 일반 세트/강도 기록표를 제거하고 반복 달력, 원본 영상, 완료 또는 중단 기준만 남겼습니다.
7. 현재 CDC 운동 시작 안내를 보조 공식 링크로 연결했습니다.
8. 고강도 하체 Flow는 seed와 source-fit 감사 기록은 보존하지만 부모 Map에서 제외하고 `/f` 공개 실행을 닫았습니다.

## 남은 위험

1. 영상 전 구간의 자세·강도·대상 적합성을 운동 전문가가 검토한 기록은 없습니다.
2. CDC 보조 안내는 영어 원문입니다. 한국어 공식 안내로 대체할 수 있는 정확한 페이지를 계속 찾을 필요가 있습니다.
3. 기존 사용자에게 이미 저장된 예전 기본 요일은 자동으로 바꾸지 않습니다. 사용자가 반복 설정에서 검토해야 합니다.
4. 선택 요일은 저장되지만 종료일 등 My Flow 반복 편집의 모든 필드가 영구 저장되는 구조는 아직 아닙니다.
5. 실제 사용자 관찰 세션은 0건입니다.

다음 감사 순서는 우편 주소 이전, 에어컨 필터, AJD 이사, 웨딩 2개 등 중간 위험 공개 실행 Flow입니다.
