# Allblanc 운동 영상 source-fit evidence

2026-07-12 기준으로 `curated-allblanc-workout-park`와 연결된 정확한 YouTube 영상 3개를 다시 확인한 기록입니다.

이번 감사는 `source_checked_at`이 오늘이라고 해서 원문 자체도 최신이라고 보지 않습니다. 아래 세 값을 따로 판정합니다.

- 원문 게시일: 영상이 실제로 게시된 시점
- 원문 확인 기록: URL, 제목, 재생 가능 상태를 다시 확인한 시점
- 현재 적용 범위: 오래된 영상에서 지금도 그대로 쓸 수 있는 내용과 제외할 주장

## 결론

- 아침 5분 영상: 2020-03-26 게시, 현재 재생 가능. 영상 링크와 5분 전신 운동 범위만 유지합니다.
- 점프 없는 10분 영상: 2021-06-23 게시, 현재 재생 가능. 점프 없는 전신 운동 범위만 유지하고 감량·저소음 효과 주장은 제외합니다.
- 고강도 하체 영상: 2023-02-21 게시, 현재 재생 가능하지만 고강도 적합성 확인이 부족해 공개 Map과 `/f` 실행에서 보류합니다.
- 부모 Map은 전체 저장 화면이 아니라 영상 하나를 고르는 선반으로 변경했습니다.
- 반복 요일은 원문 처방이 아니라 사용자가 정하는 캘린더 설정이며, 선택한 요일은 저장 후 My Flow에서도 유지됩니다.

## 검증 범위

- Playwright 390px/1024px 화면 확인
- 정확한 영상 URL 3개 HTTP 200 / playability `OK`
- source-fit 단위 테스트와 의료 민감 공개 실행 감사
- 선택 요일 저장 레코드 확인
- 고강도 하체 공개 route 404/noindex 확인
- 전체 unit/docs/build 및 주요 회귀 E2E는 커밋 전 최종 검증에서 다시 실행

실제 사용자 관찰 세션과 운동 전문가의 영상 전 구간 안전성 검토는 아직 0건입니다.
