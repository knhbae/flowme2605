남은 백로그

우선순위 주제 상태 다음 조건
P0 엄선 원컨텐츠 9개를 Source-to-Flow 기준으로 재기획 다음 작업 사용자가 제공한 원문 목록을 먼저 기획 파일로 분석하고, Flow Map/Flow 전환안을 검토받는다.
P1 홈과 Flow 찾기 차별화 보류 대표 컨텐츠 수, 리뷰/사용수/신뢰 신호가 쌓인 뒤 홈 정보 구조를 다시 평가한다.
P1 Step의 일정 필드 고도화 보류 ICS 수준의 시간, 반복, 알림, 장소, URL 필드가 필요한 Flow를 실제 컨텐츠 기반으로 확정한다.
P2 레거시/실험 후보 정리 진행 중 대표 후보와 direct-route experiment를 계속 분리하고, 홈 노출 후보는 2~3개만 유지한다.
P2 실제 사용자 관찰 검증 미완료 자동 테스트와 내부 시뮬레이션만으로 “사용자 검증 완료”라고 표현하지 않는다.
