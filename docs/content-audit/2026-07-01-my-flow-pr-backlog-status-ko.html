남은 백로그

우선순위 일감 왜 남았나 다음 행동
P0 next 엄선 원컨텐츠 9개 기획 재검토 지금 UI 기준선은 잡혔지만 대표 콘텐츠 공급이 약하면 서비스가 여전히 테스트처럼 보인다. 바로 개발하지 말고 원문별 Flow Map/Flow/Step/Item 전환안을 기획 HTML로 먼저 작성한다.
P0 next 대표 후보 2~3개 재선정 홈/Flow 찾기에 아무 후보나 올리면 다시 리뷰 선반처럼 보인다. 이사, 전세, 중1 수학, 신규 원문 후보를 같은 기준으로 비교한다.
P1 My Flow 상단 프레임 밀도 축소 Today 본문은 정리됐지만 모바일 첫 viewport에서 헤더와 요약이 아직 높다. 실제 사용자 데이터가 들어간 상태에서 상단 문구/탭/요약 높이를 다시 줄인다.
P1 Step 일정 필드 고도화 Step은 ICS 수준의 날짜/시간/반복/장소/URL을 가질 수 있으나 기본 화면에 다 드러내면 무겁다. Step detail 안에서 progressive edit로 다루고, 실제 콘텐츠 기반 필요성을 확인한다.
P2 홈과 Flow 찾기 차별화 컨텐츠 수, 사용기록, 리뷰, 완료율 같은 신뢰 신호가 아직 없다. 가짜 social proof 없이 source, input count, artifact preview, update date만 사용한다.
P2 실제 사용자 관찰 검증 자동 QA와 내부 시뮬레이션은 제품 가능성 근거이지 실제 검증은 아니다. 대표 후보가 다시 정리되면 1~3명 관찰 세션으로 save→execute를 본다.
