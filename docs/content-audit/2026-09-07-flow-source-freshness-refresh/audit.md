# 2026-09-07 Flow source freshness audit

## 판정 방법

1. 저장된 원문 URL의 현재 응답과 페이지 제목을 확인했습니다.
2. Flow의 제목, 설명, 실행 항목, 일정·주기를 원문 본문과 다시 대조했습니다.
3. 행정·재정·건강 영역에서 원문이 직접 지지하지 않는 판단이나 보장을 Flow가 추가하지 않는지 확인했습니다.
4. 의미 범위가 유지된 경로만 `source_checked_at`과 source-fit `checkedAt`을 갱신했습니다.
5. 실제 페이지 제목과 저장 제목의 차이가 내용 식별에 영향을 주는 3개는 제목을 동기화했습니다.

## 추가 링크 수리

전체 공개 경로 링크 검사에서 `ev-subsidy-apply`의 예전 공식 주소가 HTTP 404로 바뀐 것을 확인했습니다. 기본 원문은 현재 지원 대상·신청절차 페이지로, 보조금 현황 항목 링크는 현재 지자체별 지급현황 페이지로 교체했습니다. 실행 순서와 위험 경계는 현재 공식 내용과 일치해 유지했습니다.

## 유지한 경계

- 통신 요금제와 여행 상품은 추천하거나 가격을 고정하지 않습니다.
- 전세 계약의 법률·안전 판단과 보증보험 가입 가능 여부를 Flow가 확정하지 않습니다.
- 반려동물 건강과 예방접종 판단은 동물병원 상담을 우선합니다.
- 초등 입학 준비는 현재 학교·교육청 안내를 우선하며 아동의 민감정보를 저장하지 않습니다.
- 정수기 필터 주기는 모델별 제조사 안내를 우선합니다.
- 플랭크 원문의 효과, 체지방, 식단 주장은 일정으로 옮기지 않고 통증·어지러움·호흡 곤란 시 중단 조건을 유지합니다.

## 별도 보안 게이트

같은 유지보수 작업에서 잠금 파일의 전이 의존성만 갱신했습니다. `browserslist`는 `4.28.2`에서 `4.28.9`, `postcss-selector-parser`는 `6.1.2`에서 `6.1.4`로 갱신하며 `package.json`의 직접 의존성 범위와 제품 코드는 바꾸지 않았습니다.

## 증거 한계

전체 실행 경로의 고유 링크 156개 중 148개는 직접 도달했고 1개는 정상 페이지로 리디렉션됐습니다. 접근 차단 1개와 네트워크 오류 6개는 수동 재확인 대상으로 남겼으며, HTTP 404·410처럼 자동 판정 가능한 끊어진 링크는 0개입니다.

이 검토는 원문 의미와 현재 변환 범위를 확인한 것입니다. 배포 확인, 실제 기기 확인, 관찰 사용자 테스트를 수행했다는 뜻이 아닙니다.
