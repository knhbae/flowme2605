같은 부모·같은 레벨에 묶인 이동 제한을 없앴다. 이번 변경은 독립 시안의 문서 본문에 적용했다.

## 확인할 조작

| 해볼 일 | 기대 결과 |
| --- | --- |
| ‘큰 박스 확인’을 길게 누르고 다른 부모 아래로 끌기 | 형제가 없어도 이동. 자신의 진행·날짜는 유지 |
| 왼쪽으로 끌어 최상위 또는 폴더 바로 아래로 꺼내기 | 같은 ID의 독립 할 일이 됨 |
| 기존 할 일을 다른 할 일 아래로 넣기 | 하위에 있어도 원래 일정·진행 기록·연결·기간 목록 유지 |
| 부모나 폴더·Flow 연결을 잡고 이동 | 딸린 원문 줄도 함께 이동 |
| ↔ 깊이 버튼 → ‘여기’ | 드래그 없이 같은 위치 선택 |
| 기존 상단 ↶ | 한 번의 이동 전체 복원 |

자기 자신/후손으로 넣는 순환과 잘못된 연결은 막는다. 들여쓰기 때문에 날짜·메모·시간의 주인이 사라지는 경우도 원문을 유지한다. 본문에서 날짜 구획을 넘겨도 기존 일정과 과거 진행 기록을 보존한다.

새 하위 체크는 기간 목록에 자동으로 추가하지 않는다. 독립 할 일로 꺼낸 뒤에는 다시 하위로 넣어도 기존 기간 목록에 남는다. 부모·자식 진행률은 자동 합산하지 않는다.

## 범위

이 버전은 독립 HTML 문서 본문에서의 자유 이동이다. 문서 안 폴더·Flow 연결의 배치를 바꿔도 실제 폴더 카탈로그·원본 Flow 소속은 그대로다. 다른 문서로 직접 드래그, 실제 폴더 트리 재편, 공유 원본 수정, 제품 통합은 추가하지 않았다.

기존 v10·저장 키는 보존하며 데이터 자동 이전은 없다. 문서 1,200행·100,000자와 깊이 32의 자원 제한은 남는다. 매우 깊은 원문은 좁은 화면에서 줄바꿈이 많아질 수 있다. Figma 미사용.

휴대전화에서는 ‘큰 박스 확인’을 다른 부모 아래로 옮기기 → 최상위로 꺼내기 → 상단 ↶로 되돌리기를 확인하면 된다. 실제 손가락 조작감과 OS 키보드는 자동 시뮬레이션과 별도 확인이 필요하다.

## 열기와 재검사

Node.js와 저장소의 Playwright 의존성이 준비된 상태에서 이 폴더를 기준으로 실행한다.

- 화면만 열기: `node serve.cjs`를 실행하고 출력된 주소를 연다. 포트를 바꾸려면 `node serve.cjs 8780`처럼 적는다.
- 전체 재검사: `node verify-all.cjs`. 임시 로컬 서버를 자동으로 열고 닫으며 모델 405개, 브라우저 93개, 단일 HTML 13개와 파일 정합성을 확인한다.
- 설치 없이 보기: `flowme-text-workspace-v11.html`을 직접 연다.

브라우저 runner와 최종 검증은 v10 폴더나 기존 dirty 파일이 없어도 실행된다. `baseline.json`의 39개 해시는 v11을 만들 당시 선행 파일을 보존했다는 역사적 기록이며 현재 파일을 다시 요구하지 않는다. 자동 캡처 전체는 gitignore된 `output/`에 생성되고, 위 대표 3장만 이 패키지에 보관한다.

보관 커밋의 최소 범위는 이 v11 폴더와 `docs/specs/2026-09-08-text-workspace-free-move-v11/`이다. 제품 코드·기존 v10·다른 미추적 문서·선행 dirty 파일은 포함하지 않는다.
