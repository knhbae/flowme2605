- CDP 가로 드래그, 깊이 버튼 미리보기, 좌우/상하 키보드, 목적지 탭, 취소, Undo/Redo/reload를 확인했다. 새 이동창·하단바·Undo 버튼은 없다.
- 저장 실패는 저장본 원위치+화면 초안을 유지하고 재시도로 전체 반영했다. 다른 탭 충돌은 선택 해제·덮어쓰기 차단을 확인했다.
- F06에서 Task 아래 Picker 연결·날짜 keep·동일 ID·자기참조 거부를 확인했다. 내려받은 TXT 참조 보충줄은 실제 깊이+1이었다.
- F13에서 다운로드 스트림을 읽어 v11 recovery JSON 형식·미저장 전체 상태·진행 기록을 확인했다. 재가져오기는 검사하지 않았다.

초도 발견과 수정 재검증

- R928 참조 직속 메모/날짜/시간의 미승인 해석은 거부로 복원됐다. 일반 하위를 참조 아래 옮기는 허용 경로는 F06에서 통과했다.
- F15 속성만 Tab해 소유 관계가 사라지는 전이는 원문·속성 불변으로 거부됐다. 정상 깊이6의 Tab/Shift+Tab·재부모는 허용됐다.
- F06 빈 하위 삽입 줄의 Picker 연결 거부는 수정 후 통과했다. P911 깊이 선택·F03 seed 메모·다운로드 메뉴 잔존은 하네스 전제 오류로 구분했다.
- 초도에서 발견한 결함과 수정 결과는 위 항목에 남겼다. 중간 원시 결과 14개는 최종 보관본에서 제외했고, 뒤에 추가한 검사도 최종 93개 실행에 포함했다.
