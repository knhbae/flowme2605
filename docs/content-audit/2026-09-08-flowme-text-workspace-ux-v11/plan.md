# v11 자유 이동 작업 계획

사용자 승인: 가능한 이동은 허용하고 순환 등 구조적 문제만 차단한다. 부모·레벨 변경으로 날짜·진행 기록·연결을 잃는 문제는 사용 제한 대신 구현으로 해결한다.

1. v10/명세/선행 dirty 파일 보존 해시, 독립 v11 저장소.
2. 같은 ID를 유지하는 부모 변경·들여쓰기 전이 모델과 안전한 대상 목록.
3. 직접 드래그의 가로 위치로 들여쓰기 미리보기, 본문 탭/키보드 대안·기존 Undo.
4. 앱 연결·기간/진행/참조 회귀, 다양한 문서 구조·모바일/태블릿 시뮬레이션.
5. 모델/브라우저/단일 HTML/보존 해시/문서 검사와 짧은 결과.

범위: 독립 HTML 시안의 문서 본문과 기존 개인 Flow/폴더 연결. 실제 공유 원본·외부툴·제품 앱 통합·공개/배포는 제외. 같은 부모/고정 레벨 제한을 대체하며, 문서 배치는 실제 폴더 카탈로그/Flow 공개본을 몰래 바꾸지 않는다.
