My Flow 유형 혼합 시뮬레이션

저장 개수 다음 축으로, 일정형, 루틴형, 단일 체크리스트, 학습 지도형이 한 My Flow 안에 섞였을 때도 사용자가 같은 방식으로 실행할 수 있는지 내부 시뮬레이션했다. 사용자용 화면과 검토 문서는 분리한다.

사용자용 유형 혼합 화면 유형 혼합 관찰 키트 관찰 롤업 저장 개수별 v4 서비스 UX 백로그

판정

유형이 달라도 My Flow에서는 Step 중심으로 합쳐지는 방향이 맞다

학습 지도형의 하위 Step을 별도 지도 UI로 크게 보여주면 화면이 다시 과해진다. 이번 PoC처럼 Today 목록에서는 모든 항목을 같은 Step row로 보이고, 상세에서만 원문 범위, 체크, 메모, 외부 앱 fallback을 제공하는 방식이 전세/10개 Flow 수준과 가장 가깝다.

  • 캘린더/투두에 저장되는 최소 단위는 Step이다.
  • Item은 상세 안 체크 또는 외부 앱 텍스트로 접는다.
  • Flow Map은 My Flow에서 별도 대시보드가 아니라, 현재 이어볼 Step으로 들어온다.
  • 사용자 화면에는 내부 평가, source fit, Flow Map 설명을 넣지 않는다.

UX 리뷰

좋은 점과 의심할 점

좋은 점날짜형, 루틴형, 학습 지도형이 모두 같은 row/detail 패턴으로 열려서 화면 모델을 새로 배우지 않아도 된다.
좋은 점Flow Map의 하위 Step이 기존 Flow Step과 같게 보이므로 “큰 지도 안의 작은 실행”이 과하지 않다.
의심할 점일정/루틴/학습/체크/보관 chip이 많아지면 카테고리 관리 앱처럼 보일 수 있다.
의심할 점학습 지도 사용자는 가끔 전체 단원 위치를 보고 싶을 수 있다. 다만 첫 화면에 항상 보일 필요는 없다.
줄인 것진행률 대시보드, Flow Map 전체 구조, 상태 버튼 묶음, 큰 완료 CTA를 넣지 않았다.
남긴 것날짜 레일, 오늘 목록, 저장한 Flow 찾기, Step 상세, 체크, 메모, 외부 앱 텍스트만 유지했다.

신호등급수정
사용자가 유형 chip을 눌러야 하는 필터로 오해한다. Medium 목록 row의 유형 chip을 더 작게 만들거나 일부만 표시한다.
학습 지도 사용자가 전체 단원 위치를 계속 찾는다. Medium 상세 하단에 접힌 전체 단원 보기만 추가하고 첫 화면에는 두지 않는다.
사용자가 자동 저장 표시를 보지 못해 메모가 저장됐는지 불안해한다. High 자동 저장 표시를 메모 입력창 바로 위나 안쪽으로 더 가깝게 옮긴다.
저장한 Flow 찾기에서 검색보다 필터가 눈에 먼저 들어와 헤맨다. Medium 필터를 검색 아래 작은 보조 row로 유지하거나, 초기에는 숨긴다.
