FlowMe Input Composer UX v1.1 interactive prototype

Executive verdict

좋은 콘텐츠와 3열 workbench는 유지하고, 여정과 상태를 제품 수준으로 연결한다.

v1은 source fidelity와 artifact 판단이 강합니다. v1.1은 입력 경로 선선택, 역할 혼합, 빈 결과 탭, 미리보기에서 끊기는 여정을 고칩니다. 전면 재설계가 아니라 구조적 focused iteration입니다.

유지

  • 3열 입력·결과 비교 구조
  • 원문 범위와 출처 추적
  • 8개 사례의 source-specific 결과
  • 가짜 Flow를 만들지 않는 경계

변경

  • 네 입력 경로를 통합 composer로
  • 5개 탭을 추천 결과 + 보조 결과로
  • 역할 토글을 진입 기반 lane으로
  • 미리보기를 export/save receipt까지

추가 판단

  • source update 수동 재연결
  • 권리·안전 승인 주체
  • protected source 보관 정책
  • 외부 연동 전 receipt 보관 기간

1. 감지·lookup

URL/한 줄/여러 줄 deterministic 감지, 감지 수정, canonical URL 기존 Flow 조회.

2. overlay·receipt

이사일과 세탁조 trigger를 user overlay/run에 분리하고 export/save receipt를 남김.

3. 경계·재시도

Todoist source import required, provider/retry error, draft recovery를 실제 상태 계약으로 연결.
