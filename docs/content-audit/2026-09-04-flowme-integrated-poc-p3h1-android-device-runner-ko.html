E5-D actual Android Chrome

휴대폰에서 직접 확인하고 근거를 남깁니다

이 기록기는 자동화 결과를 실제 기기 판정으로 바꾸지 않습니다. 같은 Wi-Fi의 Android Chrome에서 고정된 후보를 직접 조작하고, A1~A6과 운영 저장 데이터 불변을 모두 기록해야 E5-D가 통과합니다.

02 · Scenarios

A1~A6 실제 조작

각 카드의 ‘측정 시작’을 눌러 별도 후보 탭에서 조작하고, 기록기 탭으로 돌아와 ‘측정 종료’ 후 판정과 근거를 적습니다. 추정으로 PASS를 선택하지 않습니다.

A1

짧은 이동은 길게 누르기로 오인하지 않음

누른 뒤 350ms 전에 8px보다 크게 이동합니다. 이동 패널이 열리지 않고 저장도 일어나지 않아야 합니다.

A2

길게 눌러 날짜 이동

항목을 길게 눌러 날짜 목적지를 선택합니다. 기본 컨텍스트 메뉴 없이 같은 transition으로 정확히 한 번 저장되어야 합니다.

A3

드래그 중단은 취소

드래그 중 스크롤하거나 앱을 전환해 포인터를 끊습니다. 패널이 닫히고 이동·저장이 0건이어야 합니다.

A4

메뉴·비드래그 이동과 데스크톱 키보드 근거의 동등성

Android에서는 더보기 메뉴로 폴더 이동과 화면 안의 순서 버튼 이동을 실행합니다. 같은 SHA 후보의 P3-G 데스크톱 키보드 회귀 ID를 함께 적어 세 경로가 같은 transition·저장 규칙을 따르는지 확인합니다.

A5

작성 결과의 소유 화면과 닫기/적용

작성 → Result → 항목 검토 → 속성 편집을 열고 키보드·스크롤로 마지막 행까지 확인합니다. 닫기는 저장 0회와 초점 복귀, 적용은 1회 저장이어야 합니다.

후보 SHA를 유지하기 위한 현재 조작 대응: 과거 문서의 고정 ‘+’ 대신 [data-action="open-authoring-properties"][data-line]과 [data-owner-line] 트레이를 사용합니다.
A6

키보드와 새로고침 복구

마지막 입력과 저장 CTA가 키보드 위에 보이는지 확인하고 저장합니다. 키보드를 닫고 새로고침해 마지막 성공 상태가 복원되는지 확인합니다.

04 · Evidence

근거 파일과 판정 내보내기

화면 녹화·스크린샷의 상대 파일명을 적습니다. 내려받은 JSON과 실제 파일을 PC로 옮긴 뒤 SHA-256·bytes 검증과 사람의 내용 검토를 마쳐야 E5-D가 가능합니다.

    실제 Android Chrome에서 사람의 조작을 기록하는 도구입니다. 자동 브라우저 검사와 실제 기기 검증은 별도 근거로 유지합니다.
