1. 복사 가능한 공유 패킷

첫 관찰 run에는 이 문구를 그대로 사용합니다. 자세한 규정 판단은 최신 학교/기숙사 공지로 되돌립니다.

[기숙사 입사 준비 확인 요청]

대상: 학생 / 보호자 / 기숙사 준비 담당자
마감: 입사 D-7까지 1차 확인, D-Day에는 현장 절차 확인
출처: 최신 학교/기숙사 공지 링크를 먼저 확인하세요.

해야 할 일

  1. D-14 최신 학교/기숙사 공지에서 입사일, 제출서류, 반입금지 품목, 택배 주소, 입사 시간 변경 여부 확인
  2. D-10 제출서류 목록, 제출 방법, 제출 기한 확인
  3. D-7 침구, 세면도구, 수건, 슬리퍼, 첫날 생활용품 준비
  4. D-5 전열기구, 취사도구, 위험물, 주류 등 학교별 반입금지 품목 제외
  5. D-Day 호실/동선 확인, 서류 제출, 카드/키 수령, 시설 점검

주의

  • 학교/기숙사별 최신 공지가 이 패킷보다 우선입니다.
  • 건강검진 결과, 결제 정보, 방 비밀번호, 학생번호, 주민번호, 카드키 번호, 채팅방 ID, 초대 링크는 공유 채널에 올리지 마세요.
  • 확인이 끝나면 공지 확인 완료 / 서류 준비 완료 / 반입금지 제외 완료 / 당일 절차 확인 필요 중 하나로 답해주세요.

2. 채널별 사용 형태

KakaoTalk 가족/그룹 채팅

짧은 텍스트 패킷과 출처 링크를 보내고 네 가지 완료 라벨 중 하나로 답을 받습니다.

Naver Cafe 글/댓글

게시글 제목, 출처 링크, 체크리스트, 댓글 요청을 분리합니다. 막힌 원문은 복사하지 않습니다.

Google Forms / Sheet

상태 선택과 보류 사유만 남깁니다. 이메일 수집이나 민감 문서 업로드는 켜지 않습니다.

Notion / Markdown memo

체크리스트와 출처/주의 경계를 붙여 넣되 API 연동이나 workspace 권한은 만들지 않습니다.
