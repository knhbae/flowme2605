# 공개 콘텐츠 최신성·행동 게이트 감사

## 문제

기존 원문 도달성 검사는 `flow.source_url`만 확인했습니다. 사용자가 항목 상세에서 누르는 링크는 범위 밖이었고, 원문이 열리더라도 해당 Flow가 현재 source-fit 기준으로 저장·실행 가능한지는 공개 화면에서 강제되지 않았습니다. 또한 seed 문구를 고친 뒤에도 `ArtifactWorkbench` 안의 별도 세탁기 사본에 임의 정량과 주기가 남아 있었습니다.

## 적용한 정책

1. 대표 원문과 사용자에게 노출되는 항목 상세 링크를 모두 검사합니다.
2. `keep_representative` 수동 승인 또는 감사 기록이 없는 `real + exact` 콘텐츠만 indexable로 봅니다.
3. source-fit 재검토 또는 source review 대기 route는 `noindex, nofollow`와 읽기 전용 상태로 둡니다.
4. 읽기 전용 route에는 원문 링크와 최대 5개의 확인 중 항목만 보여주며, 저장·완료 표시·파일 받기·숨은 모바일 저장 바를 렌더하지 않습니다.
5. 네트워크 도달성은 의미 최신성의 증거로 사용하지 않습니다.

## 링크와 콘텐츠 정리

- 전기차 충전소 상세의 폐기 URL을 `https://ev.or.kr/`로 교체했습니다.
- 출생신고 상세 링크를 법원 출생신고 안내 주소로 교체했습니다.
- 고용보험 일반 홈을 고용24 구직급여 안내로 교체했습니다.
- 해외안전여행과 한국공항공사 링크를 현재 도달 경로로 교체했습니다.
- 신차 인수, 냉장고 재고 소진, 세탁기 통세척 Flow를 현재 원문과 대조해 대표 승인으로 승격했습니다.
- 세탁기 화면의 `과탄산소다 100g`, 임의 `2주 1회` 문구를 제거하고 모델 설명서가 허용한 종류·양과 서비스 안내를 우선하도록 바꿨습니다.
- 아이 도안, 운동 영상, 몬스테라, 정수기처럼 원문이 열려도 현재 구조 보강이 필요한 route는 승격하지 않았습니다.

## 화면 판정

- 승인 route: 실제 제목, `index, follow`, 저장·Flow 단위 export·저장 전 미리보기 유지
- 재검토 route: `원문 확인 중 | FlowMe`, `noindex, nofollow`, 읽기 전용 게이트, 저장 0, export 0, checkbox 0
- 모바일 390px과 wide 1024px 모두 horizontal overflow 0
- 세탁기 승인 화면의 금지된 과거 정량/주기 문구 0

## 남은 위험

- 법원 출생신고 안내 1건은 현재 법원 서비스 안내 화면으로 리다이렉트됩니다.
- KDCA, NHIS, MOLIT 등 7개 URL은 자동 fetch를 차단하거나 네트워크 오류를 반환했고, 외부 2개 URL은 403입니다. 링크 rot로 단정하지 않고 수동 확인 대상으로 유지합니다.
- 568개 읽기 전용 route의 source-fit 재검토는 끝난 것이 아닙니다. 다만 완료 전에는 검색·저장·내보내기로 확산되지 않습니다.
- 실제 사용자 관찰은 0/15이므로 이번 결과는 자동 QA와 시각 확인이며 사용성 검증 완료를 뜻하지 않습니다.
