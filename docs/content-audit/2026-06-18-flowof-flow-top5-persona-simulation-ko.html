Top 5 실행형 지도 PoC를 페르소나 기준으로 다시 돌리고 고쳤다

이번 작업은 후보를 더 고르는 것이 아니라, 이미 만든 클릭 PoC가 실제 사용자와 제작자 저니에서 막히는지 확인하고, 막히는 부분을 HTML에 반영한 반복 개선 기록이다. 실제 사용자 행동 데이터가 아니므로 검증 완료로 부르지 않는다.

기준 8개 페르소나 10개 1차 High 3개 수정 모바일/데스크톱 재시뮬레이션 통과

판단 기준

사용자 기준

  • 원문을 본 사용자가 왜 저장하는지 5초 안에 보인다.
  • 저장 전 화면은 생성 결과물을 먼저 말한다.
  • 내 앱 화면에는 저장하지 않은 항목이 섞이지 않는다.
  • 오늘 실행 화면은 체크, 짧은 메모, 원문 링크만 둔다.
  • 버튼명은 실제 생성물과 일치한다.

제작자/출처 기준

  • 원문에 반복 하위 단위가 최소 3개 이상 있다.
  • 하위 단위의 공통 패턴이 제작자 화면에서 보인다.
  • 원문에 없는 체크 항목을 그럴듯하게 만들지 않는다.
  • 건강/육아/지역 의존 정보는 출처와 주의 경계를 분리한다.
  • 외부 코스나 원문 앱을 FLOW 안에 복제하지 않는다.

1차 시뮬레이션에서 발견한 문제

등급 문제 영향 수정
High 모든 후보의 저장 버튼이 `전체 일정 만들기`로 고정되어 있었다. 작물표, 기타, 웹디자인, 이유식은 일정만 생기는 것이 아니어서 버튼명과 결과가 불일치했다. 후보별로 `9주 러닝 일정 만들기`, `선택 작물 캘린더 만들기`, `Grade 1 연습표 만들기`, `웹디자인 진도표 만들기`, `월령 식사 타임라인 만들기`로 분리했다.
High 내 앱 화면에 아직 저장하지 않은 후보가 `저장 전 미리보기`로 섞여 있었다. 실제 사용자 입장에서는 내 Flow에 왜 저장하지 않은 항목이 있는지 헷갈린다. 저장 전 후보는 내 앱 실행 체크를 숨기고, 먼저 저장 전 화면으로 돌아가게 했다.
High 작물표에서 `2주 간격 재파종`처럼 원문 표에서 직접 확인되지 않은 실행 항목이 있었다. 출처 충실도 문제. AI가 빈칸을 채운 것처럼 보인다. `RHS 표의 파종 구간 메모`, `수확 시작월 표시`처럼 표에서 온 단서로 줄였다.
Medium 사용자 화면 상단에 `Flow of Flow 클릭 PoC` 같은 내부 용어가 있었다. 사용자용/검토용 화면 분리가 흐려진다. `실행형 지도 샘플`, `큰 지도와 오늘 실행` 같은 사용자 언어로 바꿨다.
Medium 제작자 화면의 `원문 행` 라벨이 모든 콘텐츠에 맞지는 않았다. 러닝/기타처럼 행보다 모듈/주차인 콘텐츠에서 어색했다. `반복 단위`로 바꿔 주차, 모듈, 작물, 월령에 공통 적용되게 했다.

재시뮬레이션 결과

사용자 루프

  1. 후보를 선택한다.
  2. 저장 전 화면에서 결과물을 확인한다.
  3. 후보별 저장 버튼을 누른다.
  4. 내 앱 화면에서 오늘 실행 체크를 한다.
  5. 메모와 원문 링크 위치를 확인한다.

5개 후보 모두 모바일/데스크톱에서 저장 후 체크까지 동작했다. 저장 전 후보는 내 앱 실행 카드로 섞이지 않았다.

제작자 루프

  1. 후보를 선택한다.
  2. 제작자 화면에서 원문 URL을 본다.
  3. 반복 단위 가져오기를 누른다.
  4. 하위 반복 단위와 사용자에게 보일 결과를 확인한다.
  5. 저장 전 화면으로 돌아가 사용자 결과를 본다.

5개 후보 모두 반복 단위 가져오기, 사용자 미리보기 연결이 동작했다.

후보별 재판정

후보 판정 근거 다음 개선
러닝 9주 Go 9주/주3회/세션 반복이 명확하고 저장 전-내 앱 분리가 잘 맞는다. 다음 단계에서 전용 클릭 PoC로 확장할 1순위.
작물표 Go 표의 작물 행이 하위 Flow로 잘 내려온다. 표 기반 Flow of Flow 대표성이 있다. 지역/기후 선택은 고급 설정으로만 둔다.
기타 Grade 1 Go 제작자 코스가 모듈별 연습 Flow로 자연스럽게 바뀐다. 레슨 복제 없이 연습표/통과 기준만 유지해야 한다.
웹디자인 Watch 구조는 강하지만 LMS와 겹칠 위험이 있다. 진도표/프로젝트 상태만 다루는 비교군으로 유지.
이유식 Conditional 월령 구조는 강하지만 건강/영양 경계가 무겁다. 공식/전문가 경계와 상담 조건을 더 보강해야 한다.
