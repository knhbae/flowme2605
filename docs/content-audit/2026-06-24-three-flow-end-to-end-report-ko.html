시뮬레이션 경로

역할 경로 확인한 점
제작자 콘텐츠 선택 → 원문 구조 → Flow 편집 → 저장 결과 → 공개 전 점검 제작자가 어떤 구조를 공개하는지 보고, 원문에 없는 Item을 추가하지 않는 경계가 보임.
사용자 공개 Flow 선택 → Flow/Step 탐색 → 날짜 입력 → 저장 → 내 Flow에서 실행 저장 전 봤던 구조가 저장 후 체크/메모 가능한 실행 화면으로 이어짐.
내 도구 캘린더/진도표/체크 메모 미리보기 이사와 영유아는 캘린더형, 수학은 진도표형으로 목적지가 분리됨.

Flow별 판정

Flow 좋은 점 남은 점 현재 판단
원룸 이사 D-30 원문 체크리스트와 날짜형 실행이 잘 맞고, 사용자가 복사하고 싶은 이유가 강함. 외부 캘린더 설명 포맷과 업체 메모 필드의 실제 저장 구조를 더 구체화해야 함. 대표 후보로 유지
아이 검진·접종 생년월일 입력 하나로 캘린더 일정이 생기는 흐름이 명확함. 공식 안내, 병원 안내, 부모용 해설 중 primary source를 더 비교해야 함. 유지하되 source 보강
중1 수학 목차 Flow Map > Flow > Step 구조 설명에는 좋음. 억지 Item을 만들지 않는 경계를 보여줌. 학습 몰입 콘텐츠로는 약함. 실제 강의/문제집/커리큘럼형 원문이 있으면 교체 가능. 구조 샘플로 유지, 대표 콘텐츠는 재탐색

목표 대비 현재 위치

거의 충족

  • 사용자 화면과 제작자 화면 분리
  • Flow Map > Flow > Step > Item 구조 반영
  • 저장 전 탐색과 저장 후 실행 연결
  • 캘린더형, 진도형, 타임라인형 패턴 비교
  • 모바일/데스크톱 클릭 가능한 HTML PoC

다음에 남은 핵심

  • 더 강한 원문 후보로 3개 Flow 재선정 또는 보강
  • 외부 캘린더/투두/시트에 들어갈 실제 데이터 계약 정의
  • 제작자 화면에서 Step/Item 수정 행위까지 최소 구현
  • 공개 화면, 내 Flow, 외부 도구 간 용어 정리
  • 실제 사용자 관찰 전용 시나리오와 기록 양식 정리

검증 기록

  • 제작자 화면: 모바일 390px / 데스크톱 1280px 클릭 확인
  • 사용자 화면: 공개 Flow 선택, Flow 펼침, Step 펼침, Item 확인
  • 저장 후 내 Flow 이동, 캘린더 날짜 클릭, 체크, 메모 입력 확인
  • 가로 overflow 없음
  • JS 오류 없음
  • npm run docs:check 통과
