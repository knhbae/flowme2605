Strong 후보 3개를 Flow of Flows 모델로 변환했다

실제 원문 구조가 강한 후보 중 운동 제작자형, 공부/교육형, 육아 식단형을 골랐다. 각 모델은 상위 실행 흐름, 중간 묶음, 하위 실행 콘텐츠, 실제 일정/표/메모 항목으로 내려간다.

러닝 입문 4주 중1 수학 1학기 6개월 이유식 식단표 백신/검진은 공식 출처 분리 기준으로 보류

선정 원칙

원문 계층

주차, 단원, 식단표처럼 원문 자체에 중간 묶음이 있어야 한다.

공통 입력

시작일, 요일, 식단 시작일처럼 상위에서 한 번 받으면 하위 실행 항목에 내려가야 한다.

저장 단위

전체 저장, 구간 저장, 단일 하위 실행 콘텐츠 저장의 차이가 실제로 의미 있어야 한다.

운동 제작자형PoC 선정

러닝 입문 4주 루틴

출처: 런관장 러닝 초보 프로그램 재생목록, 5KM 완주 도전 1주차

사용자 일

러닝을 처음 시작하는 사용자가 영상 시리즈를 보고 이번 달 운동 요일에 맞춰 실행 일정을 만들고 싶다.

공통 입력

  • 시작일
  • 운동 요일
  • 알림 시간

저장 방식

  • 4주 전체 저장
  • 이번 주만 저장
  • 5KM 완주 주차부터 저장

만들지 않을 것

영상에 없는 자세 설명이나 운동 효과 보장을 새로 쓰지 않는다.

상위 실행 흐름: 러닝 입문 4주 루틴

사용자가 시작일과 운동 요일을 넣으면 주차별 캘린더 일정이 생긴다.

중간 묶음: 1주차, 2주차, 3주차, 4주차

각 주차는 하나의 영상 또는 반복 루틴을 가진다.

하위 실행 콘텐츠: 1주차 8분 달리기 + 2분 걷기 반복

캘린더 일정 설명에 원본 영상 URL, 준비, 실행, 운동 후 체크, 중단 조건을 넣는다.

하위 실행 콘텐츠목적지원문 기반 detail사용자 입력/메모
1주차 러닝calendar + check영상 링크, 달리기/걷기 반복 구조실행 여부, 강도, 통증/어지러움 메모
3주차 러닝calendar + check3분 달리기 + 2분 걷기 같은 주차별 루틴다음 주 진행 여부
5KM 도전 1주차calendar8분 달리기 + 2분 걷기 반복 구조운동 요일 변경, 알림 시간
공부/교육형PoC 선정

중1 수학 1학기 진도

출처: EBS 중학 수학 마스터 유형 β 1-1, 중학교 1학년 수학 문제풀이 재생목록

사용자 일

중1 수학 1학기 강좌/문제풀이를 단원별로 따라가며 영상 시청, 문제 풀이, 오답 복습을 관리하고 싶다.

공통 입력

  • 공부 시작일
  • 공부 요일
  • 하루 목표 강의 수

저장 방식

  • 중1 1학기 전체 저장
  • 소인수분해 단원만 저장
  • 오답표만 만들기

만들지 않을 것

원문에 없는 문제나 풀이 내용을 새로 생성하지 않는다.

상위 실행 흐름: 중1 수학 1학기 진도

단원별 학습 목록과 반복 공부 일정, 오답표가 함께 만들어진다.

중간 묶음: 소인수분해, 정수와 유리수, 문자와 식, 일차방정식

각 단원은 여러 강의/문제풀이 row와 복습 일정을 가진다.

하위 실행 콘텐츠: 소인수분해 단원

강의 보기, 문제 풀기, 오답표 작성, 다시 풀 날짜가 하나의 실행 묶음으로 생성된다.

하위 실행 콘텐츠목적지원문 기반 detail사용자 입력/메모
소인수분해 단원sheet + memo강의 번호, 주제, 교재 페이지, 영상 링크상태, 틀린 이유, 다시 풀 날짜
정수와 유리수 단원sheet + calendar강의 순서와 학습 시간목표 완료일, 복습 일정
오답표sheet문제풀이 영상/교재 범위에 연결문항 번호, 오답 이유, 재풀이 결과
육아 식단형PoC 선정

6개월 토핑이유식 식단표

출처: 완밥요정 6개월 토핑이유식 식단표, 완밥요정 6개월 면역강화 이유식 식단표

사용자 일

6개월 이유식을 시작하는 보호자가 식단표를 주간 표와 알레르기 관찰 메모로 옮겨두고 싶다.

공통 입력

  • 식단 시작일
  • 제공 시간
  • 아기 이름 또는 메모명

저장 방식

  • 4주 식단표 저장
  • 이번 주 식단만 저장
  • 첫 재료 관찰표만 만들기

만들지 않을 것

특정 재료의 효과를 보장하거나 의료 조언처럼 표현하지 않는다.

상위 실행 흐름: 6개월 토핑이유식 식단표

식단표, 제공 시간, 재료 시도, 반응 기록이 연결된다.

중간 묶음: 1주차, 2주차, 첫 식재료, 장보기

주차별 식단 row와 재료별 관찰 메모가 분리된다.

하위 실행 콘텐츠: 첫 재료 시도표

식재료, 제공일, 제공 시간, 먹은 양, 반응 메모, 원문 URL을 표로 남긴다.

하위 실행 콘텐츠목적지원문 기반 detail사용자 입력/메모
주간 식단표sheet + calendar식단표 파일, 제공 시간, 배죽 기준먹은 양, 반응, 다음 재료
첫 식재료 관찰표sheet + memo곡류/육류/채소류 등 첫 식재료 목록반응 메모, 중단/상담 메모
장보기 메모memo원문 재료 목록집에 있는 재료, 구매 필요 재료

보류했지만 강한 공식형 모델

우리 아이 예방접종 일정

질병관리청 출생일 기반 일정과 표준 예방접종 일정표는 구조가 매우 강하다. 다만 민감 카테고리이므로 이번 대표 PoC에서는 공식 출처 분리 기준으로만 둔다.

  • 공통 입력: 아이 생년월일
  • 하위 실행 콘텐츠: 월령별 접종 일정
  • 목적지: 캘린더 + 병원 예약 메모
  • 주의: 접종 판단/의료 조언 금지

영유아 건강검진 일정

회차와 월령이 명확해서 구조는 강하지만, 사용자 화면은 예약/문진표/준비물 중심이어야 한다.

  • 공통 입력: 아이 생년월일
  • 하위 실행 콘텐츠: 회차별 검진 예약
  • 목적지: 캘린더 + 체크리스트
  • 주의: 건강 상태 판단 금지

이 두 모델은 다음 민감 카테고리 테스트에서 별도 PoC로 만드는 편이 안전하다.
