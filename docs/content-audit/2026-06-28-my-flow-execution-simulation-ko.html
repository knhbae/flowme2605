Journey Rehearsal

사용자 저니별 결과

저니 시뮬레이션 판정 반영한 개선
홈에서 시작 서비스 약속을 읽고 대표 이사 Flow Map, 중1 수학, 전세 단일 Flow 중 하나로 이동. 통과 홈에서 전체 후보 목록을 제거하고, 대표 시작점만 남김.
Flow 찾기 Flow Map과 단일 Flow를 구분해서 보고, 저장 전 공개 상세로 진입. 통과 단일 Flow 대표 후보를 전세 1개로 축소. 약한 후보는 대표 화면에서 제외.
저장 직후 저장 완료 후 첫 Step을 확인하고, 전체 Flow 또는 캘린더로 이동. 통과 post-save 화면은 확인 우선. 전체 관리 화면은 사용자가 열 때만 보여줌.
내 Flow 1개 탭을 숨기고 오늘 할 일 중심으로 바로 실행. 통과 모바일 단일 저장 상태에서는 불필요한 최상위 탭을 숨김.
내 Flow 3개 오늘/캘린더/Flow 탭으로 이동하고, Step detail을 클릭한 자리에서 열어봄. 통과 Flow 카드의 다음 Step을 누르면 같은 카드 아래 detail이 열리고, 다시 누르면 닫힘.
내 Flow 8개 이상 오늘은 우선순위, 캘린더는 날짜, Flow는 목록/필터로 이동. 보류 체크리스트/루틴 최상위 탭은 제거. 다만 고밀도 목록의 검색/신뢰 신호는 후속 백로그.

UX Review

UX 디자이너 관점 평가

좋아진 점
  • 홈과 카탈로그가 같은 화면처럼 보이던 문제가 줄었다.
  • 내 Flow의 최상위 개념이 오늘/캘린더/Flow로 단순해졌다.
  • Step detail이 클릭한 카드 아래에서 열려 모바일 스크롤 부담이 줄었다.
  • 사용자 화면에 내부 평가, 후보 점수, 검토 문구가 노출되지 않는다.
아직 남은 문제
  • 콘텐츠 선택 이유를 뒷받침할 사용수, 리뷰, 제작자 신뢰 신호가 부족하다.
  • 중1 수학은 구조 검증에는 좋지만, 사용자가 실제로 공부하고 싶게 만드는 원문/학습 매력이 약하다.
  • 영유아 검진/접종은 대표 후보로 올리기 전에 공식 표 기반 Step 정보가 더 필요하다.
  • 고밀도 저장 상태의 Flow 목록은 검색, 숨김, 완료 그룹의 상품화 판단이 더 필요하다.

Decision

다음 사용자 검토 전 판단 기준

질문 이번 상태 사용자 검토에서 볼 점
서비스 입구처럼 보이는가? 개선됨 홈에서 무엇을 눌러야 할지 5초 안에 보이는지.
저장 후 다음 액션이 명확한가? 개선됨 저장 완료 후 첫 Step, 전체 보기, 캘린더 보기의 차이가 보이는지.
복잡도가 캘린더/투두 수준인가? 대체로 통과 체크/루틴/지도 용어가 화면 위로 과하게 올라오지 않는지.
대표 콘텐츠가 납득되는가? 부분 통과 이사, 중1 수학, 전세만 보고도 서비스 가능성이 보이는지.

Verification Targets

클릭 검증 대상

  • 홈: 대표 시작점만 보이고 검토 문구가 없는지.
  • Flow 찾기: Flow Map과 단일 Flow가 카탈로그처럼 정리됐는지.
  • 원룸 이사 D-30: 저장 전 사용자가 무엇을 얻는지 보이는지.
  • 내 Flow 원문 기반 데모: Flow 탭에서 Step detail이 같은 카드 아래 열리는지.
  • IA/후보 재분류 리포트: 대표 후보와 보류 후보가 분리됐는지.
