연결 문서도 같은 방식으로 읽히게 만든 한국어 HTML 묶음

메인 로드맵에서 연결한 주요 내부 문서, 제품 규칙, 후보 게이트, 보조 분석 문서를 하나의 한국어 HTML 문서로 다시 구성했다. 각 섹션은 원문 전체를 복사하지 않고, FlowMe 의사결정에 필요한 핵심만 압축하며 최신 커버리지 상태는 별도 감사 문서에서 확인한다.

읽는 순서

운영 인덱스, 로드맵, 커버리지 감사, 압축표, 제품 규칙, 후보 게이트 순서로 본다.

핵심 기준

사용자 순간, 자연 산출물, Stage 0 행동, 제품 결정, 만들지 않을 것.

주의

이 문서는 사용자 행동 검증이나 공개 라우트 승인으로 보지 않는다.

현재 실행 상태

distribution-channel-handoff는 no signal, 세션 0 / 3입니다. 다음 행동은 초대 문구 발송 후 스케줄 트래커를 invited로 갱신하고, 답장 확인 뒤 agreed 슬롯만 관찰하는 것입니다. Evidence board는 3 completed usable sessions 이후에만 바꿉니다.

자연 산출물

공개 전 조건

하나의 현재 primary source를 고르고, 최신 공지 우선과 학교별 차이를 화면에 보여야 한다.

저장 금지

건강서류 이미지, 납부계좌, 호실 비밀번호, 학생증/주민번호, 카드키 번호는 FlowMe 밖에 둔다.

만들지 않을 것

기숙사 마켓, 방 배정 추적, 학교 로그인, 결제 추적, 룸메이트 매칭, 학생 생활 대시보드.

현재 상태

`/content-flows` 리뷰 후보는 유지하되 공개 `/f/[slug]` route는 만들지 않는다.

공개 승격 전 필수 확인 이유
최신 기숙사 공지 확인이 첫 행동 학교별/학기별 규정이 다르므로 FlowMe가 일반화하면 안 된다.

7. 초등 입학 공개 라우트 근거 게이트

`elementary-school-entry-d30`은 이미 `/f/elementary-school-entry-d30` 공개 라우트가 있으므로, 일반 후보보다 더 엄격하게 관리해야 한다. 이 섹션은 공개를 유지하되 검증됨이나 대표 사례로 부르지 않기 위한 근거 조건을 정리한다.

현재 유지 조건

첫 카드는 취학통지와 예비소집 확인이어야 하며, 준비물 구매가 아니라 공식 안내 확인으로 시작해야 한다.

보조 자료 역할

학부모 체크리스트는 네임스티커, 등교 동선, 첫날 가방 점검처럼 실행 단서로만 쓴다.

D-14 보류 카드

공책, 미술도구, 정확한 수량처럼 학교별 차이가 큰 물건은 실패가 아니라 정상 보류 상태로 남긴다.

저장 금지

아동 주민번호, 취학통지서 이미지, 건강 기록, 지원금 세부 정보, 담임/교실 화면 캡처는 FlowMe에 저장하지 않는다.

만들지 않을 것

학교 배정 조회, 정부24 연동, 쇼핑 제휴, 입학준비금 추적, 만능 준비물 리스트, 학부모 코칭 프로그램.

다음 근거

관찰 세션에서 부모가 공식 안내 우선과 학교별 보류 의미를 이해하는지 확인해야 한다.

관찰 세션에서 볼 것 통과 신호

8. 원격 도움 세션 사전 체크 게이트

AnyDesk 자체 설정법보다 더 중요한 것은 “화면 공유만으로 충분한지, 1회 원격제어가 필요한지, 반복 관리가 필요한지”를 먼저 고르는 것이다.

1. 요청자와 범위 확인

내가 요청한 도움인지, 누가 무엇을 도와주는지 먼저 확인한다.

2. 최소 권한 방식 선택

화면 공유, 1회 원격제어, 반복 관리 중 가장 작은 권한을 고른다.

3. 민감값은 밖에서 처리

코드, ID, 링크, 비밀번호, 토큰, 스크린샷, 채팅은 FlowMe에 저장하지 않는다.

4. 종료와 접근 검토

세션을 끊고 임시 접근을 검토하며 반복 접근은 해지 또는 재검토한다.

검색 콘솔 축에서 한국어 우선 시나리오로 고른 후보다. 목적은 SEO 성과가 아니라, 사용자가 소유권 확인과 수집 준비를 직접 할 수 있는지, 개발자나 호스팅 관리자에게 무엇을 물어야 하는지 정하는 것이다.

검토 산출물 5단계

  • 사이트 단위와 접근권한 먼저 고르기
  • 소유확인 방법은 Flow 밖에서 선택하기
  • robots, noindex, redirect, frame 이슈 확인하기
  • sitemap, RSS, 수집요청 상태만 남기기
  • 다시 볼 날짜 정하기

저장하지 않을 것

  • 검증값, DNS 값, HTML tag 내용
  • OAuth grant, API key, credential
  • sitemap 파일, generated asset
  • SEO score, ranking tracker, analytics dashboard
현재 상태

/content-flows 리뷰 후보는 만들어졌지만 공개 라우트, Naver integration, DNS automation, SEO 기능은 만들지 않는다.
