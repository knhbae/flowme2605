진행 규칙

진행자는 목표만 읽는다

  • 버튼명과 위치를 말하지 않는다.
  • 90초 동안 스스로 탐색하게 둔다.
  • 도움을 요청하면 먼저 찾는 대상을 되묻는다.
  • 힌트를 줬다면 도움 후 성공으로 기록한다.
  • 가상 데이터와 참가자 ID를 사용한다.
