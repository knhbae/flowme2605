# 한글 원문 기반 Flow 콘텐츠 후보 30개

Date: 2026-06-01

목적:

1. 한글 원문/제작자 콘텐츠 중 FlowMe로 만들 만한 후보를 다시 찾는다.
2. 원문에 있는 실행 구조만 사용해 사용자가 실제로 따라 할 수 있는 Flow 초안을 만든다.
3. 사용자가 1~5점과 메모로 평가할 수 있게 한다.

이번 배치의 원칙:

- 영어 원문은 제외한다.
- 유료/비공개/내용 확인 어려운 원문은 대표 후보에서 제외한다.
- Flow는 캘린더, 루틴, 체크리스트, 시트, 메모 중 하나로 얇게 옮긴다.
- 사진/증빙/상세 기록은 기본 필드로 넣지 않는다.
- 방법, 준비물, 영상, 상품 링크, 주의 문구는 메모에 둔다.
- 유아/이유식/운동/차량/행정은 판단이나 보장처럼 보이지 않게 출처 링크와 실행 메모로 제한한다.

평가 기준:

| 점수 | 의미 |
| ---: | --- |
| 5 | 바로 seed/demo Flow로 만들어도 좋음 |

| 3 | 주제는 괜찮으나 Flow 구조가 약하거나 범위 조정 필요 |
| 2 | 지금은 약함. 다른 원문과 묶거나 재구성 필요 |
| 1 | FlowMe에 맞지 않음 |

## 1. 5세 연간 한글·수 놀이 계획

- 제작자/출처: 어린이집정보공개포털 보육계획안
- 원문: [2026년 연간 놀이 예상안 5세 온누리반](https://info.childcare.go.kr/info/pnis/search/PnisFileDownload.jsp?STCODE_POP=44130000017&filetype=YUPLOADU&flag=DNGB&schoolyear=2026&wkyear=202604)
- 원문 실행 신호: 계절별 놀이 주제, 산책/나들이/행사, 환경교육 날짜, MOMO 한글·수 항목이 월/계절 단위로 정리되어 있다.
- Flow 제목: `5세 한글·수 놀이 캘린더`
- CTA: `놀이 캘린더로 받기`
- 입력: 시작월, 아이 연령, 주 1회/2회 선택
- 캘린더/루틴:
  - 3월: 기본 자음자와 모음자 놀이
  - 4월: 20까지 숫자 알아보기
  - 9월: 흉내 내는 말 놀이
  - 10월: 50까지 숫자 알아보기
  - 11월: 복합 규칙 찾기
- 메모: 놀이 주제, 준비물, 원문 링크, 부모가 같이 해볼 질문 1개
- 완료 기준: 오늘 놀이를 하고 아이가 반응한 단어/숫자를 한 줄 메모
- 평가 메모:

## 2. 5세 월간 보육계획안 캘린더

- 제작자/출처: 어린이집정보공개포털 월간보육계획안
- 원문: [2025년 7월 5세 보육계획안](https://info.childcare.go.kr/info_html5/pnis/search/PnisFileDownload.jsp?STCODE_POP=11620000013&filetype=MUPLOADU&flag=DNGB&schoolyear=2025&wkyear=202507)
- 원문 실행 신호: 7월 1주~5주 소주제, 실내 놀이, 바깥놀이, 기본생활습관, 안전교육, 행사, 한글/수 활동이 주차별로 있다.
- Flow 제목: `5세 7월 놀이 일정`
- CTA: `월간 놀이 캘린더로 받기`

  - 2주: 세탁소 구성놀이
  - 3주: 물놀이 안전 포스터
  - 4주: 같은 물고기 찾기
  - 5주: 이를 깨끗하게 닦아요
- 메모: 놀이 준비물, 안전교육 원문, 부모 질문
- 완료 기준: 놀이 실행 여부와 아이가 고른 활동 1개 체크
