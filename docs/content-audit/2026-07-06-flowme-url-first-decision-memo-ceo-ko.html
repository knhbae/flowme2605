FlowMe Decision Memo 2026-07-06 CEO 승인안

오늘 결정할 것은 “무엇을 만들까”가 아니라 “무엇을 승인할까”다

기존 Executive Report의 결론은 충분히 좁혀졌다. 이제 CEO/임원이 판단해야 할 것은 세 가지다: URL-first를 P0 진입점으로 승인할지, Export Pack v1을 P0 연결 방식으로 승인할지, source trust와 민감 영역 잠금 원칙을 승인할지다.

추천 결론

세 항목 모두 승인을 추천한다. 단, 승인 범위는 P0에 한정한다. Home redesign, direct API/OAuth, AI-first 생성, full editor는 이번 결정에 포함하지 않는다.

왜 지금 결정해야 하나

이 세 결정을 미루면 개발 세션이 URL lookup, export, trust, UI 범위를 동시에 흔들게 된다. 결정이 먼저 있어야 구현 범위와 QA 기준이 좁아진다.

승인 1 URL-first를 P0 진입점으로 확정
승인 2 Export Pack v1을 P0 연결 방식으로 확정
승인 3 source trust와 민감 영역 잠금 원칙 확정

2. 결정 1: URL-first를 P0 진입점으로 승인할 것인가

이 결정은 FlowMe가 “AI 계획 생성기”가 아니라 “URL을 실행 Flow로 바꾸는 연결 레이어”로 시작한다는 의미다.

recommended: approve
1 추천: 승인

추천안

`/flows`에서 사용자가 URL을 넣고, FlowMe가 기존 Flow를 먼저 찾아주는 방식을 P0 진입점으로 승인한다.

대안Home redesign, memo-first, AI-first를 먼저 검토한다.
장점사용자가 이미 보고 있는 URL에서 시작하므로 설명 비용이 낮고 AI 비용도 줄일 수 있다.
리스크초기에는 충분한 source-backed Flow가 필요하다.
보류 시 영향첫 진입점이 흔들려 UI, QA, canary 기준이 계속 바뀐다.
승인 후 다음 행동P0-now canary 4개를 기준으로 URL lookup loop를 개발 handoff한다.
수정 승인 조건memo는 보조 진입으로 남기되 P0의 첫 검증 루프는 URL-first로 둔다.

3. 결정 2: Export Pack v1을 P0 연결 방식으로 승인할 것인가

이 결정은 FlowMe가 초기부터 모든 앱과 직접 연동하지 않고, 사용자의 기존 도구로 옮겨 쓰게 한다는 의미다.

recommended: approve
2 추천: 승인

추천안

P0 연결 방식은 `.ics`, Markdown, checklist 중심의 Export Pack v1로 승인한다. direct OAuth/API는 P1/P2로 둔다.

대안Google Calendar, Notion, Todoist 직접 연동을 P0에 포함한다.
장점계정 연동 없이 캘린더·문서·체크리스트로 바로 가져갈 수 있다.
리스크직접 동기화 경험은 아직 제공하지 않는다.
보류 시 영향외부 연결 전략이 API 논의로 커져 URL-first 검증 속도가 늦어진다.
승인 후 다음 행동canary별 기본 export를 확정하고 export 문구와 잠금 조건을 QA한다.
수정 승인 조건CSV/sheet는 P1 후보로 두되 P0 승인 범위에는 넣지 않는다.

4. 결정 3: source trust와 민감 영역 잠금 원칙을 승인할 것인가

이 결정은 FlowMe가 실행을 도와주되, 출처와 위험을 숨기지 않는 제품이라는 의미다.

recommended: approve
3 추천: 승인

추천안

출처 URL, 확인일, source 상태, 위험도, 주의 문구를 P0 제품 원칙으로 승인한다. 민감 후보는 검토 전 export/save를 잠근다.

대안출처 표시는 나중으로 미루고 UX를 먼저 단순화한다.
장점의료·법률·재무·육아·계약 영역에서 신뢰와 안전 기준을 먼저 세운다.
리스크일부 후보는 바로 저장/export하지 못해 성장 속도가 느려 보일 수 있다.
보류 시 영향민감 canary의 사용 가능 여부와 문구 기준이 계속 논쟁된다.
승인 후 다음 행동P0-now, P1-review, P2-hold 운영 기준을 제품 copy와 QA 기준에 반영한다.
수정 승인 조건본문 copy는 단순하게 두고 상세 출처는 접힘/부록 UI로 뺄 수 있다.
