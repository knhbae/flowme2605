# FlowMe 핵심 여정 UX 검토

2026-09-07 · 설계 검토 / 제품 구현 승인 아님

## 목표와 범위

기존 개발은 보존한다. 개인 TXT 기록과 공개 Flow 재사용의 시작·저장·복귀를 클릭 가능한 작은 시뮬레이터로 검토한다. 새 정책이나 데이터 모델을 확정하지 않는다.

- A: 빈 문서 → 자유 기록 → 그대로 보관 또는 선택한 줄만 할 일 연결 → 날짜/미정 → 오늘 실행 → 원문으로 복귀.
- B: 공개 Flow 읽기 → 읽고 끝내기, 외부 텍스트 받기 또는 개인 사본 → 항목 날짜·메모 조정 → 오늘 실행 또는 외부 전달 → 사본 재진입.
- 작성·공개 / 기여·개선 / 탐색·참여는 선택 분기로 연결 위치를 검토한다. 계정 모드나 필수 단계로 만들지 않는다.

## 작업 순서

1. 현재 개발 증거와 기존 v4.1 화면을 확인한다.
2. 단일 HTML에 두 와이어플로우와 선택적 검토 요약을 만든다.
3. 원문·실행 상태·공개본 분리, 취소·실패·복귀를 시뮬레이션한다.
4. 390px 모바일, 1024×768 및 1194×834 가로 태블릿, 1440×900 화면을 확인한다.
5. 유지/화면 연결 조정/신규 검토 항목과 후속 개발 후보를 정리한다.

## 수정 소유권

이 폴더만 현재 기획 세션이 수정한다. 코드·기존 보고서·DECISIONS·STATUS 등 정본은 수정하지 않는다. 지정 정리 세션 `019e87ae-0f5d-7760-8a60-2b1b01ec5686`은 보존 목록과 정본 문서·PR 관계를 담당한다. 최초 기획 범위에는 게시 작업을 포함하지 않았다. 이후 사용자가 별도 승인한 이 패키지의 commit·push·PR·merge는 정리 세션이 깨끗한 워크트리에서 수행한다. 이 기획 세션은 패키지 경로 점검·인계까지만 맡으며, 제품 코드 수정·삭제·일괄 stage·deploy는 포함하지 않는다.

## 설계 기준

기존 v4.1의 흰 배경, 청록 강조, 옅은 탐색 패널, 구분선 중심 목록, 넓은 본문을 재사용한다. 새로운 시각 브랜드나 이미지 자산을 만드는 작업이 아니므로 Figma·이미지 생성 없이 코드형 와이어프레임으로 확장한다. 기존 화면은 [v4.1 기준 이미지의 보존 사본](./reference-v4-1-desktop-month.png)으로 확인할 수 있다. 원래 경로와 큰 방향·개발 대조 시점은 [근거 보존 기록](./evidence-context.md)에 남겼다.

본문은 한 번에 한 작업을 보여준다. 원문 편집에 실행 관리·공개 설정을 상시 붙이지 않는다. 태블릿은 기존 좌측 탐색을 유지하고 작은 화면에서는 명시적인 탐색 버튼으로 연다. 드래그는 이번 검토 대상이 아니며 모든 새 동작은 버튼·키보드로 가능하게 한다.

## 저장과 시뮬레이션 경계

실제 운영/PoC 데이터를 읽지 않는다. 예시 데이터는 독립 HTML의 전용 키 `flowme:ux-review:20260907:v1` 하나에만 저장한다. 파일 직접 열기에서 저장이 제한되면 실패를 표시하고 현재 입력을 유지한다. 다른 기기 동기화·실제 TXT 파일 원본 저장·공개 발행·질문 전송·외부 도구 자동 동기화는 구현하지 않는다. 예시 날짜는 2026-09-07로 고정한다.

연결 할 일은 원문 줄의 당시 텍스트를 참조하는 설계용 항목이다. 오늘 화면은 같은 ID를 보여준다. 문서를 수정하면 이전 연결과 현재 문서를 비교하고 기존 연결만 유지한다. 미확정 재연결을 실행해 중복을 만들지 않으며 원문·완료·날짜를 덮어쓰지 않는다. 실제 편집기에서 줄 삽입/삭제/중복/이동을 견디는 식별 계약과 연결 교체·해제는 후속 개발 명세에서 정해야 한다. 주소 hash로 같은 문서/사본 화면 reload와 브라우저 Back을 시뮬레이션한다.
