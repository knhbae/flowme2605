3개 Flow 구조 탐색과 저장 후 실행 확인

사용자 화면과 안내/리포트 화면을 분리하고, 공개 Flow에서 저장 전 Flow/Step/Item 구조를 볼 수 있는지 확인했습니다.

이번 패스에서 고친 것

공개 Flow

저장 전 탐색 추가

Flow를 누르면 Step 목록이 열리고, Step을 누르면 원문 기반 Item이 읽기 전용으로 보이게 했습니다.

내 Flow

실행 화면 유지

저장 후에는 같은 Step 구조가 체크, 메모, 날짜 클릭이 가능한 화면으로 바뀝니다.

원문 충실도

억지 Item 제거

중1 수학처럼 원문이 목차형인 경우에는 체크 Item을 만들지 않고 링크, 완료 여부, 메모만 저장합니다.

페르소나별 시뮬레이션

Flow 사용자 상황 눌러본 경로 결과
아이 검진·접종 일정 첫 아이 생후 2개월 일정을 놓치고 싶지 않은 보호자 공개 Flow 선택 → 검진/접종 Step 열기 → 생년월일 입력 → 캘린더 저장 → 3월 날짜 클릭 → Item 체크와 메모 저장 전 기간과 Item을 볼 수 있고, 저장 후 캘린더에서 같은 Step을 실행할 수 있음. 공식/병원 소스 비교는 남음.
중1 수학 목차 진도 전체 목차를 보며 어디까지 봤는지 표시하려는 학생/학부모 단원 Flow 선택 → 하위 Step 열기 → 진도표 저장 → 첫 Step 완료 → 진도표 확인 Flow Map 구조 예시는 성립함. 다만 콘텐츠 자체가 학습 몰입을 만드는 강한 원문은 아니며, Step별 개별 링크 매핑이 필요함.
원룸 이사 D-30 준비 이사일 기준으로 해야 할 일을 날짜별로 복사하고 싶은 사용자 이사 Flow 선택 → D-14 Step과 Item 확인 → 이사일 입력 → 일정 저장 → 7월 날짜 클릭 → Item 체크와 메모 저장 동기와 실행 구조가 가장 강함. 전세 Flow와 유사한 날짜형 준비 콘텐츠로 대표성이 있음.

현재 판정

충족된 부분

  • 2~3개 Flow를 한 화면에서 비교 가능
  • 사용자 화면과 안내/리포트 화면 분리
  • 공개 Flow에서 저장 전 Flow/Step/Item 확인 가능
  • 저장 후 내 Flow에서 같은 구조로 체크/메모 가능
  • 캘린더형, 진도형, 타임라인형의 차이가 보임

남은 리스크

  • 영유아 원문은 공식 안내와 병원 안내 중 더 좋은 primary source 비교 필요
  • 중1 수학은 구조 샘플로는 괜찮지만, 더 매력적인 실제 학습 콘텐츠 후보가 필요
  • 외부 캘린더/투두/시트로 나갈 때의 텍스트/ICS 데이터 구조는 아직 별도 설계 필요
  • 제작자용 구조 편집 화면은 이번 파일에 포함하지 않음
  • 실제 사용자 행동 데이터 검증은 아직 아님

항목 점수 판단

Portability3.5캘린더/진도표/체크는 보이나 외부 내보내기 포맷은 아직 화면 수준.
Cognitive Load3.5공개 탐색은 길어졌지만 필요한 구조 노출로 판단. My Flow는 단순함 유지.
Copy Specificity4일반 설명보다 날짜, Step, Item, 메모 중심으로 정리됨.
Source/Safety3.5건강 관련 보장 표현은 피했지만 source 비교와 caution 구조는 더 분리 가능.
Accessibility/Operability4모바일/데스크톱에서 클릭과 입력은 동작함.

검증 기록

  • 모바일 390px, 데스크톱 1280px 브라우저 클릭 확인
  • 공개 Flow 선택, Flow 펼침, Step 펼침, 읽기 전용 Item 확인
  • 저장 후 내 Flow 이동, 캘린더 날짜 클릭, 체크, 메모 입력 확인
  • 가로 overflow 없음
  • JS 오류 없음
  • 사용자용 화면 금지어 검색 통과
  • npm run docs:check 통과
