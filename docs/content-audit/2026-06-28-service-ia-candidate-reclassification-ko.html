홈은 입구, Flow 찾기는 카탈로그, 내 Flow는 실행 공간

이번 정리는 사용자가 볼 PoC 화면에서 내부 평가와 후보 검토 문구를 빼고, 대표 후보만 남기는 작업이다. 캘린더는 글로벌 탭으로 올리지 않고 내 Flow 내부의 실행 보기로 유지한다.

홈: 약속 + 대표 시작점 Flow 찾기: 대표 후보 카탈로그 내 Flow: 오늘/캘린더/Flow 만들기/제작자: 보조 메뉴

Implementation Notes

이번 사용자용 PoC 반영 사항

홈 축소

전체 카탈로그처럼 보이던 카드 묶음을 줄이고, 대표 Flow Map 1개와 보조 시작점 2개만 노출한다.

/flows 정리

Flow Map 2개와 단일 Flow 1개만 대표 카탈로그로 남긴다. 약한 단일 Flow는 숨긴다.

내 Flow 단순화

최상위 탭을 오늘/캘린더/Flow로 제한하고, 체크리스트/루틴은 Flow detail 또는 캘린더 필터 안으로 내린다.

업데이트된 백로그 우선순위

우선순위 작업 상태 이유
P0 홈/Flow 찾기 중복 축소 반영 홈은 서비스 입구, /flows는 카탈로그로 역할을 분리해야 함.
P0 대표 후보 2~3개만 노출 반영 낮은 후보를 같이 보여주면 서비스가 검토 목록처럼 보임.
P0 내 Flow Step inline detail 토글 반영 클릭한 카드 아래에서 열리고 다시 누르면 닫혀야 모바일 스크롤 부담이 줄어듦.
P1 영유아 공식 일정 Flow 재작성 대기 저장 이유는 강하지만 현재 action item 정보성이 부족함.
P1 콘텐츠 카드 신뢰 신호 설계 대기 사용수, 리뷰, 제작자 신뢰 같은 신호가 없으면 카탈로그 선택 이유가 약함.
P2 제작자 publish gate 강화 다음 축 source row가 Step/Item으로 변환되는 과정을 제작자가 확인해야 함.
