아래 안내는 테스트 진행자용입니다. 실제 사용자 화면은 별도 파일로 분리했습니다.

사용자 화면 열기

이번에 보려는 것

판단 대상

  • 공개 Flow에서 저장할 이유가 보이는가
  • 저장 뒤 내 Flow에서 바로 다음 행동을 찾을 수 있는가
  • Step과 Item이 캘린더/투두 앱 수준의 복잡도에 머무는가
  • 원문 링크와 메모가 필요할 때만 보이는가

이번에 보지 않는 것

  • 의학·법률·입시 정보의 최신성 확정
  • 실제 사용자 행동 데이터 검증
  • 제작자 편집 화면
  • 외부 캘린더 내보내기 구현

클릭 순서

일정형

아이 검진·접종 일정

  1. 공개 Flow에서 아이 검진·접종 일정을 선택한다.
  2. 포함된 Flow와 Step을 열어 어떤 항목이 저장되는지 본다.
  3. 생년월일을 2026-01-15로 둔다.
  4. 내 캘린더로 저장한다.
  5. 내 Flow에서 다음 일정을 확인한다.
  6. 캘린더 탭에서 일정이 있는 날짜를 누른다.
  7. Item 하나를 체크하고 메모에 예약 상태를 짧게 적는다.
진도형

중1 수학 목차 진도

  1. 공개 Flow에서 중1 수학 목차 진도를 선택한다.
  2. 단원 Flow와 하위 Step을 열어 진도표 구조를 본다.
  3. 내 진도표로 저장한다.
  4. 이어보기에서 첫 Step을 연다.
  5. 완료 체크와 메모를 남긴다.
  6. 진도표 탭에서 단원별 진행률을 확인한다.
  7. 전체 지도에서 다른 단원을 연다.
타임라인형

원룸 이사 D-30 준비

  1. 공개 Flow에서 원룸 이사 D-30 준비를 선택한다.
  2. 이사 준비 일정 Flow에서 D-30 Step과 Item을 확인한다.
  3. 이사일을 2026-07-31로 둔다.
  4. 이사 일정으로 저장한다.
  5. 오늘 할 일에서 첫 Step을 확인한다.
  6. 캘린더 탭에서 2026. 07. 날짜를 누른다.
  7. 업체 연락처나 예약번호만 짧게 메모한다.

관찰 기준

구분 통과 재작업
저장 전 무엇이 내 Flow에 생기는지 예측할 수 있다. 저장 버튼 결과를 설명해야 이해한다.
첫 방문 첫 Step을 열고 체크/메모까지 자연스럽게 간다. 세부 항목을 찾기 위해 긴 스크롤이나 추측이 필요하다.
재방문 남은 Step, 날짜, 진행률 중 필요한 신호가 보인다. 어디서 다시 시작해야 하는지 모른다.
콘텐츠 원문에서 온 구조와 실행 항목이 남아 있다. 일반론이나 반복 문장으로 채운 느낌이 난다.

기록할 피드백

사용자에게 FlowMe 개념을 먼저 설명하지 말고 화면만 보게 둡니다. 막히는 지점은 “어떤 버튼에서”, “왜 헷갈렸는지”, “원문과 저장 결과 중 무엇이 어긋났는지”만 남기면 됩니다.

실제 개인정보, 의료정보, 계약정보는 입력하지 않습니다.
