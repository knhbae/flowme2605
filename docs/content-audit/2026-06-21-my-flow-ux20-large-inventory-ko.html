20개 이상 저장 상태 UX 확인

많은 Flow를 저장했을 때도 첫 화면은 실행 중심이어야 한다

저장한 Flow가 30개까지 늘어난 상태를 모바일에서 확인했다. 첫 화면은 여전히 오늘 실행 중심으로 유지되고, 전체 목록은 사용자가 Flow 찾기를 눌렀을 때만 열린다. 다만 시트 안에서도 30개 카드가 한 번에 보이면 관리 도구처럼 무거워져 초기 노출을 8개로 줄였다.

v4 실제 /my 정렬 저장 개수별 관찰 기준 서비스 UX 백로그

UX 판단

첫 화면30개 저장 상태에서도 오늘 항목, 밀린 항목, 이번 주 예정만 먼저 보인다.
Flow 찾기목록은 별도 bottom sheet로 열고, 기본 상태에서는 처음 8개만 보여준다.
전체 펼침사용자가 원하면 전체 Flow 보기 30개로 전체 목록을 연다.

변경 전후

항목변경 전변경 후
모바일 Flow 찾기 시트를 열자마자 30개 Flow 카드가 모두 노출됐다. 20개 초과 + 전체 필터 + 검색어 없음 조건에서 처음 8개만 노출한다.
검색/필터 긴 목록 안에서 검색하거나 필터를 찾아야 했다. 검색/필터를 쓰면 제한을 풀고 해당 결과를 바로 보여준다.
전체 보기 의도와 무관하게 전체를 봐야 했다. 명시적으로 전체 Flow 보기 30개를 눌렀을 때 전체 목록을 보여준다.

남은 질문

실제 사용자 관찰에서는 8개 초기 노출이 충분한지, 아니면 “최근 본 Flow / 오늘 관련 Flow / 카테고리” 같은 더 강한 분류가 필요한지 봐야 한다. 현재 단계에서는 새로운 분류 체계를 추가하지 않고, 과한 전체 노출만 줄인 상태가 적절하다.
