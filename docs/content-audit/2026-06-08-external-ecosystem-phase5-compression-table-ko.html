1. 결정 요약

모든 외부 생태계 리뷰는 “무엇을 만들 수 있는가”가 아니라 “사용자가 지금 실행해야 하는 순간과 산출물이 무엇인가”로 끝나야 한다. 이 표는 다음 액션이 문서, 리뷰 UI, public route gate, product rule, future platform 중 어디인지 결정한다.

사용자 실행 순간

학생 입사, 부모의 입학 준비, 원격 도움 요청, 사이트 소유권 확인처럼 실제 상황을 먼저 적는다.

자연 산출물

calendar, sheet, memo, internal checklist, hybrid 중 사용자가 이미 필요로 하는 모양을 고른다.

제품 경계

FlowMe가 만들지 않을 clone, integration, credential storage, automation, safety claim을 같이 남긴다.

2. 결정 등급

A 강한 규칙/후보

export-first 행동과 잘 맞는다. source/artifact가 구체적이면 `/content-flows` review도 가능하다.

A- 강하지만 게이트 필요

프레이밍, source separation, route-level caution이 필요하다. public promotion은 보류한다.

B+ docs-level 후보

필요는 있어 보이지만 변동성과 지원 부담이 크다. 선택된 source/scenario를 기다린다.

B 백업 방향

유용하지만 우선순위가 낮거나 source evidence가 약하다.

C 이번 배치 보류

이미 다룬 패턴을 반복하거나 distinct artifact가 약하다.

future_platform 미래 플랫폼

usage data, stable schema, permission clarity가 생긴 뒤 검토한다.

reject_for_now 지금 거절

너무 넓거나 위험하거나 FlowMe를 clone/platform으로 너무 빨리 밀어 넣는다.

표의 역할

구현 승인이 아니라, 다음에 필요한 evidence나 artifact의 종류를 결정한다.

4. Stage 0 실험 순서

1

기숙사 입사 준비

source-to-artifact path가 구체적이고 hybrid artifact가 자연스러워 가장 강한 다음 `/content-flows` 리뷰 방향이다.

2

초등학교 입학 준비

이미 public route가 있으므로 official-notice card와 D-14 hold state가 이해되는지 evidence gate로 묶는다.

3

범용 원격 도움 사전 체크

AnyDesk 제품별 route보다 permission choice와 closeout에서 시작하는 generic candidate가 더 안전하다.

4

Naver Search Advisor site readiness

Korean-first scenario로 `/content-flows` 리뷰가 가능하되 verification value 저장과 SEO claim은 막는다.

5. 계속 가져갈 제품 규칙

사용자 순간에서 시작

외부 생태계 분석은 platform feature list가 아니라 user moment에서 출발한다.

Export target 먼저

destination platform은 integration보다 먼저 export target이다.

Artifact job으로 목적지 선택

date, row, memo, checklist state, task project 중 주된 일을 보고 고른다.

경쟁서비스는 경계 도구

Notion, Todoist, Calendar, Sheets, Zapier/Make는 FlowMe가 되지 않을 것을 설명하는 기준이다.

API capability는 readiness가 아님

반복 destination use, import friction, stable schema, permission clarity, reversibility, source/safety boundary가 필요하다.

Validated 표현 금지

실제 사용자 행동 evidence 없이 어떤 후보도 validated라고 부르지 않는다.

6. FLOW 품질 메모

User need

외부 sources, platforms, competitors 중 무엇에 FlowMe attention을 줄지 overbuilding 없이 결정한다.

Destination

roadmap memo와 future candidate-review gate.

Low point

각 future review가 concrete artifact preview를 포함하지 않으면 execution clarity가 무너질 수 있다.

핵심 결정: Stage 0은 export-first로 유지한다. Google Calendar direct save와 Google Sheets direct append만 export friction이 증명된 뒤 Stage 1 light-integration 후보가 될 수 있다.

Integration Rule Pass

Dorm Promotion Gate Pass

Elementary Evidence Gate Pass

통합, 민감값 저장, 자동화, SEO/security/validation claim은 별도 evidence 전까지 열지 않는다.
