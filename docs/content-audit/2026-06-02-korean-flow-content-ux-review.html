한국어 Flow 콘텐츠 31개 원문-UX 적합성 리뷰

Date: 2026-06-02

리뷰 목적

/content-flows에 만든 31개 Flow 후보가 원본 콘텐츠의 구조와 실제 사용자 실행 맥락에 맞는지 UX 디자이너와 사용자 관점에서 다시 평가했다.

리뷰 대상:

  • 원본 콘텐츠 URL과 원문 구조
  • 변환된 Flow 콘텐츠의 적합성
  • /content-flows UX/UI에서 사용자가 이해하고 평가할 수 있는지
  • 실제 My Flow/캘린더/루틴/체크리스트로 옮겼을 때의 문제

대표 원문은 직접 열어 구조를 확인했다. 예를 들어 세탁기 원문은 통세척 코스, 준비물, 고무패킹, 세제통, 배수필터, 월 1회/2주 1회 같은 반복 단서가 있어 루틴화 근거가 충분했다. LG 에어컨 문서는 필터별 물세척 가능 여부와 2주/6개월/12개월 주기가 명확했다. 결혼 준비 원문은 D-12개월부터 단계별 준비 항목이 있고, 이사 원문은 D-60부터 D+7까지 일정표와 전입신고/확정일자 같은 행정 체크가 있었다. 이유식 원문은 1~4주 식단표가 있으나 건강 판단 영역이 섞여 있어 식단표 export 중심이 적절했다. 중고차 원문은 성능점검기록부, 보험이력, 실차 확인, 명의이전 같은 결정 항목이 분명했다.

전체 UX 판단

현재 /content-flows UX는 “후보 평가용 실험실”로는 적절하다. 왼쪽 후보 목록, 오른쪽 상세, 모바일 상세 미리보기, 내 평가 입력이 한 화면에서 이어진다. 사용자는 원문을 열고, 저장하면 생길 Flow 항목을 보고, 점수와 메모를 남길 수 있다.

다만 실제 서비스 UX로 바로 쓰기에는 아직 세 가지가 부족하다.

  1. 후보 선택 화면과 실제 저장 화면이 분리되어 있지 않다. 평가자는 좋지만 일반 사용자는 “그래서 지금 저장되는 건가?”를 헷갈릴 수 있다.
  2. 가전/식물/차량/반려동물처럼 보유 대상 프로필이 필요한 Flow는 현재 입력칸만 있고, “내 세탁기/내 몬스테라/내 차량”으로 이어지는 구조가 없다.
  3. 아이 놀이/독서처럼 기존 루틴에 콘텐츠 카드를 매핑해야 하는 유형은 현재 단일 Flow처럼 보인다. 이 유형은 별도 UX 패턴이 필요하다.

1세탁기 통세척 월간 관리원문에 통세척 코스, 준비물, 고무패킹, 세제통, 필터, 반복 주기가 있어 Flow 변환이 잘 맞다.현재 3개 체크는 적당하다. 저장 UX는 첫 청소 날짜, 세탁기 종류, 반복 주기 정도면 충분하다.냄새가 나기 전 반복 관리가 목적이라 월간 루틴 가치가 높다.강한 후보. 제품 프로필과 연결하면 더 좋음.
2에어컨 필터 2주 청소LG 원문에 필터별 세척/교체 가능 여부와 2주/6개월/12개월 주기가 명확하다.브랜드 지원 문서는 신뢰도가 높다. QR/보유제품 등록에서 바로 Flow 저장으로 이어지는 UX가 가장 자연스럽다.여름 전후 반복 수요가 크고 행동도 단순하다.강한 후보. 가전 온보딩 대표 케이스.
3공기청정기 필터 계절 관리원문이 필터 교체 주기와 프리필터 청소를 설명하므로 루틴/교체 알림으로 적합하다.제품명/마지막 교체일을 입력하면 각 필터 행이 생기는 구조가 좋다. 현재 단일 루틴보다 표+알림이 더 적합하다.필터 구매 링크와 교체일 관리가 실용적이다.좋은 후보. 시트/루틴 혼합으로 보강.
4로봇청소기 브러시·센서 월간 관리원문 구조는 브러시, 센서, 먼지통, 오수통으로 나뉘어 있어 체크리스트화 가능하다.물걸레형/흡입형 여부에 따라 항목이 달라져야 한다. 현재 3개 항목은 최소형으로 적절하다.실제 사용자는 청소기 성능 저하 후 찾기 때문에 예방 루틴으로 가치가 있다.좋은 후보. 제품 옵션 분기 필요.
5가습기 매일 비우고 주간 세척원문에 매일/주간 청소가 섞여 있어 반복 루틴으로 맞다.매일 체크와 주간 체크가 한 카드에 같이 보여야 한다. 단일 반복으로만 보이면 주기가 헷갈린다.겨울철 매일 쓰는 제품이라 반복성은 강하다. 다만 너무 많은 세척법을 넣으면 부담스럽다.가능. 다중 주기 UI 필요.
6정수기 필터 교체 주기 관리필터별 교체 주기가 다르므로 캘린더보다 표형 Flow가 맞다.각 필터 행에서 다음 교체 알림을 만드는 UX가 필요하다. 현재 /content-flows는 방향을 잘 보여준다.필터 구매와 교체일 관리가 연결되어 실용적이다.좋은 후보. 보유제품/소모품 UX와 잘 맞음.
7몬스테라 물주기·분갈이 루틴원문은 물주기와 관리 팁이 있지만 환경별 변동이 크다. “물주기 알림”보다 “물주기 확인 알림”이 맞다.식물명/위치/마지막 물준 날이 프로필화되어야 한다. 고정 주기로 박으면 UX가 위험하다.초보 식집사에게 유용하지만 상태 판단을 너무 많이 요구하면 부담스럽다.좋은 후보. 확인/보류 상태 필수.
8스투키 과습 방지 관리원문이 과습, 광량 변화, 무름병 등 판단 지점을 다룬다. Flow는 물주기 실행보다 보류 판단에 초점을 둬야 한다.완료 버튼 옆에 오늘은 물 안 줌이 있어야 한다. 현재 UX 메모 방향이 맞다.스투키는 과습 실패가 흔해 실사용 가치가 높다.강한 후보. 보류 UX 검증에 좋음.
9고양이 화장실 청소 루틴원문은 매일 배변 제거와 전체 교체 주기로 나눌 수 있어 루틴화가 자연스럽다.가족 공유 체크, 담당자 표시가 있으면 가치가 커진다. 단일 사용자 체크만으로는 아쉽다.매일 반복되는 집안일이라 사용 이유가 명확하다.좋은 후보. 가족/공유 루틴 후보.
10강아지 예방접종 일정표원문은 일정표로 만들 수 있지만 건강 판단이 섞인다. 병원 안내 기준을 우선해야 한다.날짜표는 좋지만 “권장 접종”을 확정 일정처럼 보여주면 위험하다. 병원 확인 상태가 필요하다.입양 직후 보호자가 실제로 캘린더에 넣고 싶어 한다.가능. 민감 문구와 병원 확인 UX 필요.
11결혼 준비 12개월 타임라인원문 자체가 D-12개월 타임라인이라 Flow 적합성이 매우 높다.My Flow 캘린더/Flow별/체크리스트 UX를 모두 검증하기 좋다. 항목이 많으므로 단계 접기가 필요하다.예식일 하나로 개인화되고, 준비 기간이 길어 반복 방문 가치가 높다.최상위 seed 후보.
12이사 D-30 체크리스트원문에 D-60~D+7 일정표와 견적/예약/신고가 있어 Flow 구조와 잘 맞다.캘린더에는 짧은 행동 제목만 보여주고 상세에 원문/메모를 둬야 한다. 이전 UX 논의와 잘 연결된다.이사일 기준으로 바로 저장할 명분이 강하다.최상위 후보.
13이사 후 전입신고·확정일자원문은 이사 후 행정 체크에 잘 맞는다. 다만 법적 효력 설명은 공식 링크와 분리해야 한다.문자/카톡 안내에서 “Flow로 저장”하는 진입점이 좋다. 체크리스트는 3개 정도로 충분하다.이사 직후 놓치면 손해가 있어 행동 동기가 강하다.좋은 후보. 공식 링크 보강 필요.
14출국 7일 전 여행 준비원문은 출국일 기준 체크리스트로 자연스럽다. 국가별 규정은 변동성이 있어 공식 링크가 필요하다.D-7/D-3/D-1 타임라인 UI가 적합하다. 여행 국가 선택 후 공식 링크 카드가 붙어야 한다.사용자는 출국 직전 준비물 누락 방지를 원한다.좋은 후보. 국가 템플릿화 필요.
15일본 여행 준비물 체크준비물 체크리스트로는 좋지만 원문이 상품/여행 정보와 섞일 수 있다.국가별 체크리스트 템플릿으로 보여주면 좋다. 과도한 추천/광고 요소는 메모 링크로 내려야 한다.일본 여행 수요가 높고 eSIM/교통/결제 준비는 실제 행동이다.가능. 체크리스트 중심 유지.
16초기 토핑 이유식 4주 식단표원문에 1~4주 식단표가 명확해 표/캘린더 전환 가치가 높다.기록 앱처럼 만들면 실패한다. 식단표 export와 한 줄 특이사항 정도가 맞다.부모는 오늘 먹일 재료와 준비 순서를 알고 싶다.좋은 후보. 의료/알레르기 경계 필수.
17아이 주말 놀이 로테이션원문은 1회 놀이 자료에 가깝다. 단독 Flow보다 “주말 놀이 루틴에 카드로 끼우는 UX”가 맞다.신규 UX 패턴이 필요하다. 루틴은 고정, 콘텐츠 카드는 회전하는 구조가 되어야 한다.부모는 매주 놀잇감을 찾기 때문에 저장 가치는 있다.좋은 실험 후보. 단독 Flow로는 약함.
18그림책 읽기 루틴 + 질문 카드원문은 지도안이라 개인 루틴과 완전히 같지는 않다. 그러나 질문 카드로 변환하면 유용하다.“책별 Flow”보다 “독서 루틴 + 책/질문 카드”가 맞다. 현재 UI는 이 차이를 충분히 설명하지 못한다.책을 산 부모에게 후속 활동으로 유용하다.가능. 카드 매핑 UX 필요.
19예비초 독서 챌린지 책 목록원문은 도서 목록이므로 시트/진도표와 잘 맞는다. 캘린더 단독은 약하다.읽은 책/다음 책/대여 링크 중심의 진도표가 적합하다.매주 1권 읽기 같은 루틴과 결합하면 쓸 만하다.가능. 목록-루틴 결합 필요.
2030일 플랭크 챌린지원문에 Day별 초수와 휴식일이 있어 캘린더 전환이 매우 명확하다.운동 기록을 무겁게 만들지 말고 Day별 목표와 원문 링크만 보여야 한다.사용자는 시작일을 넣고 매일 알림을 받고 싶다.좋은 후보. 안전 문구 필요.
21컴활 2급 필기 단기 공부원문은 후기형이지만 시험일 기준 단기 플랜으로 변환 가능하다.기출 링크, 오답, 시험일이 핵심이다. 상세 공부일지를 요구하면 부담스럽다.단기 시험 준비자는 캘린더와 기출 체크를 원한다.가능. 실제 기출/교재 링크 보강 필요.

UX/UI 개선 제안

1. 평가용 화면과 실제 저장 화면 분리

/content-flows는 현재 평가자에게는 좋지만 실제 사용자에게는 정보가 많다. 실제 서비스에서는 다음 두 화면으로 나누는 편이 좋다.

  • 발견/평가 화면: 원문, 예상 Flow, 점수, 메모
  • 저장 화면: 입력값 2~3개, 생성될 항목 미리보기, 저장 버튼

2. 대상 프로필 기반 Flow

가전, 식물, 차량, 반려동물은 콘텐츠 자체보다 “내가 가진 대상”에 붙을 때 가치가 커진다.

필요한 프로필 예:

  • 내 세탁기: 모델, 통세척 알림 여부, 마지막 청소일
  • 내 공기청정기: 모델, 필터명, 마지막 교체일
  • 내 몬스테라: 위치, 화분 크기, 마지막 물준 날
  • 내 차량: 차종, 주행거리, 마지막 정비일
  • 내 반려동물: 이름, 생일/입양일, 병원

3. 루틴 + 콘텐츠 카드 패턴

아이 놀이, 그림책 독서, 운동 영상, 공부 자료는 단독 Flow보다 기존 루틴에 콘텐츠 카드가 매핑되는 구조가 낫다.

예:

  • 토요일 오전 아이 놀이 루틴
  • 이번 주 콘텐츠 카드: 종이컵 쌓기 놀이
  • 다음 주 콘텐츠 카드 후보: 그림책 질문 카드, 숫자 놀이, 미술 놀이

4. 완료/보류/결정 상태 확장

모든 항목을 완료/미완료로만 보면 어색한 Flow가 있다.

  • 식물: 물 줌 / 오늘은 보류
  • 중고차: 구매 / 보류 / 거절
  • 정수기 필터: 교체함 / 아직 유지
  • 시험 공부: 완료 / 다시 보기
  • 행정: 처리 완료 / 방문 필요

5. 원문 링크의 위치

원문 링크는 평가 화면에서는 크게 보여도 좋지만 My Flow 상세에서는 메모 하단 또는 출처 영역으로 내려가는 것이 좋다. 사용자가 매번 원문을 읽는 것이 아니라, 알림/체크에서 바로 실행해야 하기 때문이다.
