# FlowMe 중위험 공개 출처 현재성 감사

우편물 이전, 에어컨 필터, 이사, 결혼 준비 공개 Flow가 오래된 URL이나 글의 연도만으로 최신처럼 보이지 않는지 점검한 패키지입니다.

## 결론

- URL 접속 가능, 원문 게시 시점, 원문 수정 시점, FlowMe 재확인일, 현재 실행 범위를 서로 다른 값으로 기록합니다.
- 게시일이 없는 인터넷우체국 서비스 화면에는 게시일을 만들지 않습니다.
- AJD 이사 글은 URL에 `2024`가 남아 있지만 원문이 2026-06-30에 수정됐으므로 현재 다섯 D-day 구간을 유지합니다.
- 2024년 개인 결혼 준비 글은 개인 경험 참고 타임라인으로만 사용하며 비용, 업체 조건, 건강·미용 조언을 옮기지 않습니다.
- 공여사들 원문은 2026년에 갱신됐지만 FlowMe가 네 항목만 제공하므로 `A-to-Z`가 아닌 `핵심 4가지 시작표`로 좁힙니다.
- 서로 범위가 다른 결혼 참고표 2종은 한 번에 저장하지 않고 하나를 고르게 합니다.
