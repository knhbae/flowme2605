# 감사 기록

검사일: 2026-07-12

## 판정 규칙

1. **접속 가능**은 링크가 열리는지만 뜻합니다.
2. **게시일**은 원문이 처음 공개된 시점입니다. 알 수 없으면 비워 둡니다.
3. **수정일**은 원문이 갱신된 시점입니다. URL 제목의 연도보다 이 값을 우선 확인합니다.
4. **재확인일**은 FlowMe가 해당 원문과 변환 범위를 다시 본 날짜입니다.
5. **현재 실행 범위**는 지금도 source가 직접 뒷받침하는 행동만 남긴 결과입니다.

## 출처별 결과

### 인터넷우체국 주거이전서비스

- 원문: [주거이전서비스 신청·결제·취소](https://service.epost.go.kr/front.RetrieveAddressMoveInfo.postal)
- HTTP 200, 공식 서비스 화면.
- 게시일 메타데이터 없음. FlowMe가 임의 게시일을 만들지 않음.
- 유지 범위: 전입신고 다음날 공식 화면을 열어 무료·유료·미신청 상태와 결제 필요 여부 확인.
- 제외 범위: 수수료, 서비스 기간, 결제 기한을 FlowMe가 고정 계산하거나 민감한 인증·결제 정보를 받는 동작.

### 삼성전자서비스 천장형 1way 필터

- 원문: [천장형 에어컨 1way 필터 청소 및 관리 방법](https://www.samsungsvc.co.kr/solution/28524)
- 원문 게시: 2025-01-06, 2026-07-12 재확인.
- 유지 범위: 천장형 1way 모델 확인, 운전 정지·전원 차단·분리·청소·그늘 건조·재장착·리셋, 약 2주 또는 알림 기준.
- 경계: 다른 모델과 리모컨에는 같은 방법을 확대하지 않고 사용설명서를 우선함.

- URL의 `2024`만 보고 오래된 문서로 판정하지 않음.
- 유지 범위: D-30, D-10, D-3, D-1, D-Day 다섯 구간.
- 경계: 업체 선택과 주소·정산 절차의 실제 조건은 계약서, 업체, 관리사무소, 공식 서비스에서 다시 확인.

### 네이버 개인 결혼 준비 타임라인

- 원문: [결혼준비 시작, 타임라인 1년 정리](https://blog.naver.com/wilklove/223518896995)
- 원문 게시: 2024-07-20, 확인 가능한 수정일 없음, FlowMe 재확인: 2026-07-12.
- 유지 범위: 12·10·7·6·3·1개월 전이라는 개인 경험 기반 기간 구분.
- 제외 범위: 미용 시술, 다이어트, 특정 업체 선호, 불확실한 예약 시점, 가격과 계약 조건.
- 사용자 화면에서는 `참고 타임라인`과 `개인 경험` 경계를 명시함.

### 공여사들 결혼 준비 가이드

- 원문: [결혼준비 체크리스트 A to Z](https://gongysd.com/wedding-notion/?bmode=view&idx=167989966)
- 원문 게시: 2024-12-25, 원문 수정: 2026-02-10, FlowMe 재확인: 2026-07-12.
- 현재 원문은 15개 범주를 다루지만 FlowMe는 웨딩홀, 상견례, 플래너, 스드메 네 가지 시작 항목만 제공함.
- 기존 `A-to-Z` Flow 제목은 범위를 과장하므로 `핵심 4가지 시작표`로 변경함.
- 비용, 일정, 계약 조건은 선택한 업체의 현재 안내를 다시 확인하게 함.

## UI 결과

- 원문 게시일과 수정일은 연도를 포함해 source card에 표시합니다.
- 재확인일과 Flow 정리일은 별도 메타로 유지합니다.
- 결혼 참고표 Map은 `choose_child` 정책을 사용하며 전체 저장 CTA가 없습니다.
- 선택형 Map은 각 참고표의 앞 2개 항목만 보여주고 나머지는 개수로 요약합니다.
- 모바일 390px과 wide 1024px에서 가로 overflow는 관찰되지 않았습니다.

## 남은 위험

- 외부 원문은 이후 수정·삭제될 수 있습니다.
- 게시일이 없는 공식 서비스 페이지는 제도 변경 감지를 위해 정기 재확인이 필요합니다.
- 개인 경험 결혼 타임라인의 여섯 구간은 참고값이며 실제 예약 적기 검증을 대신하지 않습니다.
- 자동화와 화면 검토만 수행했고 실제 사용자 관찰 세션은 0건입니다.
