사용자/제작자 저니를 두 번 돌려 PoC를 보강했다

대상 파일은 사용자용 PoC와 제작자용 PoC다. 이 리포트는 실제 사용자 행동 데이터가 아니라, 원컨텐츠 소비부터 저장/실행/재방문까지의 UX 시뮬레이션이다.

Blocking 없음 High 1건 수정 Medium 3건 남음 검증됨 표현 금지

검토한 산출물

  • 실제 온라인 콘텐츠 조사 리포트
  • Flow of Flows 변환 모델
  • 사용자용 클릭 PoC
  • 제작자용 클릭 PoC

시뮬레이션 1차

러닝 사용자

5KM 영상 시리즈를 본 사용자가 4주 루틴을 전체 저장하고 월/수/금 19:30 일정으로 옮기는 상황.

중1 수학 사용자

중1 자녀가 있는 보호자가 소인수분해 단원만 먼저 저장하고 오답표를 만들려는 상황.

이유식 사용자

6개월 이유식을 시작하는 보호자가 이번 주 식단표와 첫 식재료 반응 메모만 저장하는 상황.

High · 공통 입력 반영이 약함

사용자용 화면에서 시작일은 일정 미리보기에 반영됐지만, 운동 요일/알림 시간/하루 목표 강의 수/메모 이름이 결과에 충분히 보이지 않았다. 상위에서 한 번 받은 입력이 하위 실행 항목에 내려간다는 핵심 가설을 약하게 만들었다.

Medium · 날짜 생성은 아직 단순함

요일 반복 로직을 실제 캘린더처럼 완전히 계산하지 않는다. 다만 이번 PoC는 UI 구조 확인이 목적이므로, 입력값이 결과에 보이는 수준까지 우선 보강했다.

수정 내용

수정 1 · 적용 설정을 일정/표 미리보기에 표시

선택 요일, 시간, 하루 목표 강의 수, 메모 이름이 선택한 일정/표 detail에 같이 보이도록 보강했다.

수정 2 · 전체 저장/구간 저장 결과 메시지에 공통 입력 반영

사용자가 전체 저장이나 선택 구간 저장을 누르면, 몇 개 항목이 만들어졌는지와 함께 선택 요일/시간 같은 설정이 함께 표시된다.

시뮬레이션 2차

대상 원컨텐츠 소비 저장 행동 실행/재방문 판정
러닝 입문 4주 사용자가 러닝 재생목록을 보고 주차별 따라하기 구조를 이해한다. 시작일, 운동 요일, 알림 시간을 넣고 전체 또는 이번 구간만 저장한다. 일정 설명에서 원본 링크, 할 일, 적용 설정을 확인하고 체크한다. 통과
중1 수학 1학기 강좌 목차나 문제풀이 재생목록에서 단원 구조를 확인한다. 공부 시작일, 요일, 하루 목표 강의 수를 넣고 단원만 저장할 수 있다. 진도표/오답표가 생기는 결과를 예측할 수 있다. 통과
6개월 이유식 식단표 완밥요정 식단표의 제공 시간, 첫 식재료, 식단표 파일 구조를 확인한다. 식단 시작일과 제공 시간을 넣고 이번 주 식단 또는 관찰표를 저장한다. 먹은 양, 반응, 장보기 메모를 하위 항목에서 남길 수 있다. 통과
제작자 조립 화면 제작자가 원문 URL과 구조를 확인한다. 큰 제목, 섹션, 실행 항목, 목적지, 출처/주의를 지정한다. 사용자 미리보기에서 전체 저장/부분 저장 결과를 확인한다. 통과

남은 리스크

Medium · 실제 캘린더 반복 생성은 아직 아님

요일 반복이 완전한 일정 엔진처럼 계산되지는 않는다. 다음 구현 단계에서는 요일별 반복 생성과 종료일 처리가 필요하다.

Medium · 원문 자동 파싱은 아직 아님

현재 PoC는 수동으로 구조를 조립한다. 원문 URL을 넣으면 자동으로 강좌/재생목록/표를 파싱하는 기능은 비목표다.

Medium · 백신/검진은 별도 민감 카테고리 PoC 필요

구조는 매우 강하지만 의료·공식 정보 경계가 필요하다. 이번 사용자 PoC에서는 이유식으로 대표했고, 백신/검진은 다음 민감 카테고리 화면에서 따로 봐야 한다.

결론

실제 온라인 콘텐츠 기준으로 Flow of Flows는 성립한다. 특히 재생목록, 강좌 목차, 식단표, 월령표, D-day 표처럼 원문에 계층이 있는 콘텐츠는 강하다. 다만 이 결과는 구조 PoC이며, 실제 사용자의 저장/체크/재방문 행동을 증명하지는 않는다.
