My Flow 실행 UX 재정리

오늘만 보는 화면이 아니라, 저장한 Flow를 이어서 실행하는 화면

작성일: 2026-06-30 · 범위: 내 Flow 기본 화면, 저장 후 실행, 캘린더/전체 Flow 역할 분리

현재 혼란

모바일에서 오늘 항목이 비면 “오늘 남은 일정이나 루틴이 없습니다”가 중심에 보여, 사용자가 저장한 Flow 전체나 다음 Step을 어디서 이어야 하는지 헷갈린다.

판단

내 Flow는 오늘 전용 탭이 아니라 저장한 Flow의 실행 허브다. 오늘이 비어도 다음 할 일과 전체 Flow로 이어져야 한다.

UI 원칙

전체 체크리스트를 기본으로 다 펼치지 않는다. Step 하나는 캘린더/투두에 들어가는 최소 항목이고, Item은 Step을 열었을 때 보인다.

외부 서비스에서 가져온 기준

Apple Reminders: Today, Scheduled, All 같은 스마트 목록으로 오늘/예정/전체를 분리한다. Today는 오늘과 밀린 일을 보는 집중 영역이다.

Todoist: Today는 오늘 할 일을 집중해서 계획하는 화면이고, Upcoming은 다음 일정을 미리 보는 화면이다.

Microsoft To Do: My Day와 My Tasks를 분리해 하루 집중과 전체 작업 모음을 함께 둔다.

Google Calendar/Tasks: 일정 안에서 Task를 만들고 관리하지만, 모든 작업 목록은 별도 Task 맥락으로도 접근할 수 있다.

적용 결론: FlowMe도 오늘, 다음 일정, 전체 Flow를 한 덩어리로 섞지 말고, 기본 화면에서는 “지금 이어하기”를 우선한다.

새 정보 구조

  1. 지금 이어하기: 오늘 남은 Step이 있으면 오늘 Step, 없으면 밀린 Step, 없으면 가장 가까운 다음 Step을 보여준다.
  2. 오늘 할 일: 오늘 날짜에 실제로 남은 일정/루틴이 있을 때만 보인다. 비어 있음 문구를 중심 카드로 만들지 않는다.
  3. 이번 주·다음 할 일: 가까운 예정 Step을 2~4개만 보여준다. 전체 일정은 글로벌 캘린더 탭에서 본다.
  4. 저장한 Flow: 전체 체크리스트/Step 목록과 진행률은 Flow 카드 안에서 필요할 때 연다.
  5. 캘린더: 날짜 선택과 날짜별 Step 실행은 글로벌 캘린더 탭이 담당한다.

Before

오늘 중심 빈 상태

  • 오늘 남은 일이 없으면 화면이 끊긴다.
  • 저장한 Flow 카드와 오늘 카드의 관계가 약하다.
  • 전체 체크리스트가 어디 있는지 추론해야 한다.

After

이어하기 중심

  • 오늘이 비어도 다음 Step이 바로 보인다.
  • 전체 Flow는 “저장한 Flow” 영역에서 찾는다.
  • Item/detail은 Step을 열었을 때만 나온다.

제품 반영 기준

항목 결정
내 Flow 첫 화면 오늘 전용이 아니라 “지금 이어하기” 대시보드
전체 체크리스트 기본 노출 금지. Flow 상세/Step detail에서 필요할 때 열기
오늘이 비어 있을 때 빈 문구보다 다음 Step 또는 가까운 예정 Step 표시
캘린더 글로벌 탭으로 유지. My Flow 내부 CTA 중복은 줄임

이번 구현에서 볼 것

  • 모바일에서 오늘이 비어도 다음 실행 Step이 보이는가?
  • 오늘/다음/저장한 Flow의 역할이 분리되어 보이는가?
  • 전체 체크리스트가 기본 화면에 과하게 펼쳐지지 않는가?
  • Step을 누르면 바로 아래에서 Item/detail을 확인할 수 있는가?
  • 글로벌 캘린더 탭과 My Flow가 서로 중복 CTA를 만들지 않는가?
참고: Apple Reminders, Todoist, Microsoft To Do, Google Calendar/Tasks의 오늘/예정/전체 작업 분리 패턴을 참고했다. 이 문서는 사용자용 화면이 아니라 검토용 기획 문서다.
