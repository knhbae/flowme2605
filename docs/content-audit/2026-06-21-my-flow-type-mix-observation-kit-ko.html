My Flow 유형 혼합 관찰 키트

목표는 저장한 Flow가 일정, 루틴, 학습, 체크, 보관으로 섞였을 때도 사용자가 오늘 해야 할 Step을 열고 체크, 메모, 원문 확인까지 막힘 없이 처리하는지 보는 것이다. 이 문서는 관찰용이며, 사용자에게는 내 Flow 화면만 보여준다.

진행 원칙

설명하지 말고, 사용자가 어디서 막히는지 본다

“저장한 Flow들이 모인 화면입니다. 오늘 해야 할 일 하나를 처리하고, 예전에 저장한 Flow도 하나 찾아보세요.” 정도만 말한다. 유형 chip, 날짜 rail, Flow 찾기, 자동 저장은 먼저 설명하지 않는다.

관찰 질문

줄여도 되는지, 더 필요한지 판단할 것

Today 우선성사용자가 오늘 항목부터 시작하는가, 아니면 유형/검색/전체 목록으로 빠지는가.
혼합 타입 이해일정, 루틴, 학습, 체크, 보관이 모두 같은 Step 상세로 열린다는 점을 자연스럽게 받아들이는가.
Flow Map 무게중1 수학 같은 지도형 Flow가 과하게 보이지 않고 한 Step 실행으로 이해되는가.
메모 저장 신뢰큰 저장 버튼 없이 메모 저장됨 상태만으로 충분한가.
검색/필터 사용Flow 찾기에서 검색을 먼저 쓰는가, 유형 필터 때문에 헷갈리는가.
외부 앱 fallback체크리스트 지원이 없는 앱에서는 text fallback이 충분한 정보로 느껴지는가.

과제

실제 클릭 순서

  1. 오늘 할 일 하나 처리
    첫 화면에서 오늘 항목 하나를 열고, 체크 1~2개를 누른 뒤 메모를 짧게 남긴다.
  2. 학습 지도 항목 열기
    Flow 찾기를 열고 math 또는 수학으로 검색해서 정수와 유리수 10강을 연다.
  3. 여권 Flow 다시 찾기
    이번 주 또는 검색을 통해 온라인 여권 재발급의 사진 규격 Step을 찾는다.
  4. 날짜 없는 보관 항목 찾기
    보관에서 스퀴시 도안 Flow를 열고, 날짜가 없는 Flow도 저장 목록에 남을 수 있는지 확인한다.
  5. 재방문 가정
    다음 날 다시 들어왔다고 가정하고, 오늘 항목과 이전에 열었던 항목을 구분할 수 있는지 묻는다.

수정 우선순위

등급신호즉시 수정
Blocking 오늘 할 일을 찾지 못함, Step을 열지 못함, 유형 chip을 필수 조작으로 오해함, 검색 결과를 열면 맥락을 잃음 동선이나 구조를 바로 수정하고 같은 과제를 다시 관찰한다.
High 검색/필터를 이해하지 못함, 메모 저장 여부를 불안해함, 학습 지도 전체를 매번 찾아야 한다고 느낌 버튼명, 위치, 자동 저장 표시, Flow 찾기 구조를 줄이거나 바꾼다.
Medium 유형 label, 날짜 rail label, 보관 label이 애매하지만 과제는 끝냄 다음 polish 묶음으로 모으되 2회 반복되면 High로 올린다.
Pass 오늘 항목 처리, 다른 Flow 찾기, 메모 입력, fallback 이해가 모두 자연스럽다 유지한다. 단, 실제 사용자 검증 완료라고 표현하지 않는다.
