My Flow v7 관리 구조 리허설

v6가 오늘 실행 표면만 볼 수 있었던 한계를 보완했다. v7은 여러 Flow가 저장되어 있고, Flow마다 항목 수가 다르며, 큰 지도 안에 하위 Flow가 있는 상황을 판단하기 위한 사용자 화면이다.

v7 사용자 PoC v6 Today 표면 실제 사용자 검증 아님

이번에 넓힌 판단 범위

사용자 피드백의 핵심은 “8개 Step만 있는 Today 화면으로 전체 저장 구조를 판단하면 안 된다”였다. v7은 그 지적을 반영해 다음을 추가했다.

  • Flow 1개가 1개, 4개, 5개, 10개 등 서로 다른 항목 수를 가질 수 있게 했다.
  • 저장한 Flow 목록에서 각 Flow의 전체 항목 수와 완료 상태를 볼 수 있게 했다.
  • 큰 지도 안에 여러 하위 Flow가 있고, 각 하위 Flow가 다시 여러 항목을 갖는 구조를 넣었다.
  • 홈 화면은 계속 오늘 항목 중심으로 유지하고, 전체 구조는 뒤에서 열게 했다.

사용자 화면에서 볼 것

오늘여러 Flow의 오늘 항목만 섞여 나와도 사용자가 바로 체크/메모할 수 있는지 본다.
저장한 FlowFlow마다 항목 수가 다른데도 전체 구조와 이어볼 항목을 이해할 수 있는지 본다.
큰 지도중1 수학/영유아 지도처럼 하위 Flow가 있는 구조가 단순한 폴더처럼 보이지 않는지 본다.

대표 데이터 구성

구성 의도 주의점
전세계약5개 항목 기준선 Flow. 날짜형과 체크형이 섞인 단일 Flow를 본다. 상세는 전세 v6보다 과해지면 안 된다.
이사 D-3010개 항목 긴 timeline Flow가 Flow 목록 안에서 어떻게 보이는지 본다. 오늘 화면에 10개가 다 나오면 실패다.
홈트/도안/식물1개 항목 한 항목짜리 Flow가 빈약하거나 억지로 보이지 않는지 본다. 1개짜리에 전체 구조 UI가 과하게 붙으면 실패다.
중1 수학 큰 지도3개 하위 Flow · 15개 항목 Flow Map 아래 하위 Flow와 진도형 항목을 본다. 학습 앱처럼 과도한 세션/페이스 입력을 만들지 않는다.
영유아 큰 지도2개 하위 Flow · 6개 항목 민감 카테고리에서 공식 정보와 보호자 메모를 분리하는지 본다. FlowMe가 의료 판단을 하는 화면처럼 보이면 실패다.

초기 판정

v7은 v6보다 목표에 더 가깝다. 단일 Today 화면이 아니라 저장한 Flow 전체와 큰 지도 구조를 함께 볼 수 있기 때문이다. 다만 아직 제품 확정은 아니다. 실제 관찰에서는 사용자가 `저장한 Flow`와 `큰 지도`를 구분해서 이해하는지, 큰 지도가 단순 폴더처럼 보이지 않는지 확인해야 한다.

  • 한 항목짜리 Flow와 10항목짜리 Flow가 같은 목록에 있어도 어색하지 않은가?
