# P24-00B1 진행자 Runbook

## 시작 전 5분

- 참가자 ID만 기록하고 실명은 기록하지 않는다.
- 기기, 브라우저, viewport, localStorage 상태를 기록한다.
- production URL을 새 탭에서 연다.
- 화면 또는 음성 기록은 동의했을 때만 시작한다.
- 타이머와 세션 기록지를 준비한다.

## 공통 시작 문장

> FlowMe는 링크나 메모를 실행할 일로 정리하고 일정과 체크리스트로 이어 주는 서비스입니다. 화면을 자유롭게 사용해 과업을 끝내 주세요. 어디를 눌러야 하는지는 설명하지 않겠습니다. 막히면 지금 찾는 것이 무엇인지 말해 주세요.

## 힌트 단계

| 단계 | 조건 | 진행자 행동 | 기록 |
| --- | --- | --- | --- |
| H0 | 진행 중 | 침묵하고 행동과 발화를 기록 | 힌트 0 |
| H1 | 도움 요청 | `지금 무엇을 찾고 계세요?`라고 되묻기 | 힌트 1 |
| H2 | 90초 정체 | 목표가 `찾기 / 내 Flow / 날짜 / 가져가기` 중 무엇인지 한 단어로만 알려주기 | 힌트 2, 도움 후 성공 |
| H3 | 계속 정체 | 다음 화면의 목적만 알려주고 버튼 위치는 말하지 않기 | 힌트 3, 실패 후보 |
| STOP | 신뢰 오류 | 즉시 중단하고 상태·경로·화면 증거 보존 | 제품 차단 |

## 과업별 질문 시점

행동을 유도하지 않도록 버튼을 누르기 전에만 아래를 묻는다.

- 날짜 입력 전: `이 날짜가 무엇을 뜻한다고 생각하세요?`
- 저장 전: `저장하면 어디에서 무엇이 보일 것 같나요?`
- 완료 전: `체크하면 무엇이 달라질 것 같나요?`
- 날짜 배치 전: `이 동작은 하나만 바뀔까요, 전체가 바뀔까요?`
- export 전: `어떤 항목이 결과에 들어갈 것 같나요?`

## 즉시 중단 조건

- 저장한 항목이나 사용자 입력이 사라진다.
- 선택하지 않은 날짜 또는 항목으로 변경된다.
- 완료 상태가 다른 항목이나 다른 반복 회차에 연결된다.
- 예상한 범위와 다른 항목이 export된다.
- production 접근이나 핵심 저장이 반복 실패한다.

## 세션 종료

1. 확신도와 재사용 의향을 1~5로 묻는다.
2. 가장 유용한 한 가지와 가장 복잡한 한 가지를 그대로 기록한다.
3. 기록을 요약하기 전에 정확한 사용자 발화를 따로 보존한다.
4. `keep / change / defer / blocking`은 관찰자 메모로 분리한다.
5. 증거가 없는 추정을 실제 결과처럼 쓰지 않는다.
