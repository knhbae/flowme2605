Date: 2026-05-31
Status: 1차 상세 검증

## 목적

집/가전 관리는 FlowMe에 가장 잘 맞는 후보군이다. 이유는 물건, 주기, 계절, 마지막 관리일, 서비스 예약, 모델명 메모가 자연스럽게 생기기 때문이다.

이 문서는 에어컨과 정수기 관리 출처를 공식/블로그/영상/상업 페이지로 나누어 보고, 어떤 출처는 Flow로 바로 만들 수 있는지, 어떤 출처는 보조 메모로만 써야 하는지, 어떤 출처는 공개 실행 Flow로 만들면 안 되는지 검증한다.

## 후보 1. 삼성전자서비스 시스템 1WAY 필터 청소

출처:

- 제목: 시스템, 1WAY 필터 청소 및 관리 방법 안내
- URL: https://www.samsungsvc.co.kr/video/1393266/
- 발행자: 삼성전자서비스
- 출처 유형: 제조사 공식 영상/가이드
- 확인일: 2026-05-31
- 카테고리: 집/가전 관리

원 콘텐츠 요약:

- 콘텐츠 형태: 시스템 에어컨 1WAY 제품의 필터 청소 영상 자막.
- 핵심 내용: 제품 운전 정지, 보조 전원 차단, 그릴 열기, 필터 분리, 먼지 제거 또는 물청소, 그늘 건조, 필터 재장착, 필터 리셋.
- 순서/날짜/반복: 사용 환경과 사용시간에 따라 다르지만 2주에 한 번 또는 청소 알림 표시등이 켜졌을 때 청소.
- 공식 정보: 제조사 기준의 필터 청소 절차와 리셋 방법.
- 주의/위험 정보: 그릴 낙하 주의, 모델별 방법 차이, 필터 손상 방지, 직사광선 건조 피하기.

Flow 콘텐츠화:

- 사용자 니즈: 천장형 에어컨 필터 청소 시점을 놓치지 않고, 모델별 주의사항을 보면서 안전하게 반복 관리하고 싶다.
- 주 목적지: 캘린더
- 구조 타입: 반복 루틴
- 기준점: 마지막 필터 청소일 또는 필터 알림 표시일
- 필수 사용자 입력: 에어컨 이름, 마지막 청소일, 반복 주기
- 선택 사용자 입력: 모델명, 리모컨 필터 리셋 방법, 관리실/서비스 연락처
- 권장 item 수: 4-5개
- 완료 모델: 청소함 / 리셋함 / 전문가 문의함 / 보류함
- 출처/위험 처리: 제조사 링크를 상세에 고정하고, 모델별 차이는 메모로 둔다.

Flow 초안:

1. 필터 청소 알림 확인
   - 타입: routine_session
   - 시점: 2주마다 또는 필터 알림 표시 시
   - 상세/메모: 저장한 모델명과 제조사 링크를 확인한다.
   - 완료 기준: 오늘 청소할지 보류할지 정했다.
2. 전원 차단 후 필터 분리
   - 타입: check_task
   - 시점: 청소 당일
   - 상세/메모: 제품 운전을 멈추고 보조 전원을 끈 뒤 그릴을 잡고 연다.
   - 완료 기준: 필터를 안전하게 분리했다.
3. 필터 세척과 건조
   - 타입: scheduled_task
   - 시점: 청소 당일
   - 상세/메모: 먼지를 제거하고 필요하면 물청소 후 그늘에서 충분히 말린다.
   - 완료 기준: 필터가 완전히 건조됐다.
4. 재장착과 필터 리셋
   - 타입: check_task
   - 시점: 청소 후
   - 상세/메모: 필터를 고정하고 리모컨/유선리모컨에서 필터 리셋을 실행한다.
   - 완료 기준: 필터 리셋과 다음 알림 설정이 끝났다.

UX 검토:

- 입력 부담: 낮음. 에어컨 이름, 마지막 청소일, 주기만 있으면 된다.
- 캘린더 적합성: 높음.
- 체크리스트 적합성: 높음.
- 메모 적합성: 모델별 리셋 방법 저장에 적합.
- 더보기/상세로 숨길 내용: 제조사 전체 자막, 모델별 세부 리모컨 경로.
- Flow로 바꾸지 말아야 할 내용: 제조사 콘텐츠의 긴 설명 전체.

판정:

- 적합도: 가능
- 이유: 반복 주기, 절차, 완료 기준이 모두 명확하다.
- 다음 단계: 에어컨 관리 seed의 기준 출처로 사용 가능.

- 주 목적지: 캘린더
- 구조 타입: 계절 타임라인
- 기준점: 여름 사용 시작월

- 권장 item 수: 4-6개
- 완료 모델: 확인함 / 청소함 / 교체함 / 보류함

Flow 초안:

1. 여름 전 점검일 잡기
   - 타입: scheduled_task
   - 시점: 3-5월 중 선택일
   - 완료 기준: 점검일이 캘린더에 잡혔다.
2. 전원과 리모컨 확인
   - 타입: check_task
   - 완료 기준: 전원코드와 리모컨 배터리를 확인했다.
3. 필터 세척/건조
   - 타입: scheduled_task
   - 완료 기준: 세척 가능한 필터를 씻고 완전히 말렸다.
4. 실외기 주변 정리
   - 타입: check_task
   - 완료 기준: 실외기 주변과 창문/갤러리 통풍을 확인했다.

판정:

- 적합도: 가능
- 이유: 계절 기준점이 분명하고 사용자 입력이 적다.

## 후보 3. 삼성전자서비스 홈멀티 청소/세척

출처:

- 발행자: 삼성전자서비스
- 출처 유형: 제조사 공식 가이드
- 확인일: 2026-05-31
- 카테고리: 집/가전 관리

원 콘텐츠 요약:

- 콘텐츠 형태: 에어컨 외관/내부/전문세척/실외기 청소 안내.
- 핵심 내용: 전원 차단 후 외관 청소, 바람문 청소, 스마트 냉방세척 기능, 분해 세척 필요 시 전용 부서/고객센터 안내, 실외기 열교환기 관리.
- 공식 정보: 실내기 열교환기 세척은 제품 분해가 필요해 엔지니어 방문이 필요하다는 경계.
- 주의/위험 정보: 세제/유기용제 사용 금지, 내부 분해 세척은 전문가 영역, 실외기 청소가 곤란하면 엔지니어 방문.

Flow 콘텐츠화:

- 사용자 니즈: 내가 직접 해도 되는 청소와 전문가에게 맡겨야 하는 청소를 구분해서, 무리한 분해 없이 관리하고 싶다.
- 주 목적지: 메모
- 구조 타입: 판단 체크리스트
- 기준점: 냄새/냉방 약함/청소 예정일
- 필수 사용자 입력: 제품 종류, 증상, 마지막 청소일
- 선택 사용자 입력: 고객센터 번호, 예약 링크, 서비스 비용 메모
- 권장 item 수: 5-6개
- 완료 모델: 직접 청소함 / 예약함 / 문의함 / 보류함

Flow 초안:

1. 직접 청소 가능 범위 확인
   - 타입: decision_hold
   - 완료 기준: 외관/필터/바람문 청소인지, 내부 분해 세척인지 구분했다.
2. 전원 차단 후 외관 청소
   - 타입: check_task
   - 완료 기준: 외관과 좁은 틈새 먼지를 닦았다.
3. 내부 세척 필요 시 전문가 문의
   - 타입: scheduled_task
   - 완료 기준: 고객센터 또는 세척 부서 문의 여부를 결정했다.
4. 실외기 주변/열교환기 상태 확인
   - 타입: check_task
   - 완료 기준: 직접 가능한 정리와 전문가 필요 여부를 나눴다.

판정:

- 적합도: 조건부 가능
- 이유: 안전 경계가 핵심이다. "직접 분해하기" Flow가 아니라 "직접 가능/전문가 필요 판단" Flow로 만들어야 한다.

원 콘텐츠 요약:

- 주의/위험 정보: 타는 냄새, 내부 분해, 세정제 사용, 건강 영향 관련 주장은 공식 출처 보강 필요.

Flow 콘텐츠화:

- 사용자 니즈: 제조사 가이드만으로 부족한 실전 판단 기준을 참고해서 필터 청소, 냄새 점검, 전문가 예약 여부를 정하고 싶다.
- 주 목적지: 메모
- 구조 타입: 판단 메모 + 루틴 보조
- 기준점: 냄새 발생일 또는 시즌 점검일
- 필수 사용자 입력: 냄새/증상, 제품 유형, 마지막 청소일
- 선택 사용자 입력: 세정제/키트 구매 메모, 업체 견적
- 권장 item 수: 3-5개
- 완료 모델: 직접 청소함 / 전문가 예약함 / 중단함 / 보류함

Flow 초안:

1. 증상 메모
   - 타입: log_entry
   - 완료 기준: 냄새 종류, 발생 시점, 제품 유형을 적었다.
2. 공식 가이드로 직접 가능 범위 확인
   - 타입: check_task
   - 완료 기준: 필터/외관 청소인지 내부 분해 영역인지 확인했다.

### 사용자에게 보이는 1차 입력

- 마지막 관리일: 마지막 청소일 또는 필터 교체일.
- 반복 주기: 제조사 기준 기본값을 제안하되 사용자가 수정.

### 상세/더보기로 내려야 할 정보

- 제조사 원문 링크.
- 모델별 분리 방법.
- 리모컨 리셋 경로.
- 서비스센터 번호.
- 세정제/키트/업체 비교 메모.
- 블로그/영상 경험담.
- 위험/중단 기준.

### 공개 Flow 금지 경계

- PCB, 배선, 송풍팬, 드레인판 등 내부 분해를 일반 사용자에게 단계별로 따라 하게 만들면 안 된다.
- 상업 서비스 페이지의 효과/건강/만족도 주장을 Flow의 공식 기준처럼 쓰면 안 된다.
- 블로그의 절감률, 건강 영향, 청소제 안전성 주장은 공식 출처 확인 전에는 메모/참고로만 둔다.

### 가능한 최종 Flow 후보

1. `여름 전 에어컨 점검`
   - 구조: 계절 타임라인
   - 목적지: 캘린더 + 체크
   - 필수 입력: 점검월, 에어컨 이름

2. `에어컨 필터 2주 관리`
   - 구조: 반복 루틴
   - 목적지: 캘린더
   - 필수 입력: 마지막 청소일, 반복 주기

3. `에어컨 냄새/분해 청소 판단`
   - 구조: 메모 + 결정/보류
   - 목적지: 메모
   - 필수 입력: 증상, 제품 유형

4. `정수기 필터 교체 알림`
   - 구조: 다중 필터 루틴
   - 목적지: 캘린더 + 메모
   - 필수 입력: 모델명, 필터명, 마지막 교체일
