사용자 저니 시뮬레이션

1. 발견

학부모 또는 학생이 중1 수학 목차 글을 봅니다.

원문은 단원과 개념 링크가 많아서 “나중에 체계적으로 공부하고 싶다”는 저장 욕구가 있습니다.통과
2. 저장

시작일만 정하고 진도표를 저장합니다.

범위 선택은 상단 입력이 아니라 단원 목록에서 직접 누르는 행동으로 처리합니다.수정 후 통과
3. 실행

단원을 누르고 오늘 볼 개념을 체크합니다.

상태 선택, 복습 캘린더, 별도 오답표를 기본 화면에서 제거했습니다.수정 후 통과
4. 재방문

다시 들어오면 같은 진도표에서 완료한 개념과 단원 메모를 확인합니다.

반복 학습 로직은 나중에 붙일 수 있지만, 현재 사용자 화면은 기존 Flow 컨텐츠 수준으로 제한했습니다.추가 검증 필요

제작자 저니 시뮬레이션

1. URL 입력

제작자가 목차형 원문 URL을 넣습니다.

URL을 사용자가 입력하는 것이 아니라 제작자가 콘텐츠 구조를 가져오는 출발점입니다.통과
2. 구조 확인

8개 단원과 단원별 개념 수를 확인합니다.

이 단계에서 상위 지도와 하위 반복 단위가 분리됩니다.통과
3. 패턴 정의

제작자 화면에서는 단원마다 진도표, 복습 후보, 오답표 패턴을 정의할 수 있습니다.

다만 사용자 화면에는 그중 진도표와 메모만 기본 노출합니다.수정 후 통과
4. 공개 전 점검

원문에 없는 행 생성 금지, 불필요한 입력 금지, 사용자 화면 내부문구 금지를 확인합니다.

콘텐츠 품질 실패가 UI 단계에서 다시 반복되지 않도록 둔 장치입니다.통과

판정

이번에 확인된 것

중1 수학처럼 목차, 단원, 개념 행이 있는 온라인 콘텐츠는 단일 Flow를 넘어 상위 진도표와 반복 하위 공부 Flow로 전환될 수 있습니다. 전세 Flow가 하나의 일정형 실행물이었다면, 이 샘플은 같은 하위 실행물이 여러 단원에 반복되는 구조를 보여줍니다.

아직 확인되지 않은 것

실제 제작자가 원문을 가져와 자동 추출하는 정확도, 사용자가 전체 저장과 일부 저장 중 무엇을 더 쓰는지, 개념별 링크를 얼마나 깊게 열어보는지는 실제 세션 데이터가 필요합니다.
