## Why This Exists

The external ecosystem analysis room selected `distribution-channel-handoff` as the next analysis axis. The axis already has individual documents for the platform boundary, documentation stop gate, school/dorm share packet preview, observation script, observation log template, evidence board, pilot run pack, preflight checklist, pilot worksheet, session log starter, rollup template, post-rollup decision guide, and content-flows candidate prep.

This hub turns those separate documents into one Korean reading surface so the next session can follow the evidence chain without opening every file first. In the current `0 sessions / no signal` state, start with the current-state handoff, recruiting copy, and scheduling tracker before opening observation-day templates.

## Run Sequence

Use this shorter sequence before opening every document:

| Moment | Open | Output |
|---|---|---|
| Before invitation | current-state handoff, Stage 0 checkpoint, recruiting copy | copy the 15-minute comprehension-check ask only |
| After invitation | scheduling tracker | replace only the matching role-labeled row with an `invited` row snippet; no names, handles, invite links, message threads, or exact replies |
| Before adding another doc | documentation stop gate | confirm a real trigger exists before extending the document chain |
| Before session | scheduling tracker, version lock, response coding guide, preflight checklist | `school-dorm-share-packet-v2-2026-06-11-readable-preview` and all go/no-go gates pass |
| During session | observation-day quick start, pilot worksheet | pass/fail/unclear and non-private evidence notes |
| After session | session log starter, rollup template | role-label notes and one rollup label |
| After rollup | post-rollup decision guide, evidence board update runbook | rerun, revise packet, or candidate prep only |
