B2 반복 실행이 첫 회차만 표시되고 나머지 회차는 어디에도 없다

Persona 3 · Session 1–2 · route: /f/curated-allblanc-morning-workout → /my, /calendar

저장 시점 "회차 그리드" 미리보기는 4주 12회차(월/수/금)를 정확히 보여준다. 저장 후 My Flow는 "반복 항목 0/1"만 표시, Calendar month grid는 td[data-date]별 .fc-event 개수를 직접 세었을 때 첫 회차(7/15)에만 1개, 2·3회차(7/17, 7/20)에는 0개. ICS blob의 BEGIN:VEVENT 개수도 1개.

요일 기반 반복과 개인 항목의 "매일" 콤보박스 반복 두 경로 모두에서 동일하게 재현 — 특정 콘텐츠가 아니라 프로젝션 레이어 구조 문제로 보인다.

영향: Persona 3 Session 2의 "다른 occurrence skip/hold" 자체를 테스트할 화면이 없었다(occurrence가 1개뿐).

B3 메모 분할 개인 초안 중 type:"todo" 항목이 완전히 비가시

Persona 4 · Session 1 · route: /flows 미스 케이스 → /my

메모 하나를 3개 할 일로 분할해 저장했지만 My Flow에는 1개만 보인다. localStorage 원본을 직접 파싱해 3개 항목이 모두 저장돼 있음을 확인했다 — 1번은 type:"calendar", 2·3번은 type:"todo". "메모로 복사" export에도 1번 항목만 포함된다. "이 Flow 가져가기 · 3개" 라벨은 여전히 3개라고 (틀리게) 표시한다.

대조: 사용자가 "+ 할 일 추가"로 직접 만든 항목은 즉시 정상 렌더링됨 — type 처리 분기 문제로 보인다.

B4 개별 항목 날짜 override가 "다음 할 일" 요약 위젯에 반영되지 않는다

Persona 1 & 2 각각 독립 재현 · reload 후에도 지속

항목 날짜를 개별 변경해도 My Flow 홈의 "다음 할 일"/"먼저 할 일" 위젯은 계속 원래 앵커 기준 재계산값(또는 "날짜 없음")을 보여준다. 전체 목록·Calendar·ICS는 모두 정확하다 — 위젯 하나만 부정확하다. 앵커를 다시 바꿔도 위젯은 새 앵커의 재계산값으로만 갱신될 뿐 여전히 override를 무시한다.

B5 "이 Flow 다시 쓰기"의 override 유지 옵션이 동작하지 않는다

Persona 1 · Session 3

완료된 Flow를 "내가 바꾼 날짜 유지"를 선택해 다시 쓰면, UI 문구와 달리 override가 사라지고 새 앵커의 재계산값으로 리셋된다. 과거 실행 기록(히스토리)에는 override가 정확히 스냅샷돼 있는데, 새 실행에는 이관되지 않는다.
