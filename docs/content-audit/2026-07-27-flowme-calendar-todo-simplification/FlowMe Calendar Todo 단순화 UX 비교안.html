Keep / Change / Remove / Defer

P35를 폐기하지 않는다. 결과 우선과 stable projection은 유지하고 실행 composition만 재조립한다.

Keep

  • Flow 찾기와 source provenance
  • public result-first
  • primary 1 + secondary 최대 2
  • contextual personalization 방향
  • stable source/personal/run/occurrence/export 계약

Change

  • `내 Flow` 전역 label을 `할 일`로
  • Flow library를 Todo의 Flow filter/rail로
  • Calendar와 Todo가 shared Item detail 사용
  • receipt primary를 자연스러운 실행 렌즈로
  • shape 고유 의미를 Flow detail에 집중

Remove

  • 고정 `다음 행동 / 전체 계획 / 기록` 탭
  • 행마다 수정·삭제·export 노출
  • Calendar 전용 Item 생성
  • 고정 5 artifact 탭
  • 두 번째 저장 receipt와 4-way hub

Defer

  • 전역 빠른 Todo 추가
  • goal dashboard와 habit score
  • account·DB·cloud sync
  • OAuth 직접 연동
  • 순수 resource library

데이터 계약과 migration 영향

이 제안은 IA와 composition 실험이다. 저장 스키마 변경을 전제로 하지 않는다.

현재 계약으로 가능한 것

  • `/my` route를 유지하고 사용자 label과 projection adapter만 바꾼다.
  • effective Item과 completion state를 Todo list로 묶는다.
  • 날짜가 있는 Item만 기존 Calendar projection에 전달한다.
  • 기존 Item detail overlay, archive/restore, export scope를 재사용한다.
  • 기존 deep link는 `/my?flow=...`로 보존한다.

선행 계약 확인이 필요한 것

  • resource-only row를 Todo에서 제외하는 eligibility 규칙
  • 학습 Flow의 current row와 next row projection
  • routine source Item count와 occurrence count의 분리 표시
  • 완료 후 row가 사라지는 필터에서만 snackbar를 띄우는 presentation 규칙
  • 영구 삭제가 보관 상태에서만 가능한 lifecycle guard

권장 migration: 없음. route alias와 presentation VM을 먼저 만들고 기존 localStorage dual-read/backup/restore는 그대로 둔다.

적용한 reference pattern

외형을 복제하지 않고, 동일 task를 list와 calendar가 함께 읽는 방식과 project/date lens 분리를 참고했다.

Google Calendar Tasks날짜가 있는 task가 Calendar에도 나타나고, 같은 task를 완료·수정하는 pattern을 adapt. Things Today / Upcoming / Anytime / Logbookproject context와 date lens를 분리하고 완료 기록을 별도로 찾는 pattern을 adapt. Apple Reminders Smart ListsToday, Scheduled, All, Completed 같은 predictable filter vocabulary를 adapt. Todoist Today날짜 없는 task는 Today가 아니라 project/filter에서 찾는 명확한 규칙을 참고. FlowMe는 별도 `날짜 없음` filter를 더 직접적으로 노출.
