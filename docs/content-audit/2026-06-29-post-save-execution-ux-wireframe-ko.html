검토 질문

이 화면이 저장할 콘텐츠를 고르는 카탈로그처럼 보이나요?

구현 전 결정할 것

승인하면 바로 구현할 P0/P1

  • `내 Flow`에 `오늘 할 일`과 `다음 할 일`을 분리합니다.
  • Step 기본 카드를 줄이고 detail을 클릭 위치에서 엽니다.
  • 캘린더 선택 날짜 항목을 가까운 패널로 올립니다.
  • 공개 상세의 저장 CTA를 모바일 하단으로 정리합니다.
  • `바로 실행 Flow` 계열 표현을 `하나만 저장`으로 바꿉니다.

이번 범위에서 하지 않을 것

  • 홈 이미지, 리뷰, 사용 통계, 추천 로직 고도화
  • 저장 전 Step/Item 편집
  • 계정 기반 저장, 외부 캘린더 직접 연동
  • Flow Map 전체 제품화나 제작자 publish 완성
