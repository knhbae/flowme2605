# 2026-06-08 Category Representative Promotion Matrix

목적: `/content-flows` 후보가 세탁기, 정수기, 결혼, 이사, 중고차 같은 기존 강한 예시로만 반복되는 문제를 막고, 카테고리별로 어떤 후보를 실제 서비스 화면(`/f/...`)까지 올릴지 판단한다.

이 문서는 source-to-Flow QA 기준표다. 실제 사용자 행동 데이터가 없으므로 어떤 후보도 `검증됨`으로 부르지 않는다.

## 다음 검토 우선순위

사용자 피드백상 "좋지만 매번 동일한 콘텐츠"로 보이는 문제가 남아 있어, 다음 public 승격 전에 먼저 새 사용자 순간 5개를 `/content-flows`와 정적 HTML 리뷰에서 본다.

| 후보 | 새로 확인하려는 축 | Flow 산출물 | 승격 판단 포인트 |
|---|---|---|---|
| `college-dorm-move-in-checklist` | 학생/기숙사 입사 | 입사일 기준 서류/첫날 물품/현지구매/룸메이트 체크 | 결혼/이사와 다른 생활 전환 Flow로 보이는가 |
| `elementary-school-entry-d30` | 학부모/초등 입학 | D-30 학교 안내, 준비물, 이름표, 등교 연습 타임라인 | 구매 리스트가 아니라 입학 준비 실행표로 보이는가 |
| `kids-printable-squishy-craft` | 제작자 도안/아이 놀이 | 도안 링크, 출력, 재료, 놀이 당일 체크 | 도안을 복제하지 않고 원문 활용을 돕는가 |
| `anydesk-remote-setup-check` | 디지털 설치/원격지원 | 설치, 주소 확인, 연결 수락, 세션 종료 체크 | 민감 정보 저장 없이 절차형 체크가 가능한가 |
| `fridge-cleanout-weekly-plan` | 집밥/식재료 소진 | 재고 3개, 7일 메뉴 후보, 장보기 보류 시트 | 절약/영양 보장 없이 가벼운 식재료 실행표로 남는가 |

이 5개는 public route가 아니라 source-to-Flow 판단 후보다. `컴활 3일`, `가전 추가`, `여행 준비물 추가`는 이 검토가 끝날 때까지 뒤로 미룬다.

## 반복 방지 규칙

- 다음 5개 public 승격 안에서 가전 관리 후보는 추가하지 않는다.
- 결혼/이사/중고차는 이미 대표 UX를 충분히 만들었으므로, 새로 올릴 때는 기존 route의 개선일 때만 한다.
- 새 후보는 반드시 다음 중 하나를 새로 보여줘야 한다.
  - 캘린더가 아닌 내부 체크리스트 중심 온라인 절차
  - 공식 행정 마감과 준비물
  - creator interaction이 보이는 PDF/영상/댓글 기반 실행 자료
  - 장기체류, 육아 행정, 독서/놀이, 학습 variant처럼 사용자 순간이 다른 경우
- 입력은 최대 3개다. 방법, 링크, 준비물, 주의는 메모/detail로 내린다.
