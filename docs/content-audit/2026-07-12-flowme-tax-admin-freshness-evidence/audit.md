# 세금·생활행정 출처 최신성 감사

## 문제

오래된 공식 페이지나 원문에 없는 상대 날짜가 `published` 콘텐츠 안에 남으면, UI가 정돈되어 있어도 사용자는 잘못된 일정을 신뢰하게 된다. 이번 감사는 페이지 접속 가능 여부만 보지 않고 다음을 분리했다.

1. 현재 공식 페이지가 실제로 제공하는 절차
2. FlowMe가 편의를 위해 추론한 날짜
3. 새 사용자에게 실행을 열어도 되는지
4. 이미 저장한 사용자의 기록을 어떻게 보존할지

## 우편물 이전

### 공식 원문에서 확인한 내용

- 주민센터 또는 정부24에서 전입신고와 함께 신청한 건은 우체국 시스템에 익일 전송되어 다음날부터 조회·결제할 수 있다.
- 유료 건은 전입신고일 포함 7일 이내에 결제하되 토·공휴일을 제외한다.
- 서비스는 결제일로부터 3일 이후 시작하되 토·공휴일을 제외한다.
- 종료 전 연장은 우체국 창구에서만 가능하며 법원 송달장소는 별도 신고 대상이다.

### 기존 구현의 문제

- D+1 조회는 공식 근거가 있었다.
- D+3 `수수료 결제 필요 여부 확인`은 결제일이 아니라 임의 확인일이었다.
- D+7 `서비스 시작일과 종료일 메모`는 결제일과 휴일을 모르는 상태에서 계산할 수 없었다.

### 결정

- 실행 row를 3개에서 1개로 줄였다.
- D+1에 무료·유료 신청 상태와 결제 필요 여부를 한 번 확인한다.
- 결제 기한, 시작일, 종료일은 공식 화면에 표시된 날짜만 사용자 메모에 남긴다.
- 위험도는 `low`에서 `medium`으로 올리고 `review_before_apply`로 바꿨다.
- 직접 URL 전용 utility로 유지하며 홈 카탈로그에는 올리지 않는다.

## 연말정산 제출

### 공식 원문에서 확인한 내용

- 정확 연결 원문은 등록일이 2025-01-20인 근로자 간편제출 영상이다.
- 영상은 홈택스 로그인, 근무월 선택, 제출할 근무처 선택, 간편제출 순서를 설명한다.
- 현재 국세청의 연말정산 안내는 별도 종합 페이지와 연도별 자료로 갱신된다.
- 회사 제출 마감일은 회사 안내에 따르는 값이며 국세청 원문이 D-3/D-1 일정을 제공하지 않는다.

### 기존 구현의 문제

- 회사 마감일 기준 D-3, D-1, D-Day를 공식 일정처럼 표시했다.
- 연도별 변경 가능성이 큰 세금 콘텐츠인데도 새 저장과 calendar export가 열려 있었다.
- 정확 원문이 오래됐지만 최신 공식 안내로 가는 경로가 분리되어 있지 않았다.

### 결정

- 직접 route는 보존하되 `publicExecutionEnabled: false`로 새 저장·실행·export를 막았다.
- 정확 원문 URL은 추적용으로 유지하고 `reviewUrl`을 현재 국세청 종합 안내로 분리했다.
- 구 영상 URL과 현재 종합 안내 URL은 모두 같은 non-executable `needs_review` 결과로 연결한다.
- 공개 route에서는 예전 D-3/D-1/D-Day row를 렌더링하지 않는다.
- 기존 My Flow 기록은 자동 삭제·교체하지 않고 공식 내용 재확인 경고를 항상 표시한다.

## 사용자 표면 원칙

- 오래된 연도를 사용자-facing source label로 반복하지 않는다.
- review hold에서는 `최신 공식 내용 확인 필요`로 통일한다.
- `Markdown`, `Step`, `Item`, `source-backed` 같은 내부어는 노출하지 않는다.
- review hold에서 save/export/draft 우회 경로를 제공하지 않는다.
- 직접 route와 URL lookup을 막더라도 기존 개인 기록은 보존한다.

## 검증 범위

- 단위: quality gate, source alias, row 수, risk level, lookup 상태
- E2E: 우편 direct route, 연말정산 direct review hold, 구·신 국세청 URL lookup, 기존 저장 기록 경고
- 시각: 390px과 1024px, horizontal overflow 0
- 회귀: normal route guardrail, URL-first 기술어 비노출, public share CTA, workbench source density

## 남은 리스크

- 연말정산 현재 실행 rows는 기존 저장 기록 호환을 위해 내부 bundle에 남아 있다. 새 사용자에게는 노출되지 않지만, 재활성화 전에 현재 연도 자료로 완전히 다시 작성해야 한다.
- 우체국 영업일 계산은 앱에서 하지 않는다. 사용자가 공식 화면에서 확인한 날짜를 메모하는 정책이므로 자동 캘린더화 범위가 작다.
- 공식 사이트는 추후 문구·URL·수수료를 바꿀 수 있어 정기 source freshness 검사가 계속 필요하다.
