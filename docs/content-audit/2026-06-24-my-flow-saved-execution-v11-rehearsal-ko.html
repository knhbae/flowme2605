여러 Flow

오늘/일정/Flow/지도 분리

저장한 Flow가 여러 개일 때 오늘 할 일, 날짜별 보기, Flow별 보기, 지도 보기를 나눴습니다.

이번 추가 수정

정적 카드와 버튼을 분리

좌측 저장 요약과 지도 요약은 설명 카드로 낮추고, 실제 조작되는 Step, Flow, 지도 선택 카드에만 열기, 접기, 보기 라벨을 붙였습니다.

누른 결과를 카드 안에서 예측

Step과 Flow는 열린 상태에서 다시 누르면 접힙니다. 버튼처럼 보이는 요소는 실제로 상태가 바뀌고, 설명처럼 보이는 요소는 클릭 대상이 아니게 정리했습니다.

페르소나 시뮬레이션

상황 경로 결과
이사 준비 중인 사용자 오늘 탭 → D-14 Step의 열기 선택 → Item 체크 → 업체 메모 → 같은 Step을 다시 눌러 접기 처음 화면에서 바로 할 일이 보이고, 열린 Step 아래에 Item이 붙습니다. 접기 라벨이 있어 닫는 동작도 예측됩니다.
날짜별로 확인하는 사용자 일정 탭 → 2026-07-23 선택 → D-7 Step 확인 → Item 체크 캘린더에서 날짜를 누르면 해당 날짜 Step이 바로 아래에 뜹니다. 날짜 버튼과 Step 열기 버튼의 역할이 분리되어 있습니다.
학습 진도를 이어 보는 사용자 Flow 탭 → 중1 수학 필터 → 소인수분해 Flow 열기 → 소수와 합성수 완료 Flow 카드 안에 열기/접기 라벨이 있어 Flow 목록과 내부 Step 목록의 경계가 더 분명해졌습니다.
저장한 묶음을 훑어보는 사용자 지도 탭 → 생활 일정, 아이 건강 일정, 중1 수학 진도 전환 지도 탭의 지도 선택 카드는 보기/선택됨 라벨을 가집니다. 좌측 요약 카드는 더 이상 버튼처럼 보이지 않습니다.

상세 리허설 로그

이사 D-14

오늘 해야 할 일을 바로 처리하는 사용자

  1. 화면에 들어오자마자 상단 탭보다 먼저 오늘 날짜와 D-14 Step을 봅니다.
  2. Step이 이미 열려 있어 입주청소, 대형폐기물, 예약처 메모를 같은 자리에서 확인합니다.
  3. 체크박스 1개를 누르고 업체 비교 메모를 남깁니다.
  4. Step 카드의 접기를 눌러 세부 내용을 닫습니다.

판정: 사용자는 별도 설명 없이 오늘 할 일을 실행할 수 있습니다. 정적 저장 요약은 하단 보조 영역으로 밀려 있어 첫 행동을 방해하지 않습니다.

일정 찾기

다음 날짜를 확인하는 사용자

  1. 일정 탭을 눌러 2026년 7월 캘린더를 봅니다.
  2. 7월 23일의 `1개` 표시를 보고 날짜를 누릅니다.
  3. 해당 날짜 아래 D-7 Step이 열리고, 관리사무소 공유와 주소 변경 Item을 확인합니다.
  4. 필요하면 원문 열기로 세부 자료를 확인합니다.

판정: 날짜 버튼, Step 열기 버튼, 원문 링크의 역할이 서로 다릅니다. 캘린더 앱 수준에서 이해 가능한 흐름입니다.

진도 Flow

중1 수학 진도를 이어 보는 사용자

  1. Flow 탭에서 중1 수학 진도 필터를 고릅니다.
  2. 소인수분해 Flow의 열기를 누릅니다.
  3. 하위 Step 목록에서 소수와 합성수를 열고 완료 여부와 짧은 메모만 남깁니다.
  4. 같은 Flow 카드를 다시 눌러 목록을 접습니다.

판정: 수학처럼 Item이 꼭 필요하지 않은 Progress Flow는 억지 체크리스트를 만들지 않아도 됩니다. Step은 진도표의 최소 행으로 동작합니다.

UX 판정

좋아진 점

  • 모바일 첫 화면이 실제 실행 항목으로 시작함
  • Step 상세가 같은 자리에서 열려 하단으로 긴 이동이 줄어듦
  • 여러 Flow가 있어도 필터와 탭으로 스캔 가능
  • Flow Map은 상위 구조 확인으로 역할이 좁아짐
  • 수학 Step은 원문에 없는 Item을 만들지 않음

남은 리스크

  • Flow가 수십 개일 때 필터/검색이 더 필요할 수 있음
  • 일정 탭은 현재 1개월 고정 샘플이라 월 이동은 아직 단순함
  • 메모와 완료 상태는 화면 내 상태만 있고 실제 저장소는 없음
  • 외부 캘린더/투두/시트 내보내기 데이터 계약은 별도 작업 필요
  • 실제 사용자 관찰 데이터는 아직 없음

검증 기록

  • 모바일 390px, 데스크톱 1280px 브라우저 클릭 확인
  • 오늘 탭 Step 열기/닫기, Item 체크, 메모 입력 확인
  • 일정 탭 날짜 선택과 해당 Step 실행 확인
  • Flow 탭 필터, Flow 열기, 진도 Step 완료 확인
  • 지도 탭 지도 전환 확인
  • 좌측 지도 요약에 button 없음 확인
  • Step/Flow/지도 조작 카드에 열기/접기/보기/선택됨 라벨 확인
  • 사용자용 화면에 리허설/평가/제작자/개발자 문구 없음 확인
  • 가로 overflow 없음
  • JS 오류 없음
