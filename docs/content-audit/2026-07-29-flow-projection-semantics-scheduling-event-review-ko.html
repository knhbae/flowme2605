질문 1

Todo와 Checklist는 무엇이 다른가?

Checklist

한 상황에서 빠뜨리면 안 되는 유한 묶음

groups[] → orderedEntries[]
bounded=true · orderLocked=true

이사 당일 · 여권 서류 · 설치 절차 · 여행 짐

Todo

독립적으로 꺼내고 미루고 재정렬하는 다음 행동·자료 queue

tasks[]
parentTaskId · queuePosition · canDefer · due

볼 영상 · 읽을 자료 · 독립 심부름 · 결과 확인

상하관계가 아닙니다. 같은 Item을 서로 다른 실행 문법으로 보여주는 sibling projection이며, 목적지의 parent/subtask 지원은 adapter 문제입니다.
질문 2

다섯 포맷은 무엇을 보존하고 잃는가?

calendar

실행·참석 시점을 시간축에 놓는 projection

  • 단위: scheduled Item occurrence or eligible session bundle
  • 보존: start/end or all-day date
  • 손실: independent completion when bundled
checklist

한 상황에서 빠짐없이 끝내는 유한 항목 묶음

  • 단위: Step group with ordered Item entries
  • 보존: bounded membership
  • 손실: open-queue semantics
todo

독립적으로 꺼내고 미루고 재정렬하는 다음 행동·자료 queue

  • 단위: Item task, optionally Step parent plus Item subtasks
  • 보존: independent completion
  • 손실: closed-set completeness unless adapter retains it
sheet

항목·회차·상태를 안정적인 행과 열로 관리하는 projection

  • 단위: Item or Occurrence row
  • 보존: stable IDs
  • 손실: native reminders
memo

사람이 읽고 복사하기 쉬운 TXT/Markdown 문서 projection

  • 단위: Flow or Step document section
  • 보존: titles
  • 손실: typed state

JSON/DTO는 canonical raw다. Memo TXT/Markdown은 사람이 읽는 projection이며 같은 것이 아니다.
