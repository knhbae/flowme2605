# P25-00B 화면 구조 결정 기록

**상태:** P25 내부 구현 기준으로 결정 완료

**결정 근거:** 사용자의 P25 전체 진행 지시와 P25-08 현재 명령/브라우저 회귀 결과

**실제 관찰 사용자:** `0`명

이 문서는 더 이상 응답을 기다리는 설문지가 아니다. 사용자는 P25를 단계별로 끝까지 진행하고 필요하면 대폭 수정하라고 지시했고, 그 지시에 따라 Option B를 구현했다. 아래 `유지`는 구현 기준을 뜻하며 화면별 실사용자 승인이나 사용성 검증을 뜻하지 않는다.

프로토타입: [prototype.html](./prototype.html)

## 검토 방법

1. 기본값인 `B 작업공간`과 `390px`을 유지합니다.
2. Flow 유형을 `이사`, `차량 점검`, `반복 청소`, `여행`, `기록`, `개인 초안` 순서로 바꿔 봅니다.
3. 왼쪽의 아홉 화면을 순서대로 엽니다.
4. 필요할 때만 `A 최소 수정`과 비교합니다.
5. 각 화면에서 `유지 / 수정 / 기각` 중 하나를 선택하고, 수정이면 한 줄 메모를 적습니다.
6. 마지막에 `결정 JSON 복사`를 눌러 이 대화에 붙여넣습니다.

| 화면 | 추천 | 결정 | 확인할 한 가지 |
| --- | --- | --- | --- |
| 저장 전 | B | 유지 | 전체 artifact 우선. 설명 밀도는 P26에서 다시 검토 |
| 저장 직후 | B | 유지 | Today 대신 저장한 전체 Flow를 바로 확인 |

| 전체 Flow | B | 유지 | 모바일 drill-in과 wide workspace를 같은 모델로 유지 |
| Calendar | B | 유지 | `언제든 할 일`과 `일정에 놓기` 역할 분리. wide 밀도는 P26 검토 |
| 항목 조정 | B | 유지 | 제목·언제·메모 우선. 고급 경로 길이는 P26 검토 |
