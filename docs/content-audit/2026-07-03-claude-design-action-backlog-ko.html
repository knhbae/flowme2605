기준 판단

문제의 본질

화면이 아직 설명 카드 중심이다. 사용자가 행동하기 전에 이해해야 할 블록이 많다.

해결 방향

설명을 늘리지 않고, 첫 행동을 위로 올리고, source/detail/memo는 접힌 신뢰 구조로 둔다.

유지할 것

홈 / Flow 찾기 / 캘린더 / 내 Flow, 저장-실행 루프, 결과 중심 export, 원문 보존.
