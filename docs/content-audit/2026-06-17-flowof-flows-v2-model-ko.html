Flow of Flow v2 · 모델

큰 지도는 반복 단위를 만들고, 반복 단위는 같은 실행 패턴을 가진다

이 모델은 v1의 “관련 콘텐츠 묶음”을 버리고, 하위 Flow가 같은 구조로 반복되는 경우만 진짜 후보로 본다. 실제 사용자 행동 데이터는 아직 없으므로 구조 PoC 단계로만 기록한다.

메인: 중1 수학 단원별 공부 서브: 정보처리기사 과목별 공부 후보: 월령별 아기 돌보기

사용자 상황
중1 수학을 처음부터 다시 잡거나 학교 진도에 맞춰 단원별로 따라가려는 학생/학부모
상위 지도 이름
중1 수학 전체 진도표
반복 단위
단원
공통 입력
공부 시작일, 공부 요일, 하루 목표 개념 수

하위 Flow 공통 패턴

1개념 링크를 열고 오늘 볼 개념을 체크한다.
2대표 문제 또는 예제를 풀고 완료 표시한다.
3틀린 개념, 헷갈린 식, 다시 볼 링크를 오답표에 남긴다.
4복습일을 다음 공부 요일에 잡는다.
소인수분해거듭제곱, 소수와 합성수, 최대공약수/최소공배수 링크를 한 단원 Flow로 묶는다.
정수와 유리수수직선, 대소관계, 사칙연산 개념을 진도표와 오답표로 관리한다.
문자와 식문자 사용, 식의 값, 일차방정식 풀이를 반복 패턴으로 공부한다.
생성 artifact
캘린더: 공부 요일별 단원 일정 / 시트: 단원 진도표와 오답표 / 체크: 오늘 볼 개념 / 메모: 헷갈린 개념 링크
전체 저장
중1 전체 단원 지도를 만들고 현재 단원 위치를 추적한다.
일부 저장
학교 시험범위나 부족한 단원만 저장한다.
재방문
지금 단원, 다음 개념, 남은 오답 수, 다음 복습일을 먼저 보여준다.
확장 지점
중2, 중3, 심화 문제, 학교 시험범위, 제작자 강의 링크를 같은 단원 패턴에 추가한다.

2. 정보처리기사 과목별 공부 운영판

Source URL
Yes24 목차, 길벗 소개
원문 구조
필기 기본서 → 5개 과목 → 장 → 이론/문제/요약/기출
사용자 상황
시험일 전까지 5과목을 과락 없이 돌리고 싶은 수험생
상위 지도 이름
정보처리기사 필기 과목별 진도판
반복 단위
과목
공통 입력
시험일, 공부 가능 요일, 하루 공부 시간

하위 Flow 공통 패턴

1과목 장 목록을 진도표 행으로 만든다.
2이론 읽기와 바로 아래 문제 풀이를 같은 날에 묶는다.
3틀린 문제를 과목별 오답표에 남긴다.
4기출 회차와 재풀이 날짜를 시험 전 주에 배치한다.
소프트웨어 설계요구사항 확인, 화면 설계, 애플리케이션 설계, 인터페이스 설계.
데이터베이스 구축논리/물리 설계, SQL 응용, SQL 활용, 데이터 전환.
프로그래밍 언어 활용서버 프로그램 구현, 프로그래밍 언어, 응용 SW 기초 기술.
생성 artifact
캘린더: 시험일까지 과목별 공부 블록 / 시트: 과목별 진도표, 기출 회차표, 오답표 / 메모: 우선순위와 QR/강의 링크
전체 저장
5과목 전체 진도판과 시험 전 기출 주간을 만든다.
일부 저장
취약 과목만 별도 진도표와 오답표로 저장한다.
재방문
과목별 진행률, 과락 위험 과목, 다음 기출 회차를 보여준다.
경계
원서접수/시험장 준비는 부속 단일 Flow이지 이 모델의 핵심 하위 Flow가 아니다.

3. 월령별 아기 돌보기 지도

Source URL
마미톡 0~12개월 케어법, 아이사랑 4~6개월 공식 정보, 질병관리청 예방접종 일정표
원문 구조
월령 → 주요 포인트 / 건강 포인트 / 돌보기
사용자 상황
아기 월령이 바뀔 때 준비할 공식 일정과 생활 메모를 놓치고 싶지 않은 보호자
상위 지도 이름
0~12개월 월령별 돌보기 지도
반복 단위
월령 또는 월령대
공통 입력
아기 생년월일, 알림 받을 요일

하위 Flow 공통 패턴

1이번 월령의 공식 검진/접종 일정을 확인한다.
2월령별 생활 체크를 보호자 메모로 남긴다.
3이유식, 수유, 수면, 외출처럼 선택적 항목은 메모로 내린다.
4이상 증상은 판단하지 않고 상담 메모와 병원 확인으로 넘긴다.
0~1개월수유/수면 리듬, B형간염/BCG 확인, 보호자 메모.
4~6개월건강검진, 접종, 이유식 시작 시기, 외출 전 체크.
6개월 이후이유식 단계, 새 식재료 메모, 공식 일정 확인.
생성 artifact
캘린더: 월령 기준 알림 / 체크: 공식 일정 확인 / 메모: 생활 관찰 / 링크: 공식 출처
전체 저장
0~12개월 월령 변화를 큰 지도에서 본다.
일부 저장
현재 월령만 저장하거나 이유식/검진 구간만 저장한다.
재방문
현재 월령, 다음 공식 확인일, 보호자 메모를 보여준다.
경계
의료 판단, 성장 평가, 접종 가능 여부 판단은 하지 않는다. 공식 정보와 보호자 경험 메모를 분리한다.

이사는 이번 대표에서 제외

이사는 D-day timeline 하나로도 충분히 좋다. 견적/전입/청소/인터넷을 각각 하위 Flow로 쪼갤 수는 있지만, 같은 실행 패턴이 반복되는 구조가 아니라서 v2 대표로 쓰면 다시 “그냥 Flow 묶음” 문제가 생긴다.
