## 종합 분석

### 강점
- **검색 기반 수치 교정**: 영유아 구강검진 차수(총 4회), 자동차세 연납 할인율(약 4.6%), 국가장학금 구간별 금액 등 이전 버전의 stale/부정확 수치를 WebSearch로 바로잡음.
- **단정 회피의 정직성**: WebSearch로 확정되지 않은 항목(여권 신규발급 처리기간, 국민취업 재산 상한, 전기차 보조금 금액, 소상공인 금리, 안심상속 조회 소요일, 영사콜센터 언어 수)을 사실처럼 단정하지 않고 "공식 확인" 프롬프트로 전환.
- **구조 적합성**: 타임라인(국가장학금·출생신고), 페이즈/캘린더(영유아검진), 체크리스트(나머지)가 콘텐츠 성격과 대체로 일치.
- **위험 구체화**: 과태료, 가산세 40%, 동시수급 불가, 예산 소진 등 실제 불이익을 수치로 명시.

### 한계
- **개인·지역·연도 가변 항목**: 국민연금 예상액, 소상공인 금리, 전기차 보조금, 지방세 납부시기 등은 본질적으로 가변이라 구체 수치 제공 불가 → "공식 확인" 의존.
- **날짜 고정 위험**: 국가장학금 신청기간 등은 학기별로 바뀌므로 "2026-1학기 기준 예시"로만 제시. 이후 학기에는 갱신 필요.
- **URL 장기 안정성**: 정부24/공단 deep-link는 개편 시 변경 가능(`source_status: needs_review` 유지 이유).
- **WebFetch 차단**: 한국 정부 사이트가 HTTP 403이라 페이지 본문 직접 검증 불가. 모든 수치는 검색엔진 요약 기반이며 audit(정밀 대조)는 미완료.

### WebSearch로 확정하지 못해 단정을 피한 항목 (unverified)
- 여권 **신규(최초) 발급** 처리기간 — 온라인 재발급 4~5영업일은 확인되나 신규는 미확정.
- 국민취업지원제도 Ⅰ유형 **재산 상한액**(이전 4억/청년 5억) — 소득 60%/청년 120%만 확인.
- 전기차 구매보조금 **차종별 정확 금액** — 합산 구조·전환지원금 존재만 확인.
- 소상공인 정책자금 **정확 적용 금리** — 분기 고시·2026 2분기 약 3.44%만 확인(개별 사업·신용도별 상이).
- 안심상속 **조회 결과 소요일수**(이전 7~20일) — 미확정이라 삭제.
