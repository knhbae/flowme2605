System decisions

공통 component와 데이터 계약

Keep

  • Immutable source + personal overlay
  • Post-save whole Flow receipt pattern
  • Scope-first export counts
  • Wide Calendar 3-pane
  • Deterministic memo path without AI

Change

  • Explicit date intent
  • One public save handoff
  • Canonical recurrence projection
  • Phase outline and contained editor
  • One export scope vocabulary

Remove

  • Persisted example anchor
  • Series definitions in undated tray
  • Route-specific duplicate CTA
  • Control을 대신하는 persistent prose

Experiment

  • Phase outline + optional timeline
  • Batch scheduling preview
  • Post-export result receipt

Defer

  • Direct calendar/todo/Notion/Obsidian APIs
  • AI URL/memo generation
  • Accounts, sync, collaboration, versions

Contract order

  • source
  • personal overlay
  • execution run
  • occurrence
  • export
