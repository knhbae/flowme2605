1. 이번 반복의 기준

전세 Flow 기준선

입력은 작고, 첫 action이 분명하며, 날짜/체크/메모/URL의 역할이 눈에 보여야 합니다.

공통 UI 제거

메모 복사, 현재 설명 복사, 상태 버튼, 재방문 보기처럼 결과가 모호한 버튼은 제거했습니다.

destination별 화면

이사/입학/여행/검진은 캘린더, 중고차는 현장 체크, 홈트는 반복 실행 카드로 나눴습니다.

2. 페르소나별 사용자 저니

이사: 첫 포장이사를 준비하는 1인 가구

통과
  1. 이사 체크리스트 원문을 보고 이사일 기준으로 다시 보고 싶어 저장한다.
  2. 이사일과 이사 방식을 입력하고, D-30의 견적 후보 메모를 먼저 작성한다.
  3. 캘린더에서 D-14를 눌러 이전 설치와 주소 변경 항목으로 이동한다.
  4. 다시 들어오면 전체 일정에서 D-1과 D-Day를 이어서 연다.

중고차: 매물을 처음 직접 보러 가는 구매자

통과
  1. 중고차 체크리스트 글을 보고 현장에서 빠뜨릴까 봐 저장한다.
  2. 방문일과 매물 URL만 넣고, 차량번호는 필요할 때 보류 메모에 적는다.
  3. 방문 전 준비, 외관과 타이어, 시동과 주행 순서로 섹션을 눌러본다.
  4. 확신이 안 드는 항목은 상태 버튼 대신 보류 메모에 이유를 남긴다.

초등 입학: 첫 아이 입학을 준비하는 보호자

통과
  1. 입학 준비 글을 보고 입학일과 학교 안내문을 한곳에 두고 싶어 저장한다.
  2. D-30에는 예비소집/안내문을 저장하고, D-21에는 학교 안내문 기준으로 살 것만 표시한다.
  3. D-14에는 생활 연습 3가지만 확인하고, 입학일에는 당일 정보만 본다.
  4. 블로그 추천과 학교 안내가 충돌하면 학교 안내문을 우선한다.

홈트: 유튜브 영상을 주 3회 따라 하려는 사용자

통과
  1. 홈트 영상을 보고 매번 검색하지 않으려고 반복 일정으로 저장한다.
  2. 시작일, 운동 요일, 영상 URL만 넣는다.
  3. 각 회차는 같은 영상 실행 카드로 열리고, 영상 열기와 완료 체크만 남는다.
  4. 상태 기록은 기본 버튼이 아니라 필요한 경우 메모에 짧게 남긴다.

일본/eSIM: 출국 전 디지털 준비가 걱정되는 여행자

통과
  1. 여행 준비 글과 eSIM 설치 가이드를 보고 출국일 기준으로 저장한다.
  2. 출국일, 휴대폰 종류, eSIM 구매 링크만 입력한다.
  3. D-7에는 지원 여부와 여행 준비, D-1에는 설치, 도착일에는 데이터 연결을 확인한다.
  4. 여권번호, 로그인 정보, 통신 설정값은 저장하지 않는다.

영유아 검진: 18~24개월 문진표와 발달선별검사지를 준비하는 보호자

통과
  1. 병원 안내나 부모용 글을 보고, 문진표와 발달선별검사지를 미리 준비하려고 저장한다.
  2. 방문일, 검진 병원/예약 메모, 문진표 작성 경로만 입력한다.
  3. D-14에는 18~24개월 검진과 구강검진 여부를 확인하고, D-7에는 작성 경로와 등록번호를 준비한다.
  4. D-3에는 집에서 아이와 발달선별 항목을 해보고 저장하며, D-1에는 문진표 저장 여부와 질문 메모를 확인한다.
  5. 발달 평가와 검진 결과는 Flow가 해석하지 않고 의료기관에서 확인한다.

3. 반복 시뮬레이션 결과

Loop A는 실제 클릭, Loop B는 문제 분류와 수정, Loop C는 같은 흐름 재클릭입니다. Blocking/High 문제는 수정 후 재검증했습니다.

1차 클릭에서 발견한 문제

  • High: 사용자 PoC 상단에 source fit, 전세 대비 같은 검토 용어가 남아 있었습니다.
  • Medium: 중고차 안내 문구가 “Flow가 판단하지 않습니다”처럼 책임 회피 문장으로 보여 사용자 action이 약했습니다.
  • Medium: 홈트 카드에 “상태 버튼”이라는 UI 내부 표현이 남아 있었습니다.
  • High: 영유아 검진 Flow가 “공식 일정 확인”에 머물러 문진표, 발달선별검사지, 등록번호 같은 실제 준비 action이 부족했습니다.
  • Low: Playwright 첫 스크립트는 한글 정규식 인코딩과 네비게이션 버튼 strict match 때문에 실패했습니다. 제품 HTML 문제는 아니었습니다.

수정한 내용

  • 상단 meta copy를 실제 앱 문구인 “내 Flow”와 “원문 링크 보관”으로 변경.
  • 사용자 화면에서 PoC, source fit, 전세 대비, 리뷰, 개발자용 같은 용어 제거.
  • 중고차 하단 문구를 “확신이 안 드는 항목은 보류 메모에 이유만 남김”으로 변경.
  • 홈트 완료 설명을 “오늘 느낌은 필요할 때만 메모”로 변경.
  • 영유아 Flow를 18~24개월 문진표/발달선별검사지 준비로 좁히고 D-14/D-7/D-3/D-1/D-Day 실행 항목으로 재작성.

4. 전세 수준 이상 판정

통과한 기준

  • 첫 화면에서 저장 대상과 입력값이 보입니다.
  • 입력은 각 Flow에서 1-3개 수준입니다.
  • 날짜형은 캘린더와 전체 일정이 함께 있고, 날짜/항목 클릭이 됩니다.
  • 중고차와 홈트는 불필요한 캘린더를 강제로 붙이지 않았습니다.
  • 공통 상태 버튼과 모호한 복사 버튼을 제거했습니다.
  • 원문에 없는 세부 절차는 링크나 메모로 보냈습니다.

남은 리스크

  • 실제 사용자 검증은 아직 아닙니다. 검증됨이라고 부르면 안 됩니다.
  • 이사, 중고차, 입학은 더 강한 후보이고 홈트는 routine pattern 확인용에 가깝습니다.
  • 영유아 검진은 의료/가족 민감 영역이므로 실제 public route 전 최신 병원/공단 안내를 재확인해야 합니다.
  • 각 원문에서 더 구체적인 action을 추출하려면 source별 detail audit가 추가로 필요합니다.
