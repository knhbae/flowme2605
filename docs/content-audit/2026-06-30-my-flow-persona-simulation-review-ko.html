공개 Flow Map에서 직접 저장했다. 결과는 3개 지도, 4개 하위 Flow, 총 31개 Step이다.

검증 방식

390px 모바일 화면에서 저장 전, 저장 직후, 내 Flow 오늘/Flow, 캘린더, 대량 목록을 클릭했다. 콘솔 오류는 0개였다.

사용한 링크: 원룸 이사 D-30, 중1 수학 목차, 영유아 검진·접종, 대량 저장 데모

페르소나와 시나리오

페르소나 저장한 Flow 사용자가 하려는 일 시뮬레이션 경로
생활 전환 사용자 원룸 이사 D-30 이사일 기준으로 오늘부터 순서대로 실행하고 싶다. Flow Map 열기 → 이사일 입력 → 전체 저장 → 첫 Step 확인 → 캘린더 이동
학습 진도 사용자 중1 수학 목차 진도표 날짜보다 단원별 진도와 하위 개념 체크가 중요하다. 전체 저장 → 내 Flow의 Flow 탭 → 다음 단원 보기 → 하위 개념 체크
육아 일정 사용자 영유아 건강검진, 예방접종 일정 공식 일정 기준으로 지난 일정과 다음 일정을 빠르게 확인하고 싶다. 아이 생년월일 입력 → 전체 저장 → 오늘 탭 → 캘린더에서 날짜 확인
많이 저장한 사용자 30개 Flow 데모 오늘 볼 것만 먼저 보고, 필요하면 전체 목록에서 검색하고 싶다. 내 Flow 오늘 → Flow 탭 → 전체 Flow 목록 열기 → 검색/필터/Flow 열기

스크린샷 근거

Findings

High · 오늘 탭이 실제 오늘보다 “밀린 항목 처리 화면”이 되기 쉽다

영유아 검진·접종처럼 기준일이 과거인 Flow를 저장하면 첫 화면이 밀린 항목으로 채워진다. 사용자는 “오늘 할 일”을 기대하지만, 실제로는 과거 일정 정리와 오늘 실행이 섞여 보인다.

High · Flow 탭은 구조가 보이지만 사용자 언어보다 내부 구조 언어가 많다

저장한 지도, 상위 흐름, 기준일 필요, Flow 반복은 개발/기획 관점에서는 정확하지만, 사용자는 “이사 준비 전체”, “다음 단원”, “검진 일정”처럼 자기 일의 이름을 먼저 봐야 한다.

High · Step detail 기본 화면이 실행보다 편집/내보내기까지 한 번에 보여준다

체크리스트와 메모는 좋지만, 완료/수정/닫기, 출처, 분류, 복사, 캘린더 파일 버튼이 동시에 보여 Step 하나가 캘린더 일정 수준보다 무겁게 느껴진다.

Medium · 하단 탭이 콘텐츠를 가리는 순간이 있다

오늘 탭과 Flow detail 화면에서 하단 내비게이션이 카드 내용을 덮는다. 기능 오류는 아니지만 모바일 실서비스 완성도에는 직접 영향을 준다.

Medium · 캘린더 기본 월 선택이 사용자의 현재 맥락과 다를 수 있다

이번 저장 세트에서는 영유아 생년월일 기준 첫 이벤트인 2026년 1월로 열렸다. “캘린더 탭”은 맞지만 사용자는 오늘 이후 일정, 지난 일정 정리, 전체 일정 중 어디를 보고 있는지 다시 해석해야 한다.

Medium · 대량 저장 목록은 버티지만 아직 서비스형 목록이라기보다 테스트 목록에 가깝다

30개 상태에서 전체 목록을 숨긴 전략은 맞다. 다만 하단 시트 row마다 정보와 버튼이 반복되어, 실제 서비스에서는 신뢰 신호, 최근 실행, 다음 날짜, 즐겨찾기 같은 더 강한 정렬 기준이 필요하다.

항목 점수 판단

Cognitive Load 2.5/5 이전보다 좋아졌지만 실서비스 기준으로는 라벨, 카드, 버튼 반복이 아직 많다.
Copy Specificity 3/5 Step 제목은 구체적이다. 섹션 설명과 내부 구조 문구는 더 줄일 수 있다.
Source/Safety 3.5/5 영유아 일정은 공식 정보 경계를 유지하지만, 사용자 화면에서는 공식 확인 링크/주의가 detail 안에서 더 명확해야 한다.
Accessibility/Operability 3/5 클릭은 가능하고 오류는 없다. 하단 탭 겹침과 버튼 반복은 조작 품질을 낮춘다.

판정

방향은 맞다

4탭 IA, 내 Flow의 오늘/Flow 2표면, 캘린더 전역 탭, Step inline detail은 유지할 만하다. 구조 자체가 완전히 틀린 것은 아니다.

실서비스 기준선은 아직 아니다

현재는 내부 QA 기준 70점대다. 사용자는 실행할 수 있지만, 여러 Flow가 들어오면 오늘/밀림/전체 구조/편집/내보내기가 한 화면에 섞여 서비스 완성도가 떨어진다.

다음 수정 우선순위

  1. 오늘 탭 재정의: `지금 할 일`, `지난 일정 정리`, `다음 7일`을 분리한다. 지난 일정은 여러 장의 카드로 펼치지 말고 요약 + 정리 액션으로 둔다.
  2. Flow 탭 언어 정리: `상위 흐름`, `저장한 지도`, `기준일 필요` 같은 내부 문구를 줄이고, 사용자 일이름과 다음 행동을 먼저 보이게 한다.
  3. Step detail 다이어트: 기본은 제목, 날짜, Item 체크, 메모만 둔다. 출처/내보내기/수정은 접기 또는 보조 액션으로 내린다.
  4. 캘린더 기본 상태 보정: 오늘 이후 일정이 있으면 그 날짜를, 모두 과거면 오늘과 지난 일정 요약을 먼저 보여준다.
  5. 모바일 safe area: 하단 탭이 카드와 체크박스를 가리지 않도록 하단 여백과 sticky 위치를 조정한다.
  6. 대량 목록 row 축소: 하단 시트의 row는 제목, 다음 날짜/행동, 진행률만 남기고 버튼은 1개로 줄인다.
