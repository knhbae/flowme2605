## Official reference patterns

- Google Calendar Tasks: 날짜가 있는 task는 Calendar에서 보고 task detail에서 수정·완료한다. <https://support.google.com/calendar/answer/9901136?hl=en-uk>
- Todoist task view: task row와 detail editing을 분리하고 completion은 task circle로 되돌릴 수 있다. <https://www.todoist.com/help/articles/introduction-to-tasks-080OAXric>
- Todoist sections: 긴 project는 관리 가능한 phase로 나눈다. <https://www.todoist.com/help/articles/introduction-to-sections-rOrK0aEn>
- Notion views: 같은 데이터를 list/calendar/table 등 다른 view로 읽고 side peek를 사용할 수 있다. <https://www.notion.com/help/views-filters-and-sorts>
- Wanderlog: itinerary와 map을 함께 읽되 daily schedule과 checklist는 실행 가능한 row로 유지한다. <https://wanderlog.com/pages/help-center>
