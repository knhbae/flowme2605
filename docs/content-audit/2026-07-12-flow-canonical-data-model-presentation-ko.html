01어느 생활 영역인가?

집·생활, 공부, 돈·행정, 건강, 여행, 일·커리어처럼 찾기 위한 선반입니다.

02어떤 진행 방식인가?

날짜 준비, 순서 절차, 반복 루틴, 표의 행, 비교·결정처럼 구조를 설명합니다.

간단 예시: 에어컨 필터 청소 → 4주 반복
03어디에서 쓰는가?

달력, 체크리스트, 할 일, 표, 메모 중 가장 자연스러운 출력입니다.

간단 예시: 에어컨 필터 청소 → Calendar / ICS
04실제로 무엇을 하는가?

행동, 확인, 결정, 기록, 자료 사용을 Item마다 조합합니다.

간단 예시: 필터 청소하기 → 행동 + 완료 체크
