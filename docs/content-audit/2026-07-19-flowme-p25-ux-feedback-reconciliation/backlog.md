# P25 Execution Backlog

## Blocking

### P25-01A - Canonical effective projection and recurrence parity

**Problem:** The same routine can produce different dates and counts in preview, Calendar, and export.
**Outcome:** One effective item/occurrence projection powers every consumer.
**Gate:** monthly/weekly representative fixtures have identical occurrence identities and eligible counts across destinations; invented fallback schedules are zero.

## High

### P25-00B - Core-screen prototype decision

**Problem:** Implementing more screens before agreeing on the core workspace risks another large but incoherent change.
**Outcome:** Owner-approved mobile/wide frame for save, whole Flow, My Flow, Calendar, adjustment, and export.
**Gate:** keep/change/reject recorded for each screen; no app runtime change.

### P25-01B - Memo draft and count integrity

**Problem:** One memo can become one oversized task plus invented filler.
**Outcome:** Source phrase mapping, reviewable split preview, and no count-filling generic tasks.
**Gate:** saved/exported items reconcile with the accepted preview.

### P25-02 - Whole Flow workspace and post-save handoff

**Problem:** Users cannot confidently inspect the complete saved artifact or understand `전체`.
**Outcome:** Responsive whole-Flow workspace, full first-save confirmation, personal identity hierarchy, and persistent completed view.
**Gate:** all sections/items reachable, no unexplained truncation, mobile/wide hierarchy matches.

### P25-03 - Progressive and batch adjustment

**Problem:** Editing exposes too many fields while common multi-item changes remain hidden.
**Outcome:** compact default drawer, advanced schedule disclosure, and selected-item date/include/export actions.
**Gate:** common edit depth <= 1 drawer; batch preview shows affected counts and preserves overlays.

### P25-04 - Anytime work and Calendar placement

**Problem:** `날짜 없는 할 일` has no clear purpose and is difficult to find or schedule.
**Outcome:** active Anytime state in My Flow and an explicit Calendar placement queue.
**Gate:** find, complete, date, move, clear date, and keep undated paths are all reachable without explanatory prose.

## Medium

### P25-05A - Completion, undo, persistent reopen, and occurrence scope

One item/occurrence, one control. Immediate undo and later reopen must both be visible. Series editing and internal checklist progress remain separate.

### P25-05B - Export scope before format

Choose current/selected/whole Flow with an eligible count before choosing Calendar/checklist/sheet/memo. All outputs consume the canonical projection.

### P25-06 - Public Flow single artifact and copy reduction

Remove duplicate artifact representations and repeated usage/storage bands. Preview inclusion controls must not look like completion.

### P25-07 - Shared responsive visual language

Establish Flow rail, item row, state badges, toolbar, drawer, empty state, and wide/mobile layout rules. Replace route-specific actions and stretched mobile cards.

## Final Gate

### P25-08 - Internal simulated journey review

Run six Flow shapes through save, personalization, scheduling, execution, completion/reopen, export, and reuse. Record screenshot, parity, accessibility, overflow, and console evidence. This does not count as real-user observation.

## Not In P25

- account/database/cloud sync;
- real AI URL generation;
- direct Calendar/Notion/Todo OAuth;
- unrestricted document/block editor;
- drag/drop as required interaction;
- Studio/global IA expansion;
- external participant recruitment.
