# 신차 구매 Flow source-fit 감사

## 문제

`curated-new-car-basic`은 금융 민감 콘텐츠인데 Getcha의 민간 마케팅 글 하나만 전체 7단계의 근거로 사용했습니다. 앱 문구에는 원문의 고정 비율·금액이 직접 들어오지 않았지만, 등록과 보험까지 같은 민간 근거로 표시되어 사용자가 절차 참고와 공식 의무를 구분하기 어려웠습니다.

기존 freshness 검사는 `source_checked_at` 경과일만 확인합니다. 오래된 페이지를 오늘 다시 열면 `current`가 되며, 목적 페이지가 과거 점검 안내로 바뀌었거나 현재 법령과 내용이 어긋나는 경우를 놓칠 수 있습니다.

## 원문 판정

- Getcha 글은 예산, 구매 방식, 견적, 계약, 출고, 등록, 보험으로 이어지는 순서를 참고하는 데는 유용합니다.
- 같은 글의 연봉 비율, 취득·등록 비용 비율, 보험료 범위, 비교 업체 수, 계약금 비율, 기간, 보편 서류 목록은 개인 조건과 시점에 따라 달라질 수 있어 실행 기준으로 옮기지 않습니다.
- 찾기쉬운 생활법령정보는 2026년 시행 법령 상태와 함께 신규등록 의무·신청·구비서류 조건을 설명합니다.
- 같은 서비스의 자동차보험 안내는 자동차 보유자의 의무보험 가입 의무와 현재 법령 근거를 제공합니다.
- 정부24 신규등록 URL은 감사 시점에 2026-06-23~24 점검 안내로 리디렉션됐습니다. URL이 공식 도메인이고 HTTP 응답이 있다는 사실만으로 현재 목적 페이지로 채택하지 않았습니다.

## 적용 정책

1. 구매 여정 7개 행과 저장·완료·export 구조는 유지합니다.
2. `구매 방식 결정`을 `구매 방식 비교 메모`로 바꾸고 사용자가 받은 실제 조건만 기록합니다.
3. `신규등록 확인` 행은 현재 신규등록 법령 안내를 직접 엽니다.
4. `의무보험 확인` 행은 현재 의무보험 법령 안내를 직접 엽니다.
5. 두 공식 행은 `source_type=official`, 나머지 다섯 행은 `reference`로 분리합니다.
6. 고정 가격·비율·기한·보편 서류·상품 추천을 사용자 본문과 export에 넣지 않습니다.
7. 수동 source-fit audit을 추가하고 공개 실행 결정을 명시적으로 `true`로 기록합니다.
8. 출처 UI는 `원문 연결됨`, `원문 확인 기록`, `Flow 정리`로 표시합니다. `출처 확인됨`, `업데이트`처럼 최신성을 보증하는 표현을 쓰지 않습니다.
9. 체크리스트 실행 화면은 반복되는 민간 원문 링크를 숨기되, 행별 공식 링크는 상세에서 보존합니다.

## 확인 결과

- Flow Map route: 200, 저장 가능
- child `/f/curated-new-car-basic`: 200, index/follow, 저장 가능
- 구매 절차 참고 행: 5개
- 공식 신규등록·의무보험 행: 2개
- 실행 화면의 공식 링크: 2개
- fixed financial/admin claim hit: 0
- internal-copy hit: 0
- raw ISO hit: 0
- 390px/1024px horizontal overflow: 0
- 수동 감사 없는 금융 민감 공개 실행 Flow: 0

## 남은 위험과 다음 순서

1. `curated-allblanc-morning-workout`, `curated-allblanc-no-jump-cardio`, `curated-allblanc-lower-body` 3개가 의료 민감으로 분류됐지만 수동 source-fit 없이 공개 실행 중입니다. 영상 게시 시점, 실제 동작, 중단 조건, 반복 주기 근거를 다음으로 검토합니다.
2. 우편 주소 이전, 에어컨 필터, AJD 이사, 웨딩 2개 등 중간 위험 공개 실행 Flow 5개도 수동 source-fit이 없습니다.
3. 저위험 공개 실행 Flow 5개도 향후 수동 감사 큐에 남습니다.
4. 원문 게시일과 의미상 유효기간을 구조화한 필드는 아직 없습니다. 현재 `source_checked_at`은 오래된 원문 자체를 식별하지 못합니다.
5. 실제 구매자 관찰과 등록·보험 실무 검증은 0건입니다.

다음 작업은 의료 민감 운동 영상 3개를 먼저 감사한 뒤 중간 위험 5개를 순차 검토하는 것입니다.
