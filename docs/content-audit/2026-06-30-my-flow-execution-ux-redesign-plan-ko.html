My Flow 실행 UX 재설계 기획안

목표는 저장한 Flow를 사용자가 다시 열었을 때 “오늘 무엇을 하면 되는지”, “날짜별 일정은 어디서 보는지”, “전체 Flow 구조는 어디서 관리하는지”를 캘린더/투두 앱 수준의 복잡도로 이해하게 만드는 것이다.

리서치 기준

Apple Reminders

Today, Scheduled, All 같은 스마트 목록으로 날짜 실행과 전체 목록을 분리한다. 사용자는 내부 데이터 구조를 알 필요가 없다.

Todoist

Today는 오늘 할 일을, Upcoming은 예정 일을, Projects는 전체 구조를 담당한다. 오늘 화면은 모든 프로젝트의 오늘 할 일을 모아준다.

Microsoft To Do

My Day는 하루 실행에 집중하고, Planned/List는 일정과 목록 관리를 담당한다. 실행 표면과 보관 표면을 섞지 않는다.

이번 판단

4탭 IA 유지

홈 / Flow 찾기 / 캘린더 / 내 Flow를 유지한다. 캘린더는 전역 실행 탭이고, 내 Flow 안에 다시 캘린더 탭을 두지 않는다.

내 Flow는 2표면만 둔다

오늘은 지금 실행할 Step, Flow는 저장한 Flow 구조와 다음 Step을 본다. 단일 Flow와 여러 Flow 모두 같은 규칙을 쓴다.

Step은 최소 실행 단위

기본 카드에는 제목, 날짜, 소속 Flow, 진행 정도만 둔다. Item/detail은 Step을 눌렀을 때 같은 자리 아래에 열린다.

저장 직후도 같은 셸 사용

저장 완료 화면을 별도 모드로 만들지 않는다. 얇은 저장 완료 배너 뒤에 동일한 내 Flow 실행 셸을 보여준다.

현재 문제

영역 문제 사용자 영향 수정 방향
저장 직후 저장 완료 패널이 내 Flow와 다른 화면처럼 보임 저장 후 어디서 이어서 쓰는지 헷갈림 저장 완료 배너 + 동일한 오늘/Flow 구조
단일 Flow 모바일에서 로컬 탭을 숨기고 별도 버튼을 씀 Flow가 1개일 때와 여러 개일 때 규칙이 달라짐 항상 오늘/Flow 탭을 유지
Flow 탭 Flow 카드가 정보와 버튼을 많이 노출함 관리 화면처럼 보이고 실행 우선순위가 흐려짐 다음 항목 중심, 부가 정보는 접기
캘린더 저장 후 첫 일정이 아닌 빈 날짜가 선택될 수 있음 저장한 일정이 없는 것처럼 보임 가장 가까운 저장 Step 날짜를 기본 선택

화면 규칙

오늘 탭

지금 이어할 Step 1개를 가장 먼저 보여준다. 오늘 항목이 없으면 “이번 주·다음 할 일”을 바로 이어서 보여준다.

캘린더 탭

날짜가 있는 Step의 전역 실행 탭이다. 날짜를 누르면 그날 항목이 캘린더 바로 아래 가까운 위치에서 열린다.

Flow 탭

저장한 Flow별 진행과 다음 Step만 먼저 보여준다. 전체 Step 목록은 필요할 때 펼친다.

사용자 저니 시뮬레이션

1. 처음 저장한 사용자

  • Flow 찾기에서 이사 D-30을 열고 이사일을 입력한다.
  • 저장 후 내 Flow로 이동한다.
  • 얇은 저장 완료 배너와 “지금 이어하기” 카드가 보인다.
  • 첫 Step을 누르면 같은 자리 아래에 체크/메모/detail이 열린다.
  • 전체 구조가 필요하면 Flow 탭으로 간다.

2. 며칠 뒤 재방문한 사용자

  • 하단 캘린더 탭으로 들어가 날짜별 일정을 확인한다.
  • 내 Flow로 돌아오면 오늘 또는 가까운 다음 Step을 이어서 본다.
  • 전체 체크리스트를 보고 싶을 때만 Flow 탭에서 해당 Flow를 펼친다.
