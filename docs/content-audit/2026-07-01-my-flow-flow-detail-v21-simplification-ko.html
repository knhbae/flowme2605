My Flow v2.1 follow-up

Flow 탭 상세를 실행 중심으로 줄이기

대상은 모바일 /my의 Flow 탭에서 Flow row를 펼친 상태다. Figma v2.1의 요약 → Flow row → 필요한 detail 원칙에 맞춰, 펼친 상세의 주인공을 Step 실행과 Item 체크로 제한했다.

문제 판단

기존 문제

같은 Step이 반복됨

Flow row의 다음 항목 preview와 detail header가 같은 Step 제목을 반복해서, 열린 화면이 길고 중복돼 보였다.

기존 문제

보조 정보가 먼저 보임

일정, 메모, 원문, 내보내기, 수정 액션이 체크리스트와 같은 무게로 보였다.

새 기준

Item 체크 우선

Flow 탭에서는 제목 반복을 줄이고, 체크리스트를 먼저 보이게 하며 메모와 원문은 접힌 보조 정보로 둔다.

반영 전/후

영역 전 후
detail header 확인할 항목과 Step 제목을 다시 보여줌. Flow 탭 모바일에서는 Step 실행 안내만 두고, 제목은 바로 위 Flow row에 맡김.
체크리스트 일정/메모 요약 아래에 위치. detail에서 가장 먼저 실행할 영역으로 이동.
메모/일정 기본으로 크게 펼쳐짐. 메모·일정 보기 접힘 영역으로 낮춤.
원문/내보내기 원문·내보내기로 노출. 원문·내 도구로 옮기기 접힘 영역으로 유지해 목적을 명확히 함.
수정/닫기 완료와 같은 무게의 버튼처럼 보임. Flow 탭 모바일에서는 보조 액션으로 시각적 무게를 낮춤.

시뮬레이션 결과

시나리오 결과
Flow row 열기/닫기 클릭한 row 아래에서 detail이 열리고 다시 같은 row를 누르면 닫힌다.
Item 체크 detail 첫 실행 영역으로 체크리스트가 먼저 보이며, 체크 상태가 유지된다.
메모 확인 기본 화면을 가리지 않고 메모·일정 보기를 열어 확인한다.
원문/내보내기 원문·내 도구로 옮기기 접힘 영역 안에서 원문 링크, 메모앱 복사, 캘린더 파일을 제공한다.
회귀 Today와 Calendar의 모바일 detail은 기존처럼 Step 제목을 유지한다. 제목 반복 제거는 Flow 탭에만 적용했다.
