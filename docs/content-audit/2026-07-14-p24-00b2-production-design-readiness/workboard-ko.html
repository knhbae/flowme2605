Claude Design (8)

A~G fidelity

A

편집 단계 공개

제목·날짜·시간·메모를 먼저, 장소·반복·결정은 세부 설정 뒤에 둔다. 펼친 뒤의 밀도는 실제 사용자에게 확인한다.

B

제자리 완료 취소

한 행의 checkbox, 즉시 실행 취소, 같은 맥락의 완료 목록으로 되돌리기 경로를 닫았다.

C

날짜 없음 tray

Calendar 안에서 날짜 없는 일을 선택해 배치한다. 데이터가 있을 때만 나타나는入口의 발견성은 아직 미검증이다.

D

Flow-level export

범위를 먼저 고르고 destination을 선택하며 개수를 표시한다. public 긴 화면에서 내보내기入口까지 도달하는지는 관찰한다.

E

연동·고정 날짜

기준일 재계산과 개인 고정 날짜를 분리하고 preview·undo·reuse 정책을 같은 계약으로 읽는다.

F

실행 행 하나

현재 할 일만 완료 control을 갖고 다음 예정은 조작 없는 예고로 낮춘다.

G

가벼운 실행 메모

내 메모와 원본 보완을 분리하고 완료 시 자동 수집한다. 두 목적이 설명 없이 구분되는지는 재방문 세션에서 본다.

Pre

정확성 선행

공개 접근, local date, 반복 occurrence, draft item, hydration, dependency high 0을 먼저 닫았다.

  • export 범위전체·선택·현재 결과를 다운로드 전에 정확히 예측하는지 묻는다.
  • 메모 목적내 기록과 원본 보완 요청을 같은 메모로 오해하지 않는지 재방문 세션에서 본다.
