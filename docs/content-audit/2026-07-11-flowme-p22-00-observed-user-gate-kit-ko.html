3회차 과제

한 번 저장하고 끝내지 않는다

1회차 · 찾고 저장하기

홈에서 시작점 설명 없이 실제 URL 또는 메모를 사용한다.

  • URL·메모 진입을 스스로 찾는가
  • hit, miss, 초안 요청 차이를 이해하는가
  • 이사일·학습 시작일 의미를 이해하는가
  • 저장 후 내 Flow 착지를 알아채는가

2회차 · 실행하고 고치기

다음 날 다시 들어왔다고 알리고 오늘 할 일을 처리한다.

  • 오늘 할 일을 도움 없이 찾는가
  • 제목·날짜·메모를 수정하는가
  • Flow 기준일과 개별 날짜를 구분하는가
  • Calendar와 export 결과를 확인하는가

3회차 · 완료하고 다시 쓰기

완료 뒤 회고를 남기고 같은 Flow를 다른 일정에 다시 사용한다.

  • 비공개 회고와 원본 알리기를 구분하는가
  • 지난 실행이 읽기 전용임을 이해하는가
  • 새 기준일과 고정 날짜 정책을 선택하는가
  • 새 원문과 내 수정 충돌을 설명하는가
  • 백업 파일로 빈 브라우저의 기록을 복원하는가

진행자 준비

참가자에게 내부 setup 화면을 보여주지 않는다

  1. P01~P04는 Vercel 홈에서 시작하고 브라우저 저장소를 참가자별로 분리한다.
  2. P05 3회차 전에 내부 관찰 준비 화면에서 반복 사용 상태 준비를 누른다.
  3. /my로 이동된 뒤에만 참가자에게 화면을 넘긴다.
  4. 버튼 의미를 설명하지 않고 첫 클릭, 멈춤, 잘못 읽은 문구를 사실로 기록한다.
  5. 원문이 바뀌었거나 화면·콘텐츠가 오래돼 보이면 제품 사용성 문제와 분리해 URL, 보인 문구, 기대한 최신 상태를 세션 양식에 기록한다.
금지 테스트 통과를 사용자 이해로 기록하지 않는다. 참가자에게 정답 버튼을 알려주지 않는다. 실제 민감정보를 입력하지 않는다. 한 명의 성공을 제품 검증 완료로 승격하지 않는다.

실물 왕복 Gate

파일 생성이 아니라 외부 앱에서 실제로 쓰이는지 본다

Calendar

.ics를 Google, Apple 또는 Outlook Calendar 중 실제 설정된 앱 하나에 import한다. 같은 파일을 두 번 넣어 중복 결과도 기록한다.

Sheet·Memo

다운로드 또는 복사 결과를 참가자가 원래 쓰는 도구에서 열고, Flow 이름·날짜·개인 메모가 맞는지 확인한다.

기기 변경

다른 브라우저나 기기에서 로그인 없이 열어보고, 참가자가 자동 동기화를 기대했는지 기록한다. 이어서 My Flow 백업 파일로 수동 복구가 가능한지 확인한다.

출시 판정

상용 준비로 올리는 조건

  • 15개 세션 기록이 모두 존재한다.
  • 저장 손실·기존 실행 변형 Blocking이 0이다.
  • 핵심 과제를 도움 없이 완료한 참가자가 각 회차 4/5 이상이다.
  • 날짜와 완료 상태 오류가 0이다.
  • 새 버전 선택 결과를 4/5 이상이 정확히 설명한다.
  • Calendar 실 import 1종과 중복 import 결과가 기록된다.
  • 빈 브라우저의 백업 파일 복원 1건과 사용자 이해도가 기록된다.
  • local-only 또는 계정 저장 정책을 참가자가 오해하지 않는다.
  • Blocking/High 수정 뒤 해당 참가자 유형으로 재검증한다.
