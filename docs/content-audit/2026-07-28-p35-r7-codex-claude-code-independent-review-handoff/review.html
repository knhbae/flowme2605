다음 할 일의 단위

날짜형 Flow는 한 항목이 아니라 같은 날짜의 미완료 항목 묶음이 자연스러운가.

F04

저장 전 조정 깊이

제목·상세·날짜의 bounded edit가 충분한가, full editor가 필요한가.

F05

가져가기 위치

public 결과에서 primary artifact와 외부 export를 함께 예측할 수 있는가.

F06

되돌리기 조건

완료 후 행이 사라질 때만 즉시 undo가 필요하고, 남아 있으면 다시 열기로 충분한가.

F07

실행과 기록

shape-aware 실행 단위와 기록 영역이 설명 없이 이해되는가.
