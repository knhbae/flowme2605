한 줄 판단

초기에는 원컨텐츠에 FlowMe 링크가 붙어 있다고 보기 어렵다. 사용자가 URL을 넣어 Flow를 만들고, 같은 URL이면 기존 Flow를 재사용하거나 수정/fork한 뒤, 그 공유 링크가 원컨텐츠 쪽으로 되돌아가는 루프를 먼저 본다.

1. URL 입력

사용자가 블로그/유튜브/사이트 URL을 FlowMe에 붙여넣는다.

2. 기존 Flow 확인

같은 URL로 만든 Flow가 있으면 먼저 보여준다.

3. 옵션/수정

시작일, 반복, Step, Item, 메모를 내 상황에 맞게 고친다.

4. 실행/내보내기

My Flow에서 쓰거나 캘린더, 투두, 시트, Markdown으로 내보낸다.

5. 개인 메모

메모장식 계획도 같은 Flow 초안 모델로 정리한다.

6. 원문으로 회귀

공유/댓글 링크를 통해 원컨텐츠 주인도 Flow를 발견할 수 있다.

지금 볼 우선순위

모든 것을 한 번에 만들지 않는다. URL-first 획득, 중복 URL 재사용, 쉬운 수정 UX, 기존 도구 export, My Flow 기준선부터 본다.

Memo배경, 원문 링크, 옵션, 예외, 개인 기록Notion/Obsidian 본문, 일정 설명, 시트 note

기존 도구 기준선

FLOW의 화면과 출력은 사용자가 이미 쓰는 도구보다 무겁게 느껴지면 안 된다.

Calendar

날짜와 반복

짧은 제목, 날짜, 반복, 설명, 원문 URL이 중요하다.

오늘 할 일

Sheet

행과 상태

행/열, 날짜, 상태, 비교, source row가 중요하다.

Memo

맥락과 수정

원문 링크, 체크리스트, 회고, 자유 메모, Markdown 구조가 중요하다.

지금 만들지 않을 것

아래 항목은 방향성에는 포함되지만, 현재 기준선에서는 과하게 앞당기지 않는다.

  • 완전한 Notion/Obsidian 대체 workspace
  • 자동 공개 발행
  • 원컨텐츠 주인이 처음부터 FlowMe 링크를 붙여줄 것이라는 가정
  • Google Calendar, Todoist, Notion, Sheets 직접 계정 연동
  • fake review, fake active-use count, 검증되지 않은 사용량 신호
  • marketplace, 결제, 토큰, creator monetization
  • 민감 영역에서 FLOW가 의료/법률/재무 판단을 대신하는 기능
주의: 이 문서는 백로그 보드다. 자동 QA, preview, 또는 이 문서 자체를 실제 사용자 검증으로 부르지 않는다.

다음 작업에서는 URL-first 흐름을 기준으로 FUB-03, FUB-06, FUB-11, FUB-02, FUB-08을 먼저 확인한다. 메모/공유 승격은 같은 Flow 모델로 수렴하는지 텍스트 모델부터 만든다.
