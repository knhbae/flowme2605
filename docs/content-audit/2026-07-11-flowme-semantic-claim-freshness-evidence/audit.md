# 고위험 콘텐츠 시점 의존 문구 감사

작성일: 2026-07-11

## 원인

기존 freshness gate는 `source_checked_at`과 URL 생존은 확인했지만, 사용자 본문 안의 `2026학년도 1학기 신청일`, `2026년 기준 보증 한도`, `2026년 연납 공제율` 같은 값까지 자동으로 구분하지 않았다. 그 결과 출처 링크가 살아 있어도 이미 끝난 신청 기간이나 다음 공고에서 달라질 수 있는 수치가 실행 안내처럼 남을 수 있었다.

## 정리 원칙

1. medium/medical/financial route의 사용자 본문에는 연도를 붙인 정책 수치를 두지 않는다.
2. 신청기간·지원금·한도·세율은 현재 공식 화면에서 확인하고 사용자가 자기 메모·캘린더에 옮기게 한다.
3. 계약 신고 30일, 여권 사진 6개월처럼 실행 시점을 결정하는 공식 기한은 자동 삭제하지 않고 수동 검토 목록에 남긴다.
4. 50/30/20과 통장 분배 비율은 법정 기준이 아니라 조정 가능한 예시라는 문맥을 유지한다.
5. source title, source URL, `sourceTrace` 원본 데이터는 삭제하지 않는다. `sourceTrace`와 `원문 근거:` 줄은 사용자 상세에서만 제거한다.

## sourceTrace 경계

curated source-backed 데이터는 운영 검증을 위해 detail 안에 `sourceTrace`를 보존한다. 이전에는 public workbench의 접힌 상세를 열면 이 줄이 보일 가능성이 있었다. 공통 `stripUserFacingInternalLines()`를 My Flow와 Artifact Workbench에 적용해 사용자에게는 실행·완료·이유 문장만 보이고 내부 provenance는 데이터와 운영 테스트에 그대로 남도록 했다.

## 남은 수동 검토

`semantic-claim-audit.json`의 9개 route는 연도 고정 문구가 아니라 공식 기한 또는 명시적인 예시 비율을 가진다. 자동으로 삭제하면 실행성이 떨어질 수 있어 다음 source-fit 회차에서 공식 근거와 사용자 가치로 재판정한다.

- 공식 기한/유효기간: 임대차 신고, 여권 재발급, 실업급여, 여권 신규 발급, 자동차 이전등록, 출생신고, 안심상속
- 예시 비율: 월간 가계부, 월급날 재정 루틴

실제 사용자가 숫자를 신뢰하고 행동하는지는 자동 QA로 증명하지 않는다. P22 관찰 0/15 경계는 유지한다.

이 판정은 현재 저장된 문구와 화면 회귀에 대한 것이다. 공공기관 공고의 다음 변경을 자동으로 동기화하거나, 실제 사용자가 남은 9개 기한·예시 비율을 올바르게 이해했다는 뜻은 아니다.
