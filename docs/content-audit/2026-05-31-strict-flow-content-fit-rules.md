# FlowMe 콘텐츠 엄격 판정 기준

작성일: 2026-05-31

## 목적

200개 온라인 출처 후보를 다시 보면서, `원문이 있음`과 `FlowMe에 맞음`을 분리한다.

FlowMe 콘텐츠는 정보 요약이 아니라 사용자가 실제 생활에서 따라 하고, 일정/체크/루틴/기록/보류 상태로 관리할 수 있어야 한다.

## 판정 단계

### Flow 적합

다음 조건을 대부분 만족해야 한다.

- 시작점이 있다: 이사일, 시험일, 출국일, 갱신일, 신청일, 마지막 관리일.
- 실행 축이 있다: 일정, 반복, 마감, 제출, 예약, 비교, 점검, 기록 중 하나 이상.
- 완료 기준이 있다: 예약함, 제출함, 청소함, 조회함, 기록함, 보류함.
- FlowMe가 원문을 그대로 요약하는 것이 아니라 실행 관리판이 된다.
- 사용자가 나중에 다시 볼 이유가 있다.

예시:

- 에어컨 필터 청소 주기
- 시험 접수/공부 일정
- 해외여행 출국 전 준비
- 여권/전입/복지 신청
- 자동이체/연말정산/세금 납부 확인
- 중고차 구매 점검/비교

### 조건부

Flow 축은 있지만 바로 대표 Flow로 쓰기 어렵다.

- 블로그/영상/후기에서 일부 실행 단서만 건질 수 있음.
- 원문이 넓거나 개인 경험 비중이 높음.
- 입력값과 완료 기준을 더 줄여야 함.
- 공식 정보, 경험담, 위험/주의를 분리해야 함.

### 탈락

다음 중 하나에 해당하면 탈락한다.

- 읽고 이해하면 끝나는 정보.
- 단순 후기, 추천, 꿀팁, 뉴스, 트렌드.
- 상품/서비스 홍보가 중심인 페이지.
- 건강/재무/법률 판단처럼 FlowMe가 조언하는 것처럼 보이는 콘텐츠.
- 캘린더/체크/루틴/기록으로 옮기면 억지인 콘텐츠.
- 원문 제목이나 요약만 보고는 실행 구조가 안 보이는 콘텐츠.

### 원문 재확인

직접 본문 추출이 안 된 경우다. Flow 가능성이 있어도 확정하지 않는다.

## 이번 재분류 결과

- Flow 적합: 35개
- 조건부: 56개
- 탈락: 105개
- 원문 재확인: 4개

## 운영 원칙

Flow 적합은 넓게 잡지 않는다. 상위 20-35개만 실제 MVP 실험 후보로 두고, 나머지는 조건부 또는 탈락으로 내린다.

점수보다 판정이 우선이다. 높은 원문 충실도 점수가 있어도 실행 축이 약하면 탈락할 수 있다.
