# 차량검사·컴활 출처 최신성 검증

2026-07-12 기준으로 `vehicle-inspection-prep`와 `computer-skills-d30-study`의 원문 도달성, 적용 범위, 사용자 문구, 모바일·wide 화면을 다시 확인한 패키지입니다.

## 결론

- 자동차검사는 현재 TS 정기검사 대상·기준·유효기간 페이지를 정본으로 사용합니다.
- 일반 자동차검사 준비에서 일괄적인 `자동차등록증/보험 준비` 문구를 제거하고 실제 예약 내역과 차량번호 확인으로 바꿨습니다.
- 컴활 Flow는 현재 2026 교재를 계속 사용하되 `1급` 범위, 교재 게시일, 2024~2026 시험 기준, 2027년 재확인 경계를 사용자 화면에 명시합니다.
- 오래된 게시일만으로 콘텐츠를 폐기하지 않았고, 현재 원문과 실행 행이 맞는지 별도로 판정했습니다.

- 공식·출판사 원문은 2026-07-12에 다시 열어 현재 본문과 Flow를 대조했습니다.
- 390px과 1024px에서 두 public route의 원문 카드, 적용 범위, overflow를 확인했습니다.
- 실제 차량 소유자나 컴활 수험생 관찰 세션은 진행하지 않았습니다.
