# 차량검사·컴활 출처 최신성 감사

## 판정 원칙

1. URL이 현재 열리는지와 내용이 현재 유효한지는 별도로 본다.
2. 원문 게시일이 오래됐다는 이유만으로 폐기하지 않는다.
3. Flow가 원문보다 넓은 주장을 하면 더 정확한 현재 페이지로 근거를 좁힌다.
4. 연도·급수·프로그램 버전이 있는 학습 콘텐츠는 적용 범위를 사용자 화면에 드러낸다.

## 자동차 정기검사

기존 검사 절차 페이지도 현재 열리지만, public Flow는 검사 가능 기간과 부적합·재검사 기준까지 다룹니다. 따라서 정본을 TS의 `정기검사 대상·기준·유효기간 안내`로 좁혔습니다. 이 페이지는 차종별 유효기간, 부적합 기준, 재검사기간과 사이버검사소 진입을 함께 제공합니다.

TS FAQ의 현재 안내는 정기검사 기간을 유효기간 만료일 전 90일부터 후 31일까지로 설명합니다. 별도 콘텐츠 스튜디오의 예전 `만료 45일 전` 문구를 `만료 90일 전`으로 바꿨습니다. public Flow의 `D-14`는 법정 검사 가능 기간이 아니라 사용자가 확정한 검사일을 기준으로 시작하는 준비 일정입니다.

일반 자동차 정기검사 공식 페이지에는 `자동차등록증과 보험을 일괄 준비`하라는 일반 요건이 확인되지 않았습니다. 그래서 해당 문구를 차량번호, 검사소, 예약 시각, 예약자 연락처를 현재 예약 화면에서 확인하는 행동으로 바꿨습니다.

## 컴퓨터활용능력 1급

길벗의 `2026 한 권으로 끝내는 시나공 컴활 1급 필기+실기` 페이지는 현재 열리며 출간일은 2025-10-15입니다. 필기·실기 범위, 2024~2025 기출, 실습 파일과 온라인 채점 지원을 현재도 설명하므로 2026 학습 Flow의 정확한 교재 근거로 유지했습니다.

다만 기존 제목은 급수와 연도를 숨겼습니다. 사용자 화면 제목을 `컴퓨터활용능력 1급 D-30 학습`으로 좁히고, 2026 교재와 2024~2026 시험 기준용이라는 경고를 추가했습니다. 대한상공회의소 시험안내의 현재 수험용 프로그램인 `MS Office LTSC Professional Plus 2021`을 실기 환경 확인 행에 명시하고 공식 링크를 상세 안에 연결했습니다.

대한상공회의소는 2027~2029 출제기준을 2026-06-29에 이미 게시했으며 적용일은 2027-01-01입니다. 따라서 이 Flow를 2027 시험까지 자동 확장하지 않고 2027년 이후에는 새 기준을 다시 확인하도록 경계를 고정했습니다.

## 화면 관찰

- 모바일에서는 두 route 모두 현재 출처 확인일과 적용 범위가 보이고 horizontal overflow는 없었습니다.
- 1024px 컴활 화면은 기능적으로 맞지만 달력 열의 큰 빈 공간과 좁은 실행 목록 열 때문에 정보 밀도가 불균형합니다.
- 이 패키지는 콘텐츠 최신성 완료 증거이지 공통 public Flow 디자인 개편 완료 증거가 아닙니다.
- 실제 사용자 관찰 세션 수는 0입니다.
