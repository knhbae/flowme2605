P24-00C rules

느낌이 아니라 반복 행동으로 결정

사람 수가 적기 때문에 통계적 일반화가 아니라 동일 실패의 반복과 신뢰 오류를 기준으로 우선순위를 정합니다.

Blocking

데이터 손실, 잘못된 날짜, export 오류, 실행 기록 오염이 한 번이라도 재현.

High

5명 중 2명 이상이 같은 핵심 과업을 힌트 없이 완료하지 못함.

Medium

완료는 했지만 2명 이상이 같은 지점에서 되돌아가거나 잘못된 control을 먼저 선택.

Keep

5명 중 4명 이상이 힌트 없이 완료하고 신뢰 오류가 없음.

Defer

단일 선호, 재현되지 않는 불편, 가치 사슬 밖의 확장 요구.

지금 열지 않음

  • arbitrary URL production fetch와 실제 AI provider
  • source-backed 구조 편집과 source v2 UI
  • 계정, DB, cloud sync, OAuth
  • Studio 5번째 탭 승격
  • drag-and-drop 단독 조작
  • 장식 중심 대규모 visual redesign

반드시 보존

  • URL·메모 입력의 첫 행동 단일성
  • Today 실행 1행과 다음 예고 분리
  • Flow 단위 저장·export 프레이밍
  • My Flow·Calendar·export 동일 개인 상태
  • 제작자·원문·주의·지난 실행 기록
