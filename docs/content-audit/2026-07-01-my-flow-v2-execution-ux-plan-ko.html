내 Flow v2 실행 UX 기획안

목표는 저장한 Flow를 일정/체크리스트 관리 서비스처럼 가볍게 실행하게 만드는 것이다. 저장 완료 안내, 오늘 할 일, 다음 할 일, 전체 구조, Step 상세, export/edit 기능을 한 화면에서 경쟁시키지 않는다.

유지할 IA

홈 / Flow 찾기 / 캘린더 / 내 Flow. 캘린더는 글로벌 실행 탭, 내 Flow는 저장한 Flow의 실행 inbox와 관리 공간이다.

핵심 변경

저장 직후 패널을 짧은 확인/라우팅 영역으로 줄이고, 실제 실행은 일반 내 Flow Today 화면에서 이어간다.

복잡도 기준

첫 화면은 캘린더/투두 앱 수준. Item, edit, export는 Step 상세를 열었을 때만 보이게 한다.

현재 문제

영역 문제 v2 원칙
저장 직후 저장 완료, 미리보기 목록, Step 상세, Today가 동시에 보인다. 저장됨 + 지금 할 일 열기 + 전체 Flow 보기만 둔다.
평소 내 Flow 오늘 할 일, 다음 할 일, 전체 구조의 우선순위가 약하다. 지금 이어하기를 첫 카드로 두고, 다음 할 일은 아래에 둔다.
Step 상세 edit/export가 실행 화면에서 먼저 보이면 관리 도구처럼 느껴진다. 기본은 체크/메모/출처 확인. 수정과 내보내기는 보조 동작이다.
캘린더 내 Flow 안에 다시 캘린더를 만들면 글로벌 탭과 겹친다. 캘린더는 글로벌 탭 하나로 둔다.

v1

  • 저장 패널 안에서 일부 Step을 다시 보여줌
  • Step 상세가 post-save 전용 표면에 열림
  • 사용자는 저장 확인과 실행 화면을 동시에 해석해야 함

v2

  • 저장 패널은 짧은 확인과 다음 행동만 제공
  • Step 상세는 일반 Today/Flow 표면에서 열림
  • 사용자는 저장 후 곧바로 실행할 항목 하나를 봄

개발 반영 범위

P0

post-save 미니 인벤토리 제거, 일반 Today 상세로 연결, 글로벌 캘린더 유지.

P1

문구 정리, Flow 전체 구조는 Flow 탭으로 이동, 테스트 갱신.

보류

리뷰/사용량 신호, bulk edit, 직접 Google Calendar 연동, 계정 기반 저장.
