## What changed

- The live `/flows` catalog, not the sparse v3 fixtures, is the product-quality baseline.
- v3 remains a source-accounting safety layer, but its prior `4.99/5` is not a public-content score.
- Thin inputs now become `reextract_required` or `blocked` rather than generic Flow Items.
- A public candidate must include observable completion, usable projection payloads, source trace, return/export state, and all eight live-baseline capabilities.
- The report now states the actual result up front: one current-source v4 Flow was generated and eleven cases were intentionally not generated.
- The worked case includes a labeled example user date and rendered calendar/ICS, checklist, and memo output instead of projection configuration alone.
