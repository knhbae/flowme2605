My Flow 저장 후 실행 세션 기록지

이 문서는 진행자가 한 세션을 짧게 기록하기 위한 양식이다. 사용자에게 보여주는 화면이 아니며, 제품 설명이나 설득 문구를 적지 않는다. 핵심은 첫 클릭, 막힘, 체크/메모 완료 여부, 다음 수정 등급이다.

v5 기본 화면 v6 조건부 보조 보기 관찰 키트 저장 개수별 UX 판정 관찰 롤업 사용자용 v4 PoC 실제 /my 정렬

진행 원칙

말로 설명하지 말고 행동을 본다

  • 사용자에게 FlowMe의 구조, 탭 의미, Flow Map 용어를 먼저 설명하지 않는다.
  • 개인정보, 실제 계약/건강/금전 값, 연락처, 계정 정보를 기록하지 않는다.
  • 세션 하나는 5~8분 안에 끝낸다. 오래 설명해야 하면 그 자체가 UX 문제다.
  • 한 번의 세션 결과로 검증됐다고 말하지 않는다. Blocking/High가 나오면 UI를 줄이고 다시 본다.

20개 이상“저장한 Flow가 많습니다. 자동차 관련 Flow를 찾아 열어 주세요.”

판정

수정 여부를 결정

등급체크 기준다음 액션
Blocking 오늘 실행 항목을 찾지 못했거나, 버튼 결과를 반대로 이해했다. 같은 날 UI를 수정하고 같은 과제로 재관찰한다.
High 과제는 끝냈지만 탭, 상태, 목록 때문에 경로가 돌아갔다. 첫 화면 노출을 줄이거나 버튼 이름을 바꾼다.
Medium 끝내긴 했지만 카피나 위치가 약하게 헷갈렸다. 다음 polish 묶음으로 보류한다.
Pass 첫 클릭이 예상 경로이고, 체크/메모까지 60초 안에 끝냈다. 현재 구조를 유지하고 다음 저장 개수나 다른 Flow 유형을 본다.
