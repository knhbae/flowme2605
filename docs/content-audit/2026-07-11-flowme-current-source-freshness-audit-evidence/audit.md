# Current source freshness audit

## 판정 정책

1. `최근 확인일`과 `원문이 현재 Flow 행을 지지하는가`를 별도로 본다.
2. 공식 제도·의료·재무·안전 정보는 현재 공식 원문과 범위 경계가 모두 확인되어야 승인한다.
3. 오래된 생활 콘텐츠라도 메뉴·순서처럼 고정된 실행 행을 정확히 옮기고 현재 가격·효능을 보장하지 않으면 유지할 수 있다.
4. 재생목록·상업 블로그·2차 서평처럼 원문 범위가 넓거나 약하면 정확한 일부만 남기고 대표 승격을 막는다.
5. 공개 승인 외 결정은 직접 URL에서도 `noindex`와 읽기 전용 게이트를 적용하며 저장·완료·파일 받기를 열지 않는다.
6. 링크 응답과 semantic freshness는 다른 증거다. `403`, redirect, 네트워크 오류는 수동 확인 대상으로 남긴다.
