# 감사 기록

검사일: 2026-07-12

## 판정 규칙

1. **접속 가능**은 URL이 열리는지만 뜻합니다.
2. **게시일·수정일**은 원문의 나이를 설명하며, 그 자체가 유지 또는 폐기 결론은 아닙니다.
3. **재확인일**은 FlowMe가 링크와 현재 의미 범위를 다시 본 날짜입니다.
4. **현재 실행 적합성**은 원문 행이 지금도 일반 사용자 행동을 직접 뒷받침하는지 별도로 판정합니다.
5. 의료 민감 콘텐츠는 개인 경험, 공식 안내, 사용자 기록을 같은 층으로 섞지 않습니다.

## 제품 판정

Conversion decision:
- User need: 보호자가 확인한 이유식 메뉴와 날짜를 잊지 않고 기록하고 싶다.
- Content shape: 개인 경험 식단표와 레시피.
- Primary destination: 향후 사용자 선택형 calendar + memo.
- Structure: 현재 고정 33일 실행표는 공개 보류.
- Action count: 원문 11개 메뉴·레시피 record는 내부 보존.
- Playbook: 의료 민감 개인 경험 자료의 source-row staging.
- Exceptions: 원문 나이 때문이 아니라 현재 일반 실행 범위를 직접 뒷받침하지 못해 보류.
- Risk/source handling: 공식 안내를 우선하고 개인 경험은 선택 참고로만 분리.

`source-fit` 판정은 `keep_representative`에서 `catalog_preview_only`로 변경했습니다. 공개 `/f/baby-food-menu-recipe`는 신규 저장·export·완료 UI 없이 닫히며, 기존 저장은 My Flow의 `확인 후 실행` 영역에 남습니다.

## 데이터 보존

- source URL, 게시·수정·재확인 날짜를 보존함.
- 11개 meal slot, 11개 recipe, 원문 레시피 detail을 삭제하지 않음.
- 기존 local save가 있으면 My Flow에서 제목과 원문 링크를 확인할 수 있음.
- 보류 상태에서는 완료 체크, 다음 할 일, Calendar projection을 만들지 않음.

## 화면 결과

- 390px 공개 route: `이 Flow는 지금 열 수 없어요`와 다른 Flow 탐색만 제공.
- 390px 기존 저장: `실행 보류`, 공개 실행 제외 안내, `현재 원문 보기`만 제공.
- 1024px 기존 저장: 별도 `확인할 목록` 영역에 분리되고 실행·진행률 행동이 없음.
- Calendar: 보류 콘텐츠가 실행 일정으로 나타나지 않음.

## 남은 위험

- 향후 사용자 선택형 식단 기록 모델을 만들 때도 의료 판단이나 알레르기 재시도 시점을 FlowMe가 결정하면 안 됩니다.
- 질병관리청 페이지도 이후 수정될 수 있으므로 재공개 시점에 다시 확인해야 합니다.
- 실제 보호자·의료 전문가 관찰 세션은 0건입니다.
