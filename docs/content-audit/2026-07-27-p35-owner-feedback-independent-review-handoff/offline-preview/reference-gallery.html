P35-01~P35-08 전체 캡처

이전 P35 slice에서 남긴 37개 화면을 오프라인으로 복사했다. 현재 상태 캡처와 모순이 있으면 현재 로컬 캡처와 current source를 우선한다.

이 갤러리는 상태 범위를 넓게 보는 보조 자료다. 구현 완료나 실제 사용자 이해를 증명하지 않으며, 각 이미지의 원래 package는 reference-manifest.json에서 확인한다.
