FlowMe Creator

제작자가 원컨텐츠를 실행 흐름으로 조립하는 화면

원문 URL을 붙이고, 큰 제목과 섹션을 만든 뒤, 각 실행 항목이 캘린더/표/체크리스트/메모 중 어디로 갈지 지정한다.

원문 구조 우선 공통 입력 연결 출처/주의 분리

조립 순서

1원문 URL 확인
재생목록, 식단표, 강좌 목차처럼 실제 구조가 있는지 본다.
2큰 제목 만들기
사용자가 저장할 자연어 제목을 쓴다.
3섹션 나누기
주차, 단원, 식단 주차처럼 원문에 있는 묶음만 쓴다.
4실행 항목 지정
각 항목의 목적지와 완료 기준을 정한다.
