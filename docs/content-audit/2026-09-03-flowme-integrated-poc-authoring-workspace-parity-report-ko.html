  • 독립 HTML이 작성·구조 확인·저장의 3단계를 강제했습니다.

현재 구현

  • compact 화면은 입력·결과 두 상태, desktop은 두 pane을 씁니다.
  • 구조 검토는 사용자가 요청하거나 문제가 있을 때만 엽니다.
  • 인식 가능한 모든 빈칸에 source 밖 장식 예시를 표시합니다.
  • 편집기가 보일 때 CTA를 고정하지 않아 입력 영역을 가리지 않습니다.
  • source fingerprint와 state+draft transaction으로 중복·실패를 다룹니다.

ghost는 source·clipboard·selection·draft·Undo에 들어가지 않고 포인터와 접근성 트리에서도 빠집니다.

같은 source는 같은 handoff identity를 사용합니다. 늦은 실패는 state와 draft의 이전 bytes를 함께 복원합니다.
