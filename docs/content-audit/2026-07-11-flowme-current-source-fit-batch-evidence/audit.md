# 오래된 공개 콘텐츠 교정 감사

## 판단 원칙

1. URL이 열리는 것과 내용이 최신·정확한 것은 별개로 본다.
2. 원문이 현재여도 반복 실행 가치와 산출물이 약하면 저장·완료·내보내기를 열지 않는다.
3. 원문에 없는 일정, 수치, 행동을 Flow가 만들어내면 공개 승인하지 않는다.
4. 승인된 페이지는 같은 할 일을 실행판과 본문에서 중복 노출하지 않는다.
5. source-backed 원문, 상세, 메모, export 데이터는 보존한다.
