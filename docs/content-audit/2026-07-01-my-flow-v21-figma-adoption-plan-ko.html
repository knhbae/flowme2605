My Flow v2.1 Figma 반영 기획

저장한 Flow 화면을 목록이 아니라 실행 구조로 보이게 줄이기

대상: 모바일 /my의 오늘 탭과 Flow 탭. 기준 Figma: VFEFBJVBcFN4w2PgJ4Xlf3.

문제 정의

기존 모바일 화면은 오늘 실행, 밀린 일정, 완료 항목, 다음 항목이 모두 카드로 쌓여 사용자가 저장한 Flow의 구조보다 단순 Step 목록을 먼저 보게 된다. 기능은 있지만 실행 공간이 아니라 상태 카드 모음처럼 보인다.

Figma에서 차용할 구조

1. 요약 먼저

저장한 Flow 수, 남은 항목, 오늘 항목만 짧게 보여준다.

2. Flow row 중심

Flow 제목, 상위 구조, 진행률, progress bar, 다음 항목을 한 row 안에 묶는다.

3. 상세는 열 때만

Item/checklist/detail은 클릭한 Flow row 바로 아래에서 열린다.

반영 설계

영역 변경 전 변경 후
오늘 탭 Step row가 그대로 나열됨 Flow 맥락 카드 안에 다음 Step을 넣음
Flow 탭 큰 wrapper 카드 안에 설명과 목록이 함께 들어감 요약 카드와 Flow row list를 분리함
상세 Step 목록 하단에 열려 리스트 맥락이 약함 클릭한 row 바로 아래 inline detail로 표시

평가 기준

  • 첫 화면에서 오늘 할 일과 저장 구조가 동시에 경쟁하지 않을 것.
  • Flow context 없이 Step만 나열하지 않을 것.
  • 상세 정보는 클릭한 card 바로 아래에서 열릴 것.
  • 모바일에서 캘린더/투두 앱 수준의 정보량을 넘지 않을 것.
