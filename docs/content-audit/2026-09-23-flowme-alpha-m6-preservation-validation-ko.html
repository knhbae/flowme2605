구현한 기능

기존 자료는 자동 귀속하지 않는다. 사용자가 원본·계정·적용 범위를 보고 명시적으로 선택할 때만 변경한다.

선택 이관

네 saved-plan origin과 Map·QuickItem, native 작업본/저장본/대기·복구 후보를 개인 계정 read model에 투영한다. 다른 actor의 개인 자료는 전송하지 않는다.

미리보기와 중복 방지

충돌·미매핑 공개물·손상 원본은 적용하지 않는다. 같은 원본 재시도와 응답 유실 뒤 재확인은 같은 요청 ID를 쓴다.

계정 백업·복원

원문, identity, 개인 기록·명령 이력, 참조, 연결된 사진 bytes를 서명된 버전 파일로 내보낸다. 복원은 현재 revision에 새 거래로 반영하고 공개 저장소를 되감지 않는다.

사진 소실 대응

원본 Storage 객체가 없을 때 본인 private draft의 보존 bytes를 확인해 복원한다. 복원 사진을 공개 게시하려면 새로 첨부해야 한다.

큰 요청 재확인

PoC 전용 IndexedDB에 계정별 대기 요청을 기록하고 저장 완료 후 서버에 보낸다. 새로고침·응답 유실 뒤에도 같은 ID를 확인한다.

이전 앱 안전 경계

새 계정 계약을 모르는 재빌드 M5 화면은 개인공간을 열지 않고 멈춘다. 현재 M6 화면은 독립 세션에서 최신 자료를 다시 읽는다.
