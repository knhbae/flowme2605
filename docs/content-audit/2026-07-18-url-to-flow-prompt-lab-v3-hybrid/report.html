03
FLOW란 무엇인가
FLOW · URL-to-Content Lab
2026.07.18

FLOW 콘텐츠는 “요약문”이 아니라 실행 가능한 상태 묶음

01

무엇을 담나

확인, 실행, 판단, 기록, 리소스 열기. 각 Item은 완료 방식과 원문 근거를 가진다.

예: 여권 확인하기 · 구매 판단 · 영상 열어보기

02

어떤 형태가 되나

Checklist, Todo, Calendar, Sheet, Memo. 하나의 Item을 필요한 서비스 형태로 투영한다.

같은 핵심을 저장하고 출력만 달리한다.

03

어디까지만 하나

원문에 명시된 사용자 행동과 값만. 보조 출처의 내부 절차, 보이지 않는 영상 내용, 추정 날짜는 만들지 않는다.

포함명시 행동 · 명사형 확인 · 표의 행 · 판단 · 리소스 열기 · 문자 그대로의 날짜/반복
제외/보류출처 자체의 운영 절차 · 콘텐츠에 없는 결과 · 적용 지역 미확인 · SourceRow 없는 입력 · 자동 저장/게시
이번 실험 밖실 URL 렌더링 · 로그인/유료벽 · URL → SourceRow 추출 품질 · 저가/고가 모델 비교 · 실비용

Projection

LLM이 맡을 일

복잡한 페이지에서 실행 후보를 찾고 SourceRow로 정리. 메모·일정 후보도 “문자 그대로” 제안.

프롬프트를 더 길게 쓰는 것으로 해결되지 않은 사례

단계입력결과판정
v2 Round 1예약과 문진표 준비예약과 문진표 준비 확인하기 · inspect11/12 · Fail
v2 허용 수정 1회동일동일한 과변환 반복11/12 · Fail
v3 compiler동일예약과 문진표 준비 · act12/12 · Pass

문제

LLM과 validator가 한국어 표면형의 소유권을 나눠 가진 채 서로 다른 규칙을 적용했다.

수정

“준비”가 이미 행동이면 제목을 그대로 유지하고 act/check를 결정론적으로 부여했다.

의미

LLM은 의미 후보를 찾되, 반복 가능한 구조 필드는 한 버전의 compiler가 소유해야 한다.

v2 두 실행 모두 11/12, v3 두 실행 모두 12/12. v2 Round 3는 gate에 따라 실행하지 않음.

데이터 구조 밖의 서비스 리스크

Source & legal

robots/약관, 저작권, 출처 표시, 삭제 요청, 유료벽·로그인, 스냅샷 보관 기간.

Safety & privacy

PII, 의료·법률·금융 민감도, 지역 적용성, prompt injection, 악성 HTML/다운로드.

Operations

idempotency, 중복 URL, 페이지 변경, timezone, retry, provider 장애, cost limit, 감사 로그.

Quality

SourceRow 추출 누락·과잉, 사람이 수정한 정답셋, 회귀 평가, 콘텐츠 유형별 기준.

UX

원문↔Item 대응 보기, 변경점, uncertainty, 삭제·수정·승인, export 미리보기.

Portability

ICS/todo/sheet/memo round-trip, 외부 ID 매핑, 재내보내기 중복 방지, 취소·갱신.

지금 결정할 것과 아직 결정하지 않을 것

지금 채택

  • SourceRow = 증거 최소 단위
  • Item = 상태를 가진 실행 최소 단위
  • Flow = Item 조합과 관계
  • ICS/Checklist/Todo/Sheet/Memo = projection
  • SourceRow → Item은 versioned deterministic compiler
  • Save/Publish는 human approval 뒤

다음 실험

  1. 기존 10개 양성 URL 실제 fetch/snapshot
  2. URL → SourceRow extractor 2개 tier 비교
  3. 이번 frozen compiler에 연결
  4. 누락·과잉·비용·지연·수정률 측정
  5. 통과 후 DB/API contract 구현
아직 보류특정 LLM 공급자·모델, 실제 단가, vector DB, 자동 게시, production fetch 인프라
백엔드 Go 기준URL → SourceRow까지 포함해 품질·원가·보안 gate가 통과되고, approve/export idempotency 계약이 확정될 것
결론: downstream 구조는 Go. end-to-end URL backend는 다음 extractor/cost lane 결과 전까지 조건부.
