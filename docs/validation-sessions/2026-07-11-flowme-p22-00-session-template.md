## Round Checks

### Round 1: Discover And Save

- [ ] 홈에서 URL 또는 메모 시작점을 스스로 찾았다.
- [ ] hit와 miss의 차이를 설명 없이 이해했다.
- [ ] 기준일 의미를 자기 말로 설명했다.
- [ ] 저장 후 내 Flow로 이동한 사실을 알아챘다.

### Round 2: Execute And Adjust

- [ ] 오늘 할 일을 열고 한 번에 완료 처리했다.
- [ ] 전체 기준일과 개별 할 일 날짜 수정 차이를 이해했다.
- [ ] 제목 또는 메모를 수정했다.
- [ ] Calendar에서 어느 Flow의 할 일인지 식별했다.
- [ ] export가 전체 Flow인지 현재 할 일인지 구분했다.

### Round 3: Return And Reuse

- [ ] 지난 실행과 현재 실행을 구분했다.
- [ ] 비공개 회고와 원본 내용 알리기를 구분했다.
- [ ] 같은 사본 재사용 또는 새 기준일을 선택했다.
- [ ] 새 원문 검토에서 현재 내용, 새 내용, 내 수정 유지 차이를 설명했다.
- [ ] 이전 실행이 바뀌지 않는다고 이해했다.

## Severity

Choose one:

- `Blocking`: 저장 손실, 기존 실행 변형, 잘못된 날짜/완료, live AI 또는 sync 오해

- `Medium`: 완료하지만 반복적인 망설임 또는 우회
- `Low`: 표현 또는 시각 polish
- `Pass`: 도움 없이 과제를 완료하고 결과를 정확히 설명
