## 관찰 체크포인트 (이 순서로 기록)

1. **첫 화면 이해** — "이게 뭐 하는 페이지인지" 5초 안에 말할 수 있는가?
2. **앵커 입력** — 생년월일 입력란을 스스로 찾는가? 입력 형식에서 머뭇거리는가?
3. **일정 확인** — 입력 후 8차 일정이 보일 때 본인 아이 기준으로 "다음 검진"을 짚어내는가?
4. **export 발견** — "내 캘린더에 넣기" 동작을 스스로 찾는가? (핵심 체크포인트)
5. **외부 앱 착지** — ICS 파일이 본인 캘린더 앱에서 열리고, 일정이 실제로 등록되는가?
6. **재방문 의사** — "다음에 또 쓸 것 같은지, 어떤 상황에서?"

## 성공/실패 신호

- PASS: 도움 없이 5분 내 생년월일 입력 → 캘린더 등록까지 완료, 등록된 일정을 본인 캘린더에서 확인함.
- PARTIAL: 일정 확인까지는 되지만 export 단계에서 멈춤(버튼 못 찾음, ICS 열기 실패 등) — 위치/라벨 문제로 기록.
- FAIL: 첫 화면에서 페이지 목적을 오해하거나 생년월일 입력을 못 찾음 — 첫 화면 정보 구조 문제로 기록.
