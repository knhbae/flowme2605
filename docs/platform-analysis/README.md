# FLOW 플랫폼 분석 및 UX/UI 여정 제안서

> **"인간의 모든 경험을 실행 가능한 형태로 기록하고 전송한다."**
> 이 디렉터리는 FLOW 리포지토리의 소스 코드와 제품 설계 가이드를 종합적으로 검토하여 도출한 플랫폼 정체성, 유저 저니별 경험 설계, 그리고 핵심 UX/UI 구현 원칙에 대한 분석 결과를 담고 있습니다.

### [01. 플랫폼 아이덴티티 및 포지셔닝 분석](./01_platform_identity.md)

*   **주요 키워드:** 실행 레이어(Execution Layer), 액션 컴파일러, 실생활 루트 시스템, 실행 발자국(Footprint) 데이터 해자.

### [02. 유저 저니(User Journey)와 경험 설계](./02_user_journey.md)
*   **핵심 요약:** 외부 지식을 습득하고 본인의 도구(캘린더, 시트)로 복사하여 실제 현장에서 행동하고 체크하기까지의 6단계 유저 저니를 설명합니다.

*   **주요 키워드:** 변환 작업대, 아코디언 Progressive Disclosure, 스티키 가져가기 시트, 공식 팩트와 사적 팁의 시각 분리.

*   **주요 키워드:** Polymorphic Rendering, `ArtifactExportButtons` 접근성, 로컬 스토리지 비로그인 동화, 불변 데이터 버저닝.

## 💡 종합 결론 요약

FLOW는 단순한 지식의 창고가 아닌, **정보를 행동으로 즉시 컴파일해주는 변환 작업대(Conversion Workbench)**입니다. 

사용자가 복사하고(.copy), 시트로 내보내고(.xlsx), 캘린더에 담는(.ics) **"Export-First"** 행동에 초점을 맞추어 초기 마찰력을 0으로 낮춤으로써 사용자를 인입시키고, 현장에서 체크할 때 쌓이는 **"실행 발자국(Footprint) 데이터"**를 독점적인 경쟁 우위(Moat)로 확보하는 영리한 서비스 모델을 구축하고 있습니다.
